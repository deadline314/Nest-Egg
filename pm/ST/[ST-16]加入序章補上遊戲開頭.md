# [ST-16] 加入序章補上遊戲開頭

> 狀態：進行中

## 內文

### 需求
按下「開始」後直接進入第一章，整個遊玩流程沒頭沒尾：玩家不知道世界、主角、為什麼要做、操作怎麼玩、死了會怎樣。要增加一個序章（約 3 到 6 分鐘），交代世界、主角與處境，在可玩的短場景裡教基本操作，說明死亡與復原規則，並在結尾把玩家交到第一章的第一個目標。需求與限制見 `design/13-story-v2/PROLOGUE.md`。

### 來源
2026-10-07 使用者回報：「整個遊玩流程有點沒頭沒尾，就直接進入遊戲了，沒關係，這個感覺可以增加一個序章來填補，開票之後處理。」


2026-10-10需求補充：先完成序章至第三章，逐章劇本審查、正式主支線與演出、累積單檔發行；詳見[整體設計](../../design/20-campaign-experience/DESIGN.md)。

### 驗收條件
- [ ] 序章劇本（依 `PROLOGUE.md` 的六項目標）通過 `OUTLINE.md`、`CHARACTERS.md`、`CH01_NARRATIVE_V2.md` 的事實對照與連續性檢查（`ContinuityAudit`），不使用未出現過的設定；內容先寫進 `design/13-story-v2/`
- [ ] 新遊戲從序章開始，結束後無縫接第一章的開場；讀檔、繼續遊戲不重播序章；序章狀態寫入存檔
- [ ] 序章在可玩的短場景裡依序教移動、跳、射擊、近戰、格擋、衝刺：每項操作要玩家做一次才進下一項，提示都是完整的一句話並有按鍵圖示（鍵盤與手把各自顯示）
- [ ] 序章內有一次安全的「倒下與醒來」或等價說明，講清楚復原、記憶磨損與檢查點規則；序章內不會讓玩家永久失敗或卡死
- [ ] 過場佔序章時間不超過一半，其餘是可玩或地圖上的短對話；長度 3 到 6 分鐘（用節奏估計與實測驗證）
- [ ] 可跳過：第一次也可以長按跳過，跳過後仍給第一個目標與基本操作提示；之後可在圖鑑重看
- [ ] 序章結束的那一刻，NE-223 的目標列已有第一個主線目標（NE-223 完成前，以遊戲內提示或氣泡完整說明第一個目標）
- [ ] 序章所有文字符合 ST-15 的可讀性規則（完整句子，StoryLint 0 錯誤 0 警告）
- [ ] 序章的場景與演員姿勢通過場景檢查與姿勢檢查（`scene-staging` skill、NE-222 的姿勢規則），截圖附在票上
- [ ] 自動檢查：旗標模擬從新遊戲走完序章到第一章第一個場景沒有死結；序章資料與 `StoryLint`、`SceneAudit` 通過；受影響範圍測試無新失敗

- [ ] 序章劇本先依最新人物與世界觀審查，練習倒地不提前消耗第一章首次死亡建檔，完整與略過路線皆銜接正式任務。

### 測試流程
1. 開新遊戲，完整玩一遍序章，確認每項操作教學與結尾目標
2. 重新開啟遊戲讀檔，確認不重播序章
3. 另開新遊戲，長按跳過序章，確認進入第一章且仍有第一個目標
4. 執行故事與場景檢查、受影響範圍測試
