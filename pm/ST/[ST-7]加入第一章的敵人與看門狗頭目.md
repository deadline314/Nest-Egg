# [ST-7] 加入第一章的敵人與看門狗頭目

> 狀態：完成

## 內文

### 需求
第一章只出現五種敵人：清掃兵、收帳人槍手、收帳人打手、無人機、看門狗；依難度曲線分佈在街道與倉庫，每個區域最多一種新敵人。看門狗是不鎖場的迷你頭目：血量在玩家死後保留（回復一部分），倒下後打開隔牆。新敵人要有資料、音效與圖鑑，並讓第一章的名單與其他章不重複。

### 來源
2026-10-05，使用者要求敵人合理分佈、不要第一章就放出所有種類。設計見 `design/13-story-v2/CH01_LEVEL.md` 第 4 節、`BOSSES.md`。

### 驗收條件
- [x] 清掃兵、收帳人槍手、收帳人打手有各自的資料、行為與音效登記
- [x] 看門狗有資料與行為：沿用看守長的招式、血量死後保留、倒下時打開隔牆；頭目條與圖鑑提示正常（兩個部位的機制待頭目共用元件）
- [x] 敵人數量與位置符合設計（街道 7、倉庫 6＋看門狗），每區第一個敵人離入口至少 18 格，教學段之前沒有敵人
- [x] 第一章敵人名單恰為五種（有測試鎖住；無人機是舊章節也用的既有敵人，其餘四種是新的 id）
- [x] 輔助、標準、硬核三種難度都能擊敗這四種敵人
- [x] 既有敵人的行為與測試不變

### 測試流程
1. 從街道走到倉庫，確認敵人依序出現，每次只遇到一種新的
2. 在看門狗戰死亡，確認回來時它仍帶傷，且殺掉的敵人不重生
3. 打倒看門狗，確認隔牆打開
4. 執行完整測試套件
