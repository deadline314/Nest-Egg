# [ST-18] 撰寫第二章完整劇本

> 狀態：待辦

## 內文

### 需求
為新版第二章「鷺」撰寫完整可落地劇本，包含主線、可選支線、人物對話、動作與章末銜接；舊第二關不算新版第二章交付。

### 來源
2026-10-10，使用者要求逐章完成與累積發行、高清像素UI、全流程手把、豐富合理敘事與動畫、場景減雜，並追加武器差異、子彈、方向護盾、可選連段升級與打擊感總驗收；一般設計選擇由實作者決定，持續推進。

詳見[整體設計](../../design/20-campaign-experience/DESIGN.md)與[研究依據](../../design/20-campaign-experience/RESEARCH.md)。

### 驗收條件
- [ ] 從第一章結尾到第二章收尾有逐場原創對白、角色動作、玩家行動及前後因果。
- [ ] 市場帳務、阿勇與小薇、鷺的復原、留言簿與屋頂段落合理串接，與世界觀及已有事實一致。
- [ ] 主線與適用的 SQ1／SQ2／SQ4 支線有目標、前置、選擇後果、完成條件及獎勵；不做支線仍能推進。
- [ ] 每段電影、交談、通訊與情境動作有用途、可跳過／重播規則、舞台、素材和音效需求。
- [ ] 通读检查角色动机、完整句子、內容充足性、首次名詞解釋與伏筆；已修正發現的矛盾。
- [ ] 有一頁區域連線與逐區功能／節奏表，说明舊第二關的保留、改寫與移除範圍。

### 測試流程
1. 從第一章結尾通讀全部第二章與各支線分支。
2. 按不同選擇、死亡與回訪情境檢查對白與後果，留下審查結果。
