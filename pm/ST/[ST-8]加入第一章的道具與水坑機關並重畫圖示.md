# [ST-8] 加入第一章的道具與水坑機關並重畫圖示

> 狀態：待辦

## 內文

### 需求
第一章只放該放的道具：醫療針、護盾電池、信用點、單分子匕首、新故事的短文件、資料盤與灰布角。水位謎需要新的機關：水坑會因開關漲水，坑底的踏板踩下去會漲滿讓玩家溺斃，閘門與水位在死後保留。現有的道具圖示太簡陋（背包圖示 32×32 偏小、場景裡的拾取物只是幾個像素的小方塊、文件全都長一樣），要依專案畫風重新繪製。

### 來源
2026-10-05，使用者要求道具只放該放的，並重畫圖示。設計見 `design/13-story-v2/CH01_LEVEL.md` 第 5、7 節。

### 驗收條件
- [ ] 第一章用到的每個道具有資料；新故事的短文件（每種各自的內容）與關鍵道具（資料盤、灰布角）可以取得並出現在背包
- [ ] 水坑與踏板機關：開關改變水位、踏板踩下去漲水溺斃、死後水位與閘門保持，從電話亭回來後房間已經漲滿
- [ ] 背包圖示重畫（解析度提高、細節與配色更豐富、風格統一），包含信用點、醫療針、護盾電池、各種文件、資料盤、灰布角、船錢硬幣、單分子匕首、手槍
- [ ] 場景裡的拾取物換成各自的圖（帶發光與漂浮），不再是程式畫的小方塊
- [ ] 圖示由可重複執行的腳本產生；介面在新尺寸下沒有破版
- [ ] 既有道具的行為與測試不變

### 測試流程
1. 逐一拾取第一章的道具，確認背包卡片與說明
2. 解水位謎，確認機關與狀態保留
3. 檢視所有重畫的圖示與場景拾取物
4. 執行完整測試套件
