# 序章訓練：真動作結果先保存

原 Main 新遊戲走到工作桌後，真實磁碟拒寫仍會先成立練習完成、切換器材並開始解說。原同探針確認實際角色已到達原站位，9項中3項失敗；修後同探針可到達重試分支，13項全過。最早兩個未正確觸發來源的探針版本（方向／開場時序）保留為退件，不作缺陷或修正證據。

真 Main 現在擁有訓練結果的保存邊界。來源必須是原地圖建立的訓練站、原資料、已成立的前置及仍存活的玩家；後加的同位置副本不能授予正式結果。準備完整快照、寫入成功後才更新旗標與器材，再通知觀察者及原解說。拒寫保留世界、同一結果及重試；連續重試不重播或重做玩家動作。重新載入的未讀解說隨原結果保存，不增加假死亡或首次建檔。預覽模式保留本來的通知順序；發布期間的路由與關閉由同一保護管理。

## 重跑

```bash
source /workspace/.nest-egg-env/activate.sh
python3 tools/run_training_completion.py --godot "$GODOT" --output /absolute/new/output
python3 tools/run_prologue_completion.py --godot "$GODOT" --output /absolute/another/new/output
```

每案各自擁有 Main、使用者設定與存檔槽，冷讀從前一程序真正產生的主檔逐 bytes 複製，不改寫旗標或編碼。格擋／失誤／衝刺案例沿用原序章的移動、跳躍、射擊及近戰路線到達原訓練器；沒有直接補前置。取消另驗正常淡出轉場，沒有發現重複發布，不為這項猜測新增產品修補。

正式結果包括走到工作桌、訓練器第一次打停、第一次實際擋下與衝刺穿線。重試時觀察者同時核對真正的存檔及器材完成狀態；取消及成功兩份原主檔在新程序繼續。一般地圖預覽與獨立 Level 測試保留原路徑。
