## 可攜重讀

執行 `python original/verify_delivery.py`。讀者只核對封包、逐 member SHA／CRC 與原始結果，不啟動引擎、不依賴已移除的工作樹。`original/packet-manifest.json` 保留原件清單；`source-adoption.json` 記錄正式來源與保留的本機測試 WIP。Root 的發布位置獨立重讀紀錄另列於 `root-verification.json`。
