## Primary API sources

[Godot 4.7 DirAccess documentation](https://docs.godotengine.org/en/4.7/classes/class_diraccess.html) documents link/reparse detection and filesystem equivalence. [Official Windows implementation](https://github.com/godotengine/godot/blob/master/drivers/windows/dir_access_windows.cpp) implements remove using DeleteFileW/RemoveDirectoryW and is_link using GetFileAttributesW's reparse bit. [Official Unix implementation](https://github.com/godotengine/godot/blob/master/drivers/unix/dir_access_unix.cpp) uses lstat and unlink for file entries. These inspected source URLs are master, not proof of the installed 4.7.2 binary. [Microsoft symbolic-link API behavior](https://learn.microsoft.com/en-us/windows/win32/fileio/symbolic-link-effects-on-file-systems-functions) states that GetFileAttributes reports the link's attributes. Actual installed-binary dangling-link handling remains a native check.
