# 晴岸樣品房的靜窗

走進 B 靜窗展示區，反射光偏冷，風聲平滑淡成較低的通風底噪。走回晨窗或晚窗時恢復原本的採光與環境音。沿用既有 CC0 的通風素材與「環境音」音量設定。聲音實驗室的「晴岸靜窗」也可聽到同一區段。

在正式關卡用原生鍵盤輸入來回走過 A→B→C→B→A。RX 9070 XT／Forward+ 拍攝，WASAPI 從 Ambience 匯流排實際擷取 48 kHz 的 PCM。修後靜窗兩次的 RMS 為 -42.18／-42.22 dBFS，同一輪兩側房間為 -38.76／-39.37 dBFS。五次轉場各啟動一段，淡接後只留當區的一層。靜窗原互動可完成，信用點及提案和環境音獨立。
