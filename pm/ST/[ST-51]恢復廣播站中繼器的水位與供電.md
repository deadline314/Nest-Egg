# [ST-51] 恢復廣播站中繼器的水位與供電

> 狀態：完成

## 內文

### 需求

實作第六章第 6.02 場。玩家從水位尺沿維修踏台操作分流手輪、退水盒與上層的備援電源。燈亮起後可往返錄音室。

### 來源

第六章劇本 6.02 與港區前庭的水位尺路線。

### 驗收條件

- [x] 有順序的三個操作各自提示當下應做什麼，完成的刻度和燈號會保存。
- [x] 站到各自的踏台並完成手輪或按鈕接觸才推進。取消與站錯能直接重試。
- [x] 錄音室入口只在供電完成後開放，回程保留高架路。玩家可在重開後繼續。
- [x] 跨區和重開保留既有物件、裝備與灰道工錢收據，公開播出仍待後續決定。

### 測試流程

1. 從已讀水位尺的存檔走到前庭，逆序試用退水盒和備援電源。
2. 轉分流手輪，站錯一次後走上正確踏台，再開備援電源。
3. 分別用取消後和成功後留下的原始檔案重開，確認上一次進度、回程和重試。
