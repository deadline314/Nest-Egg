# [ST-48] 在電話亭交代公開帳本

> 狀態：完成

## 內文

### 需求

玩家在電話亭巷聯絡燈，交代準備公開帳本。可離開或掛掉，通話完成後才保存請託，日後可在同一座電話亭確認。

### 來源

第五章劇本 5.11。

### 驗收條件

- [x] 地面和付費路線都抵達同一座電話亭。開放條件承接葉的要約。
- [x] 凜碰到話筒扣再接通。可取消、掛掉和重試保存。
- [x] 冷讀檔保留通話請託、原有文件與工錢收據，主線地圖同步更新。

### 測試流程

1. 分別從街道和灰道抵達電話亭，先離開，再中途掛掉。
2. 模擬保存拒絕並重試。成功後開啟另一程序，再調查電話亭。
