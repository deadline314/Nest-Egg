# [ST-9] 把第一章劇本接進遊戲

> 狀態：待辦

## 內文

### 需求
把第一章劇本（ST-1）接進新的區域：每個區域的進場過場、場景舞台（用場景立繪）、通訊、可互動物件的短台詞、選項與旗標、死亡畫面序列、章節卡與章末卡。台詞資料要有中日英三欄與雙關標記；缺語言時安全退回。

### 來源
2026-10-05，使用者要求把第一章的遊戲做出來。劇本見 `design/13-story-v2/SCRIPT_CH01.md`，地圖見 `CH01_LEVEL.md`。

### 驗收條件
- [ ] 序幕到章末的過場、通訊與玩法段台詞都以資料播出，順序與劇本一致
- [ ] 過場的舞台使用對應場景的立繪；過場符合現有的長度與連續句數限制
- [ ] 過場中的選項（問鷺、追問燈、宵夜的選擇）可用，旗標會保存並影響後續
- [ ] 站在可互動物件前按鍵會說出短台詞，已聽過的有記錄
- [ ] 死亡畫面依序播出，第一次完整、之後簡化、更後面可略過
- [ ] 舊的第一章腳本不再被使用，既有功能與測試不變，完整測試套件全數通過

### 測試流程
1. 從新遊戲跑完整個第一章，確認每個事件的過場與台詞
2. 在過場中分別選擇不同選項，確認旗標與後續
3. 連續死亡三次，確認死亡畫面變化
4. 執行完整測試套件
