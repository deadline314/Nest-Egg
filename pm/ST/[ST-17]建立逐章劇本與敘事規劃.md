# [ST-17] 建立逐章劇本與敘事規劃

> 狀態：待辦

## 內文

### 需求
建立序章至終章的逐章內容與審查規劃，先確認序章與第一章的可交付版本，再指導第二、三章完整劇本；每章都先寫劇本、審查合理性與內容充足性，再建關卡。

### 來源
2026-10-10，使用者要求逐章完成與累積發行、高清像素UI、全流程手把、豐富合理敘事與動畫、場景減雜，並追加武器差異、子彈、方向護盾、可選連段升級與打擊感總驗收；一般設計選擇由實作者決定，持續推進。

詳見[整體設計](../../design/20-campaign-experience/DESIGN.md)與[研究依據](../../design/20-campaign-experience/RESEARCH.md)。

### 驗收條件
- [ ] 整理既有各章事件、人物弧線、伏筆、資訊揭露與玩法成長，標出各章開始及收尾的因果。
- [ ] 逐場複核序章與第一章的角色動機、物品、死亡規則、選擇後果與新版主支線缺口，提供可執行的修訂清單。
- [ ] 第二、三章各有明確故事目標、必要與可選內容、演出種類、素材需求與劇本審查項目。
- [ ] 第四章至終章有逐章續作路線，下一章在前一章狀態與劇本審查確定後開始關卡製作。
- [ ] 敘事增加電影演出、主動交談、環境動作與回訪反應；逐段列出目的與玩家參與，記錄強制中斷和重試成本。
- [ ] 原創對白參考指定字幕的口語語法，維持完整易懂句子與角色差異，未抄錄字幕或提前透露後章真相。

### 測試流程
1. 對照全章大綱與第一章實際內容，逐場完成因果與連續性通讀。
2. 抽查各章主支線、伏筆及演出表，確認每項新內容有目的與落地順序。
