# [ST-6] 建立第一章「傘」的地圖資料

> 狀態：待辦

## 內文

### 需求
依 ST-4 的設計建立第一章的所有區域：當舖、屋頂、港區街道、電話亭巷、碼頭倉庫、復原館、宵夜麵攤、天亮的當舖，每個區域有地圖、地形材質、環境主題與場景專屬物件、光影、音樂與環境音、提示牌、出入口；新遊戲從這一章開始。

### 來源
2026-10-05，使用者要求把第一章的遊戲做出來。設計見 `design/13-story-v2/CH01_LEVEL.md`。

### 驗收條件
- [ ] 8 個區域的地圖符合設計的尺寸與版面，可解析、無警告
- [ ] 每個區域的主路徑可通行：跳躍高度與坑寬在玩家能力內，起點、出入口、電話亭站得穩
- [ ] 區域之間的連接與玩家走的順序與設計一致
- [ ] 每個區域使用對應場景的專屬物件與適合的地形材質；暗場可讀
- [ ] 光影、音樂與環境音依區域切換；沒有對應曲目時有合理的退回
- [ ] 提示牌與教學順序符合設計
- [ ] 新遊戲從第一章的當舖開始；舊關卡不受影響
- [ ] 每個區域的檢查（可通行、可讀、出入口對應）有測試

### 測試流程
1. 逐區載入，確認地圖與物件
2. 依主線順序走完全程
3. 執行可通行與暗場可讀性檢查
4. 執行完整測試套件
