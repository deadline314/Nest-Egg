# [ST-22] 加入接近預告與寬銀幕轉場

> 狀態：待辦

## 內文

### 需求
接近可聊天人物或電影演出入口時，畫面平滑預告21:9構圖，讓玩家理解前方有演出並可決定繼續；正式人物對話及電影使用一致遮幅。

### 來源
2026-10-10，使用者要求逐章完成與累積發行、高清像素UI、全流程手把、豐富合理敘事與動畫、場景減雜，並追加武器差異、子彈、方向護盾、可選連段升級與打擊感總驗收；一般設計選擇由實作者決定，持續推進。

詳見[整體設計](../../design/20-campaign-experience/DESIGN.md)與[研究依據](../../design/20-campaign-experience/RESEARCH.md)。

### 驗收條件
- [ ] 16:9到21:9及返回有連續過渡，比例按實際視口正確，未拉伸世界或改变物理。
- [ ] 只為可交談人物與指定電影入口預告；告示牌、閱讀物件、廣播與普通氣泡不觸發。
- [ ] 靠近階段仍可移動與退回，不改故事或獎勵；正式開始有明確交互或已提示入口，必然事件另行標示。
- [ ] 離開恢復構圖；相鄰入口和反覆進出邊界不抖動、不錯切人物。
- [ ] 正式對話／電影維持21:9，字幕、關鍵動作與必要提示在安全區，預告不遮住戰鬥危險。
- [ ] 結束、跳過、死亡、换區、读檔及減少動態設定均恢復正確構圖與操作。

### 測試流程
1. 以鍵鼠及手把靠近、停留、退回、確認人物與電影入口，對照告示牌排除。
2. 在不同視口、邊界、相鄰入口、跳過與死亡等情境檢查過渡和安全區。
