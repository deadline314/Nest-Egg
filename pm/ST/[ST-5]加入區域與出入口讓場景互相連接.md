# [ST-5] 加入區域與出入口讓場景互相連接

> 狀態：待辦

## 內文

### 需求
目前一個關卡就是一條由左到右的長地圖，沒有門、沒有分區。新的故事要像《惡靈古堡》一樣，由許多小場景用門相連、可以反覆路過。需要「區域」：每個區域是一張獨立的小地圖，用出入口連到其他區域；玩家從出入口進出，世界狀態在本輪保留（殺掉的敵人、撿過的東西、開過的閘門、頭目的傷），死亡後回到最近的電話亭所在的區域。

### 來源
2026-10-05，使用者要求第一章依新的地圖設計重新做；設計見 `design/13-story-v2/CH01_LEVEL.md` 第 8、9 節。

### 驗收條件
- [ ] 地圖資料可以放出入口：互動才進入的門，或走進就切換的出口；每個出入口指定目標區域與目標出入口，並可指定需要的旗標與鎖住時的提示
- [ ] 進入新區域時玩家出現在目標出入口，有轉場，不閃黑畫面；鏡頭直接就位
- [ ] 本輪的世界狀態在區域之間保留：殺掉的敵人不重生、撿過的信用點與道具不重生、開過的閘門與機關保持、頭目的傷保留（死後回復一部分，比例是資料）
- [ ] 電話亭記錄所在的區域；死亡後回到該區域的電話亭；沒有電話亭時回到本區域起點
- [ ] 區域進場時可以自動播出過場，過場結束後可自動走出指定出入口，或讓本章結束
- [ ] 同一張地圖可以用不同的光影與進場過場當成另一個區域（天亮版的當舖）
- [ ] 只放資料就能新增區域，不需要改程式；缺少目標區域或出入口時記錄具體位置並安全退回，不崩潰
- [ ] 舊關卡的行為不變（死後敵人重生、世界還原到存檔），完整測試套件全數通過

### 測試流程
1. 從區域 A 的門進入區域 B，確認玩家出現在對應的出入口
2. 在區域 B 殺掉敵人、撿起道具、開啟閘門，回到區域 A 再回來，確認狀態保留
3. 死亡，確認從最近的電話亭所在的區域重生，敵人與閘門狀態保留
4. 故意讓一個出入口的目標不存在，確認記錄錯誤且遊戲不崩潰
5. 執行完整測試套件
