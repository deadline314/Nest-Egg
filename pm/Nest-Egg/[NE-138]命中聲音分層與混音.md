# [NE-138] 命中聲音分層與混音

> 狀態：完成

## 內文

### 需求
命中聲音單一、重複時很單調，也沒有層次與優先級。要做多層事件（衝擊、材質、尾音）、三個變體輪播、音高隨機範圍、連鎖升音、事件式壓低其他聲音，以及同時發聲的優先級與數量上限。

### 來源
2026-10-04，使用者要求處理打擊感；研究與設計見 `design/15-game-feel/RESEARCH.md`（第 4 節），母票 NE-130。

### 驗收條件
- [x] 聲音事件由多層組成，每層可有變體輪播與音高範圍
- [x] 同一音效連續播放不會連續重複同一個變體（測試）
- [x] 壓低其他聲音的深度與時間可調
- [x] 同時發聲超過上限時丟棄低優先級
- [x] 事件或音效缺漏時記錄位置並退回預設
- [x] 既有的覆蓋機制仍可使用

### 測試流程
1. 在實驗室連續播放命中聲，確認變化與層次
2. 大量爆炸時確認優先級與上限
3. 執行聲音測試

# Commit-1

## 內文

命中聲音只有單一一個音效，連續打中會很單調，同時發聲太多時也沒有取捨。
現在聲音可以定義成「事件」：由多層組成（衝擊、尾音等，可錯開時間），每層有多個變體輪播且不會連續播同一個、音高隨機範圍；連續命中會逐次升音（連鎖升音，超過時間視窗就重置）；重要事件（重擊、擊殺）會暫時壓低優先級較低的其他聲音，深度與時間都可調，結束後平滑回復。發聲位滿載時，低優先級的聲音被丟棄、高優先級的搶位，被丟棄的次數可在診斷讀到。事件引用不存在的音效或事件不存在時記錄「檔案、事件、層」並退回預設音效；原本的音效覆蓋機制不變。敵人受擊已改用三變體加尾音的命中事件，另外備有重擊與擊殺事件。
驗收：回饋套件新增聲音檢查（資料無錯誤、程式引用的事件都存在、變體不連續重複、連鎖升音與重置、滿載時優先級丟棄與搶位、壓低與回復、缺漏事件不崩潰），連同受擊、敵人與敵人特效套件共 457 項通過。這張票是聲音，沒有畫面截圖。依指示沒有跑完整測試套件。
