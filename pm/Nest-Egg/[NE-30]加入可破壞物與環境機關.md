# [NE-30] 加入可破壞物與環境機關

> 狀態：待辦

## 內文

### 需求
目前場景只有背景，沒有可以互動的東西。加入可破壞物件與環境機關，讓戰鬥與探索更有變化，並與光影連動。設計見 `design/09-content/DESIGN.md` 第三節。

### 來源
2026-10-02，使用者於開發對話中提出：「讓遊戲內容更豐富」；確認四個方向都要做（第二章／新關卡、新敵人與新頭目、場景互動與探索、成長系統），順序為先光影再內容。

### 驗收條件
- [ ] 可破壞物件（木箱、油桶、玻璃牆）被攻擊後破壞，可能掉出道具
- [ ] 油桶被引爆時會傷害附近的敵人與玩家
- [ ] 環境機關：升降梯、可開關的閘門、電力開關
- [ ] 電力開關切斷電源會讓該區域熄燈，重新啟動後恢復
- [ ] 每種新機關第一次出現時有安全的示範與一句提示
- [ ] 可破壞物與機關的狀態存進檢查點，重生後還原

### 測試流程
1. 打破木箱與玻璃牆，確認破壞效果與掉落
2. 引爆油桶傷到敵人
3. 切斷電力開關，確認區域熄燈並可重新啟動
4. 通過檢查點後死亡，確認狀態還原
5. 執行完整測試套件，全部通過
