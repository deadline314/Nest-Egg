# [NE-378] 同步任務地圖的來源索引

> 狀態：完成

## 內文

### 需求

關卡與圖例資源的來源異動後，正式交付的任務地圖應使用同步的索引。已暫存的來源刪除也要觸發驗證。

### 來源

追查開啟對話、靠近互動點及換關卡頓時，發現第一章開始時任務地圖因第四章來源摘要過期而重讀完整關卡。

### 驗收條件

- [x] 正式索引與現有來源同步，索引檢查涵蓋所有正式區域。
- [x] 圖例來源的既有修改和已暫存刪除都會選中任務地圖套件。
- [x] 現有任務指引、造訪區域和地圖標記通過回歸檢查。

### 測試流程

1. 在正式來源組合對原索引執行檢查，確認能拒絕過期資料。
2. 重新產生索引，再檢查正式來源和任務地圖。
3. 從受影響測試的靜態來源清單移除原圖例來源，同時將該路徑列為已刪除，核對任務地圖仍會排入測試。
