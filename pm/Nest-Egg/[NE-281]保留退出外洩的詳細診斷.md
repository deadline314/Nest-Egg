# [NE-281] 保留退出外洩的詳細診斷

> 狀態：完成

## 內文

### 需求
交接櫃保存程序內的行為檢查通過，但引擎退出仍回報資源未釋放時，CI 必須直接留下物件種類及資源路徑，不能只有數量和無法直接開啟的遠端輸出路徑。摘要需有上限並保留完整原文，外洩仍回報失敗。

### 來源
2026-10-30，持續交付時的 CI 41057307449：交接櫃 97 項行為全過，退出仍有 4 個物件／2 個資源未釋放；錯誤摘要缺少詳細身分。

### 驗收條件
- [x] 失敗摘要保留原物件種類與資源路徑，原始輸出完整保存。
- [x] 摘要筆數與單筆長度有上限。
- [x] 正常結果不因啟用詳細輸出而被誤判；外洩與逾時仍失敗。
- [x] 執行器邊界與真正交接櫃流程通過，新增回歸加入 CI。

### 測試流程
1. 執行正常、退出外洩及逾時樣本，確認狀態與摘要。
2. 執行交接櫃的實際保存及獨立續玩，確認原結果保持。
