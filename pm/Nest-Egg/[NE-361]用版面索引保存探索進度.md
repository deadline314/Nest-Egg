# [NE-361] 用版面索引保存探索進度

> 狀態：完成

## 內文

### 需求

保存探索以及驗證已走過的區域時，只讀取所需的地圖版面資料。保存與遷移規則沿用舊檔的正式契約。詳見[關卡載入效能](../../design/20-campaign-experience/LEVEL_ENTRY_PERFORMANCE.md#探索存檔的版面資料)。

### 來源

正式換區後第一次自動存檔會同步載入先前走過的完整關卡，只為取得地圖修訂版。多走幾個區域後，這段停頓更長。

### 驗收條件

- [x] 可用生成索引直接讀取已走過區域的版面資料。
- [x] 32 個區域的遷移輸入與完整關卡一致，受影響套件全過。
- [x] 原生第一章路線完成，換區後第一次自動存檔的長影格縮短。

### 測試流程

重建關卡索引並驗證生成內容。比較全部正式區域從索引讀取的版面資料與正式關卡資料，再跑存檔、遷移、續玩、任務與地圖回歸。以正式 Main 的路線測試核對恢復操作後最長影格。另在實際移動中檢查自動存檔成功。
