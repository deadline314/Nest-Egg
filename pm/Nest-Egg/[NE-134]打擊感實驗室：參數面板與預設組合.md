# [NE-134] 打擊感實驗室：參數面板與預設組合

> 狀態：完成

## 內文

### 需求
實驗室裡要能即時改參數並看到效果。要做依資料格式自動產生的滑桿面板、預設組合（標準、克制、厚重、街機、無障礙），並能看出每個參數被哪些事件使用。

### 來源
2026-10-04，使用者要求處理打擊感；研究與設計見 `design/15-game-feel/RESEARCH.md`（第 8 節），母票 NE-130。

### 驗收條件
- [x] 參數面板由資料格式自動產生，新增參數不用改面板程式
- [x] 改滑桿即時生效，可一鍵播放任一事件看效果
- [x] 預設組合可切換，切換後所有事件的參數一起改變
- [x] 每個參數可查「被哪些事件使用」，也能列出完全沒被使用的參數（測試鎖定反向索引正確）

### 測試流程
1. 改任一滑桿並播放事件確認即時變化
2. 切換預設組合
3. 執行反向索引測試

# Commit-1

## 內文

實驗室裡的數值要能即時改、整批切換，還要知道每個回饋被誰使用。
實驗室的「回饋」下拉選一個事件，面板會依該事件的資料自動產生所有數值滑桿（震動像素與時間、頓幀、凍結、慢動作、縮放等，新增資料欄位不用改面板程式，新種類的欄位只要補一個範圍），拖動立刻改動記憶體中的事件，按「播放回饋」就能看到；面板底下列出這個事件被哪些程式或資料檔使用。「手感」下拉有標準、克制、厚重、街機、無障礙五個預設組合，切換後所有事件的震動、頓幀、縮放一起按倍率改變（無障礙全關）。反向索引由掃描程式碼與近戰資料產生，能列出完全沒被使用的事件；目前每個事件都有被使用，之後有人加了事件卻沒接上，測試會指出來。
驗收：回饋套件新增檢查（每個事件都有可調參數且範圍已知、改參數即時生效、不存在的路徑被拒絕、五個預設可選且整體倍率正確、壞預設被拒絕並保留目前的、反向索引與實際引用一致、沒有未被使用的事件），連同其他回饋檢查共 398 項、0 失敗。畫面見實驗室票截圖。依指示沒有跑完整測試套件。
