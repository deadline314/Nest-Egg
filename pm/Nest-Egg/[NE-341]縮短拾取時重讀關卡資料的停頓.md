# [NE-341] 縮短拾取時重讀關卡資料的停頓

> 狀態：完成

## 內文

### 需求

拾取故事物品時減少重讀地圖造成的單格停頓。主檔、備份、舊地圖遷移與存檔可恢復性仍須通過驗收。

### 來源

2026-11-25 接續 NE-335。回音派傳單拾取後仍有可感受到的停頓，在原生路線中量到同一張地圖反覆讀取。

### 驗收條件

- [x] 正式關卡撿取回音派傳單，成對原生量測的最長格縮短，只取得一次且可讀回。
- [x] 舊地圖存檔仍能遷移，不支援的修訂拒絕寫入，獨立快照各自驗證。
- [x] 受影響的遊戲測試通過。

### 測試流程

1. 新輪經由當鋪到第一章街道，走進傳單可拾取範圍。
2. 比較首次拾取影格，確認物品與存檔各只新增一次。
3. 測試舊地圖修訂和故障存檔。

# Commit-1

## 內文

故事與拾取存檔在同次交易內重用已讀的關卡修訂和座標規則。已有關卡可直接用現場版面完成遷移。舊檔、備份與新候選各別驗證內容，交易結束即釋放讀取的版面資料。

### 測試結果

- RX 9070 XT Forward+，第一章當鋪轉街道後，三組交替的首次拾取最長格為 204.4 → 181.3、202.3 → 185.6、204.0 → 173.1 毫秒。三組均只取得一份傳單，存檔可讀回。拾取仍有可見的單格停頓。
- 受影響的遊戲測試共 26 組、12,455 項，全過。版面遷移的回歸確認同一份版面資料可核對不同快照，未知修訂仍拒絕。
