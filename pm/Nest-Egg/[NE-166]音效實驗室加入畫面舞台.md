# [NE-166] 音效實驗室加入畫面舞台

> 狀態：進行中

## 內文

### 需求
實驗室只能聽聲音，看不到聲音和動畫配起來是什麼感覺，也看不出一個聲音在遊戲裡會以什麼形式出現。要在實驗室裡有遊戲真正的畫面（玩家、敵人、HUD、特效），把每個聲音位置對應到它在遊戲裡出現的情境，按一下就做出真實的動作，聲音和動畫一起出現；還要能在畫面裡直接試備選素材，並能決定整段動畫（例如換彈）是分成幾段還是只用一個聲音。這張票做舞台、情境目錄與武器相關的情境。

### 來源
2026-10-04，使用者要求實驗室把聲音對應的動畫都列出來，並且以聲音在遊戲裡出現的形式顯示；換彈只是例子，目的是整段動畫不被切開，也要能整段用一個聲音。設計見 `design/16-audio/DESIGN.md` 5.3 節。

### 驗收條件
- [ ] 實驗室右側有可收合的遊戲真實畫面，按鈕驅動真實的玩家與敵人動作，聲音由遊戲自己播出；滑鼠與鍵盤可以直接玩
- [ ] 每個聲音位置都對應到一個以上的情境，或明確標示沒有畫面的原因；資料檢查保證不漏、不指向不存在的動作
- [ ] 有「情境清單」分頁，依類別列出所有情境，點一下在畫面執行，並顯示該情境實際響了哪些聲音與它對應哪些位置
- [ ] 位置分頁選一個位置會顯示它的情境，可以「在畫面中播放」，也可以選一個備選素材「用這個素材在畫面中試」，聲音只暫時替換、不寫入任何資料
- [ ] 武器情境完成：八把玩家武器的射擊（單發與連發）、各武器的換彈、空槍、換槍、近戰輕斬與重斬（揮空與命中）、終結技
- [ ] 每個武器情境執行後，實際響出來的音效包含對應位置的聲音（自動檢查）
- [ ] 換彈時間軸編輯器：顯示動畫長度、每個聲音的位置與長度、目前進度游標；可新增、刪除、拖動、換聲音與音量，一鍵套用「三段」「兩段」「一段（整段一個聲音）」；聲音比動畫長或短時有提示
- [ ] 時間軸修改立刻在畫面上生效，可預覽差異、驗證通過才寫回（先備份），也可放棄修改還原
- [ ] 慢動作滑桿（0.1 到 1 倍），動畫與聲音一起放慢；離開實驗室時還原
- [ ] 舞台不播背景音樂與環境音；原有的四個分頁與位置清單連動不受影響
- [ ] 每個按鈕與欄位有 tooltip；資料損壞或缺聲音時提示、不崩潰

### 測試流程
1. 在遊戲中按 F5 進音效實驗室，右側看到遊戲畫面
2. 在情境清單點「手槍換彈」，看到玩家換彈的畫面與彈藥進度，同時聽到聲音，時間軸游標移動
3. 在時間軸改成「整段一個聲音」，再換彈，確認只響一次；開慢動作確認看得到聲音落在動畫哪裡
4. 在位置分頁選「手槍換彈：開始」，選一個備選素材，按「用這個素材在畫面中試」，確認聽到的是備選素材，而資料檔沒有任何改變
