# [NE-166] 音效實驗室加入畫面舞台

> 狀態：進行中

## 內文

### 需求
實驗室只能聽聲音，看不到聲音和動畫配起來是什麼感覺。要在實驗室裡看到遊戲真正的畫面（玩家、敵人、HUD、特效），按一個按鈕就做出真實的動作（換彈、射擊、近戰、走路、受擊、死亡…），聲音和動畫一起出現。換彈要能看到時間軸，並直接在上面決定分幾段、每段放哪裡、播什麼，改了立刻在畫面上重試。

### 來源
2026-10-04，使用者要求實驗室能同時看到音效與動畫（例如換彈）的配合，並自行決定換彈要不要分三段；設計見 `design/16-audio/DESIGN.md` 5.3 節。

### 驗收條件
- [ ] 實驗室有「畫面對聲」分頁，右側是遊戲真正的畫面，可選武器與敵人
- [ ] 按鈕驅動真實動作並同時有畫面和聲音：換彈、單發射擊、連發、空槍、換槍、近戰、走路、落地、敵人受擊、敵人死亡、打材質靶
- [ ] 滑鼠移到畫面上可以瞄準，鍵盤照遊戲操作，可以直接玩
- [ ] 換彈時間軸編輯器顯示換彈長度、每個聲音的位置、目前進度的游標，並標出每個聲音的名稱
- [ ] 可以新增、刪除、拖動聲音位置，換聲音與音量，或一鍵套用「三段（原本）」「兩段」「一段」；修改立刻生效，下一次換彈就用新的
- [ ] 可預覽改動、驗證通過才寫回資料（先備份），也可以放棄修改還原
- [ ] 慢動作滑桿（0.1 到 1 倍），動畫與聲音一起放慢；離開實驗室時速度還原
- [ ] 舞台不播背景音樂與環境音；不影響原有的四個分頁與位置清單連動
- [ ] 每個按鈕與欄位有 tooltip；資料損壞或缺聲音時提示不崩潰

### 測試流程
1. 以命令列開啟實驗室，進「畫面對聲」分頁
2. 選一把武器按「換彈」，看到玩家換彈的畫面與彈藥進度，同時聽到聲音，游標在時間軸上移動
3. 改成一段或五段、拖動位置，再換彈，確認聲音落點改變；開慢動作確認看得到每個聲音落在動畫哪裡
4. 儲存後重開實驗室，確認設定保留；放棄修改後回到原本的設定
