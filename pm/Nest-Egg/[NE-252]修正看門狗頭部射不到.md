# [NE-252] 修正看門狗頭部射不到

> 狀態：待辦

## 內文

### 需求
頭目看門狗的頭射不到：玩家瞄準畫面上的頭部開槍，沒有命中或沒有算成頭部命中。要讓畫面上看得到的頭與實際可命中的範圍一致。

### 來源
使用者 2026-10-11：「看門狗的頭還射不到」。

### 驗收條件
- [ ] 在實際頭目戰重現，記錄瞄準位置、子彈路徑與命中結果
- [ ] 確認與 NE-248（外露核心被整體身體範圍擋住）是否同一成因；同因就一起修，不同因在本票修
- [ ] 修正後，瞄準畫面上的頭部開槍會命中頭部，傷害與回饋符合該部位設定
- [ ] 左右面向、看門狗各個動作與階段下，頭部可命中範圍跟著畫面走
- [ ] 沒有靠放大命中範圍到畫面外或移動立繪來過關；牆壁與其他敵人仍照原規則阻擋
- [ ] 附實際操作的原生畫面與受影響測試結果

### 測試流程
1. 進第一章碼頭倉庫的看門狗頭目戰
2. 用手槍瞄準頭部射擊
3. 預期出現頭部命中的回饋與對應傷害
