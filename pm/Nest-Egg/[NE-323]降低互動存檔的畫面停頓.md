# [NE-323] 降低互動存檔的畫面停頓

> 狀態：完成

## 內文

### 需求

減少互動保存時同步校驗的成本，加入可以重跑的真實按鍵幀時間工具。[遊玩效能設計](../../design/20-campaign-experience/LEVEL_ENTRY_PERFORMANCE.md)

### 來源

2026-11-24，使用者回報 F、滑鼠左右鍵及接近互動物時卡住。實際追蹤在當鋪按 E 並快速略過對話時看到連續保存，兩次都重新解析關卡格局。

### 驗收條件

- [x] 正式存檔與舊檔驗證保留。已有同一份關卡資料時，重用格局來驗證遭遇。
- [x] 用獨立 Main、原按鍵配置和原互動區量測。驗證格擋、近戰、射擊確實發生並展開提示。
- [x] 配對量測改善當鋪對話的最大幀時間。

### 測試流程

在 RX 9070 XT Forward+ 搭配 WASAPI 重跑鍵鼠流程。記錄快速完成對話的幀時間並核對一般對話。測有效與損壞存檔、不同關卡的格局、中文與跳脫字元。

# Commit-1

## 內文

當場關卡同一個資料物件可供快速核對遭遇。位元組結構掃描避免在保存的 JSON 逐字建立短字串。驗證結果與已落盤檔案繼續走原交易流程。

### 測試結果

- 配對重跑各取得 2,335 和 2,400 個渲染影格。相同當鋪用 E 開啟並快速結束對話，最大幀時間從 104.17 ms 降到 68.61 ms；正常播放對話的補充樣本最大 42.75 ms。
- 修正後，近戰 21.34 ms、格擋 17.46 ms、射擊 19.86 ms，走入提示 17.69 ms，皆為該類別取樣期間的最大值。按進接觸範圍時，工具觀察到先清掉上一個提示並顯示新提示。本機的測試條件未重現約一秒的停頓。
- 存檔先行回歸 1,026 項通過。正式受影響的 29 組、12,879 項全過。
