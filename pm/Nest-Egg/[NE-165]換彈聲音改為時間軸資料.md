# [NE-165] 換彈聲音改為時間軸資料

> 狀態：進行中

## 內文

### 需求
換彈聲固定分三段（開始、中段、完成），段數與落在動畫的位置都寫死。要能由資料決定：分幾段、每一段落在換彈的哪個時間點、播哪個聲音與多大聲，每把武器可以各自不同（例如霰彈槍一發一發裝填、重武器只有一個長音）。沒有改資料的武器聽起來要和現在完全一樣。

### 來源
2026-10-04，使用者要求在實驗室能看到聲音和換彈動畫的配合，並由自己決定要不要分三段；設計見 `design/16-audio/DESIGN.md` 5.2 節。

### 驗收條件
- [ ] 每把武器的換彈聲可以用一串「時間點＋聲音＋音量」描述，時間點是換彈進度（0 到 1），段數 0 到 12 段
- [ ] 沒有自訂的武器沿用預設的三段（開始、55%、完成），行為與聲音和改動前相同
- [ ] 武器自訂的時間軸整份取代預設；可沿用另一個武器設定；空的時間軸代表換彈不發聲
- [ ] 換彈進度越過時間點才播；義體加速換彈時聲音跟著動畫；完成時補播還沒播的；中途取消不補播
- [ ] 時間點超出 0 到 1、聲音不存在、動作名稱不認得、段數超過上限時，載入與驗證都指出是哪個設定的第幾段，且不崩潰、退回預設三段
- [ ] 寫回工具可以寫入時間軸：先預覽差異、驗證通過才寫入、寫入前備份；武器還沒有自己的設定時可建立

### 測試流程
1. 載入預設資料，換彈，確認開始、中段、完成三個聲音依序出現
2. 把某把武器改成一段與五段，換彈，確認聲音次數與時間點正確
3. 填入錯誤的時間點或不存在的聲音，確認出現指出位置的錯誤且遊戲不崩潰
