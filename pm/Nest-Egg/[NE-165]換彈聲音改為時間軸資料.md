# [NE-165] 換彈聲音改為時間軸資料

> 狀態：完成

## 內文

### 需求
換彈聲固定分三段（開始、中段、完成），段數與落在動畫的位置都寫死。要能由資料決定：分幾段、每一段落在換彈的哪個時間點、播哪個聲音與多大聲，每把武器可以各自不同（例如霰彈槍一發一發裝填、重武器只有一個長音）。沒有改資料的武器聽起來要和現在完全一樣。

### 來源
2026-10-04，使用者要求在實驗室能看到聲音和換彈動畫的配合，並由自己決定要不要分三段；設計見 `design/16-audio/DESIGN.md` 5.2 節。

### 驗收條件
- [x] 每把武器的換彈聲可以用一串「時間點＋聲音＋音量」描述，時間點是換彈進度（0 到 1），段數 0 到 12 段
- [x] 整段換彈可以只用一個聲音（一段）：開始時播一次，完成時不重複；也可以分成多段，每段各自指定聲音
- [x] 沒有自訂的武器沿用預設的三段（開始、55%、完成），行為與聲音和改動前相同
- [x] 武器自訂的時間軸整份取代預設；可沿用另一個武器設定；空的時間軸代表換彈不發聲
- [x] 換彈進度越過時間點才播；義體加速換彈時聲音跟著動畫；完成時補播還沒播的；中途取消不補播
- [x] 時間點超出 0 到 1、聲音不存在、動作名稱不認得、段數超過上限時，載入與驗證都指出是哪個設定的第幾段，且不崩潰、退回預設三段
- [x] 寫回工具可以寫入時間軸：先預覽差異、驗證通過才寫入、寫入前備份；武器還沒有自己的設定時可建立

### 測試流程
1. 載入預設資料，換彈，確認開始、中段、完成三個聲音依序出現
2. 把某把武器改成一段與五段，換彈，確認聲音次數與時間點正確
3. 填入錯誤的時間點或不存在的聲音，確認出現指出位置的錯誤且遊戲不崩潰

# Commit-1

## 內文

換彈聲固定分三段（開始、中段 55%、完成），段數與時間點寫死在程式裡；整段換彈想只用一個聲音、或想分成五段都做不到。
現在每把武器的換彈聲是一串「時間點＋聲音＋音量」的資料：預設仍是原本的三段（0／55%／100%），沒有改資料的武器聽起來和之前完全一樣；武器可以自己寫一份取代預設（0 到 12 段）。只用一個聲音蓋住整段換彈時，開始播一次，完成時不重複；空的時間軸代表換彈不發聲。播放依換彈進度，所以義體加速換彈時聲音跟著動畫，完成時補播還沒播的，中途取消不補播。資料有問題（時間點超出範圍、不認得的動作、聲音不存在、段數過多）時，載入驗證和寫回工具都會指出是哪個設定的第幾段；執行時資料壞掉會退回內建三段並記錄一次錯誤，不會變成無聲。寫回工具可以寫入時間軸（先預覽、驗證、備份，武器還沒有自己的設定時可建立），實驗室的「換彈整段」按鈕也改成依同一份時間軸播放。
另外修正三個聲音查表類別的重新載入函式與內建函式撞名的問題，改名後才會真的重新讀檔。
驗收：新增換彈時間軸測試 63 項通過（預設三段、一段、五段、空的、排序與同時間、繼承、驗證、壞資料退回、進度播放與補播與取消與跳格、真實玩家換彈的聲音次數、寫回工具），音效、音樂、近戰與實驗室測試套件連同共 18703 項通過。
