# [NE-364] 修正跨平台關卡索引摘要

> 狀態：完成

## 內文

### 需求

讓關卡清單、HUD 地圖投影及鄰區預載在 Windows 和 Linux 採用一致的來源摘要。[關卡載入效能](../../design/20-campaign-experience/LEVEL_ENTRY_PERFORMANCE.md#跨平台驗證關卡索引)

### 來源

主線 Linux CI 有 43 項失敗。索引內的 9 筆訓練道具與 12 筆關卡版面摘要是以 Windows 工作目錄的 CRLF 檔案產生，Git 提交的版本使用 LF。遊戲因此拒收索引，退回載入完整關卡。

### 驗收條件

- [x] 產生和檢查索引時使用相同的換行規則，正式來源內容變更仍可偵測。
- [x] 32 個區域的地圖與鄰區預載資料與原始資料一致。
- [x] 受影響的測試全過。

### 測試流程

執行 \`res://tools/build_level_index.tscn -- --check\`，再執行受影響測試。比對 Git 的 LF 來源與 Windows 上的 CRLF 來源，兩者應產生相同索引。
