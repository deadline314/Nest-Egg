# [NE-367] 依實際存檔進度驗證劇情拒絕

> 狀態：完成

## 內文

### 需求

在分幀保存對話進度的版本中，先確認入口主檔已寫入，再驗證損毀的劇情規則拒絕提交結果。被刻意阻擋的入口寫入也要核對原檔。詳見[對話進度保存](../../design/20-campaign-experience/LEVEL_ENTRY_PERFORMANCE.md#對話進度保存)。

### 來源

主線 CI 在第一章懷錶標籤案例的主檔逐位元組比對報錯。取樣後仍有兩格入口寫入工作，入口主檔發布後才出現拒絕提示。

### 驗收條件

- [x] 送出結果操作前確認已寫入可續播的主檔；遇到刻意阻擋時仍保留進對話前的主檔。
- [x] 拒絕後逐位元組比對主檔。原物品、旗標、NPC 紀錄與冷讀檔仍逐項驗證。
- [x] 所有標籤、關卡及物品案例與劇情契約稽核通過。

### 測試流程

執行劇情所有權及損毀資料測試組。使用獨立程序讀取修復後主檔，確認只收錄真正接受的結果。
