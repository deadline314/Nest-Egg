# [NE-530] 修正過場裡坐姿與場景互動的位置

> 狀態：待辦

## 內文

### 需求

過場裡有些角色的動作和場景對不上，看起來像沒有演完或擺錯位置。使用者指出兩類：

1. **該坐在椅子上的沒有坐在椅子上**：角色做出坐姿，但臀部不在座面上——浮在椅子上方、陷進椅子裡、坐在椅子旁邊的空氣上，或是椅子在別的位置而角色坐在原地。
2. **要和場景互動的動作，位置有問題**：角色伸手去拿、放、按、開、靠、扶的時候，手或身體沒有碰到那個東西——手停在物件旁邊的空中、穿進物件裡、朝著錯的方向，或是物件根本不在手搆得到的地方。包含桌上的杯碗與文件、櫃台、門與門把、電話與話筒、扶手與欄杆、床與床頭櫃、攤車、傘、交接櫃等。

玩家要得到的是：過場裡每一個坐、靠、拿、放、按、開的動作，都看得出角色真的在和那個東西互動。

同類的情況一起處理，不只修被點名的兩類：

- 坐下與站起來的過程（不是只有坐定的那一格）臀部與腳的位置合理，不會瞬間跳到座位上或從座位上彈起來。
- 坐著時腳的位置：腳踩在地面或腳踏上，不懸空、不陷地。
- 靠牆、靠櫃台、靠欄杆時，身體接觸的那一側真的貼著它，重心看起來撐得住。
- 手上拿著的東西（杯、文件、話筒、傘）在整段動作裡都在手上，不會飄在手邊或留在原處。
- 同一件家具在同一個舞台的不同過場裡位置一致；角色的站位、坐位和它對得上。
- 過場倍率與遊戲倍率、角色朝左與朝右都要成立。

範圍是所有有舞台的過場（目前約 137 段，分布在開頭與第一到六章），以及關卡裡會坐、會靠、會操作東西的場景人物（當舖、麵攤、診所、病房、辦公大廳等）。

不在這張票的範圍：台詞與劇情（不改）、對話框的位置（NE-492 已處理）、鏡頭與站位的其他問題（演出線的過場走位總檢另外處理）、角色零件本身的接縫破圖（另有票）。若修位置時發現是缺少姿勢或缺少道具圖才對不上，列出缺什麼並另開美術或動作票，不用遮擋或把物件藏起來帶過。

### 來源

2026-11-28，使用者在對話中提出：「我發現有一些過場裡面的角色動作有一些問題。例如應該坐在椅子上的卻沒坐在椅子上，或是有什麼要跟場景互動的動作但位置卻有問題。如果沒有 Session 正在做這件事情，就幫我先開票寫清楚就好。」提出時沒有 session 在修這件事：演出線的過場走位總檢把「姿勢與道具」列為待目看的項目，尚未開始。

### 驗收條件

- [ ] 有一份清單列出所有過場與關卡裡「坐、靠、拿、放、按、開、扶」這類和場景接觸的動作：哪一段、第幾步、哪個角色、和哪個物件、目前對不對得上；對不上的每一筆附一張過場倍率的截圖。
- [ ] 使用者指出的兩類問題在清單上都找得到具體的段落；清單交給使用者看過，確認他看到的那幾處都在裡面（漏掉的補上）。
- [ ] 每一個坐姿：坐定時臀部落在座面上（誤差在半個世界像素內，用量測而不是目測），腳踩在地面或腳踏上；坐下與站起來的過程沒有瞬間跳位。
- [ ] 每一個用手的互動：動作到位的那一格，手和物件的接觸點重合（誤差在一個世界像素內），手沒有穿進物件，物件在動作前後的位置合理（拿起來之後在手上、放下之後在桌上）。
- [ ] 每一個靠與扶：身體或手接觸的位置貼著那個表面，沒有縫也沒有穿進去。
- [ ] 朝左與朝右、過場倍率與遊戲倍率都通過上面幾條。
- [ ] 有自動檢查擋住這類問題再出現：過場裡標成坐、靠或互動的步驟，角色與對應物件的位置對不上時檢查會失敗；把一張椅子或一個角色故意移開一格，檢查要抓得到。
- [ ] 修正後沒有新的破圖或姿勢問題：受影響角色的接點稽核與動作稽核通過，腳貼地的檢查通過。
- [ ] 受影響的過場仍然播得完、選項與後續劇情照常觸發，故事與過場的既有檢查全過。
- [ ] 因為缺姿勢或缺道具圖而修不了的，逐筆列出缺什麼，並各自開了票。

### 測試流程

1. 用過場檢視工具播放清單上每一段有坐、靠或互動的過場，在過場倍率下逐步看：坐定、伸手到位、靠上去的那幾格。預期臀部在座面上、手碰到物件、身體貼著靠的表面。
2. 同一段切換角色朝向再看一次。預期一樣成立。
3. 進入關卡，走到會坐著或靠著的場景人物旁邊（當舖、麵攤、診所、病房、辦公大廳），等他坐下、站起來、說話。預期坐下與站起來的過程連續，坐著時腳在地面上。
4. 執行過場與角色動作的自動檢查。預期全部通過；把任一張椅子移開一格後重跑，預期檢查失敗並指出是哪一段、哪一步。
5. 從頭播放第一章到第三章的主要過場。預期播得完、選項與後續劇情照常。
