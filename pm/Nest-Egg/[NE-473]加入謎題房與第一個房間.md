# [NE-473] 加入謎題房與第一個房間

> 狀態：進行中

## 內文

### 需求
環境機關目前都是「看到就用」：射一下、拉一下就有效果，沒有一處要玩家想一下順序。這張票先做一個通用的「謎題房」：關卡資料裡標一段範圍、寫好完成條件（哪些開關要在什麼狀態，或走到某一頭），解開時打開出口並給一次獎勵；房裡可以放一支重置開關，讓機關回到進房時的樣子；玩家在房裡卡住一段時間還沒解開，才出現一句講方向、不講答案的提示。再用已經有的元件（吊掛貨箱、開關、閘門）做第一個房間。

### 來源
2026-11-28，使用者指示「關卡的玩法跟內容可以更多變一點，不要只有枯燥的射擊」；主 session 指派玩法線第三項「操作機關的小謎題：先做資料驅動的謎題房框架（完成條件、重置、提示在卡住一段時間後才出現），再做第一個房間」。

### 驗收條件
- [ ] 謎題房寫在關卡資料裡（範圍、完成條件、出口頻道、重置頻道、提示等待時間、獎勵、目標與提示的中日英文字），新增一個房間不用改程式；資料不合理時指出是哪一個房間、哪一項
- [ ] 進房時提示一次目標；只滿足部分條件不算解開；全部滿足才解開，出口打開、獎勵只給一次
- [ ] 拉重置開關，房裡的開關、閘門、輸送帶回到這一次進房時的樣子；已經解開的房間不會被重置回去
- [ ] 在房裡卡住設定的秒數還沒解開，才出現一句提示；解開前不會提早出現
- [ ] 解開與否跟著檢查點與存檔；從檢查點重來後解開的房間維持解開、不再給獎勵，沒解開的回到初始狀態
- [ ] 第一個房間放在不擋主線的位置：要先想到把吊著的貨箱射下來當踏板，才搆得到高處的開關、打開藏東西的閘門；獎勵用既有的信用點
- [ ] 附原生畫面（進房、射下貨箱、踩上去拉開關、閘門打開）；受影響範圍的測試全過，把完成條件或重置關掉時測試會失敗

### 測試流程
1. 進第一個謎題房，預期跳出一句目標
2. 在房裡亂走不解，預期過了設定的時間才出現一句提示
3. 射斷吊鏈讓貨箱落地，踩上貨箱跳到高處，拉開關，預期閘門打開、提示解開並給信用點
4. 從檢查點重來，預期閘門維持打開、不再給信用點
