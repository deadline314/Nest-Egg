# [NE-250] 優化 NPC 與過場演員的動作表現

> 狀態：進行中（老 K 灰色肩塊已由 NE-222 Commit-56 局部修復；完整連續接點與使用者動作確認仍待驗）

## 內文

### 需求
NE-206 讓 NPC 有了重心轉移、轉頭與說話手勢，但使用者看過後認為還可以更好。要參考業界實際做法，再提升一輪 NPC 與過場演員待著、聽、說、做事時的動作，讓人物像有重量、有個性的人，而不是換了節奏的循環擺動。

### 來源
使用者 2026-10-11：「NE-206 還是可以優化，參考一下行業最佳實例」。

### 驗收條件
- [x] 先列出目前 NPC 動作看起來不自然的具體地方（哪個角色、哪個動作、哪一段），每項附實際畫面
- [x] 查過至少三個做得好的 2D 骨架動畫實例，寫明來源、實際看到的做法、採用與不採用的理由；沒有讀到原文的不寫成已查證
- [x] 第一章每個 NPC 的待機、聆聽、說話、工作動作各自有可辨認的個性，同場兩人節奏不同步
- [x] 動作有預備、主要動作與收尾，起停與切換沒有跳格；坐、靠、站的支撐合理
- [ ] 遊戲倍率與過場倍率、左右面向的連續畫面逐格檢查，沒有破圖、露縫或穿插
- [x] 節奏與幅度仍是每個角色自己的資料，新增角色不用改程式
- [ ] 附修前修後同鏡頭的連續畫面，由使用者確認

### 測試流程
1. 進第一章有 NPC 的場景與過場，各停留 30 秒觀察
2. 預期每個人物的動作有差異、有重量，沒有機械式重複

# Commit-1

## 內文

**問題**：NPC 說話時的手勢是固定週期的擺動，所有人同一套，Mei 的前臂像鐘擺來回（量到的重複度 0.96，1 就是完全重複）；坐下、起身是瞬間換姿勢，坐下的第一格腿一下子折起來、起身 0.2 秒就彈起來而且腳往前滑，每個人起身的方式一模一樣；擦手、攪鍋、敲打每一圈完全相同；聆聽只會固定偏頭；站著沒事時沒有任何屬於這個人的小動作；揮手時舉起的袖子蓋住整張臉。逐項清單、數字與畫面見[動作表現設計](../../design/12-cast-redraw/NPC_PERFORMANCE.md)第 1 節。

**改動**：先查了 Spine 與 Live2D 的官方文件、Hu／Walker／Neff 的說故事角色研究（手勢分準備、重音、停留、收回，個性用頻率、速度、幅度表現）與動畫十二原則，查證內容與採用理由寫在同一份設計文件第 2 節。依此：
- 說話改成一個一個手勢：先往反方向蓄一下、到位、重音、停一下、收回；舉手時手肘先彎、肩膀後抬，放下時肩先落、手肘後伸；手勢接得近就直接接下一個，有時候放下手休息。每個人有自己的手勢清單與快慢、大小：老 K 慢而重、常壓手掌和指；阿莉精準、會指；夜班工人懶得比、常揮開；Mei 快而多、會聳肩。
- 聆聽時會點頭附和；站著沒事會做自己的小動作（老 K 揉後頸、阿莉看錶、夜班工人揉眼、Mei 碰耳機、居民搓手），手在忙或在說話時不做。
- 坐下、起身、靠牆都有預備：起身前上身先前傾、腳先收回到身體下方再站起；老 K 起身慢而前傾大，Mei 快。過場演員從座位站起時，身體落回地面跟著起身的進度走。
- 擦手、攪鍋、敲打、打哈欠改成有節奏的關鍵動作（敲打是慢慢舉起、停在頂點、快速敲下、回彈），每一圈長短略有不同，開始與停止會緩入緩出；打哈欠改成仰頭伸展。
- 轉頭時視線和頭先動、身體晚一點跟上；呼吸吸短呼長；揮手時手比前臂晚一點擺，袖子不再蓋住臉。
- 只改 NPC 的動作資料與演出邏輯；主角的動作、零件圖與骨架沒有改。

**驗收**：用新的連續畫面工具拍同鏡頭的修前修後（遊戲倍率 2.2 倍、過場倍率 3.4 倍、面向左右），並量同一段表演的數字（老 K／Mei）：說話的重複度 0.97／0.96 → 0.34／0.24；起身最大跳格 0.13／0.14 → 0.01／0.03；坐下再起身全程最大跳格 0.41 → 0.03 以下；兩人同時說話時手臂動作的相關係數約 -0.05（不同步）。九位角色坐下再起身都通過「沒有跳格、骨盆升起前上身已前傾」的自動檢查。
待本機原生驗收：Forward+ 原生畫面的逐格接縫檢查，以及「像不像人」由使用者看過確認。已知未解：老 K 舉手時大衣肩部會露出灰色的肩關節零件（修前就有），需要角色組補舉手用的肩袖零件或肩部網格權重，交給 NE-221／NE-222，本票不改零件圖。

# Commit-2

## 內文

**問題**：上一輪的連續畫面是用 Compatibility 拍的，Forward+ 的實際畫面只看過一場過場，「遊戲倍率、過場倍率、左右面向都沒有破圖、露縫或穿插」這條沒有真的逐格看過。另外 NE-256 把關卡鏡頭拉近後，人物在遊戲裡被放大的倍率也變了。

**改動**：沒有改動作資料。用雲端軟體 Vulkan 跑 Forward+，拍了三組連續畫面，每組都拍拉近後的遊戲倍率（2.8 倍）與過場倍率（3.4 倍）、面向左右各一次：老 K 與 Mei 的「待機→說話→聆聽」、老 K 與護理師的「站→坐」、老 K／阿梨／夜班工人十種手勢各停在重音後。另外在實際當鋪地圖用 Forward+ 重拍 NE-240 的反應連續畫面。

**驗收**（逐格看過，結果如下）：
- 說話、聆聽、坐下、起身、蹲下抱頭再站起來，左右面向都沒有新的破圖或穿插，姿勢切換沒有跳格。
- 仍然存在：老 K 舉手時，大衣肩部露出灰色的肩關節零件，遊戲倍率和過場倍率、左右面向都看得到。這是零件圖的問題（修前就有），屬角色組的 NE-221／NE-222，本票不改零件，所以這條驗收條件還不能勾。
- 夜班工人駝背、頭在肩膀前方，做「舉手打招呼」時手臂一定會擋住臉；試過三組手臂角度都一樣，問題在他的站姿，不在手勢。他的手勢清單與反應都沒有用到這個動作，遊戲裡不會出現；之後要讓他打招呼，要先替他做專屬的揮手姿勢。
- 夜班工人袖口與手套之間的白色區塊放大確認是手腕的皮膚，不是露縫。
- 「像不像人」仍待使用者看過確認，沒有勾。
