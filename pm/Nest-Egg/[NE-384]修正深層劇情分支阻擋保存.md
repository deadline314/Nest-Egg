# [NE-384] 修正深層劇情分支阻擋保存

> 狀態：完成

## 內文

### 需求

玩家確認劇情結果時，合法的巢狀分支不應阻擋保存。存檔讀取維持原有資料限制，劇本或即時進度變動後，已準備的舊結果仍需重新驗證。

### 來源

2026-11-26 第七章實走驗收。完成老 K 的雨棚對話時，另一場劇情的合法分支阻擋了保存。 [對話進度保存](../../design/20-campaign-experience/LEVEL_ENTRY_PERFORMANCE.md#對話進度保存)

### 驗收條件

- [x] 實際完成第七章雨棚對話，寫入結果並可走到麵攤。
- [x] 最深的合法劇情條件能隨正式結果一同核對。提交前若修改深層條件，舊結果拒絕提交。
- [x] 劇本目錄增加未讀場景後，原先已完成的紀錄仍可驗證，未知與重複紀錄仍拒絕。
- [x] 超出原有深度的玩家存檔仍被拒絕。既有續玩、保存結果與拒寫行為通過回歸。

### 測試流程

1. 從雨棚接觸前的隔離進度續玩。完成真實互動後核對結果、返回控制及麵攤的通行狀態。
2. 重跑深層條件、條件改動、損毀存檔與正常整輪保存測試。

# Commit-1

## 內文

完成劇情結果時，劇本的合法巢狀條件及未讀場景數不再阻擋保存。已完成場景仍核對是否存在，未知或重複的紀錄會被拒絕。玩家從原本失敗的存檔再試一次，雨棚對話完成後沿原出口抵達麵攤。
