# [NE-46] 新增偵察與狙擊型敵人

> 狀態：待辦

## 內文

### 需求
探照無人機與狙擊手。探照無人機掃光，被照到會引來警報；狙擊手用很長的紅色雷射先掃再停再開火。新增後第一、二章的戰鬥種類更豐富。

### 來源
2026-10-03，使用者於開發對話中提出：「多設計幾種不同的敵人」；「這些都可以去看看目前業界有哪一些最佳實例可以參考，我們盡可能設計的貼近完整實際的 Demo」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 探照無人機：光束掃過、發出嗶聲，被照到時警報加速並引來附近的敵人；可以躲進陰影、打掉它或切電
- [ ] 狙擊手：很長的紅色雷射先掃後停，閃三下才開火；能躲在牆後或衝刺閃避
- [ ] 每種敵人的攻擊都有明確預兆，預兆在暗處自帶光、看得清楚
- [ ] 每種敵人有敗北圖鑑卡片與攻略，數值在資料檔
- [ ] 三種難度下都能擊敗，任何難度的預兆都不少於 0.3 秒
- [ ] 已配置到關卡（第一章後半與第二章夾層區），並有第一次遭遇時的安全空間

### 測試流程
1. 在測試場地逐一遭遇，確認預兆與應對方式成立
2. 被每種敵人擊敗一次，確認圖鑑解鎖並顯示攻略
3. 在關卡裡確認配置
4. 執行完整測試套件，全部通過
