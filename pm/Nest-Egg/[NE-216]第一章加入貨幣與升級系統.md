# [NE-216] 第一章加入貨幣與升級系統

> 狀態：待辦

## 內文

### 需求
使用者覺得升級系統與貨幣系統還沒做。需要檢視現有系統（信用點、補給商店、武器改裝、義體能力）在第一章的呈現，並依業界做法補齊：第一章要有零錢掉落、老 K 的當舖（買、典當、贖回）、工作檯的武器改裝、劇情與探索給的能力；升級買下後立刻看得見；死亡扣款有上限、劇情必死不扣款；價格與收入用資料表對帳。商店與升級融入世界觀，不是冷冰冰的選單。

### 來源
2026-10-06，使用者試玩第一章後回報：「好像還沒做升級系統跟貨幣系統，可以的話都幫我做一下」。

### 驗收條件
- [ ] 檢視現有的貨幣、商店、改裝、能力系統與第一章的整合現況，列出缺什麼
- [ ] 貨幣：敵人與可破壞物掉零錢；第一次拿到錢在第一個敵人或第一個箱子；一兩處不在主路上的小額寶箱；HUD 顯示信用點
- [ ] 老 K 的當舖是商店：先看到店與價格再買得起；賣補給與改裝件；可典當物品換錢並可贖回（贖回加利息）；老 K 的對話隨死亡次數與章節進度變化
- [ ] 工作檯：一個武器改裝槽與兩三個價差明顯的選項；買下後槍上看得見差異，tooltip 顯示「之前 → 之後」
- [ ] 能力解鎖（衝刺、格擋等）靠劇情與探索發放，不靠錢買
- [ ] 死亡扣款不超過身上現金、不負債；劇情必死不扣款；取回機制與扣款只用一種
- [ ] 價格與收入放資料表；腳本算出第一章「可得總金額」與「價目表總和」，必要升級約為主線收入的六到八成，放進測試或報表
- [ ] 第一章的經濟曲線與購買流程截圖，存檔
- [ ] 本票統整出的檢查項目與自動檢查方法，寫進 skill `continuity-qa`（`.claude/skills/continuity-qa/`），參考業界做法並附出處；之後涉及流程與狀態的工作都必須先讀這份 skill

### 測試流程
1. 新遊戲打幾隻敵人，確認掉錢與 HUD
2. 到當舖買東西、典當、贖回
3. 在工作檯改裝，確認槍的外觀與數值
4. 死亡後確認扣款規則
