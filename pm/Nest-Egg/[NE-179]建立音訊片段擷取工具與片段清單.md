# [NE-179] 建立音訊片段擷取工具與片段清單

> 狀態：完成

## 內文

### 需求
有些素材一個檔案裡包含多段聲音（連發槍聲、一整組撞擊、長錄音），現在只能手寫加工清單的起訖時間，看不到波形，而且一個加工輸出只能取一段。要能把「某個素材的某一段」輸出成獨立的新素材：從原始完整檔指定起訖，輸出無損音訊檔，取得新的素材編號，和原檔並列；同時記錄來源與範圍，原始下載檔被清掉重抓後也能重做出同樣的片段。另外要提供給實驗室使用的「準備編輯」資料：可聽的完整長預聽、波形與依靜音找出的各段。設計見 `design/16-audio/DESIGN.md` 5.4 節。

### 來源
2026-10-05，使用者提出：有些音訊裡同時包含多段音效，希望有介面讓他擷取音訊的某一段，確認之後才真的把該段擷取出來另存成一個檔案。並選定：新素材加記錄範圍、看原始完整檔、依靜音自動分段。

### 驗收條件
- [x] 給原檔的素材編號與起訖秒數，輸出保留原檔取樣率與位元深度的新音訊檔，不調音量、不重新取樣
- [x] 新片段取得新的素材編號（類別與原檔相同、接在該類最大編號後面、不重用），素材目錄記錄它來自哪個原檔與起訖
- [x] 片段清單進版控；原始下載檔被清掉後，重新下載原檔並重跑工具，可以重做出同樣的片段與同樣的編號
- [x] 片段登記為來源目錄裡本機產生的素材包，授權沿用原檔（CC0）並記錄衍生自哪個素材包；下載工具略過這種素材包，不當成下載失敗
- [x] 新片段自動產生預聽檔，實驗室可以立刻試聽與挑選；擷取本身不改任何位置的預計使用
- [x] 同一個原檔上幾乎相同的範圍重複擷取時，提示已存在並回傳既有編號，不產生重複
- [x] 起訖超出檔案、起點不小於終點、原檔缺失、寫入失敗時，錯誤訊息指出是哪個素材與原因，不留下半成品檔案或半寫入的清單
- [x] 「準備編輯」輸出：完整長預聽（單聲道、不去頭尾靜音、可聽）、波形資料、依靜音與最短間隔找出的各段起訖；原檔過長時有明確上限並說明
- [x] 用合成的短音訊測試整套工具，不依賴下載的素材；沒有原始下載檔與外部工具的環境（CI）也能通過
- [x] 擷取片段的做法寫進音訊素材流程的操作手冊

### 測試流程
1. 對一個含兩聲槍響的素材準備編輯，確認找出兩段、起訖與波形合理
2. 擷取第二段，確認新素材編號、新檔案時長與起訖相符、取樣率與原檔相同
3. 刪掉輸出檔後重跑，確認還原出同樣的檔案與編號
4. 重複擷取同一範圍，確認提示已存在；給錯誤的起訖，確認錯誤訊息清楚且沒有留下檔案

# Commit-1

## 內文

有些素材一個檔案裡有多段聲音，只能手寫加工清單的起訖時間，看不到波形，而且一個加工輸出只能取一段。
現在有擷取片段的工具：指定原檔素材編號與起訖秒數，就從原始完整檔切出一段，存成無損音訊（保留原檔的取樣率、聲道數與位元深度，不調音量、不重新取樣），取得新的素材編號（類別與原檔相同、接在該類最大編號後面、編號不重用），和原檔並列在素材目錄與搜尋裡；新片段自動產生預聽檔，實驗室可以立刻試聽，但不會動任何位置的預計使用。每個片段的原檔與起訖記在進版控的片段清單，原始下載檔被清掉重抓之後，一個指令就能照清單重做出同樣的片段與同樣的編號。片段登記為來源目錄裡本機產生的素材包，授權沿用原檔的 CC0 並記錄衍生自哪個素材包；下載與授權複查工具略過這種素材包，授權登記會寫明每個用到的片段衍生自哪個原檔。
另外有「準備編輯」功能：解出可聽的完整長預聽（單聲道、不去頭尾靜音，預設最長 180 秒並標明是否被截短）、波形資料，以及依靜音找出的各段起訖，給實驗室的擷取介面（NE-180）使用。
同一個原檔上幾乎相同的範圍重複擷取會提示已存在並回傳既有編號；起訖超出檔案、起點不小於終點、原檔缺失或寫入失敗時，錯誤訊息指出是哪個素材與原因，不留下半成品檔案，寫入一半失敗也會把已寫的清單還原。片段清單另有資料檢查，損毀時會指出是哪個片段。
驗收：用 96 kHz、24 位元立體聲的真實槍聲原檔擷取一段，輸出格式與原檔一致、長度吻合、預聽檔自動產生，重複擷取回傳既有編號，目錄與清單重建後對得上，驗證完已還原專案資料；其餘用合成的雙聲音訊自動測試，不依賴下載的素材。
