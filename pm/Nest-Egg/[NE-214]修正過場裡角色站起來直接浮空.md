# [NE-214] 修正過場裡角色站起來直接浮空

> 狀態：進行中

## 內文

### 需求
過場裡角色從坐姿站起來時，位置沒有跟著從椅子或桌面放回地面，整個人直接懸在半空（例如復原館裡坐在檢查台上的凜站起來）。需要讓坐、蹲、靠換成站姿時，角色的腳自然落回地面，有站起來的過渡動作，不浮空、不瞬移；並且所有坐下的演出都有對應的起身處理。

### 來源
2026-10-06，使用者試玩第一章後回報（附復原館坐姿截圖）：「這裡站起來也直接浮空，幫我開票修正」。

### 驗收條件
- [x] 角色從坐、蹲、靠換成站、走、跑時，腳底落回該處地面，沒有懸空也沒有瞬間跳動
- [ ] 站起來有過渡動作（重心前移、腿伸直），時間合理
- [ ] 坐在檯面、椅子、箱子上的演出，起身後腳踩的位置是舞台地面而不是座位高度
- [ ] 第一章與第二章所有包含坐下或蹲下的過場逐一檢查通過
- [ ] 自動檢查：過場每個演員在每個姿勢切換前後，腳底與舞台地面的距離在容許範圍內，違反時指出場景與角色

- [ ] 本票涉及過場演員起身與地面接觸的規則、尺寸比例、位置與檢查方法，寫進 skill `scene-staging`（`.claude/skills/scene-staging/`：關卡與過場的佈景、位置、比例、構圖、圖層），參考多個不同業界實例並附出處；之後做關卡、佈景與過場都必須先讀這份 skill

### 測試流程
1. 播放復原館過場，凜從檢查台上站起來，觀察腳是否落地
2. 播放所有有坐或蹲的過場，在切換姿勢的前後暫停量腳與地面的距離
