# [NE-203] 比較並選定立繪套骨架後的呈現做法

> 狀態：完成（使用者委託決定，未做 B、C 原型）

## 內文

### 需求
凜的立繪很精緻，但拆成剛體零件套上骨架後，膝蓋、手肘、髖部出現直線切口、缺角與明暗不連續，放大到過場倍率更明顯。需要在動手全面改動之前，先用凜做出幾種做法的原型，同一個姿勢、同一個倍率並排比較，由使用者選定要採用的做法（候選：連續貼圖的網格變形、彎曲姿勢的零件變體、過場用姿勢立繪庫，以及它們的組合；見設計文件第 3 節），並定出之後各票要遵守的畫面標準。

### 來源
2026-10-05，使用者試玩第一章後回報（當舖過場截圖）：「女主在這個過場的動作還是很奇怪，為什麼套上骨架之後主角的各個部位的圖看起來都是破圖？那我當初繪製那麼好看的立繪就被浪費了，可以開票幫我處理到好嗎？看有什麼做法可以讓我套上骨架之後主角動起來的整體畫面還是好看且漂亮，然後所有 NPC 動起來不要那麼像機器人」。分析與做法見 `design/12-cast-redraw/RIG_QUALITY.md`。

### 驗收條件
- ~~至少三種候選做法各做出凜的原型~~　使用者委託決定，只做選定的 A（NE-204），B、C 作為補強選項保留
- ~~並排比較截圖~~　改為 NE-204 的修前修後並排：站立、行走、跳躍、蹲、坐、跪、手舉到胸前，每個姿勢都用同一個倍率與同一個背景，另附過場倍率（約 3.4 倍）的膝與肘特寫
- [x] 每種做法列出優缺點、新增一個角色所需的人工步驟、對效能與記憶體的影響（同屏 10 個人形的影格時間與貼圖記憶體）
- [x] 選定做法與理由記錄在設計文件（使用者 2026-10-06 委託「以業界最佳實例為主」，選網格變形 A）
- [x] 定出畫面標準：哪些姿勢、哪個倍率下，關節不得出現什麼（切口、缺角、色塊、反光斷層），寫進設計文件作為 NE-204 的驗收依據

- [x] 本票統整出的規則、數值、檢查方法與踩過的坑，寫進 skill `rig-animation`（`.claude/skills/rig-animation/`），資料來源與出處附在 skill 的參考資料裡；之後做骨架與動畫都必須先讀這份 skill

### 測試流程
1. 開預覽工具，載入凜，切換各候選做法
2. 依序播放站、走、跳、蹲、坐、跪、舉手
3. 截圖並排，放大看膝蓋與手肘
4. 使用者挑選
