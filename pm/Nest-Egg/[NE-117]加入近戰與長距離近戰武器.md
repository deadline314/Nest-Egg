# [NE-117] 加入近戰與長距離近戰武器

> 狀態：待辦

## 內文

### 需求
目前武器欄全是槍，近戰只有一個固定的短距離斬擊與終結技。要讓近戰也成為一種武器：可以撿、換、顯示在武器欄與背包，有短刃、長刀、重武器、長柄、鞭或鎖鏈等不同類型，包含攻擊距離很遠的近戰武器。強度靠攻擊速度（前搖、後搖）、威力、距離、範圍與消耗來平衡，不是單純某把比較強。

### 來源
2026-10-04，使用者說不一定每個武器都要是槍，可以給近戰武器或攻擊距離很遠的近戰武器，用攻擊速度、威力來平衡；設計見 `design/14-combat-variety/DESIGN.md`。

### 驗收條件
- [ ] 近戰武器是資料：前搖、出招區間、後搖、判定形狀、距離、傷害、衝擊力、擊退、命中頓幀、消耗、連擊段數都能在資料裡調整，新增一把不改程式
- [ ] 判定只在出招區間生效，一次揮砍對同一目標只算一次，揮空有後搖
- [ ] 第一批至少三把：短刃（快、貼身）、長刀（標準）、長柄（距離長、近身有死角）；另有一把超長距離（鞭或鎖鏈）
- [ ] 任兩把近戰武器在速度、威力、距離上有明顯取捨，沒有哪一把全面勝過其他
- [ ] 近戰武器的衝擊力會依輕重讓敵人畏縮或硬直（沿用 NE-102 的分層），重武器能打出硬直
- [ ] 武器欄、背包卡片與 HUD 能顯示近戰武器（沒有彈匣時的資訊），每把有一句說明
- [ ] 角色有對應的持武器與揮砍動作，揮動有軌跡，命中有回饋，特效克制
- [ ] 既有的槍械、格擋、完美反彈與終結技行為不變

### 測試流程
1. 逐把撿起並換上，對不同敵人揮砍，確認距離、速度與威力的差異
2. 對同一敵人比較各把的清敵效率，確認取捨成立
3. 揮空、連續揮砍、被打斷時確認後搖與判定正確
