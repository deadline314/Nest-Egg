# [NE-163] 建立素材與位置的編號體系與位置清單

> 狀態：完成

## 內文

### 需求
目前只有音效的名稱，沒辦法精確指著「遊戲裡的哪個位置」說要用「哪一個聲音」。要讓每個會響的位置與每個候選素材各自有永久不變的編號（兩套體系格式不同、不同種類前綴不同），建立素材目錄與位置登記，並維護一份給人編輯的位置清單文件，使用者填入想用的素材編號後可以一鍵套用。

### 來源
2026-10-04，使用者要求每個遊戲內的聲音位置與每個候選素材各自編號（兩套不同體系、不同種類用不同前綴）、每個位置至少十個備選、實驗室能跨類別挑選，並維護一份位置清單 md；設計見 `design/16-audio/DESIGN.md` 5.1 節。

### 驗收條件
- [x] 每個已下載的 CC0 音訊檔都有全專案唯一、不重編的素材編號，格式依種類分前綴（槍聲、槍械操作、撞擊、爆炸、近戰、移動、人聲生物、機械、電子、介面、環境循環、音樂）
- [x] 遊戲裡每一個會響的位置（槍聲、換彈、命中材質、角色受擊死亡、腳步、機關、介面、環境音、背景音樂各狀態）都有位置編號，格式與素材編號明顯不同
- [x] 位置清單文件列出所有位置：編號、名稱、遊戲裡的哪裡用到、目前用哪些素材（素材編號）、預計使用（空白讓使用者填）、手動放入勾選
- [x] 重新產生位置清單時，使用者已填的預計使用與勾選會保留
- [x] 素材目錄的編號在新增素材後不變，新素材接在後面
- [x] 預聽用小檔案（統一響度與長度）可由工具產生，重跑結果一致；不進版控
- [x] 套用工具讀位置清單：預計使用有填、且沒勾手動放入的位置，依素材編號改寫加工清單並重建；勾了手動放入的位置不動
- [x] 位置的目前素材能正確對應回素材編號（包含多層疊音、逐發切割的素材）
- [x] 資料檢查能指出：位置引用不存在的素材編號、重複的編號、清單裡不存在的位置

### 測試流程
1. 執行產生工具，確認素材目錄與位置清單產生
2. 在位置清單某一格填入一個素材編號，重新產生，確認沒有被清掉
3. 執行套用工具，確認該位置的加工清單改成指定素材並能重建

# Commit-1

## 內文

要精確地說「這個位置用那個聲音」，需要兩邊都有編號。
現在 2571 個已下載的 CC0 音訊檔各有一個永久的素材編號，格式 `GUN-0031`：槍聲 GUN、槍械操作 RLD、撞擊與命中 IMP、爆炸 EXP、近戰揮擊 MLE、移動與衣物 MOV、人聲與生物 VOX、物品與拾取 ITM、機械與機關 MEC、電子與能量 ELC、介面 UIS、環境循環 AMB、音樂 MUS（沒歸類的 OTH）；編號只增不改，新素材接在後面，分類規則改了也不會換號。整句語音（比賽播報員）不收。遊戲裡 143 個會響的位置各有一個位置編號，格式 `P-WPN-001`（域：武器 WPN、命中與材質 HIT、角色 CHR、移動與腳步 MOV、機關與場景互動 ENV、介面 UIS、環境音 AMB、背景音樂 BGM），和素材編號一眼分得出來；包含每把武器的射擊、換彈、空槍、近戰、命中材質、敵人與玩家受擊死亡、腳步、機關、電話亭、介面、環境音，以及 22 首背景音樂。
位置清單文件（design/16-audio/PLACEMENTS.md）一個位置一列：位置、名稱、遊戲裡的位置、目前素材（素材編號）、預計使用（空白，使用者填）、手動放入（勾選）、備選素材（每個位置 30 個依類別與調查建議排序的備選，但可以填任何類別的編號）。素材清單文件（CATALOG.md）列出全部素材編號、時長、出處與目前用在哪些位置。重新產生文件時，使用者填的預計使用與勾選會保留。
填好預計使用的編號後執行套用工具：沒勾手動放入的位置會改寫加工清單、重建音訊與授權登記，勾了的位置不動；格式看不出編號、編號不存在、音樂位置填了多個編號都會指出來。預聽用小檔案（每個素材一個，同一套響度標準）由工具產生，不進版控；位置清單文件的讀寫也做成程式（只改那一格、寫前先重讀、外部改過會偵測），給實驗室與這份文件連動使用。
驗收：音效測試套件新增編號與目錄檢查（編號格式與唯一、素材與位置的編號不會互相誤認、目標存在、每個會響的音效與每首曲目都有位置、位置列出目前素材、搜尋、缺預聽檔不崩潰）與位置清單文件讀寫檢查（每個位置恰好一列、與登記相符、只改被編輯的那一列、外部修改會被偵測且不會被覆蓋、看不出編號與不存在的編號會被指出），共 5134 項通過。套用工具以模擬清單實測：填了編號的位置被改寫、勾了手動放入的略過、無法辨識的內容被指出。這張票是工具與資料，沒有畫面截圖。
