# [NE-163] 建立素材與位置的編號體系與位置清單

> 狀態：待辦

## 內文

### 需求
目前只有音效的名稱，沒辦法精確指著「遊戲裡的哪個位置」說要用「哪一個聲音」。要讓每個會響的位置與每個候選素材各自有永久不變的編號（兩套體系格式不同、不同種類前綴不同），建立素材目錄與位置登記，並維護一份給人編輯的位置清單文件，使用者填入想用的素材編號後可以一鍵套用。

### 來源
2026-10-04，使用者要求每個遊戲內的聲音位置與每個候選素材各自編號（兩套不同體系、不同種類用不同前綴）、每個位置至少十個備選、實驗室能跨類別挑選，並維護一份位置清單 md；設計見 `design/16-audio/DESIGN.md` 5.1 節。

### 驗收條件
- [ ] 每個已下載的 CC0 音訊檔都有全專案唯一、不重編的素材編號，格式依種類分前綴（槍聲、槍械操作、撞擊、爆炸、近戰、移動、人聲生物、機械、電子、介面、環境循環、音樂）
- [ ] 遊戲裡每一個會響的位置（槍聲、換彈、命中材質、角色受擊死亡、腳步、機關、介面、環境音、背景音樂各狀態）都有位置編號，格式與素材編號明顯不同
- [ ] 位置清單文件列出所有位置：編號、名稱、遊戲裡的哪裡用到、目前用哪些素材（素材編號）、預計使用（空白讓使用者填）、手動放入勾選
- [ ] 重新產生位置清單時，使用者已填的預計使用與勾選會保留
- [ ] 素材目錄的編號在新增素材後不變，新素材接在後面
- [ ] 預聽用小檔案（統一響度與長度）可由工具產生，重跑結果一致；不進版控
- [ ] 套用工具讀位置清單：預計使用有填、且沒勾手動放入的位置，依素材編號改寫加工清單並重建；勾了手動放入的位置不動
- [ ] 位置的目前素材能正確對應回素材編號（包含多層疊音、逐發切割的素材）
- [ ] 資料檢查能指出：位置引用不存在的素材編號、重複的編號、清單裡不存在的位置

### 測試流程
1. 執行產生工具，確認素材目錄與位置清單產生
2. 在位置清單某一格填入一個素材編號，重新產生，確認沒有被清掉
3. 執行套用工具，確認該位置的加工清單改成指定素材並能重建
