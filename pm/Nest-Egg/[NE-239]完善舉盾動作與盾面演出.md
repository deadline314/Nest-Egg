# [NE-239] 完善舉盾動作與盾面演出

> 狀態：待辦

## 內文

### 需求
將過小蓝色盾面改为合理、可读的角色前方弧面，補完整舉盾時序与受力回饋，強化防禦打擊感並忠实表达方向格挡。

### 來源
2026-10-10，使用者要求逐章完成與累積發行、高清像素UI、全流程手把、豐富合理敘事與動畫、場景減雜，並追加武器差異、子彈、方向護盾、可選連段升級與打擊感總驗收；一般設計選擇由實作者決定，持續推進。

詳見[整體設計](../../design/20-campaign-experience/DESIGN.md)與[研究依據](../../design/20-campaign-experience/RESEARCH.md)。

### 驗收條件
- [ ] 舉起、維持、普通受擊、完美反彈、破盾与收盾各有連續动作和可辨回饋。
- [ ] 盾面大小與角色姿態合理，方向／角度與真實防禦一致，背面不顯示不存在的全身保護。
- [ ] 左右面向、上下瞄準、不同武器、走／跳／落地时盾與腕／手臂相接，不漂浮或穿插。
- [ ] 衝擊显示在真实接触點，聲音、角色受力、盾量与反彈同步；普通／完美／破防明显不同而不堆閃光。
- [ ] 舉收動作不暗中改變既有完美窗口、連按縮短、能量与反射规则，结算不重复。
- [ ] 右鍵与手把同一防禦語義，亮暗與減動態仍可讀，盾面不蓋敵人或角色關鍵動作。

### 測試流程
1. 測窗口前／中／後、正面／背面與不同距离的攻击，核對方向和结果。
2. 逐武器與移動姿勢測舉盾／反彈／破防／收盾，核對聲音受力与真手把畫面。
