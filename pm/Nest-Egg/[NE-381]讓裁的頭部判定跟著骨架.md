# [NE-381] 讓裁的頭部判定跟著骨架

> 狀態：完成

## 內文

### 需求

在廠房戰瞄準裁的頭部時，子彈須命中看得見的位置。換邊與演出暫停沿用各自的戰鬥規則。

### 來源

第五章整合時重現第四章廠房頭目的左右兩種朝向都無法被打中頭部。

### 驗收條件

- [x] 左右朝向各一發瞄頭的實際子彈各造成一次普通傷害。
- [x] 中段演出接管時，命中頭部仍保護裁的生命值與劇情節奏。

### 測試流程

1. 左右面向各用一發實際手槍投射物瞄準裁的頭部。
2. 進入劇情暫停，重試並比對生命值。
3. 執行受影響戰鬥與章節測試。

# Commit-1

把裁的頭部受擊區掛在頭骨，左右轉身會一起移動。射中露在身體判定之外的可見頭部，會造成一次普通傷害。中段演出暫停仍保有生命保護。關卡索引換成同一份敵人資源的指紋。
