# [NE-160] 建立背景音樂系統

> 狀態：待辦

## 內文

### 需求
遊戲沒有背景音樂，設定選單也沒有音樂音量。要有獨立的音樂匯流排與音量設定、兩軌交叉淡化的串流播放、依關卡與狀態（平靜、戰鬥、頭目）切換、暫停與過場時的處理，所有曲目與對應都由資料指定。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [ ] 設定選單有音樂與環境音兩條音量滑桿，有 tooltip，音量存檔並在下次啟動套用
- [ ] 曲目串流播放，不整首載入記憶體
- [ ] 換曲目時交叉淡化，淡化時間由資料指定
- [ ] 進入戰鬥（附近有警戒中的敵人）切到戰鬥曲目，離開後延遲幾秒才切回，不會來回跳
- [ ] 頭目戰開始切頭目曲目，擊敗後切回；死亡與通關播短 sting
- [ ] 暫停與背包開啟時音樂變悶且變小，關閉後平滑還原
- [ ] 過場動畫期間音樂壓低
- [ ] 曲目遺失或格式錯誤時記錄具體位置並維持靜音，不崩潰
- [ ] 曲目、cue、對應表由資料指定，新增曲目不改程式
- [ ] 切換畫面與重新開始時不留下播放中的舊曲（無記憶體累積）

### 測試流程
1. 打開設定選單調整音樂音量，重開遊戲確認保留
2. 走進有敵人的地方，確認切到戰鬥音樂，清完後切回
3. 暫停遊戲確認音樂變悶，繼續後還原
