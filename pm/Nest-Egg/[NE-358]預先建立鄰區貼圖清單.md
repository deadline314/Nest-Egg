# [NE-358] 預先建立鄰區貼圖清單

> 狀態：完成

## 內文

### 需求

進區後鄰區貼圖的查詢只讀取已建立的路徑清單，避開主執行緒同步讀取鄰區關卡與資源。保留原有預載優先順序、渲染策略、記憶體上限和無清單時的備援。詳見[進場設計](../../design/20-campaign-experience/HUD_READING_SPACE.md#鄰區貼圖清單)。

### 來源

市集進區後前 0.13 秒會出現停頓。切換預載的原生對照將最長暖機影格從 72.6 ms 降到 24.4 ms。

### 驗收條件

- [x] 鄰區貼圖清單由正式資料生成，區域能沿用原預載佇列。
- [x] 兩組冷啟動原生對照中，市集首次移動的最長暖機影格降低。
- [x] 受影響測試通過。

### 測試流程

以當前基準與修復版交替進入市集，再到裝卸區與街道。用正式移動輸入記錄每區頭兩秒的暖機與後續影格，同時核對實際載入張數。用關卡索引工具驗證 32 個區域的候選與原資料一致。
