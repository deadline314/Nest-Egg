# [NE-382] 讓同一筆存檔共用關卡索引

> 狀態：完成

## 內文

### 需求

減少走過自動拾取物時，存檔在同一幀反覆列目錄的時間。

### 來源

NE-379 修正持續步行，沿用當舖文件路線量到剩餘卡頓。逐段計時可重現同筆存檔多次讀取關卡目錄。

### 驗收條件

- [x] 存檔每筆建立一次關卡索引檢視，已開啟的檢視保持一致，新存檔會辨識新增或移除的區域。
- [x] 主檔、備份和候選內容維持各自的驗證。存檔失敗仍可完整回復並重試。
- [x] 鎖定同一正式當舖路線比對幀時間，文件進入持有清單，玩家持續移動。

### 測試流程

1. 讀相同正式存檔，從同一座標走過當舖文件，量測寫入前後。
2. 模擬同一筆保存期間修改區域清單，檢查使用中的索引和下一筆怎麼讀取。
3. 試獨立通知寫入、直接改動、暫存拒絕以及檔案輪替失敗後的重試。
