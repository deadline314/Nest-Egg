# [NE-158] 換入受擊、材質、角色受傷死亡與爆炸音效

> 狀態：待辦

## 內文

### 需求
命中、材質回饋、敵人受擊與死亡、玩家受傷、爆炸都是合成音，所有敵人的受擊與死亡聽起來一樣。要換成 CC0 錄音素材，並讓機械類與生物類敵人的受擊與死亡聲不同。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [ ] 命中材質（肉、護甲、金屬、混凝土、玻璃、木、能量、通用）、跳彈、弱點、格擋、完美格擋、破防的聲音換成正式素材
- [ ] 每種材質聽起來能分辨
- [ ] 敵人的受擊與死亡依敵人類型有不同聲音（人形、機械、無人機、生物、頭目至少各有一組）
- [ ] 玩家受傷與死亡有專屬聲音，血量低時的受傷聲有變化
- [ ] 爆炸（小、大）、油桶、炸彈兵、迫擊砲換成正式素材
- [ ] 擊殺、清場、重擊的疊層與壓低效果仍然正常
- [ ] 新增敵人沒有登記聲音時使用預設而不是靜音

### 測試流程
1. 在音效實驗室依序播放每種材質與每種敵人的受擊與死亡
2. 預期：材質、敵人類型之間能分辨
3. 遊戲內打各類敵人確認
