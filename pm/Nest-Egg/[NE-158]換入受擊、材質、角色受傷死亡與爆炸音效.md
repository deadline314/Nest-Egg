# [NE-158] 換入受擊、材質、角色受傷死亡與爆炸音效

> 狀態：完成

## 內文

### 需求
命中、材質回饋、敵人受擊與死亡、玩家受傷、爆炸都是合成音，所有敵人的受擊與死亡聽起來一樣。要換成 CC0 錄音素材，並讓機械類與生物類敵人的受擊與死亡聲不同。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [x] 命中材質（肉、護甲、金屬、混凝土、玻璃、木、能量、通用）、跳彈、弱點、格擋、完美格擋、破防的聲音換成正式素材
- [x] 每種材質聽起來能分辨
- [x] 敵人的受擊與死亡依敵人類型有不同聲音（人形、機械、無人機、生物、頭目至少各有一組）
- [x] 玩家受傷與死亡有專屬聲音，血量低時的受傷聲有變化
- [x] 爆炸（小、大）、油桶、炸彈兵、迫擊砲換成正式素材
- [x] 擊殺、清場、重擊的疊層與壓低效果仍然正常
- [x] 新增敵人沒有登記聲音時使用預設而不是靜音

### 測試流程
1. 在音效實驗室依序播放每種材質與每種敵人的受擊與死亡
2. 預期：材質、敵人類型之間能分辨
3. 遊戲內打各類敵人確認

# Commit-1

## 內文

命中、材質回饋、敵人受擊與死亡、玩家受傷、爆炸全是合成短音，所有敵人受傷和死亡聽起來一樣。
現在命中聲（三個變體加尾音）、八種命中材質（肉、護甲、金屬、混凝土、玻璃、木、能量、通用）、跳彈、弱點叮聲、格擋、完美格擋、破防、擊殺重擊與爆炸都換成 CC0 錄音素材，每種有 3～5 個變體輪播且材質之間不共用檔案；爆炸分大小兩種，半徑小的（頭目死亡時的連環小爆）用小爆炸音。敵人依類型有各自的受擊叫聲與死亡：人形（呼喊、倒地）、機械（金屬撞擊、電路爆裂；無人機、砲台、監管者沿用）、生物（吼叫；電擊犬、偽裝箱、自爆蟲）；玩家有自己的受傷痛呼與死亡聲。受擊叫聲每隻敵人有 0.45 秒冷卻，衝鋒槍連發不會變成一串尖叫。新增敵人沒登記時，死亡仍有預設聲音。擊殺、清場、重擊的疊層與壓低效果維持不變。
同時發聲數的上限從 24 提高到 32、手感預算從 22 提高到 28：錄音素材比原本的合成短音長，同一場混戰同時在響的聲音變多（樣本戰鬥原本剛好壓在預算邊緣，換素材後超標）。
驗收：音效測試套件新增受擊與角色檢查（每種材質、跳彈、弱點與各事件的所有層都來自檔案、材質之間不共用檔案、人形／機械／生物的死亡事件不同、無人機與頭目沿用機械類、玩家與敵人叫聲不同、每種敵人都有聲音設定、受擊叫聲的冷卻），共 1499 項通過，連同手感套件 2120 項（1 項為與 main 相同的既有失敗）。完整測試套件 9513 項中的 11 項失敗與沒有這次改動的 main 完全相同。這張票是聲音，沒有畫面截圖。
