# [NE-385] 縮短對話結果寫入前的驗證

> 狀態：完成

## 內文

### 需求

劇情增加後，完成同一段對話仍應花接近的時間，並保留存檔及重試結果的一致性。

### 來源

玩家回報對話和互動的卡頓，以及 2026-11-26 較大劇情的結算量測。

### 驗收條件

- [x] 真實 NPC 對話在等價存檔下重複結算的中位耗時下降。
- [x] 使用中的選項、分派、角色、請求被更改時，保留原存檔或進入既有已寫入復原流程。
- [x] 無關對白可獨立變更，深層合法條件可以完成，舊晚餐與診所流程維持可續玩。

### 測試流程

1. 等價存檔下重放當舖物件的真實對話。
2. 分別模擬寫入前、提交後的內容變動，對照存檔與活躍等待者。
3. 重走晚餐拒絕與重試、初次死亡的診所流程。
