# [NE-42] 加入主角旁的動態彈匣介面

> 狀態：待辦

## 內文

### 需求
彈藥目前是準星旁的弧線與數字。改成主角身旁一排排子彈圖示，隨射擊、換彈、彈量變化即時反應，閒置時淡出。

### 來源
2026-10-03，使用者於開發對話中提出：「子彈可以的話就用高解析度的Icon來代替，然後用dynamic ui放在主角旁邊」；「這些都可以去看看目前業界有哪一些最佳實例可以參考，我們盡可能設計的貼近完整實際的 Demo」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 主角身旁（與準星相反的一側）顯示彈匣：每排最多 10 發，滿匣是彩色圖示，用掉的是輪廓
- [ ] 開槍時最上面一發的彈殼彈出並淡出；換彈時依序填回去，節奏與換彈時間一致
- [ ] 彈量不到四分之一時圖示變紅並脈動；空匣整排變輪廓並出現換彈按鍵提示
- [ ] 換武器時整排圖示換成新的彈種；能量武器顯示電池格
- [ ] 超過 30 發的彈匣用一顆代表多發並標示倍率；備彈以小數字顯示，無限備彈顯示符號
- [ ] 閒置一段時間後淡出，射擊、換彈、彈量變化、換武器、低彈量時彈出或常駐
- [ ] 不遮擋瞄準，跟隨主角平滑移動不抖動
- [ ] 準星保留換彈進度弧；不造成每影格的配置

### 測試流程
1. 連射一整匣，確認每發的動畫與低彈量
2. 換彈，確認依序填回
3. 換成每一種武器，確認彈種與排列
4. 執行完整測試套件，全部通過
