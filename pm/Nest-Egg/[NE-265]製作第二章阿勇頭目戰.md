# [NE-265] 製作第二章阿勇頭目戰

> 狀態：待辦

## 內文

### 需求
第二章的頭目阿勇要有自己的打法，並且能接上劇本的「永久解除或保留父女連結」兩條路。阿勇是收帳人的頭，用鐵棍近身對決，戰中會疊「利息」標記；血量到門檻時退到終端前，遊戲安全暫停讓玩家選擇；斷連路要玩家親手操作主隔離箱再制伏，保留路會先真正死亡、復原一次，第二階段更慢、更重、匣蓋閉不上。兩路最後都是活著被制伏，不是被殺。

詳細打法、提示與每條路的結果見 `design/13-story-v2/SCRIPT_CH02.md` 的 S11～S13，故事端的接點見 `design/13-story-v2/CH02_IMPLEMENTATION.md`。

### 來源
2026-10-11 故事主線 Session 落地第二章（ST-19）時拆出；頭目戰設計原則見 NE-253（每個頭目有獨立機制）。敵人與頭目屬於戰鬥 Session。

### 驗收條件
- [ ] 鐵棍蓄力重擊有約 0.8 秒的預兆，可閃可擋，撲空時有反擊空檔；慢速紙頁扇形可以跳過；同屏最多兩名小弟，第二階段不再增援
- [ ] 「利息」標記每受擊疊一層、最多五層、每層讓下一擊多 10% 傷害；踩亮著的「結帳」地墊或 6 秒未受擊會清除，圖示與地墊白框看得出層數
- [ ] 血量到 25% 時阿勇退到終端前，戰鬥安全暫停（敵人不會在暫停中出手），由故事端播出選擇說明；選擇沒有倒數，可以返回
- [ ] 斷連路：玩家到主隔離箱操作約 1.5 秒（受擊會中斷、未完成不算），成功後阿勇的血量條改成「制伏進度」，打斷棍柄鎖扣後以互動拔出儲能匣完成制伏；全程沒有死亡與復原
- [ ] 保留路：第一階段最後一擊讓阿勇真正倒下並復原一次（只一次），第二階段動作較慢、單擊較重、匣蓋閉不上；鷺關上維修暫停閂之後才改成「制伏進度」，同樣以拔匣完成制伏
- [ ] 戰鬥的階段與結果寫進故事旗標（斷連選擇、連結解除、阿勇復原一次、制伏完成），重試從正確的階段開始：斷連成功後不會回到保留，保留路的復原不會因凜死亡重試而再發生一次
- [ ] 小薇所在的高臺隔間不是攻擊目標，子彈與爆炸穿不過去
- [ ] 鍵鼠與手把都能打完；普通難度不靠刷錢可通過，附實際戰鬥的連續畫面

### 測試流程
1. 從第二章帳房前室進入戰鬥，各走一次斷連路與保留路到制伏
2. 兩條路各在第二階段死亡一次再重試，確認階段、旗標與小薇的讀取次數都沒有重複
