# [NE-101] 特效升級（二）：玩家、環境與全面檢查

> 狀態：待辦

## 內文

### 需求
NE-95 做完了敵人與爆炸、命中、槍口。還沒升級的：玩家子彈的飛行與拖尾、格擋與完美反彈、衝刺殘影、近戰揮砍與終結技、義體能力與重生、拾取與補給，以及環境特效（雨、蒸汽、火花、霓虹閃爍）。原則：合理且順暢、粒子克制，不誇張（數量與強度由 `Fx` 的三個克制係數統一調整）。最後在所有光影設定下檢查不過曝、不被泛光吃掉，並實際玩一輪調整 NE-95 的強度與時機。

### 來源
2026-10-03～04，使用者在敵人與 NPC 重畫的討論中提出；設計見 `design/12-cast-redraw/CREATURES.md`、`ANIMATION.md`。

### 驗收條件
- [ ] 玩家子彈：飛行拖尾與命中，各武器自己的槍口與彈道風格，克制不誇張
- [ ] 格擋、完美反彈、衝刺殘影、近戰與終結技、義體能力、重生與拾取的特效升級
- [ ] 環境特效（雨、蒸汽、火花、霓虹閃爍）升級，不干擾可讀性
- [ ] 所有光影設定下不過曝；同屏多個爆炸時效能不下降
- [ ] 實際玩一輪調整 NE-95 的強度與時機

### 測試流程
1. 執行特效相關截圖情境
2. 各光影設定下檢查
3. 玩一輪第一章與第二章
4. 單獨執行特效相關測試
