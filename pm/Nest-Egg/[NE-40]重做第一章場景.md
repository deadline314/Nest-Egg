# [NE-40] 重做第一章場景

> 狀態：待辦

## 內文

### 需求
第一章的地圖是色塊，看不出是屋頂、夜市、貨運站還是設施。需要用環境元件重做六個區段的美術與地圖，做成「像一個真的地方」。

### 來源
2026-10-03，使用者於開發對話中提出：「把第一關的地圖設計的更實際一點，最好是用高解析度的元件來替代掉現在的色塊設計」；「這些都可以去看看目前業界有哪一些最佳實例可以參考，我們盡可能設計的貼近完整實際的 Demo」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 屋頂巷弄、霓虹市集、貨運站、設施入口、停電走廊、頭目機庫六個區段，各有對應的材質、立面與道具
- [ ] 加入更多垂直結構（逃生梯、疊起來的貨櫃、屋頂之間的高低差），地圖仍通過可通行檢查，每個檢查點站得穩
- [ ] 可以站的地方看得出來可以站，單向平台有明顯的邊緣
- [ ] 裝飾不遮住敵人、子彈與危險物
- [ ] 麵攤、工人休息室等對話點有對應的場景物件
- [ ] 暗場可讀性量測每個區段都通過
- [ ] 原有的教學、敵人配置、檢查點、劇情觸發點與收集品功能不變

### 測試流程
1. 從頭到尾玩一遍第一章，確認每個區段的外觀與路線
2. 執行暗場可讀性量測
3. 截圖比較重做前後
4. 執行完整測試套件，全部通過
