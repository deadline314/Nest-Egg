# [NE-278] 交談與閱讀時主角收起武器

> 狀態：待辦

## 內文

### 需求
和人物說話、讀標籤或文件、操作交接櫃這類地圖上的互動開始後，凜仍舉著槍朝前瞄準，準星也留在畫面中間，看起來像在拿槍指著對方或物件。互動期間應該收起武器、放下手、隱藏準星，互動結束再恢復原本拿著的武器；電話亭（NE-121）已經這樣做，其他互動要一致。

### 來源
2026-10-11，故事 Session 用第一章流程探針（軟體 Vulkan）檢查 ST-9 畫面時發現：讀懷錶標籤、交接櫃保留摘要時凜都在瞄準。

### 驗收條件
- [ ] 地圖上的交談、閱讀與物件互動（疊在地圖上的對話與選擇）開始後，凜收起槍或近戰武器、呈自然站姿，準星隱藏；結束後恢復原本的武器與準星
- [ ] 互動中切換鍵盤、滑鼠與手把不會讓槍或準星重新出現
- [ ] 戰鬥中被打斷或互動被取消時，武器狀態正確恢復，不卡在收起或舉起
- [ ] 舞台過場（切換成場景立繪的那種）不受影響
- [ ] 第一章交接櫃、四張標籤、阿梨與燈的互動各附修前修後截圖

### 測試流程
1. 拿著槍走到懷錶標籤前按互動，確認凜放下槍、準星消失
2. 讀完關閉，確認槍與準星恢復
3. 對交接櫃、燈的耳機重複一次；互動中換成手把再確認
4. 執行受影響範圍測試
