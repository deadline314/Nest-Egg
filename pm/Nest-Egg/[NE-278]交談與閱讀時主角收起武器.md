> 狀態：進行中

## 內文

### 需求
和人物說話、讀標籤或文件、操作交接櫃這類地圖上的互動開始後，凜仍舉著槍朝前瞄準，準星也留在畫面中間，看起來像在拿槍指著對方或物件。互動期間應該收起武器、放下手、隱藏準星，互動結束再恢復原本拿著的武器；電話亭（NE-121）已經這樣做，其他互動要一致。

### 來源
2026-10-11，故事 Session 用第一章流程探針（軟體 Vulkan）檢查 ST-9 畫面時發現：讀懷錶標籤、交接櫃保留摘要時凜都在瞄準。

### 驗收條件
- [x] 地圖上的交談、閱讀與物件互動（疊在地圖上的對話與選擇）開始後，凜收起槍或近戰武器、呈自然站姿，準星隱藏；結束後恢復原本的武器與準星
- [ ] 互動中切換鍵盤、滑鼠與手把不會讓槍或準星重新出現（鍵鼠與合成裝置切換回歸通過；實體手把保留本機原生驗收）
- [x] 戰鬥中被打斷或互動被取消時，武器狀態正確恢復，不卡在收起或舉起
- [x] 舞台過場（切換成場景立繪的那種）不受影響
- [x] 第一章交接櫃、四張標籤、阿梨與燈的互動各附修前修後截圖

### 測試流程
1. 拿著槍走到懷錶標籤前按互動，確認凜放下槍、準星消失
2. 讀完關閉，確認槍與準星恢復
3. 對交接櫃、燈的耳機重複一次；互動中換成手把再確認
4. 執行受影響範圍測試

# Commit-1

## 內文

交談、閱讀標籤及查看交接櫃時，原本凜仍舉槍瞄準。現在開始地圖互動就收起槍或近戰武器、放下手並隱藏準星，槍燈與刃光也一起收起；離開或取消後恢復當下真正裝備的武器。閱讀中切換輸入裝置或更新裝備，不會提前把武器顯示回來。

受傷會中止閱讀並回到戰鬥，死亡、離場與換關不留下收起狀態；新玩家不會再被舊的準星狀態干擾。搬著物件時保留雙手支撐，不讓箱子浮空。電話亭話筒及獨立舞台演員維持原有動作。阿梨的地圖比較使用夜攤晚餐後回訪，初見舞台另外對照。

2026-10-17 使用官方 Godot 4.7、Forward+／軟體 Vulkan llvmpipe，以真實地圖人物與物件入口驗證；故事進度與裝備由明示樣本準備。這是程式化回歸及軟體渲染畫面，不代表整章人工通關、硬體 GPU 或實體手把驗收。狀態保留進行中，實體裝置項不代勾。
