# [NE-306] 將診斷輸出預設留在本機

> 狀態：完成

## 內文

### 需求

場景舞台、震波圈和武器平衡工具直接啟動時，把結果存到 Godot 的使用者資料夾。一般檢查只留下固定檔名的最新輸出。需要進票或保留某一輪時，可用原有的輸出參數指定位置。

### 來源

2026-11-23 使用者要求節省 pm 與專用驗收磁碟的空間，只保留必要輪次。

### 驗收條件

- [x] 三個工具使用固定的本機預設路徑，正常完成後列出實際位置。
- [x] 指定輸出位置仍可建立資料夾與寫檔。無法建立路徑時報出位置並以失敗結束。
- [x] 檢查三個本機預設與三個指定路徑，兩輪各自可寫。沒有新增或改寫 pm 檔案。
- [x] 既有原始證據保留規則沿用，正式附件按交付需求保存。

### 測試流程

在隔離的 Godot 使用者目錄各跑一次預設與指定路徑。檢查兩份場景圖、兩份特效圖、兩份有實際命中樣本的 JSON，並確認存檔位置。再以相同工具驗證輸出路徑受阻、未知舞台、缺少繪圖環境。

---

# Commit-1（預設輸出留在本機）

12 項驗證全過，其中四輪使用 RX 9070 XT Forward+ 擷取原生畫面。兩輪武器量測各跑一個真實近戰樣本，結束前等待音訊釋放，避免工具輸出後仍有資源未回收。其餘檢查確認工具在環境或路徑不合時回報原因。受影響測試選擇器確認三支診斷工具未進入遊戲套件。
