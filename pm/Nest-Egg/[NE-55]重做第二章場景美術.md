# [NE-55] 重做第二章場景美術

> 狀態：待辦

## 內文

### 需求
第二章的地形與牆面同樣是色塊。套用環境元件，讓升降井、夾層區、電力室、轉運站各有自己的材質與道具。

### 來源
2026-10-03，使用者於開發對話中提出：「把第一關的地圖設計的更實際一點，最好是用高解析度的元件來替代掉現在的色塊設計」；「幫我做完整的第二關」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 升降井、夾層區、電力室、轉運站、頭目場地各用一組材質、立面與道具
- [ ] 電力室的設備、轉運站的病床與護理站、夾層區的住宅與走廊都有對應的場景物件
- [ ] 可以站的地方看得出來；裝飾不遮擋敵人、子彈與危險物
- [ ] 暗場可讀性量測每個區段都通過
- [ ] 原有的機關、可破壞物、收集品、檢查點與劇情觸發功能不變

### 測試流程
1. 從頭玩到尾，確認每個區段的外觀
2. 執行暗場可讀性量測
3. 執行完整測試套件，全部通過
