# [NE-76] 新增切割者與迷彩獵手的人形外觀

> 狀態：待辦

## 內文

### 需求
切割者（slasher）與迷彩獵手（stalker）。目前是程式畫的暫代圖（或整隻用程式直接畫），要和凜一樣精細：由 Qwen 畫出透明背景的側面全身圖，再依這個角色自己的骨骼分成零件，裝甲做成獨立零件，受傷時逐片脫落。兩者目前整隻用程式直接畫，沒有骨架外觀；要新增兩個人形外觀並改用骨架，原本由程式畫的蓄力、撲擊、現形與隱形等表現要在骨架上保留。

外觀設定：切割者：低伏瘦長，一隻手臂是刀刃，面罩下紅色視覺線；迷彩獵手：貼身光學迷彩服、半透明斗篷般衣襬、洋紅單眼
比例：切割者瘦、約 6.5 頭身、前傾、身高約 52；迷彩獵手修長、約 7.5 頭身、身高約 56　發光色：紅（切割者）、洋紅（迷彩獵手）。

### 來源
2026-10-03，使用者在凜（NE-17、NE-68～72）完成後要求重畫敵人與其他 NPC、精細度與凜一致、敵人依各自骨骼分件、可以的話替 NPC 加動畫；並確認先做人形、每個敵人有自己的比例、所有 NPC 都做、芽當成可操控角色設計。設計見 `design/12-cast-redraw/DESIGN.md`。

### 驗收條件
- [ ] 外觀符合設定（切割者：低伏瘦長，一隻手臂是刀刃，面罩下紅色視覺線；迷彩獵手：貼身光學迷彩服、半透明斗篷般衣襬、洋紅單眼）
- [ ] 比例是這個角色獨有的（切割者瘦、約 6.5 頭身、前傾、身高約 52；迷彩獵手修長、約 7.5 頭身、身高約 56），與其他敵人並排時能一眼分辨
- [ ] 零件圖由定稿立繪切出，放大 2 倍看沒有多餘線條、碎片、拼貼感或色塊，邊緣沒有點狀亮邊
- [ ] 裝甲（肩甲、胸甲、護臂、護膝等，依角色而定）是獨立零件，依生命比例逐片脫落噴飛，底下的身體完整，生命 100% 時外觀與完整立繪一致
- [ ] 預覽的八種動作（待機、跑、瞄準、蹲、跳、格擋、硬直、倒下）關節沒有露縫或錯位，手持武器位置自然、槍口位置正確
- [ ] 發光部位（依設定）附上對應的發光層，位置與新圖一致
- [ ] 遊戲內身高與碰撞框相稱（頭探出碰撞框的程度與其他敵人相近），受擊判定位置與畫面沒有明顯差距
- [ ] 遊戲內的預兆、受擊閃白、死亡與掉落表現沿用原本的，沒有壞掉；在該敵人出現的關卡光影下清楚可辨
- [ ] 切割者蓄力時蹲伏、刀臂舉到身後，撲出時刀臂前伸，刀刃發光，頭上驚嘆號預兆仍清楚
- [ ] 迷彩獵手的隱形、受光或開火時現形的透明度變化套用在整個外觀上，沒有零件各自露出來
- [ ] 兩者的敵人資料改為掛骨架外觀，原有的行為與數值不變
- [ ] 附預覽（站姿特寫、八種動作、裝甲脫落各階段）與遊戲內截圖

### 測試流程
1. 依 `design/03-art-pipeline/CHARACTER_PIPELINE.md` 以配方與規格重新產生，確認零件、角色定義、法線都正確
2. 預覽站姿特寫、頭部放大、八種動作與裝甲脫落階段
3. 進入該敵人出現的關卡，與它交戰，確認預兆、受擊、裝甲脫落、死亡
4. 觀察切割者的蓄力與撲擊、迷彩獵手的隱形與現形
