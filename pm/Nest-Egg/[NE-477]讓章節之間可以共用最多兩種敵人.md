# [NE-477] 讓章節之間可以共用最多兩種敵人

> 狀態：完成

## 內文

### 需求
章節名單的檢查規定一種敵人只能屬於一章，所以天穹保全不能同時出現在第三章（辦公、閘門）與第四章（廠房），雖然兩章都是天穹的地盤。這條規則來自使用者 2026-10-03～04 的要求「跨章最多一至兩種重複敵人」（NE-97），但檢查做成了一種都不能重複，比使用者要的更嚴。改成使用者原本的說法：
- 任兩章之間最多共用兩種敵人
- 共用的要在名單裡寫明：哪一種、哪兩章、為什麼兩章都合理
- 每章仍然要有只屬於自己的敵人
- 共用的不能是該章的主力

地圖線在等這張才能把天穹保全同時放進第三、四章。

### 來源
2026-11-28，主 session 依 NE-474 的建議決定：「『一種敵人只屬於一章』照你的建議放寬……請你改檢查與 chapter_rosters.json 的格式。」原始規則見 NE-97。

### 驗收條件
- [x] 名單格式有一個地方可以寫共用：敵人、兩個章節、原因
- [x] 檢查：沒寫明的跨章重複、超過兩種、沒寫原因、某章沒有自己的敵人、共用的是該章擺放最多的敵人，都會被抓出來
- [x] 舊開發關卡的示範名單不算進跨章規則
- [x] 現在的名單照舊通過；用假名單確認每一種違規都抓得到
- [x] 盤點文件與章節名單設計文件寫明新規則與它的來源

### 測試流程
1. 在名單的共用欄寫一筆天穹保全（第三章與第四章），兩章的名單都加上牠
2. 預期檢查通過；拿掉共用那一筆，預期檢查報出沒寫明的重複

# Commit-1

## 內文

章節名單的檢查原本讓每種敵人只能屬於一章，比使用者「跨章最多一至兩種重複敵人」的要求更嚴，天穹保全放不進兩章天穹的地盤。
名單頂層多了「共用」清單：每一筆寫一種敵人、兩個章節、為什麼兩章都合理。檢查改成：正式名單（含保留名單）裡出現在兩章的敵人一定要在共用清單寫明；任兩章最多共用兩種；每章至少一種自己的敵人；共用的不能是該章擺放最多的敵人。舊開發關卡的示範名單不算。現在的名單沒有任何共用，照舊通過。
用假名單逐項確認：兩種寫明的共用通過；沒寫明、沒寫原因、第三種共用、共用的變成主力、某章沒有自己的敵人，各自都會被報出。盤點文件「擺放前要知道」與章節名單設計文件更新成新規則並寫明來源。
地圖線要把天穹保全放進第四章時，第四章還沒有名單，要先加第四章的章節資料。
