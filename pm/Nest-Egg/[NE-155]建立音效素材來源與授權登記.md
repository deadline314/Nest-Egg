# [NE-155] 建立音效素材來源與授權登記

> 狀態：完成

## 內文

### 需求
專案沒有任何音訊素材。要找出可以放心使用的 CC0 音效與音樂來源，建立可重跑的抓取與轉檔流程，並登記每個素材包的作者、授權與網址，之後換入音效時不用再回頭查來源。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [x] 只收 CC0 的素材包，每個包有作者、授權、頁面網址、下載網址的登記
- [x] 原始下載檔不進版控，重跑抓取工具能重新取得
- [x] 轉檔工具輸出統一規格（音效單聲道、音樂立體聲，統一響度與峰值），重跑結果一致
- [x] 清單內有任何一個來源下載失敗時只記錄、不中斷其他項目
- [x] 授權登記能對應到遊戲內每一個音訊檔（查得到它出自哪個包）
- [x] 涵蓋槍械、命中、爆炸、近戰、腳步、角色、機關、介面、環境與音樂的素材都找得到來源，找不到的類別在登記中列為缺口

### 測試流程
1. 執行抓取工具，確認原始檔下載到忽略版控的資料夾
2. 執行轉檔工具，確認輸出規格與響度一致
3. 隨機抽一個遊戲內音訊檔，能在授權登記查到作者與授權

# Commit-1

## 內文

專案沒有任何音訊素材，也沒有辦法追溯素材從哪來。
現在有一份來源目錄（296 個 CC0 素材包：Kenney 的音效包、OpenGameArt 的槍聲、命中、爆炸、腳步、環境音、介面音與 143 首音樂），每筆記錄作者、頁面網址、下載連結；抓取工具依目錄下載到不進版控的資料夾，已下載的略過，單項失敗只記錄、不影響其他項目（實測：刪掉一個包重抓得到逐檔相同的內容；混入一個壞連結，其餘照常完成）。加工工具依加工清單把原始檔轉成統一規格——音效單聲道、有聲部分響度一致、峰值不超過 -1 dBFS、自動取第一發槍聲並淡出；音樂立體聲、整合響度一致——重跑得到逐位元相同的輸出，並自動更新音效庫與授權登記，只登記實際用到的素材包與檔案。另有看素材特徵的工具輔助挑檔案、素材來源說明文件（各類別對應的素材包與缺口）和操作手冊。
缺口已列在說明文件：電話撥號與話筒聲、真正的跳彈聲、軌道砲與發射器的專屬錄音、火焰噴射持續音、機械損壞專用錄音、販賣機與人群低語、較重的衣物聲，這些會在換入音效的票上用相近素材加工處理。
驗收：音效測試套件新增來源目錄與授權檢查（每個素材包都是 CC0 且記錄作者、頁面、下載連結；授權登記的包都在目錄裡；音效庫的 pack 都在授權登記；遊戲內每個音訊檔都有被引用），共 819 項通過。這張票是工具與資料，沒有畫面截圖。
