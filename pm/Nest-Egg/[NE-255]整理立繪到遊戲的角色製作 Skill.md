# [NE-255] 整理立繪到遊戲的角色製作 Skill

> 狀態：進行中

## 內文

### 需求
主角骨架與立繪（特別是 NE-222）累積了很多經驗，但散在票、交接文件與多份 Skill 裡。要整理成一套完整的 Skill，涵蓋從生成立繪一路到放進 Godot 的全部流程，之後要生成任何新角色或新姿勢都能照同一套做法，不再重新摸索。這套流程必須能解決三類反覆出現的問題：破圖、零件組合後邊緣稜稜角角、立繪上出現奇怪的東西。

### 來源
使用者 2026-10-11：「目前在設計主角的骨架跟立繪的部分，特別是 NE-222，我希望最後可以整理一套 Skill，包含完整的從立繪一路到放進 godot 的流程……務必要解決像是破圖、元件組合起來之後稜稜角角的，或是模型立繪會有一些奇怪的東西」。

### 驗收條件
- [x] Skill 涵蓋完整流程：來源與姿勢規劃、生成、透明與人體檢查、取骨架、分件與補底層、解析度與重組、綁定、全動作檢查、操作手感、原生畫面與效能、交付
- [ ] 破圖、組合後稜角、立繪怪東西三類問題各有：成因、怎麼提早發現、怎麼修、不能用的掩蓋做法，並附 NE-222 等票的實際前後例子
- [x] 每一關有明確的通過與退回條件，退回時回到哪一關寫清楚
- [x] 內容以實際做成功的做法為準；試過失敗的做法列為反例，不寫成建議
- [ ] 用這份 Skill 從頭做一個新的角色或新姿勢，全程不需要回頭查舊票，成品通過同一套驗收
- [ ] 舊的重複內容整併或改為連結，三處共用 Skill 副本內容一致

### 測試流程
1. 開新對話，只說「幫我做一個新角色放進遊戲」
2. 預期自動讀到這份 Skill，並照流程做到通過驗收

# Commit-1

## 內文

角色從立繪到進遊戲的做法散在很多張票、交接文件與兩份 Skill 裡，每次做新角色都要回頭翻。

現在有一份入口 Skill「從立繪到放進 Godot」：九關照順序走（決定做什麼、畫立繪、產生規格、建置、看底層圖與零件、引擎內近拍、逐格接點稽核、接到遊戲、測試與交付），每一關寫了要看什麼、沒過回到哪一關；最前面是破圖、組合後稜角、立繪怪東西三類問題的總表；最後一節是四足與其他非人形的做法。逐項案例（成因、怎麼提早發現、修法、不能用的掩蓋做法）放在累積筆記裡，Skill 連過去。內容都來自這次實際做過的角色：凜的遊戲內外觀、鷺、阿梨、燈、清掃兵、兩種收帳人與看門狗；試過不行的做法（走姿當來源、手寫規格、太多裝飾的提示詞）寫成反例。

還沒做的：

- 「用這份 Skill 從頭做一個新角色、全程不查舊票」還沒有用新對話實測。
- 三類問題的案例在累積筆記裡有成因與修法，但前後對照圖分散在 NE-222、NE-218 的票上，還沒有整理進同一份。
- 舊的兩份角色 Skill 還有重複的段落沒有整併。

### 測試結果

| 項目 | 結果 |
|---|---|
| 文件檢查 | 兩處 Skill 副本內容相同；Skill 裡提到的工具與檔案路徑都存在 |
| 遊戲測試 | 只有文件，沒有受影響的遊戲測試 |
