# [NE-255] 整理立繪到遊戲的角色製作 Skill

> 狀態：待辦

## 內文

### 需求
主角骨架與立繪（特別是 NE-222）累積了很多經驗，但散在票、交接文件與多份 Skill 裡。要整理成一套完整的 Skill，涵蓋從生成立繪一路到放進 Godot 的全部流程，之後要生成任何新角色或新姿勢都能照同一套做法，不再重新摸索。這套流程必須能解決三類反覆出現的問題：破圖、零件組合後邊緣稜稜角角、立繪上出現奇怪的東西。

### 來源
使用者 2026-10-11：「目前在設計主角的骨架跟立繪的部分，特別是 NE-222，我希望最後可以整理一套 Skill，包含完整的從立繪一路到放進 godot 的流程……務必要解決像是破圖、元件組合起來之後稜稜角角的，或是模型立繪會有一些奇怪的東西」。

### 驗收條件
- [ ] Skill 涵蓋完整流程：來源與姿勢規劃、生成、透明與人體檢查、取骨架、分件與補底層、解析度與重組、綁定、全動作檢查、操作手感、原生畫面與效能、交付
- [ ] 破圖、組合後稜角、立繪怪東西三類問題各有：成因、怎麼提早發現、怎麼修、不能用的掩蓋做法，並附 NE-222 等票的實際前後例子
- [ ] 每一關有明確的通過與退回條件，退回時回到哪一關寫清楚
- [ ] 內容以實際做成功的做法為準；試過失敗的做法列為反例，不寫成建議
- [ ] 用這份 Skill 從頭做一個新的角色或新姿勢，全程不需要回頭查舊票，成品通過同一套驗收
- [ ] 舊的重複內容整併或改為連結，三處共用 Skill 副本內容一致

### 測試流程
1. 開新對話，只說「幫我做一個新角色放進遊戲」
2. 預期自動讀到這份 Skill，並照流程做到通過驗收
