# [NE-29] 製作第二章頭目

> 狀態：待辦

## 內文

### 需求
第二章需要一個與監管者風格不同的頭目。設計見 `design/09-content/DESIGN.md` 第二節。

### 來源
2026-10-02，使用者於開發對話中提出：「讓遊戲內容更豐富」；確認四個方向都要做（第二章／新關卡、新敵人與新頭目、場景互動與探索、成長系統），順序為先光影再內容。

### 驗收條件
- [ ] 頭目至少兩個階段，每個招式都有明確預兆，並在暗處看得清楚
- [ ] 有登場過場、頭目血條與擊敗後的結尾演出
- [ ] 有對應的敗北圖鑑卡片與攻略
- [ ] 風格與機制和監管者明顯不同
- [ ] 輔助、標準、硬核三種難度都能通關

### 測試流程
1. 進入頭目戰，確認登場過場與血條
2. 逐一觀察每個招式的預兆與應對
3. 三種難度各打贏一次
4. 執行完整測試套件，全部通過
