# [NE-391] 把拾取物的厚白框改成貼合輪廓的微光

> 狀態：待辦

## 內文

### 需求
地上的拾取物外面包著一圈厚厚的淺色外框，像貼紙的白邊，和場景的光影沒有關係。這張票把外框改成貼著物品輪廓的細微光，平常低調、玩家靠近時才明顯。

### 來源
2026-11-27，使用者貼出教學看板的截圖（青色方框加驚嘆號），指出所有方方框框的東西，不管是介面還是場景裡的，看起來都不精緻，要求更貼合遊戲美術與世界觀。設計見[畫面活化與融入](../../design/22-living-scenes/DESIGN.md)的「方框告示與介面面板」，研究依據見[研究](../../design/22-living-scenes/RESEARCH.md)。

### 驗收條件
- [ ] 拾取物的外框改成貼合輪廓的細微光，寬度明顯比修前細；遠處看到的是物品本身，不是一圈白框
- [ ] 玩家靠近到可以撿的距離時微光變亮並緩慢脈動，離開後回到低調狀態；「減少閃光」開啟時不脈動
- [ ] 暗場景與亮場景裡拾取物仍然找得到（既有的拾取物可讀性檢查通過）
- [ ] 武器、消耗品、劇情物品三類拾取物都套用，附三類的修前修後截圖
- [ ] 不增加每影格配置；受影響範圍的測試全過

### 測試流程
1. 進第一章街道，從遠處看地上的武器與補給
2. 預期看到物品本身與一圈細微光，沒有厚白框
3. 走近到可以撿的距離，預期微光變亮並脈動
