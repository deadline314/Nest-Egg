# [NE-52] 製作第一章過場動畫

> 狀態：待辦

## 內文

### 需求
第一章的開場、頭目登場與結尾目前只有黑底頭像。依分鏡製作成有畫面與演出的過場動畫，並加上片頭。

### 來源
2026-10-03，使用者於開發對話中提出：「幫我設計一些動畫跟轉場進去，還有過場動畫，就交給你設計了，發揮你的想像力」；「完善目前的劇情設計，整體起承轉合可以參照邊緣行者、尼爾之類類似宿命論這種」「劇情最好要有暗線、伏筆等等更有深度的設計」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 片頭（C0）：氣象預報、城市到塔的鏡頭、標題
- [ ] 開場（C1）：老 K 的舖子，數錢、航的咳嗽與哼歌、老 K 摸右臂、遞委託單、芽的聲音、出門
- [ ] 頭目登場（C2）：機庫、紅燈、監管者轉身、標題卡
- [ ] 結尾（C3）：終端與全像、掃描 62%、晶片捏裂、凌晨 3:12 雨停、沉默
- [ ] 右臂雜訊（C8）
- [ ] 每段演出可略過、不重播、台詞通過劇本檢查，並與劇本文字一致

### 測試流程
1. 從新遊戲看完片頭與開場
2. 玩到頭目與結尾，確認演出
3. 中途略過每一段，確認狀態正確
4. 執行完整測試套件，全部通過
