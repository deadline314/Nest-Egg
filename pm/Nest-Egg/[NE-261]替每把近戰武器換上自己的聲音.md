# [NE-261] 替每把近戰武器換上自己的聲音

> 狀態：待辦

## 內文

### 需求
五把近戰武器的揮動與命中共用幾個一般的刀劍聲，聽不出是發熱的刀、帶電的戟還是液壓的錘。使用者要近戰的音效也換掉。

### 來源
2026-10-11，使用者看完場景與光影那批票之後提出（原話整理在 `pm/user_guide.md` 的「光影要從光源出發，近戰武器要換一批」）。設計與查到的資料見 [光源驅動的光影](../../design/08-lighting/LIGHT_SOURCES.md)。

### 驗收條件
- [ ] 每把武器有自己的揮動聲與命中聲，閉著眼睛分得出五把；重的招式比輕的招式低沉、長
- [ ] 每把武器拿在手上時有很小聲的待機聲（熱刃的低嗡、戟的電弧、鞭的細鳴…），不蓋過腳步與環境音，收起武器就停
- [ ] 連段的每一段聲音略有不同，最後一段最重；揮空不播命中聲
- [ ] 命中不同材質（人、機械、盾）聽得出差別，沿用既有的命中材質分類
- [ ] 所有新聲音來源都是 CC0，授權逐檔登記；素材檢查通過
- [ ] 音量在設定的音效滑桿下和槍聲平衡：近戰聲不比同場的槍聲大
- [ ] 附一段原生錄下來的五把武器各打一輪連段的聲音，或聲音實驗室的截圖與波形

### 測試流程
1. 在聲音實驗室逐把試聽揮動、命中、待機
2. 原生打一輪連段確認每一段的聲音
3. 跑音訊的授權與缺檔檢查
4. 跑受影響的測試

### 參考

- [Kenney 素材皆為 CC0](https://kenney.nl/support)
