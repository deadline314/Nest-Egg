# [NE-257] 加入衣服頭髮與胸部的次級擺動

> 狀態：待辦

## 內文

### 需求
主角動起來時身上的東西幾乎不跟著動，看起來僵硬。讓頭髮、衣服、胸部等部位在移動、起跳、落地、急停、轉身時有合理的跟隨與延遲，幅度克制、看起來自然，不誇張、不持續亂晃。

現況、業界資料與採用順序見[鏡頭遠近與次級擺動](../../design/20-campaign-experience/FRAMING_AND_SECONDARY_MOTION.md)。

### 來源
2026-10-11，使用者：「可以增加一些東西的擺動，例如衣服、頭髮、胸部等等，最好是合理的擺動。看一下業界大家都是怎麼做以及怎麼調會比較好」。

### 驗收條件
- [ ] 馬尾：跑、急停、起跳、落地、衝刺、轉身時根部先動、末端晚一點跟上；靜止 2 秒內停下來；任何動作都不會甩到穿過臉或折成不合理的角度。
- [ ] 外套：下襬與袖口在起停與落地時有很小的延遲，站著不動時不飄；外套仍然讀成穿在身上的短夾克。
- [ ] 胸部：落地、急停、起跳時有一次輕微的跟隨後就停，走路與站立時不持續晃動；輪廓不變形、不和外套或手臂穿插。
- [ ] 每一項都附原生畫面的連續影格（跑→急停、起跳→落地、衝刺、轉身各一組），兩個面向、遊戲倍率與過場倍率都看過。
- [ ] 翻面、瞬移、重生、進出過場時不會甩一大下；畫面更新率 30 與 60 時擺動幅度相近。
- [ ] 擺動的設定寫在角色自己的資料檔，沒有設定的角色維持原樣；設定缺漏或不合理時記錄錯誤並退回不擺動。
- [ ] 效能：每個角色每格增加的成本用既有的效能探針量過並記在票上，胸口若使用可變形區域，頂點數算進現有預算。
- [ ] 接點逐格稽核與既有的動畫、動作測試沒有新的失敗。

### 測試流程
1. 用角色預覽工具輸出跑→急停、起跳→落地、衝刺、轉身的連續影格，兩個面向各一組。
2. 進關卡實際操作，看站立、走、跑、跳、蹲、受擊、倒地時各部位的擺動。
3. 播放一場過場，確認進出時沒有甩動。
4. 執行效能探針與受影響範圍的測試。
