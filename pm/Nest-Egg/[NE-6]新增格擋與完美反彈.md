# [NE-6] 新增格擋與完美反彈

> 狀態：待辦

## 內文

### 需求
新增按住右鍵格擋：擋下準星方向的子彈與接觸攻擊；剛按下的瞬間格擋可把子彈朝準星反彈。讓防守有技巧上限，並與衝刺形成不同用途。

### 來源
2026-10-02，使用者於開發對話中提出：「右鍵格擋」。

### 驗收條件
- [ ] 按住右鍵時角色舉起護盾，準星方向扇形內的子彈與接觸攻擊被擋下且不扣血
- [ ] 剛按下的短時間內格擋子彈會朝準星方向反彈並造成加倍傷害，有專屬的頓幀與音效
- [ ] 格擋消耗護盾能量並在 HUD 顯示，放開後自動回復
- [ ] 能量耗盡時破防並短暫硬直
- [ ] 爆炸無法格擋
- [ ] 格擋中移動變慢且不能射擊
- [ ] 手把以 LT 格擋

### 測試流程
1. 面對清掃兵按住右鍵，確認子彈被擋下
2. 在子彈到達前一刻按下右鍵，確認子彈反彈並擊中敵人
3. 連續格擋到能量耗盡，確認破防硬直
4. 站在自爆蟲爆炸範圍內格擋，確認仍會受傷
5. 執行完整測試套件，全部通過
