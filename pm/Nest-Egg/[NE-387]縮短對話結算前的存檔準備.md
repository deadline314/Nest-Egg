# [NE-387] 縮短對話結算前的存檔準備

> 狀態：完成

## 內文

### 需求

縮短結束會寫入劇情結果的對話時，主執行緒準備候選存檔的時間。保留既有存檔、拒絕寫入及舊地圖遷移的結果。

### 來源

[存檔編碼耗時](../../design/06-roadmap/SAVE_ENCODING_LATENCY.md)

### 驗收條件

- [x] 更新前後的合法候選產生相同結果，包括斜向瞄準及舊版地圖資料。
- [x] 關卡路徑或資源有異時，照正式資料解析地圖；只有現場存在的敵人生成點不能通過驗證。
- [x] 以相同存檔交錯量測對話結算的這段準備，並跑受影響的回歸。

### 測試流程

1. 使用正式採樣存檔從第一章資料走到結算，驗證候選、存檔和已安裝結果。
2. 分別重跑斜向瞄準、舊版地圖、不正確關卡路徑、同路徑替換資源及未登記的敵人生成點。
3. 在同一機器交錯比較原本與新版的準備時間。
