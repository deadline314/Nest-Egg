# [NE-262] 拿掉敵人頭上的弱點框

> 狀態：完成

## 內文

### 需求
敵人的頭上一直有一個黃色的四角框，標示頭是弱點。使用者覺得它看起來很突兀，要拿掉。

### 來源
2026-10-11，使用者在看槍燈的畫面時提出：「敵人的頭那個框框拿掉，看起來很突兀」。

### 驗收條件
- [x] 平常遊玩時，敵人身上不再出現四角框（頭部與其他弱點都一樣）
- [x] 打頭仍然是弱點：傷害倍率、打中弱點的火花、命中聲與準星上的弱點標記都和原本一樣
- [x] 開發檢查用的受擊框顯示照常可用（黃色是弱點、青色是其他部位）
- [x] 原生畫面修前修後對照

### 測試流程
1. 原生進任一有敵人的區域，看敵人的頭
2. 打敵人的頭，確認傷害與回饋
3. 跑敵人相關的測試

# Commit-1

## 內文

每個敵人的頭上都有一個淡淡呼吸的黃色四角框，用來提示頭是弱點；畫面調暗之後它在暗處特別顯眼，像一塊貼在敵人頭上的介面。

現在平常遊玩不再畫這個框。頭是弱點這件事不變，打中時的金色火花、較亮的命中聲與準星上的弱點標記都還在；開發檢查用的受擊框顯示也保留。

原生畫面對照：同一個位置的敵人，修前頭上有框、修後沒有。敵人相關的測試全過。

### 測試結果

| 項目 | 結果 |
|---|---|
| 受擊反應、新敵人、第一章敵人、曝光四組測試 | 550 項檢查；新失敗 0、已知失敗 0 |
| 原生畫面對照 | 修後敵人頭上沒有框 |

分支 `feature/light-sources`；提交見[遠端 main 上本票的提交](https://github.com/deadline314/Nest-Egg/commits/main/pm/Nest-Egg/%5BNE-262%5D%E6%8B%BF%E6%8E%89%E6%95%B5%E4%BA%BA%E9%A0%AD%E4%B8%8A%E7%9A%84%E5%BC%B1%E9%BB%9E%E6%A1%86.md)。

# Commit-2

## 內文

補上可獨立重算的原生畫面與命中回饋證據。平常遊玩時，頭部與其他弱點都沒有四角框；開發檢查仍清楚顯示黃色弱點和青色普通受擊框。固定同一批角色、姿勢及鏡頭交替比較，三次正常畫面的完整像素一致。

真頭部與身體受擊分別扣 2／1 點；弱點旗標、火花、命中聲音事件與準星弱點標記照常發布。故意把身體當頭部、讓框仍然存在、關閉開發顯示及使用錯誤投影，都有被拒絕。

原票 550 項測試未找到可回讀的原始執行收據，保留為歷史紀錄。本次的修前畫面只還原舊標記繪製行為，不冒稱完整歷史版本重跑；首輪工具期待錯誤與出框構圖也完整保存。[來源、全部原件及獨立驗收](attachments/NE-262-weak-bracket-2026-11-12/README.md)。

### 測試結果

| 項目 | 結果 |
|---|---|
| 真頭部／身體命中 | 14／0；身體冒稱頭部的 4 項失敗被正確辨認 |
| 正常原生序列 | 13／0，無引擎錯誤；獨立 24 段舊框及 12 段開發框全通過 |
| 故障與錯投影 | 三個故障讀取程序皆退出失敗，原始畫面保持 |
| 封存原件重算 | 539＋90 檔 SHA／CRC 全通過；讀取器 10 個控制通過 |
