# [NE-310] 防止轉場前存檔卡住操作

> 狀態：完成

## 內文

### 需求

選擇新遊戲、續玩或跨區後，畫面應立即回應操作。進度成功保存才能進入目的地；保存失敗時仍能留在原區域或重試。

### 來源

Stanley 於 2026-11-23 回報卡頓並要求從完整遊戲路徑修正。

### 驗收條件

- [x] 原生測量的八條路線，從操作到轉場蓋住畫面的每格耗時低於 33.3 ms。
- [x] 續玩開始轉場後才讀取、校驗存檔。
- [x] 主檔內容被替換時會重新驗證，未知版本和原備份受到保護。

### 測試流程

1. 從選單開始新遊戲或續玩，量測發出操作後的畫面回饋。
2. 越過正式出入口及章末，核對保存和目的地。模擬保存故障，核對原地與重試。

# Commit-1

## 內文

轉場先接手畫面，讀寫進度和關卡準備在蓋住後執行。用 RX 9070 XT、Godot 4.7.2、Forward+ 與 1280×720 執行實際 Main 路線。新世代存檔保護及來源變動檢查全過。
