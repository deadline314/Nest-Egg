# [NE-218] 補畫第一章還沒有專屬立繪的角色

> 狀態：進行中

## 內文

### 需求
第一章有些角色與敵人還沒有專屬的立繪與骨架外觀，目前借用別人的圖當替身：鷺借用居民、阿梨借用護理師、燈借用渡的頭像，清掃兵借用保全、收帳人（槍手、打手）借用鎮暴員、看門狗借用監管者（人形的大機器人，不是一隻狗）。這些要畫專屬立繪、頭像與骨架零件（看門狗是四足生物，需要生物外觀與動畫）。目前的環境無法繪製，先開票記錄，之後在能跑繪圖流程的環境處理。

### 2026-10-11 使用者要求與停工交接索引

第一章專屬角色保持賽博龐克風格、合理人體、真正透明背景及正確單件；看門狗為四足外觀與動畫，不再借人形監管者。後續章節依既有NE-242優先順序，不擴大成一次畫完。

[角色製作、品質要求、拒收例子與業界原始參考](../user_guide.md) · [本次停工交接](../handoff/character-art-2026-10-11.md)。本次只整理既有需求與證據，既有驗收勾選和真實狀態保持原樣。

### 來源
2026-10-06，使用者試玩第一章後回報：「是不是有一些角色的立繪還沒畫，如果是的話就幫我開票（或是票已經存在）。不過這個就先開票就好了，因為現在的環境沒辦法繪製」。已查過：沒有針對這些角色的現有票。

### 驗收條件
- [ ] 鷺：專屬立繪、頭像、骨架外觀（46 歲資深傭兵，見 CHARACTERS.md）
- [ ] 阿梨：專屬立繪、頭像、骨架外觀（27 歲復原館夜班，麵攤；現在借用護理師）
- [ ] 燈：專屬頭像與立繪（16 歲通訊員，主要以通訊出現）
- [ ] 清掃兵：專屬立繪與骨架外觀（現在借用保全）
- [ ] 收帳人：槍手與打手兩種專屬立繪與骨架外觀（現在借用鎮暴員）
- [ ] 看門狗：專屬生物外觀與動畫（四足，現在借用監管者的人形外觀）
- [ ] 錄音與系統頭像確認是否需要專屬圖
- [x] 後續章節會出現的角色（阿勇、小薇、利息、必安與收屍人、沈望、汐、葉、蘇、棘、榕伯、芷姐等）列出清單與優先順序，另開票（NE-242）
- [ ] 每個角色依角色製作流程完成（零件分割、骨架、動畫、預覽）並通過動畫稽核，換上後遊戲內檢查

3. 執行動畫稽核

# Commit-3

## 內文

鷺在遊戲裡一直借用夜班工人的身體與居民的頭像，看不出是 46 歲的資深傭兵。

現在鷺有自己的外觀：灰白短髮、顴骨上一道舊疤、愛笑的臉；穿好的石板灰防風外套（白色羽毛內裡、青綠色滾邊、袖口捲起）、橘色背帶、黑色工作褲與港區的高筒膠靴，背上斜揹一把收起的戰術傘。立繪直接畫成自然走姿、四肢分開，照凜這次整理出來的流程分件：外套身片與袖子分開、下襬跟著骨盆、髖與踝用圓形接合、頸與腕有藏在底下的重疊。她在關卡裡的身體、對話頭像與眨眼都換成自己的；動作資料是她自己的一份。故事、台詞與出場位置沒有改。

還沒做的：正式關卡與過場裡的實機檢視、逐格接點稽核、兩個面向的近拍；阿梨、燈、清掃兵、兩種收帳人與看門狗的骨架。
