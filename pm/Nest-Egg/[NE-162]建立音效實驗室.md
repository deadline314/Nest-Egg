# [NE-162] 建立音效實驗室

> 狀態：待辦

## 內文

### 需求
調音效時要一直進遊戲打一遍才聽得到。要有一個獨立的實驗室，可以選角色、武器、材質、曲目，一鍵播放對應的聲音，看到每個聲音用哪個檔案、授權是什麼，調整音量後寫回資料。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [ ] 可以從命令列開啟，主選單與遊戲流程進不去
- [ ] 角色分頁：選玩家、敵人、NPC，播放受擊、死亡、攻擊、預兆、腳步
- [ ] 武器分頁：選武器，播放單發、連發、整段換彈、空槍、換槍，以及近戰招式
- [ ] 受擊分頁：選材質與力道，一鍵播放整組回饋
- [ ] BGM 分頁：列出曲目與 cue，可切換平靜／戰鬥／頭目，可跳到迴圈尾端試接縫，可調音量
- [ ] 環境分頁：試聽與疊加環境音
- [ ] 全部音效分頁：可搜尋，列出檔案、時長、授權，標示缺檔或使用合成音的項目
- [ ] 混音分頁：各匯流排音量與靜音，即時音量表，同時發聲數與被丟棄數
- [ ] 調整後的音量與淡化時間可預覽差異並驗證後寫回資料，寫入前備份
- [ ] 資料有錯誤時指出位置，不寫入
- [ ] 每個按鈕與欄位有 tooltip

### 測試流程
1. 以命令列開啟實驗室
2. 依序切換各分頁，選不同角色、武器、曲目試聽
3. 調整一個音量，預覽差異並儲存，重開確認生效
