# [NE-251] 修正診間醒來時主角頭部過亮

> 狀態：待辦

## 內文

### 需求
NE-213 修過之後，主角過曝的情況好很多，但少數情況仍會發生：第一次在水下死亡後，在診間醒來時，主角的頭很亮、看不清楚頭髮與臉。要在這條實際路線上重現並修好，同時找出其他還會發生的場合。

### 來源
使用者 2026-10-11：「NE-213 過曝的情況好很多了，但在少數情況下還是會（第一次在水下死亡後在診間醒來的時候，主角的頭會很亮）」。

### 驗收條件
- [ ] 在最新版本走實際路線重現：倉庫水位謎溺斃 → 診間醒來，記錄頭部區域的亮度量測與原生畫面
- [ ] 說明成因（光源、材質、發光或前一場景留下的狀態），並確認 NE-222 已交付的診間補光修正為何沒有涵蓋這個情況
- [ ] 修正後同一路線、同一鏡頭，頭髮與臉的細節清楚，沒有大片純白；附修前修後對照
- [ ] 其他死亡方式醒來、讀檔續玩進診間、重複死亡多次後，結果一致
- [ ] 逐一檢查其他「從暗場景切到獨立舞台」的過場，列出還會過亮的地方並修正或另開票
- [ ] 主角的霓虹發光保留，沒有用整體調暗或關掉發光來掩蓋

### 測試流程
1. 新遊戲玩到碼頭倉庫，在水坑溺斃
2. 在診間醒來，看主角頭部
3. 預期頭髮與臉清楚可辨，不過亮
