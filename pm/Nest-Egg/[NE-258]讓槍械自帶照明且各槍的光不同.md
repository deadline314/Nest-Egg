# [NE-258] 讓槍械自帶照明且各槍的光不同

> 狀態：待辦

## 內文

### 需求
槍現在只有開火瞬間的槍口閃光，沒有常亮的照明；主角身上的光是一盞不跟瞄準方向、看不到來源的全向光。使用者要主角的槍有類似手電筒的光，不同槍可以有不同的光，光源少的場景要靠它才看得清楚。

### 來源
2026-10-11，使用者看完場景與光影那批票之後提出（原話整理在 `pm/user_guide.md` 的「光影要從光源出發，近戰武器要換一批」）。設計與查到的資料見 [光源驅動的光影](../../design/08-lighting/LIGHT_SOURCES.md)。

### 驗收條件
- [ ] 拿著槍時有一道常亮的光從槍口朝瞄準方向照出去，跟著滑鼠或右搖桿轉；不需要電量，開火、換彈、衝刺時都不會熄
- [ ] 光掃到的牆、平台與敵人被照亮；主角身邊留一小圈微光，背後的平台與落點仍看得到
- [ ] 七把槍的光各不相同並寫在武器資料裡（寬窄、遠近、顏色、是否抖動）：手槍中等暖白、步槍窄而遠、衝鋒槍連射時輕微抖動、霰彈槍寬而短、榴彈發射器寬而暗、光束槍是一條常亮的細瞄準光、軌道砲蓄力時變亮；換槍時光跟著換
- [ ] 暗的區域裡不開槍也能靠槍燈看到 8 格內的敵人與平台；拿掉槍燈對照時看不到（原生截圖對照）
- [ ] 槍口火光在暗的區域會照亮主角與附近一小段時間；主角的白色頭髮不過曝（沿用既有的曝光量測）
- [ ] 潛行者被槍燈照到會現形（和被場景燈照到一樣）
- [ ] 載具與過場裡不出現槍燈；主角死亡時熄滅
- [ ] 光影品質低、中、高都有槍燈；連續戰鬥的每影格耗時不高於修前的 105%（同機、關垂直同步）
- [ ] 設定的「減少閃光」打開時，衝鋒槍的抖動與槍口火光的強度降低

### 測試流程
1. 原生進暗的區域，七把槍各拍一張朝右、朝上、朝左下瞄準的畫面
2. 同一位置開、關槍燈對照
3. 對著潛行者照
4. 跑曝光量測與連續戰鬥的耗時量測
5. 跑受影響的測試
