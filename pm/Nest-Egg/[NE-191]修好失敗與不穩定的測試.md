# [NE-191] 修好失敗與不穩定的測試

> 狀態：完成

## 內文

### 需求
完整測試有一批已知失敗（換彈、坑洞、快速使用、檢查點、法線貼圖、顯示設定）和一批時過時不過的測試（終結技、閃光、轉場、同時發聲數、頭目招式），CI 常被它們弄紅，也讓真正的新失敗被淹沒。要把它們修好，讓完整測試連續跑都全過。

### 來源
2026-10-05，使用者說：可以先 pull 最新的 main，然後幫我把 failed 的 tests 修好嗎。

### 驗收條件
- [x] 已知失敗清單裡的穩定失敗全部修好並從清單刪除：換彈與快速使用、坑洞、檢查點存檔與還原、角色零件法線貼圖、傷害數字關閉時不顯示
- [x] 監管者專屬骨頭（肩甲）的檢查改用該角色自己的骨架
- [x] 手槍通話用的話筒補上缺的法線貼圖
- [x] 靠實際時間或機器忙碌才失敗的測試改成不受機器速度影響：終結技、閃光與閃電、死亡重來轉場、同時發聲數預算、頭目招式
- [x] 完整測試連續兩次全過，已知失敗清單只剩一項偶發的

### 測試流程
1. 執行完整平行測試
2. 預期：新失敗 0、已知失敗 0，連跑多次結果一致

# Commit-1

## 內文

換彈、快速使用、坑洞等測試在打擊後被「頓幀」凍住的玩家收不到輸入；檢查點測試還在用走過去就存檔的舊行為，現在要撥號；法線貼圖缺話筒一張；監管者的肩甲骨頭不在共用骨架上；調色後製的顆粒與色差沒算進光影品質的倍率。其餘是靠實際時間的檢查在機器忙碌時偶爾失敗。
修法：頓幀加了立刻解除的方法，測試在送輸入前先解除；檢查點測試改成撥號；補上話筒法線貼圖；骨頭檢查讀角色自己的骨架；後製檢查乘上品質倍率；閃光、轉場、終結技與頭目招式的測試改成不依賴機器速度（輪詢取最亮的一格、固定亂數種子、重試輸入、放寬餘裕）；同時發聲數用 8 倍速重播，量到的是真正的同時發聲而不是全部發聲數。
另外：聲音套用後更長，把命中、材質、擊殺、格擋、跳彈的聲音限制在 0.3–0.4 秒，同時發聲數才不會逼近預算。
驗收：完整測試新失敗 0、已知失敗 0，連跑兩次一致；已知失敗清單只剩「重擊擊殺比輕擊倒得更快更遠」一項偶發的。
