# [NE-130] 打擊感（母票）

> 狀態：完成

## 內文

### 需求
讓玩家的槍、近戰、格擋、鏡頭、聲音、畫面、輸入與擊殺回饋達到「克制但有力、可以用資料調整、可以為怕暈的玩家降低或關閉」，並做一個打擊感實驗室讓開發者即時調整參數、比較與存檔。依據 `design/15-game-feel/RESEARCH.md`（業界做法研究與票的拆分），各子票各負責一個可驗收的需求。

### 來源
2026-10-04，使用者說打擊感非常重要，要有一個打擊感實驗室，並先分析業界最佳實例再開票。

### 共通驗收條件（每張子票都要滿足，不另外寫進子票）
- [x] 回饋參數以資料表達；缺漏或損毀時記錄「檔案、事件、欄位」並退回安全預設
- [x] 每個新增的參數有一句 tooltip
- [x] 不引入每影格配置；粒子、聲音、光源有預算上限並顯示在診斷
- [x] 「減少閃光」與新的「畫面震動」設定都生效
- [x] 該票範圍的測試通過，截圖放進票

3. 玩家武器與近戰：NE-139、NE-140、NE-141；NE-142、NE-143；NE-144
4. 輸入、畫面與敵人側：NE-145、NE-146、NE-147、NE-148
5. 實驗室補完：NE-149、NE-150、NE-151

### 驗收條件
- [x] 所有子票完成
- [x] 在實驗室與實際關卡中，槍、近戰、格擋、擊殺的回饋都能依資料調整，並有至少一組「克制」與一組「無障礙」預設
- [x] 最亮與最暗的光影下都不過曝，也沒有每秒超過三次的明暗交替

### 測試流程
1. 在實驗室逐項檢查各回饋，調到滿意後存檔
2. 進關卡與各種敵人交戰，確認回饋與實驗室一致
3. 開啟無障礙設定，確認震動、縮放與閃光降低
