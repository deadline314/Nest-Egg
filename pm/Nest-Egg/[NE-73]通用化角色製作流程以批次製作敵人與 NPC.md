# [NE-73] 通用化角色製作流程以批次製作敵人與 NPC

> 狀態：完成

## 內文

### 需求
凜的角色製作流程目前針對單一角色（路徑、零件名稱、破衣步驟都寫死）。要改成任何人形角色都能用：一份配方（造型提示詞、種子）加一份規格（分群、零件、關節、裝甲）就能一鍵產出零件圖、角色定義、骨架、法線與預覽；規格可由範本複製再改差異；敵人專用的「裝甲分件」成為正式步驟（從立繪摳出肩甲、胸甲、護臂、護膝等，補完底下的身體，設定脫落順序）；破衣底層變成可選步驟；幾個角色可以接著批次跑。流程文件隨之更新。

### 來源
2026-10-03，使用者在凜（NE-17、NE-68～72）完成後要求重畫敵人與其他 NPC、精細度與凜一致、敵人依各自骨骼分件、可以的話替 NPC 加動畫；並確認先做人形、每個敵人有自己的比例、所有 NPC 都做、芽當成可操控角色設計。設計見 `design/12-cast-redraw/DESIGN.md`。

### 驗收條件
- [x] 新增一個角色只需要複製範本、改配方與規格，不需要改程式
- [x] 裝甲零件可以在規格裡宣告（要摳的部位、脫落順序、掛載骨頭、是否一組一起脫落），產出的零件底下的身體完整
- [x] 破衣步驟可以略過（敵人與一般 NPC 不用）
- [x] 多個角色可以一次排隊產生，其中一個失敗不會讓其他角色的結果被覆蓋
- [x] 缺少輸入圖、規格寫錯（零件名稱、關節）時，錯誤訊息指出具體位置，並退回安全預設值，不產生壞掉的檔案
- [x] 凜重新跑一次流程，結果與目前一致（沒有被這次改動影響）
- [x] 流程文件說明新增角色的完整步驟、裝甲分件怎麼設定、輸入輸出位置
- [x] 以天穹保全做一次完整試跑（正式成果由 NE-74 驗收）

### 測試流程
1. 複製範本建立一個新角色，執行一鍵腳本，檢查每一步的輸出
2. 故意把規格的零件名稱寫錯，確認錯誤訊息指出位置
3. 同時排兩個角色，確認互不影響
4. 重新產生凜，與現有結果對照

# Commit-1

## 內文

凜的流程把路徑、零件、關節數字都寫死，做下一個角色要手寫一份幾百行的規格，量關節也要靠人。
現在新增角色只要一行指令：用範本（有裝甲的士兵、沒裝甲的 NPC）產生配方與規格，關節、縮放與切線高度由流程從圖自動量出並畫成檢查圖（手動填的數字不會被蓋掉）；裝甲（肩甲、前臂護甲、護膝、胸甲）做成獨立零件，破壞順序就是設定的順序，前後側同一種護甲一起飛走，底下的身體由「移除所有裝甲」的階段圖補完；破衣底層維持可選。規格寫錯時（零件、關節、骨頭、群組、階段名稱）在慢的步驟開始前就指出具體位置並停下；貼圖先寫到暫存資料夾，全部切完才換掉舊的，失敗不會留下壞掉的貼圖；多個角色可以一起排隊（或 `--all`），其中一個失敗不影響其他的。
角色測試也改成能容納各自骨架的角色（不再拿 Q 版規格比對），身高改由骨架量出。
用天穹保全跑完整條流程（見 NE-74）；重跑凜的流程，所有貼圖與角色定義與原本完全一致。依使用者指示，沒有跑完整測試套件，只跑角色與重裝敵人的測試。
