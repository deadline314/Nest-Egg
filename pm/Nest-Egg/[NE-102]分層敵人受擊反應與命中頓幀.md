# [NE-102] 分層敵人受擊反應與命中頓幀

> 狀態：待辦

## 內文

### 需求
目前一般中彈只有閃白與擊退，敵人不會畏縮，打起來沒有重量感；命中頓幀只在死亡時出現。要做出輕微畏縮、硬直、被打斷三層受擊反應，由攻擊的重量與敵人的耐打程度決定；命中頓幀只凍結攻擊方與被打方，依武器輕重不同。

### 來源
2026-10-04，使用者希望敵人動起來更有真實感、要有受擊判定與動畫；業界做法整理見 `design/12-cast-redraw/ENEMY_FEEL_RESEARCH.md`。

### 驗收條件
- [ ] 輕武器的子彈命中：敵人只有閃白與輕微晃動，不中斷當前動作
- [ ] 中等武器或連續命中累積後：敵人畏縮並短暫中斷動作
- [ ] 重武器、近戰、格擋反彈：敵人明顯硬直後仰，動作被打斷
- [ ] 敵人出招瞬間可以有霸體（輕擊打不斷），蓄力階段不行；頭目對輕擊幾乎不畏縮
- [ ] 命中頓幀：子彈幾乎無、近戰明顯、擊殺最長；多次命中重疊時取最長而非相加；不影響其他敵人與介面
- [ ] 閃白強度不過曝，在最亮的光影設定下不被泛光吃掉
- [ ] 每個敵人的耐打程度與各層門檻是資料，可以個別調整
- [ ] 連續射擊同一隻敵人不會被無限硬直鎖死
- [ ] 所有現有敵人的行為與數值不變（除了新增的受擊反應）

### 測試流程
1. 對每種武器各打一次普通敵人、精銳敵人、頭目，觀察三層反應是否分明
2. 連續射擊同一隻敵人，確認不會被鎖死
3. 在雨夜與最亮的區段檢查閃白不過曝
