# [NE-157] 換入槍械與近戰音效

> 狀態：待辦

## 內文

### 需求
八把武器的射擊聲、換彈、空槍、換槍現在都是合成的短音，而且換彈與空槍所有武器共用同一個聲音。要換成 CC0 的槍聲素材，每把武器聽起來有辨識度，近戰的出手與命中也換成錄音素材。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [ ] 手槍、突擊步槍、衝鋒槍、霰彈（散射）、發射器、軌道砲、雷射、機甲砲八把武器的射擊聲各自不同且是正式素材
- [ ] 每把武器的換彈（取出彈匣、裝入、上膛）依武器類型有對應聲音，空槍與換槍也有
- [ ] 連發武器連續射擊不會出現破音或明顯的重複感（多個變體輪播）
- [ ] 低彈量時的音高變化仍然有效
- [ ] 近戰各段出手聲與命中聲換成正式素材
- [ ] 敵人使用的槍械聲與玩家的明顯可區分
- [ ] 同時多把槍射擊與爆炸時不爆音、不超過發聲上限

### 測試流程
1. 在音效實驗室或遊戲內依序換每把武器各射擊、換彈、空槍
2. 預期：八把武器聲音各異，連發自然
3. 玩到有敵人開火的段落，確認敵我槍聲能分辨
