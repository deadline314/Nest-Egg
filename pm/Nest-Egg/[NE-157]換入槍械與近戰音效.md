# [NE-157] 換入槍械與近戰音效

> 狀態：完成

## 內文

### 需求
八把武器的射擊聲、換彈、空槍、換槍現在都是合成的短音，而且換彈與空槍所有武器共用同一個聲音。要換成 CC0 的槍聲素材，每把武器聽起來有辨識度，近戰的出手與命中也換成錄音素材。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [x] 手槍、突擊步槍、衝鋒槍、霰彈（散射）、發射器、軌道砲、雷射、機甲砲八把武器的射擊聲各自不同且是正式素材
- [x] 每把武器的換彈（取出彈匣、裝入、上膛）依武器類型有對應聲音，空槍與換槍也有
- [x] 連發武器連續射擊不會出現破音或明顯的重複感（多個變體輪播）
- [x] 低彈量時的音高變化仍然有效
- [x] 近戰各段出手聲與命中聲換成正式素材
- [x] 敵人使用的槍械聲與玩家的明顯可區分
- [x] 同時多把槍射擊與爆炸時不爆音、不超過發聲上限

### 測試流程
1. 在音效實驗室或遊戲內依序換每把武器各射擊、換彈、空槍
2. 預期：八把武器聲音各異，連發自然
3. 玩到有敵人開火的段落，確認敵我槍聲能分辨

# Commit-1

## 內文

八把武器的射擊聲都是合成的短音，換彈與空槍所有武器共用，近戰出手與命中也是合成音；敵人的槍聲和玩家的也分不出來。
現在八把武器的射擊都換成 CC0 的真實槍聲錄音，各有 2～5 個變體輪播：手槍（.45 與 9mm）、突擊步槍（5.56 與 7.62）、衝鋒槍、霰彈槍、發射器與機甲砲（砲聲疊爆炸）、軌道砲（光束疊低頻爆音）、雷射。每發都只取一發槍聲並壓在 0.5～1.6 秒內，連發不會被房間殘響糊成一片。換彈（取出、裝入、上膛）依武器類型各自不同：手槍、步槍、衝鋒槍、霰彈槍（逐顆裝彈與拉栓）、重型武器（機械撞擊）、能量武器（充能電子聲），空槍與換槍也分類型；專屬音效缺檔時自動退回通用音效。近戰的出手聲與命中聲改由招式資料指定，輕斬與重斬各一組，終結技也換成金屬重擊疊低頻。敵方槍聲改用較遠、較悶的錄音，狙擊手、重裝機槍手、砲台各有自己的聲音，狙擊手不再疊玩家的軌道砲聲。Master 匯流排加上硬限幅器（-1 dBFS），多把槍與爆炸同時發聲也不會破音。
驗收：音效測試套件新增槍械檢查（每把武器的射擊、換彈、空槍都來自檔案、射擊聲至少兩個變體且各武器不共用檔案、各類型換彈聲不同、敵我槍聲不同、近戰與終結技來自檔案、Master 有限幅器），連同近戰套件共 1175 項通過。完整測試套件 9165 項中有 11 項失敗，與沒有這次改動的 main 相同。這張票是聲音，沒有畫面截圖。
