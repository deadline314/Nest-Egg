# [NE-213] 修正主角有時候過曝、光暈過大看不清楚

> 狀態：進行中（修正已上，需要使用者在 Forward+ 實機確認）

## 內文

### 需求
主角有時候會變得非常刺眼：整個人發白、頭部帶著一大團光暈，輪廓與細節都看不清楚（例如爬梯子時、在很亮的白色房間裡）。需要找出什麼情況下會發生（發光倍率疊加、補光、閃光、泛光強度、白色頭髮與亮場景），讓主角在任何光線與場景下都維持清楚可辨、亮度穩定。

### 來源
2026-10-06，使用者試玩第一章後回報（附梯子與復原館截圖）：「有時候主角也會超級暈，不知道為什麼，可以的話也幫我開票修正」。這裡「暈」依畫面理解為過曝與光暈過大；若指的是別的現象以使用者補充為準。

### 驗收條件
- [ ] 重現並記錄會讓主角過曝的情況（場景、光源、動作、特效），附截圖
- [x] 找出原因並修正：任何情況下主角的亮度都落在可讀範圍，白色頭髮與亮色衣物不會糊成一團
- [ ] 全部場景（關卡、過場舞台、白色與高亮的房間）量測主角輪廓與背景的對比，達到標準
- [x] 泛光（發光層）的強度有上限，與場景光、補光、閃光疊加後不超過上限
- [x] 自動檢查：在最亮的場景與光影預設下量測主角的亮度與對比，超標會失敗
- [ ] 修前修後截圖並排留存

### 測試流程
1. 到梯子旁、復原館、白天的當舖與其他高亮場景觀察主角
2. 做衝刺、受擊閃白、開槍、換武器等動作，觀察主角亮度
3. 執行對比量測

# Commit-1

## 內文

限制：這個環境沒有 Vulkan，只能用 Compatibility 渲染器截圖，而泛光（bloom）只在 Forward+ 的 HDR 2D 下出現，所以「過曝」本身在這裡重現不出來（量了 25 份光影設定與主角身邊加 0～3 能量的光，主角像素沒有全白、沒有光暈外擴）。下面是依程式與引擎文件找出的原因與修正，需要使用者在實機（Forward+）確認；沒好就補一張截圖與場景，我再量。

原因（疊加造成）：
1. 角色補光倍率（`character_fill`，最高 4 倍）把白色零件的底色拉高，再加上玩家自己那盞固定能量 0.75 的光與附近的路燈，白色頭髮的亮度很容易大於泛光門檻 1.0。
2. 受傷、格擋反彈、補給等貼在玩家身上的閃光能量高達 2.5～3.0，疊上去等於把角色照成白色。
3. 閃電把環境光拉到全亮時，上面的疊加沒有任何東西會讓路。
4. 泛光每個像素能貢獻的亮度上限是引擎預設的 12，一個過亮的像素就能暈出一大團。

修正：
- 玩家自己的光依場景亮度自動調暗（`LightKit.player_light_for`：預算 1.0 扣掉環境光 × 補光與附近燈光預留，夾在 0.15～0.75），由光影控制器更新、玩家每影格平順套用；閃電全亮時降到最低；離開關卡還原。
- 貼近玩家的閃光能量上限 1.4（`LightKit.capped_flash_energy`，Fx 發出閃光時自動套用），遠處的不受影響。
- 泛光亮度上限 2.0（`glow_hdr_luminance_cap`），發光物原本的亮度上限 3.5 不變。
- 光影設定的泛光強度上限 1.2 由測試檢查。

自動檢查（`ExposureSuite`，97 項）：每份光影設定的白色零件曝光估計峰值不超過預算（亮度預算 1.0＋容許 0.4，本來就全亮的設定也在範圍內）、玩家的光隨亮度單調調暗、閃光上限、泛光上限、玩家的光在關卡裡確實跟著目標調整。量測工具：`tools/screenshot.tscn --scenario=exposure`（每份光影設定）、`exposure@關卡@欄`（實際位置）、`exposure_light:能量…`（主角身邊加光），印出全白像素比例、光暈比與平均亮度，在有 Forward+ 的機器上跑會是真正的數字。

尚待：Forward+ 實機確認與修前修後並排截圖（本環境做不到）。
