# [NE-182] 射速加快時音效跟著加快並收掉上一發尾音

> 狀態：待辦

## 內文

### 需求
射擊間隔比音效短時，上一發的尾音還沒播完就響起下一發。例如霰彈槍每 0.55 秒一發、音效最長 0.84 秒；超頻（目前的射速加成）或之後的射速升級讓間隔更短時更明顯。要讓射擊音效隨射速加快，音高不變，並在下一發響起時把上一發的尾音快速收掉。設計見 `design/16-audio/DESIGN.md` 5.5 節。

### 來源
2026-10-05，使用者提出：霰彈槍開一發的速度比音效快，音效還沒播完就開下一發；希望音效可以加速，遊戲未來的升級系統升級射速時也加快音效。並選定加速時音高保持不變。

### 驗收條件
- [ ] 加工時為每個玩家武器的射擊音效產生幾級加速的變體（預設 1.25、1.5、2.0 倍，資料可調），音高不變、響度與原速對齊、起音保留；原速的檔案不變
- [ ] 加速變體的長度約等於原長除以倍率，頻譜重心與原速相近（音高沒變），有自動驗證
- [ ] 音效庫的每個音效可以登記各級速度的檔案；沒有登記或檔案遺失時退回原速並記錄具體位置，遊戲不崩潰
- [ ] 播放射擊音效時依「射速倍率」選最接近的一級變體；玩家的射速倍率由目前有效射擊間隔算出，超頻中自動加快，之後的射速升級不必另外處理音效
- [ ] 同一個音效的上一發還沒播完又響起時，上一發在很短時間內淡出（時間資料可調，預設只給射擊音效）；敵人射擊與非射擊音效的行為不變
- [ ] 霰彈槍在原本的射擊間隔下，上一發的尾音不再蓋到下一發；超頻時射擊音效明顯變短、音高聽起來沒變
- [ ] 實驗室的即時試玩可以選射速倍率，逐級試聽每一把槍
- [ ] 沒有加速變體的環境（例如 CI 與沒跑過加工的機器）測試照常通過

### 測試流程
1. 在實驗室即時試玩選霰彈槍，依序選 1、1.25、1.5、2 倍聽，音效逐級變短、音高沒變
2. 進遊戲用霰彈槍連射，確認上一發的尾音不再蓋到下一發
3. 啟動超頻連射，確認音效跟著加快；結束後恢復原速
