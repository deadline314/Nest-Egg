# [NE-136] 頓幀與時間管理

> 狀態：完成

## 內文

### 需求
頓幀目前散在各處，全域與局部各一套，重疊時行為不一致，也沒有慢動作的規範。要做統一的頓幀管理：全域與局部、重疊取最大不相加、有預算，慢動作只在白名單情境使用並有冷卻。

### 來源
2026-10-04，使用者要求處理打擊感；研究與設計見 `design/15-game-feel/RESEARCH.md`（第 0 節、第 5 節），母票 NE-130。

### 驗收條件
- [x] 全域頓幀期間粒子與介面照常運作，不被一起放慢
- [x] 多次命中的頓幀取最長者，不累加
- [x] 慢動作只用於白名單情境（頭目與終結技、清場），有冷卻與敵人數條件
- [x] 凍結中參與者有極小的微抖，避免看起來像當機
- [x] 診斷顯示目前頓幀與預算

### 測試流程
1. 連續快速命中同一敵人，確認停頓不累加
2. 觸發頭目死亡與終結技，確認慢動作與冷卻
3. 執行頓幀相關測試

# Commit-1

## 內文

原本的全域頓幀是把整個遊戲時間降到 5%，粒子與介面也一起慢下來，連續命中時停頓還會互相拖長，也沒有慢動作的規範。
現在全域頓幀只凍結玩家、敵人、載具與子彈，粒子與介面照常運作；多次命中取最長者而不累加；單次最多 0.2 秒，任一 1 秒內累計最多 0.4 秒，避免連打變成卡頓。凍結中的角色與敵人在原位極小幅度微抖，看起來不像當機，放開時回到原位。慢動作改成只在白名單情境（頭目死亡、終結技、清場）才播，有 6 秒冷卻，終結技慢動作在場上敵人超過 3 隻時不播；頭目死亡與終結技已接上。診斷計數可讀到目前頓幀剩餘預算、被凍結的節點數與是否正在慢動作。
驗收：回饋套件新增頓幀與慢動作檢查（凍結對象、時間縮放維持 1、單次上限、累計預算、微抖與回到原位、白名單、冷卻、人多時跳過）；連同受擊、站姿、敵人與頭目套件共 435 項、0 失敗，執行紀錄只有刻意觸發的錯誤。依指示沒有跑完整測試套件。這張票是時間行為，沒有新的畫面截圖。
