# [NE-245] 移除普通遭遇的戰鬥封路

> 狀態：待辦

## 內文

### 需求
普通探索和戰鬥不以升起牆壁把玩家關住，避免在觸發邊界被擋在區域外。只有明確的競技場或特殊空間才允許合理鎖場。

### 來源
2026-10-10，使用者提供背包參考圖與屋頂遊戲截圖，要求中性角色立繪、一般畫面減噪、合理材質與陰影、移除普通戰鬥封路、修正高低差造成的背景鏤空，並保留目前文字避開角色的告示提示。

詳見[本輪設計與研究](../../design/20-campaign-experience/INVENTORY_WORLD_CLARITY.md)。

### 驗收條件
- [ ] 序章與已建立一般關卡不因敵人刷新或戰鬥觸發而新增封路牆，左右入場、離開與回訪暢通。
- [ ] 移除封路後敵人、增援、遭遇完成與主線任務仍按真實戰鬥事件運作。
- [ ] 新內容預設自由遭遇；特殊鎖場必須有明確用途且玩家完整進入安全範圍才封閉。
- [ ] 衝刺、死亡重試、續玩及換區不遺留門牆或提前封閉，boss出場與進度不受破壞。
- [ ] 受影響局部測試通過，附原生入場與離場畫面及逐區核對。

### 測試流程
1. 逐區從左右走入和衝刺跨過原觸發處，再退出、回訪與擊敗敵人。
2. 測死亡、重試、續玩和boss出場，確認沒有困住玩家或錯誤贈送遭遇完成。
