# [NE-383] 縮短存檔編碼造成的停頓

> 狀態：完成

## 內文

### 需求

撿起故事文件時，畫面除了顯示通知還要保存這次取得。讓第一章與較後章節的存檔較快完成檢查，維持原本可讀檔、持續移動及失敗重試的行為。

### 來源

Stanley 回報移動、互動及對話仍有明顯停頓。NE-382 完成後重新量測當舖的自然撿取與正式存檔。

### 驗收條件

- [x] 含較多區域的實際存檔能縮短完整編碼檢查時間，玩家原有資料一致。
- [x] 不同語言、跳脫字元與數值往返一致。過大、過深、已損毀及未支援的存檔按原規則安全處理。
- [x] 按住移動走過當舖文件時能繼續走，文件、物品與場景進度只存一次。其他玩家狀態的同步變動仍可續玩。
- [x] 寫入暫存或輪替失敗時可重新嘗試，之前完整存檔留在安全位置。
- [x] 使用 RX 9070 XT Forward+ 無焦點的同一路線交替量測，確認目標影格的耗時變化。

### 測試流程

1. 載入第一章與第六章實際存檔，對照更新前後讀回的資料和準備耗時。
2. 從當舖同一位置按住移動，走過文件，核對是否繼續移動及正式存檔的物品和放置結果。
3. 分別測試正常保存、暫存與輪替失敗及再次讀檔。
