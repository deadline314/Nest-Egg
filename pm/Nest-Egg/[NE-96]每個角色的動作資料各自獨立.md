# [NE-96] 每個角色的動作資料各自獨立

> 狀態：完成

## 內文

### 需求
所有角色（敵人、頭目、NPC、凜）原本共用 `HumanoidAnimator` 內建的走、跑、待機、死亡動作。改成動畫器引擎共用、動作資料每個角色一份（`art/motion/<角色>.json`），並讓敵人招式動作也各自獨立（`art/rigs/action_poses.json`，名稱「敵人.動作」）。

### 來源
2026-10-03～04，使用者在敵人與 NPC 重畫的討論中提出；設計見 `design/12-cast-redraw/CREATURES.md`、`ANIMATION.md`。

### 驗收條件
- [x] 待機、移動、蹲、空中、衝刺、格擋、受擊、看向準星、死亡的倒法全部來自角色自己的動作資料，缺欄位用預設補
- [x] 20 個角色各有自己的檔案；死亡倒法有明顯差異（向後倒、向前趴、跪下、癱坐、僵直倒…）
- [x] 敵人招式動作每個敵人自己一份，同一個動作只能被一個敵人使用
- [x] NPC 的說話速度、幅度與站姿微調也在角色自己的檔案
- [x] 測試鎖定：每個角色都有檔案、任兩個角色至少 4 個數值不同、招式動作不共用
- [ ] 在遊戲裡實際玩一輪確認手感，逐一微調（目前數值是第一版）

### 測試流程
1. 預覽八種動作與死亡，對照不同角色
2. 單獨執行 `RigActionsSuite`
