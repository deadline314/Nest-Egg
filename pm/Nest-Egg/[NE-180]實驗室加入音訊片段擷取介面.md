# [NE-180] 實驗室加入音訊片段擷取介面

> 狀態：待辦

## 內文

### 需求
在音效實驗室選一個素材，開啟擷取介面：看到原始完整音訊的波形與依靜音自動標出的各段，選一段或手動框選，拖動起訖或輸入秒數微調並試聽；按「擷取成新素材」後先出確認，使用者確認才真的輸出成新素材；取消不寫任何檔案。工具與資料由 NE-179 提供。設計見 `design/16-audio/DESIGN.md` 5.4 節。

### 來源
2026-10-05，使用者提出：有些音訊裡同時包含多段音效，希望有一個讓他擷取音訊某一段的小介面，確認之後才真的把該音訊擷取出來另存成一個檔案。

### 驗收條件
- [ ] 在「位置與備選」分頁的素材清單（備選、搜尋結果、目前用的）選一個素材可以開啟擷取介面；沒有原始檔時說明怎麼補，不報錯
- [ ] 顯示原始完整檔的波形與時間軸（不是只有預聽檔的前幾秒），長音訊可以捲動與縮放
- [ ] 依靜音自動標出各段並顯示段數；一鍵選用某一段；也可以在波形上手動框選
- [ ] 起訖可以拖動，也可以輸入秒數微調；顯示選取的時長
- [ ] 可以試聽選取範圍（單次與循環），播放游標跟著走；播放中調整範圍立刻生效
- [ ] 按「擷取成新素材」先出確認，列出來源素材、起訖、時長與新素材編號預覽；確認後才輸出，取消或關閉介面不寫任何檔案、不改任何清單
- [ ] 成功後新素材立刻出現在備選與搜尋，可以試聽，並顯示新編號；失敗時顯示 NE-179 工具給的具體原因
- [ ] 有「擷取後設為這個位置的預計使用」選項，預設不勾；不勾時擷取不改位置清單文件
- [ ] 測試不依賴本機素材與外部程式：用合成音訊與假的工具輸出測試；沒有 Python 與 ffmpeg 的環境（CI）也通過
- [ ] 介面每個控制項都有 tooltip，操作說明一句講重點

### 測試流程
1. 開啟實驗室，在備選清單選一個含多聲的素材，按「擷取」
2. 確認看到完整波形與自動標出的各段，點第二段，按試聽範圍
3. 拖動終點微調後按「擷取成新素材」，先在確認視窗取消，確認沒有新檔案
4. 再按一次並確認，確認新素材出現在搜尋，可以試聽；重複擷取同一範圍時提示已存在
