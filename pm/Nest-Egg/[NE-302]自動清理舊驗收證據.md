# [NE-302] 自動清理舊驗收證據

> 狀態：完成

## 內文

### 需求

在日常交付流程中，自動清理到期且已有正式封存副本的本機驗收證據。

### 來源

2026-11-21，使用者要求 Nest Egg 的流程加入自動刪除舊證據。設計見 [本機驗收證據的保留期限](../../design/06-roadmap/EVIDENCE_RETENTION.md)。

### 驗收條件

- [x] 日常受影響測試會自動清理已到期、已有正式附件副本的本機檔案。
- [x] 尚未交付、近期變更、內容不符的證據，以及正式附件仍能使用。
- [x] 可先列出會清理的檔案，錯誤指出位置且測試流程可繼續執行。

### 測試流程

1. 建立包含已發布、未發布及內容變更的證據，以預覽核對會刪除的範圍。
2. 執行受影響測試，驗證只有到期而且與正式附件相同的檔案會清除。
