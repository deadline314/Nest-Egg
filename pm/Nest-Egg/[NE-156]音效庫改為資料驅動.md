# [NE-156] 音效庫改為資料驅動

> 狀態：待辦

## 內文

### 需求
音效目前寫死在程式裡，換成錄音檔要改程式。要讓音效 id 可以對應到一或多個音訊檔（變體），有檔案就播檔案，缺檔或檔案壞掉時記錄具體位置並退回原本的合成音；換彈、空槍、換槍依武器查表，敵人與玩家的受擊、死亡、攻擊依角色查表，新增武器或敵人只改資料。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [ ] 音效 id 可對應到多個音訊檔，連播不會連續播同一個變體
- [ ] 音訊檔遺失或損毀時記錄一次錯誤（含 id 與路徑）並退回合成音，遊戲不崩潰
- [ ] 不改任何呼叫端，現有音效在沒有音訊檔時聽起來與現在相同
- [ ] 換彈開始、換彈中段、換彈完成、空槍、換槍可依武器指定不同音效，沒寫的武器退回預設
- [ ] 敵人受擊、死亡、攻擊、預兆、警戒可依敵人指定不同事件，沒寫的敵人退回預設
- [ ] 資料檢查能列出所有錯誤：引用不存在的檔案、不存在的 id、格式不對
- [ ] 診斷能讀到目前有多少音效用檔案、多少退回合成音、被丟棄的次數
- [ ] 同時發聲的上限與優先級行為不變

### 測試流程
1. 在資料中把某個音效指到一個真實檔案，進遊戲確認聽到的是該檔案
2. 把檔案路徑改錯，確認 log 指出位置且遊戲照常發聲
3. 在資料中給某把武器指定專屬換彈聲，換到那把槍確認
