# [NE-156] 音效庫改為資料驅動

> 狀態：完成

## 內文

### 需求
音效目前寫死在程式裡，換成錄音檔要改程式。要讓音效 id 可以對應到一或多個音訊檔（變體），有檔案就播檔案，缺檔或檔案壞掉時記錄具體位置並退回原本的合成音；換彈、空槍、換槍依武器查表，敵人與玩家的受擊、死亡、攻擊依角色查表，新增武器或敵人只改資料。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [x] 音效 id 可對應到多個音訊檔，連播不會連續播同一個變體
- [x] 音訊檔遺失或損毀時記錄一次錯誤（含 id 與路徑）並退回合成音，遊戲不崩潰
- [x] 不改任何呼叫端，現有音效在沒有音訊檔時聽起來與現在相同
- [x] 換彈開始、換彈中段、換彈完成、空槍、換槍可依武器指定不同音效，沒寫的武器退回預設
- [x] 敵人受擊、死亡、攻擊、預兆、警戒可依敵人指定不同事件，沒寫的敵人退回預設
- [x] 資料檢查能列出所有錯誤：引用不存在的檔案、不存在的 id、格式不對
- [x] 診斷能讀到目前有多少音效用檔案、多少退回合成音、被丟棄的次數
- [x] 同時發聲的上限與優先級行為不變

### 測試流程
1. 在資料中把某個音效指到一個真實檔案，進遊戲確認聽到的是該檔案
2. 把檔案路徑改錯，確認 log 指出位置且遊戲照常發聲
3. 在資料中給某把武器指定專屬換彈聲，換到那把槍確認

# Commit-1

## 內文

音效寫死在程式裡，換成錄音檔要改程式；換彈、空槍所有武器共用同一個聲音，敵人的受擊、死亡、開火也全部共用同一組。
現在每個音效 id 可以對應到一或多個音訊檔，連播時輪流使用且不連續重複，檔案也可以各自指定音量微調與音高範圍；沒有登記或檔案遺失的 id 照舊播原本的合成音，所以目前聽起來和以前完全相同。檔案遺失、無法解碼或格式不對時，log 會指出音效 id、檔案路徑與資料檔位置，同一個問題只記錄一次，遊戲照常發聲。
換彈開始、換彈中段、換彈完成、空槍、換槍，現在依手上武器查表（沒寫的武器用預設）；敵人與玩家的受擊、死亡、開火、攻擊預兆、警戒，依角色查表（沒寫的角色用預設，也可以沿用另一組，例如「機械類」共用一組）。新增武器或敵人只需要改資料。換槍新增了一個事件，滾輪、數字鍵、撿到武器與彈盡自動切回都會觸發，讀檔還原不會。
診斷可以讀到目前有多少音效用檔案、多少退回合成音、多少檔案載入失敗。
驗收：新增音效測試套件 222 項通過，涵蓋音效庫載入與缺檔、資料檢查、變體不連續重複、音量套用、聲音設定表的繼承／靜音／清單挑選／代入欄位／迴圈偵測、所有武器與敵人都查得到聲音、換槍事件。完整測試套件 8236 項中有 11 項失敗，與沒有這次改動的 main 上完全相同的 11 項（角色零件法線貼圖缺一張、檢查點與換彈等流程檢查），不是這張票造成的。這張票是聲音，沒有畫面截圖。
