# [NE-159] 換入腳步、機關、拾取、電話亭、介面與環境音效

> 狀態：完成

## 內文

### 需求
玩家走路沒有任何腳步聲，機關、拾取、電話亭、介面音效是簡單的合成音，雨天關卡沒有雨聲。要加上依地面材質變化的腳步聲，把機關、拾取、電話亭、介面換成 CC0 錄音素材，並為有環境氛圍的區段加上環境音。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [x] 玩家走路與落地有腳步聲，會依腳下的地形材質（金屬、混凝土、潮濕等）變化，節奏跟移動速度一致
- [x] 閘門、開關、電源、斷電、玻璃與木箱破壞換成正式素材
- [x] 拾取、電話亭（拿起、撥號、來電、掛上）、義體能力、警報、無人機聲換成正式素材
- [x] 介面（移動、確認、取消、開關選單）換成正式素材，音量不刺耳
- [x] 雨、風、機械嗡鳴等環境音依區段的光影設定播放，區段切換時淡入淡出
- [x] 環境音有獨立的音量滑桿
- [x] 站著不動時沒有腳步聲，空中沒有腳步聲

### 測試流程
1. 在第一章走過不同地面，聽腳步聲變化
2. 操作閘門、開關、拾取、電話亭
3. 走過不同光影區段，環境音淡入淡出

# Commit-1

## 內文

玩家走路沒有腳步聲，機關、拾取、電話亭、介面是簡單的合成音，雨天關卡沒有雨聲，也沒有環境音量滑桿。
現在玩家走路每走約 24 像素響一步，音量隨速度變化、蹲著更輕；站著不動、在空中、騎載具或被打斷時沒有；落地聲依衝擊力。腳步與落地依腳下的地形材質分成金屬、混凝土、潮濕三種地面，十六種地形材質都有對應，資料不全時有檢查。閘門、開關、電源開關與斷電復電、玻璃與木箱破壞、拾取、義體能力（過載、電磁脈衝、就緒）、警報與嗶聲、無人機與火焰兵與電擊犬等敵人的專屬聲、打雷、電話亭的拿起／掛上／來電／話筒雜音，以及介面的移動／確認都換成 CC0 錄音素材；電話撥號音維持標準的 DTMF 合成音（找不到合適的錄音）。另新增介面「取消」與「錯誤」兩個聲音，暫停選單與背包的關閉改用取消聲，暫停選單開啟加上確認聲。
環境音是新的系統：依光影區段自動切換，一個區段最多三層（雨、風、機房嗡鳴、通風、發電機、滴水、夜城人聲…），換區段時舊的淡出、新的淡入，離開關卡時全部淡出；二十五種光影設定都登記了環境音配置，新增光影設定沒有登記時就是無聲。設定選單多一條「環境音」音量滑桿，有說明。環境音檔是無縫迴圈、立體聲，用串流播放，不整段載入。
驗收：音效測試套件新增腳步（資料涵蓋所有地形材質、各地面音效不同、走路次數合理、站立與空中無聲）、區段宣告（進入第一關宣告屋頂區、離開宣告空 id、腳下查得到材質）、交叉淡化播放器（同曲不重播、淡化期間兩軌、淡出後停止、迴圈只改副本）、環境音（資料無錯誤、所有光影設定有配置、層數上限、離開關卡停止）、環境音量滑桿與匯流排，連同介面與電話亭套件共 1969 項通過。完整測試套件 9921 項中的 10 項失敗都是沒有這次改動的 main 上就有的。這張票是聲音，沒有畫面截圖。
