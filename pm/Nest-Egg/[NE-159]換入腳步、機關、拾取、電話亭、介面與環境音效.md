# [NE-159] 換入腳步、機關、拾取、電話亭、介面與環境音效

> 狀態：待辦

## 內文

### 需求
玩家走路沒有任何腳步聲，機關、拾取、電話亭、介面音效是簡單的合成音，雨天關卡沒有雨聲。要加上依地面材質變化的腳步聲，把機關、拾取、電話亭、介面換成 CC0 錄音素材，並為有環境氛圍的區段加上環境音。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [ ] 玩家走路與落地有腳步聲，會依腳下的地形材質（金屬、混凝土、潮濕等）變化，節奏跟移動速度一致
- [ ] 閘門、開關、電源、斷電、玻璃與木箱破壞換成正式素材
- [ ] 拾取、電話亭（拿起、撥號、來電、掛上）、義體能力、警報、無人機聲換成正式素材
- [ ] 介面（移動、確認、取消、開關選單）換成正式素材，音量不刺耳
- [ ] 雨、風、機械嗡鳴等環境音依區段的光影設定播放，區段切換時淡入淡出
- [ ] 環境音有獨立的音量滑桿
- [ ] 站著不動時沒有腳步聲，空中沒有腳步聲

### 測試流程
1. 在第一章走過不同地面，聽腳步聲變化
2. 操作閘門、開關、拾取、電話亭
3. 走過不同光影區段，環境音淡入淡出
