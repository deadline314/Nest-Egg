# [NE-54] 擴充第二章關卡內容

> 狀態：待辦

## 內文

### 需求
第二章是完整的一關，但體驗偏單薄：缺少場景人物、不同節奏的橋段與迷你頭目。擴充成更完整的一關。

### 來源
2026-10-03，使用者於開發對話中提出：「幫我做完整的第二關」；「完善目前的劇情設計，整體起承轉合可以參照邊緣行者、尼爾之類類似宿命論這種」「劇情最好要有暗線、伏筆等等更有深度的設計」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 加入場景人物：維修員老陳、夾層區住戶、轉運站的護理師
- [ ] 加入追逐橋段「回收燈幕」：一面向前推進的燈幕從背後逼近，撞上即重來，橋段前後都有檢查點
- [ ] 加入迷你頭目「看守長」：電力室尾，有血條、攻擊比一般敵人強，擊敗後解開通往轉運站的閘門
- [ ] 夾層區加長並加入中庭，轉運站加入病房區
- [ ] 第二批新敵人依設計配置，並有第一次遭遇的安全空間
- [ ] 再增加一處隱藏房間與一處只靠光才看得到的路徑
- [ ] 第二章收集品、補給點與檢查點配置隨之調整，地圖仍通過可通行檢查
- [ ] 輔助、標準、硬核三種難度都能通關

### 測試流程
1. 從頭玩到尾，確認每個新橋段
2. 在追逐橋段死亡，確認從正確的檢查點重來
3. 三種難度各通關一次
4. 執行完整測試套件，全部通過
