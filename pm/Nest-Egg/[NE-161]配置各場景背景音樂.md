# [NE-161] 配置各場景背景音樂

> 狀態：完成

## 內文

### 需求
有了音樂系統之後，每個場景要有合適的曲子。要挑選 CC0 的曲目，轉成統一規格並調整響度，依主選單、各章關卡、戰鬥、頭目、安全區、過場、通關與死亡建立對應表。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [x] 主選單、第一章、第二章的平靜曲目各自不同且符合場景調性
- [x] 戰鬥曲目至少兩首，輪流使用
- [x] 兩位頭目（監管者、回收員）各有專屬曲目
- [x] 電話亭附近、診所、麵攤等安全區有安靜的曲目
- [x] 通關與死亡有短 sting
- [x] 所有曲目的響度一致，切換時不會突然變大聲
- [x] 每首曲目在迴圈接縫處聽起來自然，或以淡出淡入處理
- [x] 每首曲目都能在授權登記查到作者與授權
- [x] 沒有找到合適 CC0 曲目的場景，用相近曲目頂替並在票上註明

### 測試流程
1. 從主選單開始玩到第二章頭目戰
2. 預期：各場景音樂與氣氛相符，戰鬥與頭目戰切換自然，音量一致
3. 在音效實驗室逐首試聽迴圈接縫

# Commit-1

## 內文

音樂系統有了，但沒有實際曲目。
現在 22 首 CC0 曲目已放入並配置：主選單一首暗色緩慢的曲子；第一章屋頂、市場、貨運站、設施、機庫與第二章豎井、深井、住宅區、電力室、轉運站、回收員戰場各有不同的平靜曲（暗色賽博環境音樂、工業機械、恐怖合成器）；戰鬥有三首輪流（每次進入戰鬥換下一首）；監管者（機庫）與回收員（戰場）各有專屬頭目曲；通關與死亡各有短音樂。另外新增「安全區」狀態：玩家站在電話亭或場景人物旁（沒有戰鬥時）換成安靜的鋼琴曲，診所與當鋪區段整段是安靜曲。新增光影設定沒有登記曲目時，用預設的平靜曲，不會無聲。所有曲目統一響度（-18 LUFS，受峰值限制的 3 首為 -21），長曲目截到 150 秒內並做成無縫迴圈（尾端與開頭交疊），每首都登記作者與授權。
沒有找到完全合適的 CC0 曲目，用相近的頂替：監管者（機械監管者）用合成器頭目曲而非工業機械曲；通關用暗色科幻短曲而非賽博風格；屋頂的風聲環境音由環境音層負責，沒有專屬的屋頂曲。這些曲目是依頁面標籤與訊號分析挑選，沒有逐首聽過，請在音效實驗室試聽後回饋要換哪一首。
驗收：音樂測試套件新增實際資料檢查（資料無錯誤、三個畫面都有 cue、每個光影設定都有平靜曲、戰鬥曲至少兩首、兩位頭目不同、每首曲目載得進來且長度合理、都登記授權包）、cue 串輪流、安全區狀態與來源消失的處理，連同音效與電話亭套件共 155 項（音樂）／2512 項（含音效、電話亭、NPC）通過。這張票是音樂，沒有畫面截圖。
