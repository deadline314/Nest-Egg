# [NE-161] 配置各場景背景音樂

> 狀態：待辦

## 內文

### 需求
有了音樂系統之後，每個場景要有合適的曲子。要挑選 CC0 的曲目，轉成統一規格並調整響度，依主選單、各章關卡、戰鬥、頭目、安全區、過場、通關與死亡建立對應表。

### 來源
2026-10-04，使用者要求處理整個遊戲的音效（所有槍械、受擊音效、場景 BGM），素材用 CC0，並做音效實驗室；設計見 `design/16-audio/DESIGN.md`。

### 驗收條件
- [ ] 主選單、第一章、第二章的平靜曲目各自不同且符合場景調性
- [ ] 戰鬥曲目至少兩首，輪流使用
- [ ] 兩位頭目（監管者、回收員）各有專屬曲目
- [ ] 電話亭附近、診所、麵攤等安全區有安靜的曲目
- [ ] 通關與死亡有短 sting
- [ ] 所有曲目的響度一致，切換時不會突然變大聲
- [ ] 每首曲目在迴圈接縫處聽起來自然，或以淡出淡入處理
- [ ] 每首曲目都能在授權登記查到作者與授權
- [ ] 沒有找到合適 CC0 曲目的場景，用相近曲目頂替並在票上註明

### 測試流程
1. 從主選單開始玩到第二章頭目戰
2. 預期：各場景音樂與氣氛相符，戰鬥與頭目戰切換自然，音量一致
3. 在音效實驗室逐首試聽迴圈接縫
