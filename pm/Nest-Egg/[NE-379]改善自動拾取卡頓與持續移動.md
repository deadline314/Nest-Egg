# [NE-379] 改善自動拾取卡頓與持續移動

> 狀態：完成

## 內文

### 需求

玩家走過可自動取得的文件時，拾取應維持連續移動。已保存的物品與來源不應因同一組結果再寫一次，通知引發的其他進度也應能保存。

### 來源

追查移動與互動卡頓時，持續走向當票存根可在同一格重現停頓，且按住前進時角色會停下。

### 驗收條件

- [x] 首次走過當票仍能取得文件。持續按前進的角色可走過拾取點。
- [x] 實際領取及通知期間的獨立進度可保存，文件、已取得狀態和先前物品維持一致。
- [x] 檔案寫入或輪替拒絕時可從原提示重試。成功之前保留原主檔並等待玩家操作。
- [x] 舊的延後請求不能完成新的接觸，完成通知也不能重複取得同一個物品。
- [x] 量測相同拾取點改善前後的影格，回報仍存在的耗時。

### 測試流程

1. 從當舖向右走過當票存根，維持按住移動，量測同一位置的影格。
2. 在取得通知加入其他信用點，核對原取得結果和追加修改都存入。
3. 讓暫存或最後輪替拒絕，檢查提示、主檔和物品，再按重試。
4. 延後一次拾取，離開後回到同一個接觸點，驗證新舊請求的結果。

# Commit-1

## 內文

在當舖走過文件後，角色仍維持玩家按住的前進輸入。拾取結果公布後，以正式保存內容核對是否須再存。通知另加的信用點也已驗證保存。拒絕寫入時仍顯示重試提示，先前的文件、錢包及主檔保持原值。

RX 9070 XT、Forward+、1280 × 720、144 Hz 下，當票拾取影格由 181.39 降至 114.64 毫秒。基準版拾取後速度為零，更新後同一路段持續以每秒 150 世界像素移動。拾取一份文件仍要確認原主檔、備份和新內容，其驗證有剩餘耗時。

原生測試也執行當舖對話開啟、取消和格擋。本次查到的持續輸入中斷發生在自動拾取，對話開啟與取消的最長影格分別是 17.14 和 19.59 毫秒。
