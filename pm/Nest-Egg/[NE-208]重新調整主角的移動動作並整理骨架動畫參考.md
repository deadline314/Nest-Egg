# [NE-208] 重新調整主角的移動動作並整理骨架動畫參考

> 狀態：待辦

## 內文

### 需求
主角移動時身體一直上下抖，看起來不自然。原因是步伐太快、骨盆起伏幅度遠大於真人（目前約七像素，相當於站立身高的八分之一）。需要參考業界與生物力學的做法重新調整走、跑的步頻、步長、身體起伏、腳的落點與起跑煞車，讓移動平順、有重量感；並把查到的資料與可量測的檢查標準整理成文件與 skill，之後做任何骨架動作都要先參考。

### 來源
2026-10-06，使用者試玩第一章後回報：「走路的時候主角也會一直上下抖，可以幫我重新調整主角的移動動作嗎？請參考一下業界最佳實例們是怎麼樣讓骨架動起來會比較合理，可以把資料整理起來，然後做成 skill，之後做骨架都要參考」。

### 驗收條件
- [ ] 整理業界與生物力學的移動動作資料（走跑循環、起伏幅度、步頻、落腳、頭穩定、次級動態、待機），標明出處與哪些是我們的建議值，放進設計文件
- [ ] 做成 skill：之後新增或調整骨架動作時照著查規則、跑稽核、對照檢查清單
- [ ] 提供可重複執行的量測工具：以固定速度移動，量出骨盆上下起伏幅度、主頻率、高頻比例、加速度峰值、單格變化、腳滑步
- [ ] 主角各速度的移動通過量測門檻：起伏幅度在建議範圍內、沒有高頻抖動、踩地的腳不滑
- [ ] 步頻隨速度連續變化，慢走與全速跑的步長、起伏、膝蓋彎曲都是平滑過渡，沒有速度門檻造成的跳變
- [ ] 腳步聲仍對齊腳著地的瞬間；跳躍、落地、衝刺、蹲、瞄準時的姿勢沒有退步
- [ ] 自動測試鎖定量測門檻，之後調動作資料超標會失敗

### 測試流程
1. 執行移動量測工具，看各速度的數字
2. 進遊戲左右移動、起跑、煞車、轉身，觀察身體高度平順、腳不滑
3. 聽腳步聲與腳著地同步
