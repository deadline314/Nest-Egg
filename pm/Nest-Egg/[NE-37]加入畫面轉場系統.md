# [NE-37] 加入畫面轉場系統

> 狀態：待辦

## 內文

### 需求
畫面切換目前就是直接切，沒有情緒。需要一套轉場（淡入淡出、光圈、掃描線、雜訊溶解、電梯門、百葉），並在適當的地方使用。

### 來源
2026-10-03，使用者於開發對話中提出：「幫我設計一些動畫跟轉場進去，還有過場動畫，就交給你設計了，發揮你的想像力」；「這些都可以去看看目前業界有哪一些最佳實例可以參考，我們盡可能設計的貼近完整實際的 Demo」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 有六種轉場：淡入淡出、光圈、掃描線、雜訊溶解、電梯門、百葉
- [ ] 轉場期間輸入鎖定，按略過鍵可以縮短
- [ ] 主選單進入遊戲、章節切換、死亡重來、從檢查點重生、結算畫面進出都使用合適的轉場
- [ ] 死亡重來的轉場不超過 1 秒
- [ ] 「減少閃光」開啟時，雜訊與閃白的轉場降級為淡入淡出
- [ ] 轉場不造成持續的記憶體增長，也不影響遊戲暫停狀態

### 測試流程
1. 逐一觸發每種轉場，確認外觀與時間
2. 死亡十次，確認不卡、不累積
3. 開啟減少閃光，確認降級
4. 執行完整測試套件，全部通過
