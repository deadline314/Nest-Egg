# [NE-81] 重畫頭目監管者

> 狀態：進行中

## 內文

### 需求
頭目監管者（warden）。目前是程式畫的暫代圖（或整隻用程式直接畫），要和凜一樣精細：由 Qwen 畫出透明背景的側面全身圖，再依這個角色自己的骨骼分成零件，裝甲做成獨立零件，受傷時逐片脫落。

外觀設定：銀白重甲、無表情面罩、巨大機槍；壓迫感
比例：巨大，約 6 頭身，身高約 97　發光色：紅。

### 來源
2026-10-03，使用者在凜（NE-17、NE-68～72）完成後要求重畫敵人與其他 NPC、精細度與凜一致、敵人依各自骨骼分件、可以的話替 NPC 加動畫；並確認先做人形、每個敵人有自己的比例、所有 NPC 都做、芽當成可操控角色設計。設計見 `design/12-cast-redraw/DESIGN.md`。

### 驗收條件
- [x] 外觀符合設定（銀白重甲、無表情面罩、巨大機槍；壓迫感）
- [x] 比例是這個角色獨有的（巨大，約 6 頭身，身高約 97），與其他敵人並排時能一眼分辨
- [x] 零件圖由定稿立繪切出，放大 2 倍看沒有多餘線條、碎片、拼貼感或色塊，邊緣沒有點狀亮邊
- [x] 裝甲（肩甲、胸甲、護臂、護膝等，依角色而定）是獨立零件，依生命比例逐片脫落噴飛，底下的身體完整，生命 100% 時外觀與完整立繪一致
- [ ] 預覽的八種動作（待機、跑、瞄準、蹲、跳、格擋、硬直、倒下）關節沒有露縫或錯位，手持武器位置自然、槍口位置正確
- [x] 發光部位（依設定）附上對應的發光層，位置與新圖一致
- [x] 遊戲內身高與碰撞框相稱（頭探出碰撞框的程度與其他敵人相近），受擊判定位置與畫面沒有明顯差距
- [x] 遊戲內的預兆、受擊閃白、死亡與掉落表現沿用原本的，沒有壞掉；在該敵人出現的關卡光影下清楚可辨
- [x] 頭目所有招式的預兆（紅色警示、瞄準線、衝擊範圍）位置與新外觀一致
- [x] 對話頭像與頭目戰前過場的監管者改用新造型
- [x] 附預覽（站姿特寫、八種動作、裝甲脫落各階段）與遊戲內截圖

### 測試流程
1. 依 `design/03-art-pipeline/CHARACTER_PIPELINE.md` 以配方與規格重新產生，確認零件、角色定義、法線都正確
2. 預覽站姿特寫、頭部放大、八種動作與裝甲脫落階段
3. 進入該敵人出現的關卡，與它交戰，確認預兆、受擊、裝甲脫落、死亡
4. 玩一次頭目戰，確認每個招式的預兆與外觀對得上

# Commit-1

## 內文

# Commit-2

## 內文

監管者換成新外觀後，頭目戰前過場裡它被放大到 1.8 倍，頭整個超出畫面上緣；核心外露時的弱點光環也畫在碰撞框 62% 高的位置，比新外觀的胸口低約 10 像素。
現在過場縮成 1.3 倍，整個身形完整入鏡，對話頭像用新造型；核心光環改成跟著新外觀的胸口走，不管動作怎麼動都對在胸口。碰撞框 86、畫面高 97，頭探出 11，與其他敵人相近。散彈扇形的槍口閃光與彈道都從機槍口出去，預兆、受擊閃白、死亡與掉落正常。在頭目機庫的紅色光影下對比 0.69，高於門檻 0.45。
預覽與過場中看得到軀幹下緣有一條平直的切邊、下面接著很細的大腿，另開 NE-181 處理，所以「預覽的八種動作沒有縫」這條退回未勾，本票維持進行中。
