# [NE-135] 打擊感實驗室：存檔回寫

> 狀態：待辦

## 內文

### 需求
調好的參數要能寫回專案資料檔，而不是看過就忘。要做驗證、差異預覽、安全寫入與備份，匯出版唯讀。

### 來源
2026-10-04，使用者要求處理打擊感；研究與設計見 `design/15-game-feel/RESEARCH.md`（第 8 節），母票 NE-130。

### 驗收條件
- [ ] 可把目前參數儲存到回饋資料檔，寫入前先驗證並顯示差異預覽
- [ ] 驗證失敗時不寫入並指出具體位置
- [ ] 寫入是安全的（寫暫存檔再替換），並留下備份；檔案差異只含被改的項目
- [ ] 寫入後重新載入的結果與寫入前一致（測試）
- [ ] 匯出的遊戲版本不能寫回

### 測試流程
1. 改幾個參數後儲存，檢查檔案差異只含這些項目
2. 故意輸入不合法的值，確認不寫入
