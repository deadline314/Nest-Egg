# [NE-50] 重寫第二章劇本並補上更多內容

> 狀態：待辦

## 內文

### 需求
第二章的劇本同樣需要依新風格重寫，並補上場景人物、更多通訊、收集品與回收伏筆。

### 來源
2026-10-03，使用者於開發對話中提出：「完善目前的劇情設計，整體起承轉合可以參照邊緣行者、尼爾之類類似宿命論這種」「劇情最好要有暗線、伏筆等等更有深度的設計」；「文本盡量減少AI感，可以看看實際文本內容應該是什麼」「`監視蜂在頭頂`這種句子就很AI味」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 依場景清單寫完第二章全部場景：開場、通訊、場景人物對話、記憶、迷你頭目、頭目登場、結尾
- [ ] 所有台詞通過劇本品質檢查
- [ ] 對白不教操作；每個講者有各自的聲音
- [ ] 第二章要埋與要回收的伏筆（F02、F04、F07、F08、F10、F11、F14、F15、F16、F17、F18）都有對應的文字或細節
- [ ] 第二章收集品增加到 7 件，文字符合風格
- [ ] 原有的劇情觸發、劇情道具取得與收集進度功能不變

### 測試流程
1. 完整玩一遍第二章，逐段閱讀台詞
2. 執行劇本品質檢查
3. 對照伏筆表確認埋設點
4. 執行完整測試套件，全部通過
