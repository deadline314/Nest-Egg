# [NE-27] 製作第二章關卡

> 狀態：待辦

## 內文

### 需求
第二章需要一個與第一章同規格的完整關卡：從開場到頭目戰到章節結算，並與第一章銜接。設計見 `design/09-content/DESIGN.md` 第一節。

### 來源
2026-10-02，使用者於開發對話中提出：「讓遊戲內容更豐富」；確認四個方向都要做（第二章／新關卡、新敵人與新頭目、場景互動與探索、成長系統），順序為先光影再內容。

### 驗收條件
- [ ] 第二章是一個可玩的完整關卡，包含開場過場、通訊、頭目戰、結尾與章節結算
- [ ] 至少五個區段，每個區段有自己的光影設定與色彩腳本
- [ ] 使用新敵人、新頭目與環境機關
- [ ] 每種機關（升降梯、閘門與開關、電力開關、油桶、玻璃牆）第一次出現時，放在沒有敵人的空曠處作為安全示範（提示文字已在 NE-30 完成）
- [ ] 至少四個檢查點，死亡後從最近的檢查點繼續
- [ ] 第一章結算後可接續進入第二章
- [ ] 關卡地圖通過自動可通行檢查，每個檢查點都能站穩
- [ ] 輔助、標準、硬核三種難度都能通關

### 測試流程
1. 從第一章結算進入第二章，確認銜接
2. 走完整個第二章，逐區段確認光影與敵人配置
3. 三種難度各通關一次
4. 執行完整測試套件，全部通過
