# [NE-453] 讓四章的地圖產生器重跑零差異

> 狀態：進行中

## 內文

### 需求
地圖由各章的產生器輸出，但其他線常直接改地圖 JSON（放人物、告示、機關），改完沒有寫回產生器；之後誰一重跑，這些東西就被洗掉。故事線回報第三章重跑時玻璃邊緣、夾層通道、樣品房仍有差異，也剛在第三章的廣場、泵室與兩個秘密空間、第一章麵攤的鐵皮棚放了東西。這張票把這些都寫回產生器，讓第一到四章的產生器重跑後地圖沒有內容差異，並加一支檢查：不改動工作樹地重跑四章產生器、逐檔比對，有人直接改了地圖沒寫回時指出是哪一區、哪一個檔。

順手處理兩件：第四章接線廊的劇情意圖是「下層一組看守、上層一組，玩家可以選正面通過或換層」，測試只數敵人數量，沒有確認兩組真的分在兩層、而且有換層的路；第二章北棟前室秘密空間的描述替劇情先命名了，改成只描述空間本身。

### 來源
2026-11-28，主 session 轉述故事線與使用者的要求（產生器由地圖線負責；之後任何一條線直接改 JSON 沒回報要能被抓到）。見[畫面與玩法的後續待辦](../../design/22-living-scenes/BACKLOG.md)的工具債。

### 驗收條件
- [ ] 第一到四章的產生器重跑後，地圖、關卡、人物、主題與遭遇資料都沒有內容差異（只容許資源編號、鍵順序、換行這類不影響遊戲的差異）
- [ ] 有一支檢查不改動工作樹就能重跑四章產生器並逐檔比對；有差異時指出區域與檔名，沒有差異時回報通過
- [ ] 故事線在第三章廣場、泵室、診所備品間、辦公接待廊維修廊，第一章麵攤鐵皮棚放的東西都在產生器裡
- [ ] 第四章接線廊的測試檢查地面與走道各有一組敵人、兩層之間有換層的路
- [ ] 第四章舊廠清掃路線的文件寫的是目前的敵人配置
- [ ] 第二章北棟前室秘密空間的描述只寫空間本身
- [ ] 受影響範圍的測試 0 個新失敗

### 測試流程
1. 跑產生器重跑檢查，預期四章都通過
2. 故意在一張地圖上改一格，再跑一次，預期指出那一區那一個檔
3. 跑第四章故事測試
