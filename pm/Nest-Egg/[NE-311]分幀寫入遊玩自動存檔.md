# [NE-311] 分幀寫入遊玩自動存檔

> 狀態：完成

## 內文

### 需求

移動、探索和例行狀態更新的自動存檔應在玩家操作時維持順暢。途中若切區、提交故事結果或明確保存，先前的自動存檔不能覆蓋新進度。

### 來源

Stanley 於 2026-11-23 要求完整修正關卡載入及遊玩效能。

### 驗收條件

- [x] 同一份序章存檔交替量測兩次。修正版真正寫入存檔，操作期間沒有超過 33.3 ms 的影格。
- [x] 暫存期間仍可讀到上一份完整存檔；校驗通過後才輪替主檔和備份。
- [x] 重要故事結果、同步保存或離開原畫面後，先前的自動存檔不得再提交。

### 測試流程

1. 在序章走動並等待自動存檔，再透過獨立程序驗證存檔。
2. 在暫存期間發起明確保存或完成故事，確認新進度不受舊暫存覆蓋。
