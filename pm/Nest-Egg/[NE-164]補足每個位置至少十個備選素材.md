# [NE-164] 補足每個位置至少十個備選素材

> 狀態：完成

## 內文

### 需求
每個位置要有足夠多的不同聲音可以聽、可以挑。要盤點每個位置目前有幾個備選，不足十個的去找更多 CC0 的音效與音樂補齊（音樂不同用途至少十首），新素材一樣登記授權並編號。

### 來源
2026-10-04，使用者要求每個遊戲內的聲音位置與每個候選素材各自編號（兩套不同體系、不同種類用不同前綴）、每個位置至少十個備選、實驗室能跨類別挑選，並維護一份位置清單 md；設計見 `design/16-audio/DESIGN.md` 5.1 節。

### 驗收條件
- [x] 每個位置（音效與音樂）都有至少十個備選素材編號，且備選與位置的種類相符（槍聲位置給槍聲、音樂位置給音樂）
- [x] 備選不足十個的位置，新找的 CC0 素材已下載、登記作者與授權並加入素材目錄
- [x] 音樂每個用途（選單、平靜、緊張、戰鬥、頭目、安全區、情緒、通關、死亡、地下、實驗室、花園）至少十首備選
- [x] 所有新素材的授權都確認是 CC0
- [x] 仍然找不到足夠備選的位置，在說明文件列出缺口與原因
- [x] 新素材有素材編號與預聽小檔案

### 測試流程
1. 執行盤點工具，列出每個位置的備選數
2. 確認沒有任何位置少於十個（或缺口已列出）
3. 抽查新素材的授權登記

# Commit-1

## 內文

原本每個位置雖然有備選，但音樂各用途的曲目少（選單只有 5 首、通關 5 首、屋頂 1 首），槍械操作、電話、跳彈、機械損壞等音效的來源也很單薄。
再找了一輪：新增 271 個音效素材包（約 2,300 個檔案：槍械操作與裝填、消音槍、電話撥號／話筒／鈴聲、跳彈與子彈掠過、機械與機器人、電弧、火焰與蒸氣、金屬／石頭／水中腳步、人與生物的痛呼、環境底噪與循環、UI、近戰…）與 178 首音樂（選單 18、實驗室 18、花園 16、緊張 26、戰鬥 20、頭目 17、平靜 21、安全區 19、情緒 17、地下 16、屋頂 17、通關 10、死亡 8）。素材目錄增加到 5,258 個素材（編號接在後面，舊編號不變），每個素材都有預聽檔。位置清單的每個位置現在有 30 個備選：先放目前用的，再放關鍵字對得上的（槍種、電話、跳彈…，不限類別），再依類別排序，所以電話亭的位置排在最前面的就是真的電話錄音。槍聲素材的說明（槍種、距離）也進了目錄，可以用 shotgun、AK 這類字搜尋。
授權複查：全部 734 個來源頁面重新抓取檢查，授權欄只能有 CC0；標示多種授權（CC0 與 CC-BY、OGA-BY、GPL 並列）的 11 個素材包剔除並刪除。Internet Archive 的 52 個包依 archive.org 的授權 metadata（必須是 CC0 1.0）；這是管理者設定的、來源可信度略低於 OpenGameArt 頁面，已在說明文件註明。找不到的聲音（電話撥號音與 DTMF 錄音、現代彈匣取放、軌道砲／能量砲專用錄音、消音步槍與衝鋒槍、單獨的子彈掠過、金屬格柵與濕柏油腳步、乾淨無字的人群低語、乾淨的夜城底噪；音樂的暗色賽博通關曲、工業節奏曲、無菌實驗室曲、獵人型頭目曲）列在說明文件。
驗收：音效測試套件新增備選檢查（每個位置至少十個、至少十個類別相符、音樂位置只有音樂、音樂十三種用途各至少十首、最新授權複查沒有問題、每個素材的素材包都在目錄裡、預聽檔齊全），連同實驗室與音樂測試共 18619 項通過。這張票是素材與資料，沒有畫面截圖。
