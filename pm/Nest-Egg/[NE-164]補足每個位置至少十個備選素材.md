# [NE-164] 補足每個位置至少十個備選素材

> 狀態：待辦

## 內文

### 需求
每個位置要有足夠多的不同聲音可以聽、可以挑。要盤點每個位置目前有幾個備選，不足十個的去找更多 CC0 的音效與音樂補齊（音樂不同用途至少十首），新素材一樣登記授權並編號。

### 來源
2026-10-04，使用者要求每個遊戲內的聲音位置與每個候選素材各自編號（兩套不同體系、不同種類用不同前綴）、每個位置至少十個備選、實驗室能跨類別挑選，並維護一份位置清單 md；設計見 `design/16-audio/DESIGN.md` 5.1 節。

### 驗收條件
- [ ] 每個位置（音效與音樂）都有至少十個備選素材編號，且備選與位置的種類相符（槍聲位置給槍聲、音樂位置給音樂）
- [ ] 備選不足十個的位置，新找的 CC0 素材已下載、登記作者與授權並加入素材目錄
- [ ] 音樂每個用途（選單、平靜、緊張、戰鬥、頭目、安全區、情緒、通關、死亡、地下、實驗室、花園）至少十首備選
- [ ] 所有新素材的授權都確認是 CC0
- [ ] 仍然找不到足夠備選的位置，在說明文件列出缺口與原因
- [ ] 新素材有素材編號與預聽小檔案

### 測試流程
1. 執行盤點工具，列出每個位置的備選數
2. 確認沒有任何位置少於十個（或缺口已列出）
3. 抽查新素材的授權登記
