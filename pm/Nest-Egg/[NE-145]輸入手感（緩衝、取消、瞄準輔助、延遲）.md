# [NE-145] 輸入手感（緩衝、取消、瞄準輔助、延遲）

> 狀態：完成

## 內文

### 需求
戰鬥動作的輸入緩衝與取消窗口沒有統一，手把沒有瞄準輔助，也沒有輸入延遲的量測。要做資料化的緩衝與取消窗口、手把瞄準輔助、延遲量測，並評估更高的物理頻率。

### 來源
2026-10-04，使用者要求處理打擊感；研究與設計見 `design/15-game-feel/RESEARCH.md`（第 6 節），母票 NE-130。

### 驗收條件
- [x] 戰鬥動作的緩衝與取消窗口寫進資料
- [x] 瞄準輔助只給手把，且玩家輸入優先
- [x] 實驗室顯示輸入延遲
- [x] 有物理頻率的實測結論，含最低規格機器的成本

### 測試流程
1. 手把與滑鼠分別測試瞄準
2. 在實驗室查看延遲數字

# Commit-1

## 內文

戰鬥動作的輸入緩衝與取消窗口散在程式與不同資料裡，手把沒有瞄準輔助，也量不到輸入延遲。
現在緩衝與取消窗口集中在一份資料（起跳緩衝、離地後仍可起跳、衝刺緩衝、近戰緩衝，上限 0.3 秒，壞值退回預設並記錄）；新增衝刺提前按：冷卻或收招中提前按，結束的瞬間自動衝刺。手把有瞄準輔助：只給手把（滑鼠永遠不受影響），目標要在搖桿方向的錐形與距離之內，越靠近中心拉得越多，拉力有上限；玩家搖桿正在快速轉動時輔助立刻關閉，輸入優先。射擊、近戰、起跳、衝刺從按下到效果發生的延遲會被量測，診斷面板顯示最近一次與平均。物理頻率有實測結論（見設計文件）：維持 60 Hz，90 Hz 約 1.3 倍成本、最壞延遲少 5.6 毫秒，120 Hz 的無頭量測異常，不能採用；沒有最低規格真機的數字，文件寫明要在真機上用同一支探針重量。
驗收：輸入手感套件 44 項（含近戰套件）、0 失敗（資料無錯誤、窗口來自資料與預設退回、輔助只給手把與錐形距離限制與快速轉動關閉與不越過目標、延遲量測與平均、衝刺提前按排隊後執行）。依指示沒有跑完整測試套件。
