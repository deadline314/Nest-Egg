# [NE-417] 盤點敵人與頭目的行為差異

> 狀態：完成

## 內文

### 需求
換皮的敵人很多，但戰鬥打起來都差不多。先把現有每種敵人與每個頭目的移動、攻擊、預兆、弱點、逼玩家做的反應列成一張表，標出行為幾乎一樣的種類，以及還缺哪些會逼玩家換打法的角色（持盾推進、遠距壓制、會繞後、會呼叫支援、怕光或怕水）。每個頭目列出目前的招式與階段，寫出哪些招式只能靠輸出解、哪些要靠移動或環境。之後補敵人行為與改頭目的票都從這份盤點排順序。

### 來源
2026-11-28，使用者指示：「故事、遊戲玩法、地圖、關卡細節、敵人、Boss 動作等等的，可以開多個 Session 同時做。關卡的玩法跟內容可以更多變一點，不要只有枯燥的射擊。」後續清單見[畫面與玩法的後續待辦](../../design/22-living-scenes/BACKLOG.md)「敵人與頭目」第 1 項。

### 驗收條件
- [x] 每種敵人一列：出現在哪裡、移動方式、攻擊與預兆、弱點與對付方法、逼玩家做什麼；正式章節與只在舊開發關卡的敵人分開
- [x] 標出行為幾乎一樣的種類（同一套行為只差數字、或節奏相同的不同行為）
- [x] 列出缺少的角色，分別寫正式章節與整個專案有沒有
- [x] 每個頭目列出階段與每階段的變化、每一招的預兆與化解方法，並分類為輸出、移動、格擋或環境
- [x] 內容從程式與資料讀出，數字與實際資料一致
- [x] 寫出這條線接下來的順序

### 測試流程
1. 打開[敵人與頭目盤點](../../design/22-living-scenes/ENEMY_ROSTER.md)
2. 任挑一種敵人或一個頭目，對照它的資料檔與行為，預兆時間、傷害、招式清單一致

# Commit-1

## 內文

敵人與頭目的行為差異沒有整理過，不知道哪些是換皮、缺什麼角色。
現在有一份盤點：正式章節只用到 11 種一般敵人與 4 個頭目，其中只有兩種節奏（往前衝的近戰、站著鎖定的遠程）加兩種空中單位；另有 26 種敵人只在舊開發關卡。章節裡完全沒有持盾推進、遠距壓制、繞後、叫增援、怕光或怕水的敵人；其中「繞後」、「叫出新的敵人」、「怕光或怕水」在整個專案都還沒有。四個頭目都沒有一招要用玩家前面學過的機關化解；裁的第二階段沒有轉換停頓與提示，看門狗的階段轉換若發生在跳砸空中會被略過。最後依缺口排出接下來的順序：繞後、叫增援、持盾推進，再改看門狗。
抽查：看門狗的階段門檻與招式、清掃兵與槍手的預兆、探照無人機的警報範圍，與資料檔逐項對照一致。
