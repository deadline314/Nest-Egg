# [NE-321] 平滑高更新率下的走路畫面

> 狀態：完成

## 內文

### 需求

角色持續移動時，背景與主角應平順更新，並維持原本的鍵盤操作與 60 Hz 物理。換區、電話亭定位、坑洞回復與離開載具後立即顯示新位置。[遊玩效能設計](../../design/20-campaign-experience/LEVEL_ENTRY_PERFORMANCE.md)

### 來源

2026-11-24，使用者回報一直往前走時有明顯的斷續頓挫。

### 驗收條件

- [x] 144 Hz 實機持續移動且鏡頭未到邊界時，背景位置逐格變動。
- [x] 行走距離與物理頻率維持一致。新關卡立即完成對位，HUD、準星及文字避讓跟隨當格畫面。

### 測試流程

在第一章街道雙向持續走動，逐格記錄角色位移與背景。重複固定 60 fps 驗證；檢查瞬移、彈帶、角色狀態與世界文字。

# Commit-1

## 內文

插值由關卡鏡頭為主角與自身啟用。定位時發佈目的地的鏡頭變換，再做平滑更新。進入畫面的 HUD 與文字沿用該影格的畫布。

### 測試結果

- RX 9070 XT Forward+，144 Hz，同一條街道與輸入走了約 2,452.16 世界像素。穩定移動且鏡頭在界限以內的連續影格，背景位置相同由 1,624 / 2,610 降至 0 / 2,848。最長影格 27.86 ms 降至 17.68 ms。
- 固定 60 fps 的先行候選驗證，986 組穩定移動影格都各有背景位移。物理頻率皆為 60 Hz。
- 受影響的 73 組測試共 92,362 項通過。首次有一個程序未產生測試結果，單獨重跑該程序的 10 組，全數通過。
