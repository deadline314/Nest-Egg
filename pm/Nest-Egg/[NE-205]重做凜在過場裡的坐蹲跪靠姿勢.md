# [NE-205] 重做凜在過場裡的坐蹲跪靠姿勢

> 狀態：進行中

## 內文

### 需求
第一章當舖過場裡凜「蹲在櫃台前」的姿勢沒有任何支撐：臀部懸空、雙腳不踩地，身體角度和櫃台沒有關係，看起來像在半空中半跳。需要為凜設計一組自然的過場姿勢（站、靠、坐、蹲、跪、遞東西、拿起東西），姿勢依凜自己的比例（腿長、厚底靴）與場景的地面、椅子、櫃台高度校正，讓重心落在支撐點上；並讓過場的檢查能提早發現懸空與穿模。

### 來源
2026-10-05，使用者試玩第一章後回報（當舖過場截圖）：「女主在這個過場的動作還是很奇怪，為什麼套上骨架之後主角的各個部位的圖看起來都是破圖？那我當初繪製那麼好看的立繪就被浪費了，可以開票幫我處理到好嗎？看有什麼做法可以讓我套上骨架之後主角動起來的整體畫面還是好看且漂亮，然後所有 NPC 動起來不要那麼像機器人」。分析與做法見 `design/12-cast-redraw/RIG_QUALITY.md`。

### 驗收條件
- [x] 凜有坐（椅子、箱子）、蹲、單膝跪、靠牆、靠櫃台、站著遞東西的姿勢，各自重心穩定、雙腳踩在地面或支撐物上
- [ ] 第一章所有過場裡凜的姿勢逐一檢查：臀部、雙腳與地面或椅面的距離在容許範圍內，不懸空、不穿進家具
- [ ] 當舖過場（`ch1_c01_shop`）的凜與老 K 位置、視線與手勢自然，畫面截圖附在票上
- [ ] 姿勢切換（站 → 蹲、站 → 坐）有過渡，沒有瞬間跳動
- [ ] 過場檢查加入「角色離地面高度」與「與家具的相對位置」的檢查，違反時指出場景與角色
- [ ] 每個過場姿勢在過場倍率下的特寫沒有破圖（依 NE-203 的畫面標準）

- [ ] 本票統整出的規則、數值、檢查方法與踩過的坑，寫進 skill `rig-animation`（`.claude/skills/rig-animation/`），資料來源與出處附在 skill 的參考資料裡；之後做骨架與動畫都必須先讀這份 skill
- [ ] 本票涉及過場演員站坐位置的規則、尺寸比例、位置與檢查方法，寫進 skill `scene-staging`（`.claude/skills/scene-staging/`：關卡與過場的佈景、位置、比例、構圖、圖層），參考多個不同業界實例並附出處；之後做關卡、佈景與過場都必須先讀這份 skill

### 測試流程
1. 播放第一章每一個有凜出場的過場
2. 在姿勢切換的前後暫停，量腳與地面的距離
3. 對照截圖確認坐、蹲、靠的重心
4. 執行過場檢查
