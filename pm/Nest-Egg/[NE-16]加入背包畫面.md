# [NE-16] 加入背包畫面

> 狀態：待辦

## 內文

### 需求
沒有地方可以一次看清楚武器、彈藥、道具與角色狀態。按 Tab 開啟暫停的背包畫面，以高清像素風與動畫呈現四個分頁。設計見 `design/07-weapons-inventory/DESIGN.md` 第 5 節。

### 來源
2026-10-03，使用者於開發對話中提出：「案 Tab 會有背包的畫面（可以的話用超高清像素風＋動畫）」；確認分四個分頁、開啟時暫停。

### 驗收條件
- [ ] 按 Tab 或 I 開關背包，開啟時遊戲暫停，關閉後繼續
- [ ] 背包有武器與彈藥、消耗品、劇情道具、角色狀態四個分頁，可用 Q／E 或滑鼠切換
- [ ] 武器分頁顯示每把武器的像素圖示、彈匣／備彈、類型與說明，可以直接換成手上武器
- [ ] 消耗品分頁可以查看數量並使用
- [ ] 劇情道具分頁可以查看說明，新取得的道具標記 NEW
- [ ] 角色狀態分頁顯示凜的像素立繪（有待機動畫）與生命、護盾、殘機、難度、遊玩時間、擊破數
- [ ] 所有圖示與立繪是高解析像素圖、放大後保持銳利，並可用同名 PNG 替換
- [ ] 有開啟、切換分頁、選取項目的動畫
- [ ] 每個可操作項目都有一句提示說明

### 測試流程
1. 遊戲中按 Tab，確認畫面暫停並播放開啟動畫
2. 逐一切換四個分頁，確認內容正確
3. 在武器分頁選一把武器，關閉背包後確認手上換成該武器
4. 在消耗品分頁使用醫療針，確認回血
5. 執行完整測試套件，全部通過
