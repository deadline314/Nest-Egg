# [NE-121] 把檢查點改成電話亭並加入互動與動畫

> 狀態：待辦

## 內文

### 需求
現在的檢查點是一根發光的柱子，走過去就啟動，沒有儀式感，也看不出它在世界裡是什麼。世界觀中，備份與復原的地方（錨點）是**老式公共電話亭**：拿起話筒撥給帳房，把現在的自己轉存一份；死後就在最近的亭子醒來；話筒裡永遠是沈望錄的標語「再來一次，沒關係」。

要把檢查點換成電話亭：玩家走近後按互動鍵拿起話筒才啟動，角色有對應的拿話筒、通話、掛上的動作，亭子本身有待機、啟動、已啟動的狀態與動畫。

### 來源
2026-10-03，使用者在戰鬥設計討論中決定「篝火用電話亭」，並確認改成按鍵互動、要有適配動畫；先開票放著，不立即實作。設計見 `design/15-combat-feel/DESIGN.md` 第 6 節與 `design/13-story-v2/WORLD.md` 的錨點說明。

### 驗收條件
- [ ] 檢查點的外觀換成老式公共電話亭：玻璃帶雨痕、發光，未啟動與已啟動的光色與亮度不同
- [ ] 玩家走近時出現一句提示（例如「撥號備份」），按互動鍵才會啟動；只是路過不會啟動
- [ ] 啟動時角色做出拿起話筒、通話、掛上的動作，期間不能被打斷成怪異姿勢；通話時間短（約一秒內），不拖慢節奏
- [ ] 啟動時話筒播放標語「再來一次，沒關係」的錄音音效（先用占位音效，內容留給之後的配音）
- [ ] 啟動後行為與現有檢查點一致：記錄位置與武器配置，依難度回滿血，死亡後從這裡重來；已啟動的亭子可以再次互動（補滿彈藥、整備），不會重複扣東西
- [ ] 從這個亭子重生時直接顯示為已啟動，亭子裡有重生的小演出（錨點的語音與狀態列沿用既有死亡畫面，不重複）
- [ ] 手把與鍵盤都能互動，提示會依目前輸入裝置顯示正確的按鍵
- [ ] 角色的動作以骨架動畫實作，與現有人形動畫器的姿勢、腳步與手持武器相容；握槍或持近戰武器時，拿話筒會先收起武器再放回，不出現武器穿過身體的畫面
- [ ] 動作逐影格檢查：以骨架逐格播放並擷取畫面，確認拿起、通話、掛上每個階段的手臂、手持話筒與身體位置合理，沒有穿模、斷肢或姿勢跳變（本票的動作驗證以程式逐格擷取檢查為準，不需要人工驗收）
- [ ] 既有的檢查點相關功能與測試不變

### 測試流程
1. 走過未啟動的亭子，確認不會啟動；走近，確認出現提示
2. 按互動鍵，確認角色拿起話筒、通話、掛上，亭子變為已啟動，並播放標語
3. 手持槍與近戰武器各做一次，確認武器的收起與放回
4. 死亡，確認從該亭子重生且亭子已是啟動狀態
5. 以骨架逐格播放整段動作並擷取畫面，逐格檢查姿勢
