## 原始失敗與最小修正

原工具在地圖改版後仍用舊列座標，五張圖都是空景，卻 exit 0。改用現有地圖版本位移後，真實受擊的凍結特效又在安排下一個站位時恢復舊座標，令投手超出範圍；兩版失敗、唯讀位置追蹤、凍結快照及單一無敵控制均保留。正式示範只沿用既有無敵設定，沒有更改遊戲的受擊或凍結。

最後四個工具使用現有座標遷移，等待並確認真實敵人階段，將儲存／場景失敗傳到既有公開退出碼。共用登記的唯一呼叫端已同步處理回傳值；各情境沒有重複宣告新的失敗欄位。原遊戲載入與戰鬥流程不增加每影格工作。

`source/baseline`、`source/final` 保存四個完整前後來源；`raw/*/source-before.json`、`source-after.json` 記錄各次實際來源。原始第一次在 `56bb233d` 且含當時凍結的任務字形候選，非乾淨 main；後續隔離到 `6e47e2fe`。所有 epoch 明示於各 `request.json`，不混稱同一份來源。私有位置／凍結追蹤只在診斷複本執行，沒有加進正式工具。

封包省略各次隔離測試帳號的 user data，其餘 110 份原始結果、圖、來源快照、正式 shard log 均逐 bytes 保存；另附 19 份驅動／私有 fixture 與 9 份基準／候選來源。原始錯誤控制與歷史失敗沒有從 log 刪除。本資料夾的屬性只保留封包與原始紀錄 bytes，不放寬遊戲來源的格式檢查。
