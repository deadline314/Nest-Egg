# 第一章帳冊調查與機殼維修

本次沿用既有主角、手部接點、物件互動、場景人物與結果保存，新增夜晚當舖的鎖扣調查及倉庫的可選機殼維修。箱蓋保持關閉；機殼維修與原水閘獨立。原有十個任務及全部既有劇情段落逐項相同。

## 原生畫面

`native/` 是 Godot 4.7.2、Forward+、Vulkan、RX 9070 XT、640×360、固定60FPS 的直接輸出。13張原圖已逐張檢視，`viewed.json` 保留各圖 SHA。`frames.json` 記錄322個實際動作畫格；轉動／回彈時，帳冊箱30幀、抽水機33幀的掌心誤差均小於0.001世界像素。`raw.log` 與實際退出紀錄一併保存。

這是安排好的物件互動檢查。玩家經真正人物／物件入口及原選單觸發動作；倉庫敵人停用供拍攝。範圍包含可選拒絕、伸手、接觸、回彈、放手、回訪與機殼狀態燈。全章自然戰鬥、真人流程、實體手把、聽感、HDR曝光及效能配對量測屬各自驗收範圍。

## 重跑

使用專案的共享GPU鎖執行 `tools/ch1_maintenance_probe.tscn`，引數為 `--out=<獨立絕對路徑>`；設定上述渲染條件與隔離的APPDATA／LOCALAPPDATA／XDG_DATA_HOME／XDG_CONFIG_HOME。CPU測試使用 `tools/story/test_ch1_world_maintenance.py`、`test_story_contracts.py` 與 `test_completion_policies.py`。正式受影響回歸使用 `tools/run_tests_changed.sh 43c6429f8efabf1fbef79be4d9217526e91268a2`，保留選擇器決定的套件。

解壓縮後執行 `python verify.py <解壓目錄>`，核對原圖、接觸紀錄、原故事一致性及正式回歸的實際結果。接觸誤差是原生互動器的即時診斷值；讀取器沒有把它冒稱為從圖像重新量得的誤差。

## 診斷歷史

`history.json` 說明每次拒收或中止的原因，對應原始日誌保留於 `history/`。包括舊截圖器的退出資源錯誤、台詞子字串檢查、生成後支撐高度、測試讀取器錯誤與略過語意。它們均獨立於最終通過結果。

## 最終結果

正式受影響回歸：56組、59214項、0新失敗、0已知失敗，552秒。第一章／環境／任務指引／節奏四組9,803項全過；三組作者與結果契約測試31項全過。HUD雙解析度52項通過，六張原圖已檢視。
