# 守門人的外接工作架

門禁大廳的守門人使用原有人體骨架，外接工作架使用獨立的 256×272 透明貼圖。支架、完整／破損的盾板和通訊器、掃描臂與插銷共七個區塊，由[專案原創繪圖程式](../../../../art_src/characters/janus/work_frame/draw.py)逐像素重建。

Windows RX 9070 XT／Forward+ 在實際門禁大廳拍攝七個定點狀態。原版與新圖的盾板、盾鎖、臂鎖、通訊器、插銷位置，以及首領生命與狀態一致。近拍在兩側的低掃蓄力都顯示張開的臂鎖，盾裂、通訊器斷裂和停機後的亮插銷也可辨識。鏡頭近拍固定，以便核對外觀。

隔離副本分別餵入缺失路徑、錯尺寸貼圖及物件型別，三種異常各自記錄 `hooks.work_frame_art` 並回退到原線稿，每種的七張原圖雜湊都和原版相同。阿勇的 `hooks.baton_art` 也驗證錯型別後沿用線段，六個狀態與原版一致。各次異常驗證結束後還原設定。
