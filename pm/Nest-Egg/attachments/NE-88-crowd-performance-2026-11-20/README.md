# 十一名人形敵人的群戰效能

本機 AMD Radeon RX 9070 XT，Godot 4.7.2、Vulkan Forward+、1280×720、高光影，關閉垂直同步及畫面上限。使用同一測試場與正式敵人控制器。凜與 11 名敵人同屏，包含 8 種敵人，使用三種正式光影預設。每次暖機 3 秒後量 10 秒，依重畫前、現行、現行、重畫前的順序各跑兩次，共 18,301 幀。開始計時前截圖。四個程序各自開啟並隔離使用者資料。

現行場景、行為和動作資料取自 `73a354fbd`。兩組沿用同一份現行動作資料；修前組替換為 NE-74 前 `d906549a` 的原始貼圖、部件與共用骨架。Godot 使用舊匯入設定建置專用資源。舊監管者缺少現行受擊部位的 `core_port` 掛點，沿既有規則回退固定位置，日誌保留。凜未對敵人開火。每輪確認 11 名敵人的頭部與腳底都在畫面範圍，並有正式投射物。交戰中的自然遮擋仍會發生。
