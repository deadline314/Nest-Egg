# 葉的透明傘

葉的合攏透明傘由[原創繪圖程式](../../../../art_src/characters/ye/office_umbrella/draw.py)輸出 80×164 RGBA，傘面保留半透明，傘骨、束帶和傘柄仍看得見。傘柄的支點綁在辦公接待廊背景的桌沿，位於人物與玻璃後方舞台層級，換鏡頭時仍掛在同一個位置。

RX 9070 XT／Forward+ 播放正式 C18、C19、C20 共四個畫面。C18 先拿公文的畫面維持原樣，C19 葉掛傘後及 C20 兩個鏡頭的像素變化都只在桌邊傘的位置。編譯前後的中文、日文、英文、玩家選項、旗標與結果逐項一致。

原選擇器 33 套、51,947 項、0 新失敗、0 已知失敗、535 秒。[遊戲原圖、像素範圍與測試原始紀錄](evidence.zip) 共 26 檔，SHA-256 `277d6f27290be1dde788beef84314a98d1a6a00ebf361f806597f32dfdd3a942`。
