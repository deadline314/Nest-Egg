# 小薇的座椅與黃傘

二樓帳房玻璃隔間的小薇沿用現有骨架坐姿與互動，靠腳踏擺放一把合攏的黃色兒童傘。矮椅和傘用[專案原創繪圖程式](../../../../art_src/characters/xiaowei/office_seat/draw.py)逐像素重建，兩張 128×112 透明圖和各自的法線圖使用相同擺位。

RX 9070 XT／Forward+ 在正式帳房驗證兩側接近會自然轉向，骨盆和椅面接合，雙向的腳底都對齊地面及腳踏。原有對話完成後仍坐著。制伏結果旗標成立後人物淡出、道具切到空椅；重進同一關卡維持此狀態。玻璃遮擋和非戰鬥 NPC 由既有回歸測試核對，新增測試檢查坐姿與空椅切換。

原選擇器 55 套、64,383 項、0 新失敗、0 已知失敗、537 秒。[畫面、關卡探針、成果和測試原始日誌](evidence.zip) 共 33 檔，SHA-256 `c6d019013948a2b2c6a3c5c2b8638aa21af0164518929c0c8115ebff0e3adf6f`。
