# 第一、二章的通訊與對話頭像

以 Story 實際合併的正式章節資料核對繁中、日文及英文。正式第一、二章的 `dialogue`／`radio`／`cinematic` 共 55 個場景與每語 134 句，合計 402 筆顯示資料。每個宣告的頭像都能由引擎載入，通用圖只由紀錄、說明等系統角色使用。鷺、燈、榕伯、小販和沈望使用自己的頭像，遠處小販與市集小販共用同一人的頭像。

Windows RX 9070 XT／Forward+ 1280×720、文字 120%。用真實對話層顯示每種講者與通訊形式的 13 個樣本，另外經過 `Story.play` 播放六段正式內容，核對講者名與頭像的實際資源。探針在隔離地圖使用正式原文與介面，播放畫面涵蓋老 K、鷺、燈、榕伯、遠處小販與沈望。

這組驗證涵蓋可直接顯示頭像的通訊與對話。動畫舞台的逐段演出、地圖氣泡、自然關卡完整實玩及其他模型的視覺比對仍待驗收。本次交付為驗證紀錄，受影響選擇器回傳零套件。[原始程式、19 張原生圖、逐段資料與日誌](evidence.zip) 共 26 個檔案，SHA-256 `70e6992e139a1221f0c7fa16f129b6954825d9b0dba60819e11d467fd2b57f44`。
