# NE-257 貼腕袖口定案

原條件的袖口延遲改為貼腕收口隨前臂固定，自由衣襬提供小幅延遲；這是依使用者授權作出的設計調整，不宣稱原條件已實作。已查看近遠袖原圖的羅紋收口與現有下臂綁定，也重新查看Ghost Song／Dead Cells研究圖。

[source-receipt.json](source-receipt.json)逐一確認130份來源與Commit-6相同，包含主角圖、法線、發光、角色資料、rig與共用動畫器。cuff-rig-tests.log及原shard保存最新主線5,835／0（9秒），cuff-curves保存原工具30／60Hz全部序列（headless，不是新原生畫面）。research.json區分成功Spine官方頁、未成功Blender頁及專案推論。

[原衣襬負控制、像素／原生／效能與接點失敗](../NE-257-rin-cloth/README.md)、[原胸口／馬尾、30／60Hz與效能](../NE-257-chest-follow/README.md)保持原檔。原15,360筆／1,039接點失敗不算通過，只證明新增0；缺陷仍屬NE-222。軟體Forward+證據不冒充實體GPU、實體手把或整章人工體驗。

[Spine官方物理約束](https://esotericsoftware.com/spine-physics-constraints)支持依部位選擇物理影響，未宣稱有統一袖口規範。研究圖來源及原圖沿用[既有帳本](../NE-257-rin-cloth/references.json)，不取用為遊戲素材。
