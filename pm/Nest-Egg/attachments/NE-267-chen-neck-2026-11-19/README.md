# 陳女士頸部接合

敲擊循環中，下巴和衣領的動作交錯，幾個影格會在外輪廓內露出背景。依原始立繪的頸部與衣領位置重新分配重疊，把來源像素保留在原有頭部取樣格。頭部增加 20 個貼圖列，原支點與已發布的可見臉部像素維持。軀幹、肩部、骨架與演出資料仍用正式配置。

| 驗證 | 實際結果 |
|---|---|
| 雙向、遊戲及過場倍率 | 28,800 個原生接點採樣，166 個舊失敗下降為 64 個，新增 0 |
| 敲擊時原本封閉孔洞 | 24 筆降為 0，該動作另有 4 筆既有輪廓邊緣結果 |
| 正式客人簿 S19 | 3 段、14 張原圖，持碗接點 41 筆，最大偏差 0.00006824 舞台像素 |
| 原生站坐、靠身、蹲 | RX 9070 XT、Forward+，亮暗與左右四組 |
| 資源匯入與受影響回歸 | 4 組、7,366 項，0 新失敗，28 秒 |
| 可重建來源 | 覆寫重跑一致，來源損毀被拒絕 |

留存的 64 筆是原來的輪廓邊緣或關節採樣帶切到折彎部位，仍按既有檢查器判定。兩個先前試作的真原生結果收錄於 `diagnostic/`，完整候選沒有放寬判斷門檻。

調整來源前，在專案根目錄執行 `python art_src/characters/guest_chen_neck_20261119/rebuild.py` 核對原圖、取樣和正式貼圖。重切角色圖之前加上 `--write-overrides`，供既有分件流程套用已核對的來源與頭部成品。
