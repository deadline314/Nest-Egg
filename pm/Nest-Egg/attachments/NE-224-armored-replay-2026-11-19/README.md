# NE-224 重裝敵人整場驗收

基準 `0de0698ab57db76cee6344a393a74ec2ccff6aad`。Godot 4.7.2、AMD Radeon RX 9070 XT、Vulkan Forward+，每張原始截圖為 1280 × 720。三名敵人皆在正式 Level、正式 Player 與安排站位的測試場地交戰。為觀察每一階段，測試玩家為 999 HP，保留原本 1 秒受擊保護；敵方血量、階段、AI 與碰撞規則維持正式資料。

| 敵人 | 打法及戰鬥結果 | 裝甲四次脫落時的生命 |
|---|---|---|
| 鎮暴員 | P-9 真實子彈從背後打到 1 HP，公開近戰輸入觸發終結技 | 6、4、2、0 |
| 重裝機槍手 | 預熱、真實掃射打中玩家、散熱，再以 P-9 逐步打完 | 10、6、2、0 |
| 監管者 | 公開方向、瞄準、射擊與換彈輸入，實際手槍自然進入第二階段並驗證三種核心／身體命中，到 0 HP | 67、45、22、0 |

兩個方向的裝甲順序都為後肩、後前臂、後膝、胸甲。各案最後檢查原生穿著底層的頭、軀幹及骨盆仍可見。四個場次的重裝機槍手與鎮暴員紀錄在 `release-*`，兩個監管者場次在 `warden-*`。機槍手計算的是活躍子彈第一個觀測影格與槍口的距離，驗收範圍是一物理格飛行距離加兩像素。監管者核心砲的生成座標另有[獨立原點測試](../NE-81-core-origin/README.md)，其角色、武器和彈道來源自衣領交付以來一致。

回歸以 `tools/run_tests_parallel.sh --only=EnforcerArtDeliverySuite,HeavyGunnerArtDeliverySuite,HeavyEnemiesSuite,RigActionsSuite` 指定四套，33,058 項，0 新失敗、0 已知失敗。首輪嘗試只用手槍，鎮暴員到 1 HP 亮起可終結標記後尚未卸胸甲，因此保留在 `trial-right/`，正式重播改按原有終結鍵結束。

[原始紀錄](evidence.zip)含每個方向的 `command.json`、腳本、逐步 JSON 與未後製 PNG。重跑時在同一版本完成 Godot 資源匯入，把解壓後 `.tscn` 的外部腳本路徑改為同一資料夾內的絕對 `.gd` 路徑，再照收錄命令調整專案與輸出目錄。測試使用隔離的 `APPDATA` 與 `LOCALAPPDATA`，並照既有 GPU 鎖互斥執行。這一輪的證據範圍為上述裝甲、武器與實戰，逐格關節與主線難度另有對應驗收條件。
