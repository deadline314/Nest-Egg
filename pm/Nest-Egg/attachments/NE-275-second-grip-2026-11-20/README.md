# 雙手武器後手握位原生驗證

基準為 `baseline.txt` 的現行版本。候選只改後手握點的選擇順序。原始搜尋保留給離開射程、換側或沒有可確認的前次握位時使用。

- 原求解與候選在 60,000 組資料逐一回傳相同的 `Vector2`，包含遠座標、兩側切換、離開射程與無效前次握點。8 組各 36,000 次的穩定握位微量測，中位數約為 377 ms 與 22 ms。[求解結果](grip-check.log)
- Godot 4.7.2 Forward+、RX 9070 XT、1280×720、固定 60 Hz 下，五把原裝武器、長刀切回朝左及缺圖備援各擷取待機和攻擊。147 筆姿勢與重繪記錄、14 對原圖像素全部相同。[比較結果](compare.log)
- 以模擬手把瞄準方向驗證五把武器各四種動態與閃光輔助設定。[輔助設定資料](current-settings.json)
- 整幀計時使用相同裝備、1280×720、高光照、關閉垂直同步與畫面上限。先暖機，再跑六組交替的前後順序，每組每把武器各 600 幀。離子戰戟成對整幀中位數 +0.39%（-11.18% 至 +15.73%），液壓錘 -1.08%（-11.38% 至 +14.07%）。整幀波動大，這次只確認握位求解本身較省。[成對摘要](timing-summary.json) · [原始幀耗時](timing/)

在專案根目錄用 Godot `--headless --path .` 開啟 `replay/grip-check.tscn` 可重新比對求解。原生探針傳入 `--out=絕對輸出目錄`。畫面探針用固定 60 Hz，整幀探針取消固定幀率並傳入 `--tag=after-replay --perf`。用 `python replay/compare.py` 比較保存的原圖與逐格狀態，需要 Pillow 和 NumPy。
