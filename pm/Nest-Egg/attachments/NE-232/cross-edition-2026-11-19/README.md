# Windows 獨立執行檔跨章存檔

三份 `0.1.261112-candidate` 以 `99dfc03b2f2c0e2ea597fc6826d8e4ba8f3b5a8c` 固定來源建置。每份單獨複製到空目錄，啟動前後都核對原匯出清單的 EXE 校驗碼。Windows 原生視窗使用 RX 9070 XT、Vulkan Forward+，以滑鼠按跨版的「繼續遊戲」，再以鍵盤 Enter 從本版的存檔續玩。

| 路線 | 遊戲內實際結果 | 財產承接 |
|---|---|---|
| 第一章至第二章 | 第二章版顯示第一章接續提示，進入第二章的當舖入口 | 246 點 |
| 第二章至第三章 | 第三章版顯示第二章接續提示，進入第三章的當舖早餐目標 | 357 點 |

兩份章末測試存檔由對應固定來源的正式保存流程在隔離環境寫出。以測試工具進入末區並發送完成事件以建立資料。實際 EXE 從主選單讀檔，沒有變更執行檔、正式玩家資料或新章入口。

兩份新存檔都寫入新版自己的資料夾，舊槽逐位元保持。關閉後開新程序，恢復各自的難度、章節入口及成長，主選單無匯入提示。反向各開一次，較舊的 EXE 在只有較新存檔時會顯示所需版本，沒有「繼續遊戲」，退出後沒有建立舊槽，較新存檔的 SHA-256 一致。

6 個視窗程序都正常結束，原生日誌無腳本錯誤或退出時的資源洩漏。獨立資料版本的例行接續訊息保留。首次資料建立發生焦點過早的診斷，調整探針等待後兩份種子都乾淨退出。首次桌面前景切換失敗也保存為診斷，沒有計入這六個視窗程序。

附件含實際操作後的原畫面、原始 log、啟動命令、版本雜湊與測試存檔。正式遊玩的鍵鼠、實體手把與從新遊戲起全章通關各有獨立驗收條件。
