## Nonblocking extension boundaries

The current Rig texture path is cached standalone textures/CanvasTexture. AtlasTexture, alternate filtering, arbitrary clipping or custom shader discard are not a generic supported source guarantee; the current pool does not identify and reject every future custom texture/shader class. Future source changes need explicit adapter/rejection checks, not a silent claim of broad support. Polygon UV texture transforms and vertex-color replacement behavior were cross-checked against [Godot's official Polygon2D source](https://raw.githubusercontent.com/godotengine/godot/master/scene/2d/polygon_2d.cpp); that current primary source does not replace native verification of the exact installed engine.

Only the independent trail checkbox clears synchronously on display_changed. Quality reductions, reduced flashes or particles=0 while paused change effective policy, but existing samples are reduced/cleared at the next tick after resume. Helper's particles-zero assertion calls tick(0), so it does not establish immediate paused particles-zero lease release. This does not weaken the independent trail-off immediate contract.

CPU gdtoolkit parses seven reviewed .gd files. Full existing Player.gd reaches a gdtoolkit grammar limitation at the pre-existing local variable `set` (`754–755`), present identically in the lethal-fix preimage, which the tool parser treats as a keyword. It is recorded as a parser limitation, not mislabeled PASS or a new engine error. No Godot compile/test ran here; shader compilation, actual input, pixels and performance remain native evidence. The nine byte hashes were checked again without changing repo, Git, PM, prior Ctmp freezes or product sources.
