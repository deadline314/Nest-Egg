# NE-259：RX 9070 XT 原生交付證據

基準為 `38d8f3d3d404cb7baba0727804e86ffb1e882157`，使用 Godot 4.7.2、Vulkan Forward+、AMD Radeon RX 9070 XT。`frozen-candidate/sources.json` 列出最終七個來源的精確 SHA256，全部為 LF；產品只改敵人光的零件掛點／繪製層與看門狗的眼位／標記大小。人形骨架維持原偏移方式；沒有修改角色圖、骨架、傷害、死亡規則或光源預算。

## 實際缺口與修正

原生效能通過後，放大畫面仍發現看門狗眼燈不可見。第一個原版控制量到標記投影約 `(209.94,309.42)`，真正眼點約 `(192.10,327.09)`，相差約 25 像素；標記落在頭圖來源 `(80.32,97.89)` 的不透明像素，且自身 Z=1 低於頭部 Z=2。只升 Z 會把標記顯示在額角，移到眼位仍會留下過大的舊矩形。

實際來源紅眼的判準、14 個像素、半開 bbox `[158,118,163,123)`、來源圖與 SHA 都在 `eye-source-geometry.json`。中心 `(160.5,120.5)` 減支點 `(39,178)`，只乘一次貼圖縮放 `0.08`，得到關節中的遊戲像素偏移 `(9.72,-4.60)`；標記大小為實際 5×5 來源像素換算的 `0.4×0.4`。關節本身沒有貼圖的 0.08 縮放。

`eye-control-v1` 是真原版產品的三張運行中控制，僅首階段有完整座標收據；不把它冒稱逐階段完整。`eye-receipts-final` 在最終候選的單一敵人實例中明示復原原掛點函式和舊資料，固定其姿態，逐階段記錄真來源像素、basis、螢幕點、Z 與 PNG SHA。三階段分別是原值、只升 Z、移到眼位；它是運行中介入，不是歷史 checkout。最後一階段實際來源像素為 `(160.5,120.5)`，三格頭部 transform 完全相同。

正式回歸使用真正的頭部 Sprite2D 來源座標，測兩面向、三個頭角、非單位父縮放／旋轉、父鏈 Z、掛點釋放後的容錯，以及人形原偏移。原碼有效負控制 38/18；最終 40/0。首輪私有 fixture 漏了正式 smoke runner 的關閉畫外休眠設定，得到 38/20；那兩個人形翻面／死亡的 fixture 失敗與原 18 個掛點失敗分開保留，沒有刪除。

## 紅綠、正式結果與原始失敗

- Gate CPU：原工具 2/2、自然 exit1；最終 15/0、自然 exit0。包含六燈、完整對數、零／非有限耗時、預算溢出、1.050001 雖取整為1.05仍拒絕，以及死亡前無光的負控制。拒絕真的增加正式退出計數。
- 掛點回歸：原有效 fixture 38/18、最終40/0。四個 anchor CPU log 各有一筆原測試刻意觸發的 missing-part ERROR（`test_missing_prop_bone`），原樣保留；不是「整份 raw 零 ERROR」。
- 首次獨立讀者把 `1.70-1.69` 的二進位浮點尾差誤判為超出0.01，兩輪各2fail；結果檔另存。只在讀者的兩位小數亮度診斷增加1e-9比較容忍，未修改原生資料、性能 raw ratio 或105%門檻。
- 正式受影響34組、2程序自然 exit0／source-held，57,208 檢查、新失敗0、known0，745秒；兩 shard 實際末行為15,795／0與41,413／0。原始 ERROR 175／30筆為既有容錯負控制，原始 SCRIPT ERROR均0，沒有ObjectDB／CanvasItem／Area／resources的EOF診斷。原 filters／known清單與基準逐位元組相同，沒有放寬錯誤規則。實際產品七路徑的獨立選擇也同為34組，私有fixture未擴大選擇。

```powershell
python verify.py
# 產品合回後另核對工作區七來源；不改檔案

```

讀者離線驗每個 member SHA、實際來源、四輪 pair 中位數、眼來源像素／變換收據與正式末行，不依賴原 D 槽存在。`reproduce/` 保存啟動腳本與私有 fixture，原命令另見各 case 的 launch；重跑時使用自己的獨立輸出資料夾與共享 GPU 鎖，性能須獨占。腳本中的機器絕對路徑是原啟動證據，換機時只調 checkout／引擎／輸出位置。

原始 Godot Windows log 可能採系統 CP950，SHA／計數用原位元組，不轉碼改寫。局部 `.gitattributes` 僅保護 raw case、原來源及啟動腳本的位元組與換行，沒有變更任何遊戲測試錯誤篩選規則。個人 profile 與可重建快取不封裝。
