# NE-257 胸口跟隨：量測與原始資料

環境：雲端，Godot 4.7.2，軟體 Vulkan（llvmpipe）Forward+，1280×720。不是本機 GPU。

| 檔案 | 內容 | 指令 |
|---|---|---|
| `curves.json` | 真實輸入序列（站→走→跑→急停、起跳、落地、衝刺、再跑、轉身、靜止）下每個擺動的峰值角度與停下時間，60 與 30 更新率各一次 | `godot --headless --path . res://tools/sway_region_probe.tscn -- --curves --out=…/curves.json` |
| `region-fixed-angle-game.json` | 只動胸口、其他擺動固定 0，±0.06 弧度在關卡倍率 1.92 下改變的像素數與範圍 | `… sway_region_probe.tscn -- --angles=-0.06,0,0.06 --zoom=1.92 --out=…` |
| `region-fixed-angle-close.json` | 同上，倍率 6.5（比過場的 3.4 倍更近） | `--zoom=6.5` |
| `strip-*.json` | 連續影格的取樣時間與每格胸口角度（急停、起跳、落地、衝刺；朝右、朝左） | `… sway_region_probe.tscn -- --strip=land --zoom=6 [--left] --out=…` |

## 主要數字

- 胸口峰值（弧度）：急停 0.036、起跳 0.026、落地（衝擊 0.75）0.042、衝刺結束的急停 0.036；站、走（70）、跑（150）、衝刺中都是 0。
- 停下時間：每次事件後 0.3 秒內角度 < 0.002 且角速度 < 0.05。
- 30 與 60 更新率的峰值相同（小數第四位）。
- 固定 ±0.06 弧度：關卡倍率下改變範圍約 15×18 螢幕像素、43～46 個像素，全部在胸口；倍率 6.5 下約 50×65、約 475 個像素。腰、臀、腿、外套 0 改變。
- 效能（`tools/rig_perf_probe.tscn --count=10 --frames=600 --skin=rin`，有／沒有胸口擺動交替各三輪）：關節網格 10 隻每格 3705～4250 µs 對 3869～4157 µs，剛體 2930～3022 µs 對 2839～3046 µs；差異在雜訊內，剛體中位數多約 7 µs／隻（約 2%）。網格頂點數 423 不變（區域擺動在著色器裡做，不加頂點）。

## 調整紀錄

- 第一版上限 ±0.04、範圍外淡出到 1.4 倍長度：關卡倍率下約 1 個螢幕像素，幾乎看不到。
- 試 ±0.1：看得到，但胸口下方的腰線被帶歪（放大圖可見）。
- 定案 ±0.06、淡出縮到 1.2 倍長度，落地注入 −2.2、急停 1.4、起跳 1.0。
