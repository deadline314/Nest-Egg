# 跨版存檔提示的三語顯示

原本在日文與英文劇本語言下，主選單仍用中文顯示存檔版本及接續限制。現在可接續的版本、需要開啟的新版、右下角收錄範圍及繼續按鈕說明使用同一語言。存檔識別與發行版號報告維持既有格式。

以真實主選單讀取隔離的第一章章末存檔及第三章存檔。繁中、日文、英文各測可接續與需要新版兩種。原本 6 組只有繁中 2 組吻合，修正後 6 組都顯示正確版本與選項。兩個狀態都只讀原存檔，沒有寫出當前版本的槽。

RX 9070 XT／Forward+、1280×720、最大 120% 文字。六組提示全部在畫面內，行高合計 40／可用 64，收錄範圍沒有截字。發行工具 90 項，88 項通過，2 項為 Windows 符號連結權限案例跳過。首輪 Python 未將 UTF-8 環境傳給 Windows 子程序，讀取錯誤保留，使用一致編碼重跑通過。受影響回歸 21 套、9,652 項全過，241 秒。
