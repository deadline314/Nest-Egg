# 近戰武器持有圖的本機量測

候選把已有發光貼圖保留在一個可重用的 Sprite2D。它以同一握點更新轉換，並沿用發光強度。軟鞭的程序鞭身和找不到貼圖時的線段仍逐格繪製。測試確認四把剛性武器主節點的待機 60 次和揮擊／收招 75 次重繪降為零，五把武器的反射底圖也從 60／75 次降為零。軟鞭保有鞭身的 60／75 次，缺圖測試保有兩層的 60／75 次。這個計數描述繪製命令的重建次數。 [Godot 自訂 2D 繪製](https://docs.godotengine.org/en/stable/tutorials/2d/custom_drawing_in_2d.html)

五把武器、缺圖備援及反向切回長刀共 147 筆握點、繪製姿勢與招式狀態完全一致。比較 14 對 1280×720 原圖，單通道最大差異為 2／255，單張最多 163 個像素有差異。軟鞭與缺圖備援的兩對畫面逐像素一致。五把武器在一般、減少閃光、減少動態及兩者都開啟時，共 20 組真實遊戲設定驗證通過。

使用同一張 RX 9070 XT、Godot 4.7.2 Vulkan Forward+、1280×720、高光影，關閉垂直同步和幀率上限。歷史組使用原始提交 `a42eaa524`。現行及候選在 `113b22ac9` 上只切換 `game/player/melee_held.gd`。三個版本各跑一輪暖機，六組把版本順序輪替，每次每把暖機 150 幀後記錄 600 幀。共 54,000 個正式樣本，以下是每組整幀中位數的配對百分比，再取六組的中位數和範圍。負值代表候選較快。
