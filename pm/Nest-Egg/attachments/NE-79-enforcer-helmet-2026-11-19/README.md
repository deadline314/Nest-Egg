# 鎮暴員頭盔下緣

從仰瞄與倒地的實機畫面反查來源座標，在藍黑頭盔內襯延伸一小段，讓它在原支點下繼續與衣領相接。角色原圖、頭盔支點、黃色飾線及發光遮罩沿用。正式 152×160 貼圖和法線從同一份可重建素材產生。

RX 9070 XT／Forward+。8 種動作、左右面向和兩種倍率，隔離兩片與穿戴畫法各 3,840 項。兩種畫法都看得到的透光孔 150 → 8，兩種畫法均沒有新增封閉孔、游離片或接點中心漏空的樣本。穿戴畫法也會取到外層護甲的輪廓和縫隙，案件紀錄保留原有規則與數字。全身與剩餘接點留在原票繼續驗收。

前後實際交戰在既有測試場地使用同一個 99 生命的玩家，保留遊戲原有受傷保護。兩輪各 16 項通過。正面手槍被盾擋下 8→8，鎮暴員自然衝撞造成 2 點傷害，從後方打中 8→7。舊探針以 12 生命及零受傷保護讓玩家在衝撞時死亡，故修驗收站位的耐久配置後才做前後對照。
