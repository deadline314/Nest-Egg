## 保留的中途問題

v1因未處理無頭擷取而未完成，核對自己的PID後停止；v2–v8分別修正無頭剔除、矮牆前停步、頭目零血尚未完成倒地、重要通訊未讀完、過早清回下限導致別的敵人殺死等探針假設。v9原生只送合成MouseMotion，準星／實際方向未跟到目標、沒有命中，已停止；後續改用既有虛擬搖桿，不虛構OS同步根因。v10來源與續玩檢查通過，但死後照片仍是回溯卡，故v11增加鎖、暫停與轉場全釋放的檢查再拍。歷史來源、失敗、停止與退出原文均保留。

12張圖仍看到遠距水坑提示、過長／重疊世界文字；這些另在NE-228修正。本包只支持本條實際路線／續玩驗收，不代表全部UI、角色接縫、效能或故事語義已通過。phase1圖是實際排隊通訊，phase2／3才有戰中頭目，不將phase1冒稱有效命中截圖。
