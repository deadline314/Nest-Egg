# NE-97 第一章實機流程

Godot 4.7.2，RX 9070 XT，Vulkan Forward+。所有分段用普通難度及原本生命設定，透過 Main 接上前段實際保存的遊戲。沒有自行給道具、補旗標或重設敵人。這是用遊戲原有輸入和關卡執行的腳本走查，沒有量真人的遊玩時間。序章到街道離開的模式、先前版本與紀錄在 [第一段證據](../NE-97-street-radio-2026-11-19/README.md)。

| 分段 | 實際過程 |
|---|---|
| `native-warehouse-v2` | 從街道真出口繼續、清前廳，正常打倒看門狗並保留開門結果 |
| `native-flood-v2` | 於電話亭備份，操作兩個實際開關，踩坑底踏板後溺水一次，完成初次建檔並回到電話亭。使用水閘修正的第一版，該動作與正式交付一致 |
| `native-raft-v2` | 續讀同一存檔踏浮橋，從八層交錯平台到倉庫深處 |
| `native-vault-v1`、`native-upper-vault-v2` | 正式拾取，第一次驗證多要求一場可繞過的督察擊倒而停止。後一程序確認原道具並用二段跳上高台，下一次跳躍受擊後保留當時狀態 |
| `native-vault-bridge-v1` | 從前段當時位置重試原跳躍，走完倉庫深處的上層出口 |
| `native-handoff-v2` | 交盤、取回執、保存摘要，正常與阿梨用餐、回家並結束第一章，進第二章當舖。末段依正式提示等物件冷卻再按一次 |
| `native-ch2-open-v1` | 冷續玩保留第一章真實結果，在第二章早上結算、完成收音機與屋頂簡報，走到市集入口通過巡帳員。 |

原始資料中的 `produced-slot.json` 是對應程序正常退出時實際寫入的存檔，逐份核對保存資料與存檔內的 SHA-256。將前段檔案複製至新的隔離存檔路徑，依 `command.json` 使用原場景與輸入，來源腳本在 [證據包](evidence.zip) 中。解壓後調整 `.tscn` 及 `watchdog-driver.gd` 的本機絕對路徑引用即可重跑。最後主檔指向第二章當舖，第一章完成、紙本回執及摘要在手，資料盤的保管轉移給既有交接櫃，死亡次數為一。
