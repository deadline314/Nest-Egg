# 監管者前膝接點

Godot 4.7.2、RX 9070 XT、Vulkan Forward+。用正式載入器檢查八種動作、兩面向、兩倍率與 14 個接點。監管者每種取樣 53,760 項，蹲下及起跳的封閉孔在兩種取樣都是 4 → 0。原門檻和其他關節的輪廓記錄保留。

由真實骨架逐格量測手部與機槍。修前修後的 16 組結果相同，槍口誤差為零，掌心與握把最大距離 0.000009 世界像素。從左、右進入原頭目戰，實際手槍打完兩場，各 19 項，兩場都打到第二階段核心並看到四組裝甲脫落。

來源從定稿裁切圖延伸 51 個像素，切件尺寸與支點相同。由原生法線產生工具重建，只有膝縫周圍 404 個法線像素改變。4 套受影響回歸共 7,627 項全過，35 秒。
