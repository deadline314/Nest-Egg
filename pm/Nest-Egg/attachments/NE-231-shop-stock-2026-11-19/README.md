# 補給點的缺漏商品

測試貨架交錯放置遺失的商品、醫療針、沒有合法價格的商品、護盾電池。原版略過遺失商品後，畫面上的位置和購買時讀取的位置錯開。原測試重現 4 項失敗和腳本錯誤。

修正後留下兩個有效商品，確認時依卡片所指的商品扣款。只有損壞項目時保留空貨架提示與正常退出。既有關卡載入的資料診斷照常核對。

原生畫面使用 RX 9070 XT／Vulkan Forward+，顯示護盾電池售價 80。購買後由 1,000 信用點變為 920，護盾電池由 0 變為 1。購買按鈕的 Hover 文字使用同一價格。正式受影響回歸 4 套、1,194 項通過，62 秒。
