# NE-229 設定頁裝置與改鍵提示

設定頁先接收事件，可能使裝置觀察者收不到RB、改鍵或取消。修正先觀察事件，並在提示刷新時保留正在等待的「按下…」。手把短按可綁、長按0.6秒取消指實際B（右），不能隨鍵盤來源誤顯示Escape；Esc始終取消。

原生使用Godot4.7.2 Forward+/HDR、1280×720、llvmpipe與隔離設定。直接建立真正SettingsScreen，安排分頁／焦點／改鍵目標，以公開鍵鼠與虛擬pad999事件操作；不是Main全流程、實體手把或震動驗收。100%與120%各原版／最終九張，共36張逐張檢視。長句與按鍵狀態可讀；控制器頁原本為可捲動內容，不宣稱整頁無需捲動。120%共28筆狀態量測每輪均容納，最終最大359px、最少可用592px。四輪最終原生比較紀錄均0引擎ERROR／退出洩漏；完整套件中的既有錯誤診斷不因此宣稱全部0ERROR。

最初helper v1為442／7、原生22／7；v2為447／10、原生27／10。逐步加上實際捕捉提示與控制器說明檢查，最終相同helper得到448／11與28／11。原版本、觀察者單行控制與全日誌保留，未放寬原判定、未修改原選擇器、已知失敗或導航時間。
