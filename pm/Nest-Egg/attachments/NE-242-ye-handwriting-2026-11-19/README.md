# 葉的手背近拍

玩家在等候臺主動選擇看清手背時，看到一行可辨識字樣。兩個閱讀分支共用這個鏡頭。由[重建程式](../../../../art_src/characters/ye/handwriting/draw.py)從原有葉的袖口、腕帶、手部圖和專案字型重建 900×306 的透明近拍。

原生 Windows RX 9070 XT／Forward+ 拍到兩個分支各自的繁中、日文與英文字幕。六張圖的近拍字樣區像素一致，維持葉寫下的原文。兩個分支透過正式分派進入，以既有的跳過操作結束後都寫入旗標並發放 20 信用點。旗標已成立時無法重領。正式劇本只有兩分支的開頭鏡頭變動。

原選擇器 33 套、51,954 項、0 新失敗、0 已知失敗、529 秒。[三語原圖、獎勵檢查與回歸](evidence.zip) 共 34 檔，SHA-256 `00bbd5efee4ced84c62e95bf084b0b15b42a427c8a36e42100322a93c7053848`。
