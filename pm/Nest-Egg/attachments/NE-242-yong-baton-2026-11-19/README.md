# 阿勇的鐵棍貼圖

透過專案原創程式繪製 96×20 透明圖，在遊戲中寬 24、高 5。帶包帶的握柄、暗色護箍和磨損鋼材沿用阿勇的低彩度配色。正式貼圖由 [重建程式](../../../../art_src/characters/yong/baton/draw.py) 產生，可逐像素重建。沒有第三方圖檔。

二樓帳房的正式首領使用自己的手腕和前臂定位鐵棍。原生 Windows RX 9070 XT／Forward+ 在左右朝向各用實際物理步拍攝 0.15、0.30、0.45 秒的重擊蓄力，棍頭每格仍有紅色預兆。獨立的六狀態對照中，原版、貼圖版與缺圖版的握點、棍頭、首領生命和狀態一致。實際擊中三次鎖扣後棄棍，棄棍時手和棍尖的畫面區塊逐像素一致。缺圖版有 3 張全畫面與原版位元相同，其他畫面的動態背景與粒子另見原圖。

缺圖的隔離副本記錄 `data/bosses/yong.json` 的 `hooks.baton_art` 與遺失的路徑，並走原線段。失敗控制結束後還原原設定。Godot 匯入檔按原比例保留完整尺寸，透明預覽與資源由實際關卡讀取。

原選擇器 8 套、3,384 項、0 新失敗、0 已知失敗、130 秒。[原始截圖、動作數值、缺圖控制與測試日誌](evidence.zip) 共 51 個檔案，SHA-256 `da8460270fd2f7285200d48cc6b49e91ff31bcf70bce21a7491e178d658653da`。
