# [NE-43] 改版戰鬥介面

> 狀態：待辦

## 內文

### 需求
生命、頭目血條、武器欄、信用點、義體電量與提示橫幅仍是舊風格。需要依新的視覺語言重做，並維持動態介面的淡出規則。

### 來源
2026-10-03，使用者於開發對話中提出：「也設計一個好看合適的UI，現在的設計都太簡略了」；「這些都可以去看看目前業界有哪一些最佳實例可以參考，我們盡可能設計的貼近完整實際的 Demo」。設計見 `design/10-presentation/DESIGN.md`、`design/04-story/`。

### 驗收條件
- [ ] 生命與護盾改成分段的切角條，受傷時掉落的段落有殘影，低血量常駐並脈動
- [ ] 頭目血條有名牌與階段刻度，登場時從兩側展開，階段轉換時閃一下
- [ ] 武器欄顯示武器與彈種圖示，手上武器高亮
- [ ] 信用點與義體電量套用新元件；取得、檢查點、警告使用橫幅
- [ ] 通訊對話框改版：側邊滑入的頭像框、打字機效果、講者名字帶顏色條
- [ ] 所有元素維持原有的淡出與常駐規則；每個元素有一句說明（滑鼠移上去）

### 測試流程
1. 進入戰鬥，確認每個元素的外觀與行為
2. 受傷到低血量，確認常駐與脈動
3. 打頭目，確認血條與階段
4. 執行完整測試套件，全部通過
