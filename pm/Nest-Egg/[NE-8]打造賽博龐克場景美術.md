# [NE-8] 打造賽博龐克場景美術

> 狀態：待辦

## 內文

### 需求
把遊戲美術風格改為賽博龐克：雨夜的沉港市，霓虹招牌、全像廣告、多層城市天際線、雨與水花、霧氣與濕地反光，敵方機械改為霓虹機械風格。

### 來源
2026-10-02，使用者於開發對話中提出：「我希望遊戲的風格是賽博龐克」「整個遊戲應該要以美術風格、人物、劇情為主」。

### 驗收條件
- [ ] 場景持續降雨，地面有水花
- [ ] 有會閃爍的霓虹招牌與全像廣告，招牌光會映在濕地上
- [ ] 背景有多層視差的城市天際線與霧氣
- [ ] 整體配色以洋紅、青、黃霓虹為主光
- [ ] 無人機、砲台、自爆機改為霓虹機械風格
- [ ] 開啟所有效果時畫面仍維持流暢，不隨遊戲時間增加記憶體

### 測試流程
1. 從關卡開頭走到結尾，確認每個區段都有雨、霓虹與天際線
2. 靠近霓虹招牌，確認地面倒影與閃爍
3. 長時間停留同一區域，確認效能穩定
4. 執行完整測試套件，全部通過
