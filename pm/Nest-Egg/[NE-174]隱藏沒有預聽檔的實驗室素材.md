# [NE-174] 隱藏沒有預聽檔的實驗室素材

> 狀態：完成

## 內文

### 需求
有些素材包下載不到（來源網站 404 或 500），或素材還沒做過預聽檔，音效實驗室仍然把它們列出來，點了才發現沒有聲音。沒有預聽檔的素材不要出現在實驗室的清單裡，並告訴使用者有幾個被隱藏、怎麼補齊。

### 來源
2026-10-04，使用者回報：「因為有一些素材已經找不到了，還是該素材沒有被 build 過，就不要出現在音效實驗室，這樣也不會點了之後才發現沒有素材」（附下載素材包大量失敗的畫面）。

### 驗收條件
- [x] 位置的備選素材清單、跨類別搜尋結果、目前用的素材清單，都只列出有預聽檔的素材
- [x] 有備選素材因此被隱藏時，清單旁用一句話說明隱藏了幾個，以及補齊預聽檔的方法
- [x] 位置清單文件裡的「預計使用」紀錄不會因為素材沒有預聽檔而被改動
- [x] 預聽檔後來補齊，重新開啟實驗室就會出現
- [x] 沒有任何預聽檔的環境（例如 CI）也能正常跑，實驗室不報錯、測試不依賴本機有沒有預聽檔

### 測試流程
1. 暫時移走某個備選素材的預聽檔，開啟實驗室選到那個位置，確認清單不再列出它並顯示隱藏數量
2. 搜尋該素材的編號，確認搜尋結果也沒有
3. 補回預聽檔，重新開啟實驗室，確認它回到清單

# Commit-1

## 內文

實驗室的位置分頁會列出沒有預聽檔的素材，點了才發現沒有聲音。
現在位置的備選素材、跨類別搜尋結果、目前用的素材都只列有預聽檔的素材；有被隱藏的，清單最上面用一行灰字說明隱藏了幾個，以及用 python tools/audio/build_candidates.py 補齊。位置清單文件的「預計使用」不受影響（沒有預聽檔的素材仍留在文件和「預計使用」欄位）；預聽檔補齊後重新開啟實驗室就會回到清單。
驗收：測試裡暫時移走某備選素材的預聽檔，備選清單與以編號搜尋都不再列出且顯示隱藏數量，預計使用與文件內容不變，補回後清單恢復。測試改為自己建立所需的預聽檔，沒有任何預聽檔的環境（例如 CI）也能通過。這次沒有截圖：此環境沒有預聽檔，無法呈現有素材的清單。
