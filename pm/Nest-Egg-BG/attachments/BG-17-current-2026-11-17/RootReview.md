# BG-17 原生交付核對（2026-11-17）

Godot 4.7.2、Forward+／HDR 2D、AMD Radeon RX 9070 XT。本次保持既有原圖與世界尺寸，補齊過場的材質狀態與不同長寬比的四倍像素保護，並讓局部素材加工使用與完整加工相同的匯入分類。16 張 diffuse／normal／glow 匯入設定恢復必要解析度，沒有重畫素材、移動家具或改全域光影。

舊第一關實際載入的 663 筆新舊 Image 記錄逐筆獨立重算格式、尺寸及完整 mip chain：替換後歷史 321 張 322,205,351 bytes，現在 342 張 120,619,372 bytes，上限比 37.44%。歷史版本不支援預載快取內省，舊總量是下限，因此比例是保守上限；不是 PNG 檔案大小，也不是 dedicated VRAM。原歷史實際重新匯入，拒絕的過期 cache 對照沒有拿來替代。

低品質環境成本使用同一探針在歷史 ca369c71 與現在交替 ABBA，三處各 180 個影格、每版本各兩次：現在／歷史為 101.03%、98.80%、103.54%，全部低於 105%。12 張實際 PNG 是 320×180。每處原生記錄確認玩家不更新、NPC／ALWAYS 骨架／敵人均為零；正常模式控制保留兩名 NPC、兩個骨架、主角及五名敵人，故這是環境成本，不能冒稱完整交戰效能。只停 NPC 父節點的負控制確實退出失敗。原先未排除 ALWAYS 子節點的 122.99%／118.30%／119.54% 失敗保留；另一個數值達標但有外部 Godot 負載的 v3 也不作最後驗收。最終 v6 的 Godot 程序前後稽核為空、本工作測試與截圖皆已結束，持鎖交替完成；machine_exclusive 僅描述 Godot 程序稽核，不聲稱所有 OS 背景服務不存在。

可讀性使用原四份取樣工具、位置、16 個時間樣本、公式與門檻（主角 0.6、平台邊緣 1.0、敵人 0.45）。舊兩關 16 點、現行第一章 18 點、第二章 22 點、第三章 20 點，低／高品質及受限／全解析度均完成，共 304 張原圖、16 次自然 exit0、0 SCRIPT ERROR、9,549 份來源保持。全解析度工作副本只保留 930 份刻意還原的環境匯入差異，其餘現行程式逐份對齊。

舊關卡的失敗在全解析度亦重現，不能歸因縮圖。局部修正機庫兩世界像素頂邊 alpha 0.4→0.65，保留顏色；舊第二關最後回收員區域單獨使用 character_floor=0.7，其餘複製原 tower_white，第三章共用設定不變。新光影 id 沿用原通風與機房兩層環境音及音量。初次原 60 組測試 64,513 checks 有 1 項缺環境音映射失敗，原始紀錄保留；補映射後原 Audio／Music 27,822 checks 通過，最後從固定 011cfed6 基準跑原受影響入口 63 組、64,722 checks，新失敗 0、已知失敗 0、1,336 秒、10,085 份來源保持。匯入政策原五項 Python 測試及完整 --check 通過，分類／長寬比兩個單因素負控制均拒絕。

畫面核對先看 10 頁、29 組受限／全解析度並排，再看舊 330／400／492、當前第二章碼頭 120、第三章辦公廳原尺寸圖，以及舊 492 兩品質完整雙人補拍。頂邊、腳下平台、道具比例與世界尺寸保持，兩解析度無明顯外觀退化；自然雨霧相位不同，不宣稱像素相等。舊 492 原取樣相機會裁敵人腿，原量測保持原相機；另在取樣完成後只移相機補拍，兩人腳下座標保持、身體框完整入鏡，不拿補拍冒充原量測。

核對中發現世界提示每影格重新 visible，且人物恰好站在主角取樣點；原先 304 張數值雖通過，仍全部降為舊方法資料。共用取樣父工具改為持續停提示，並只停 PERSON NPC 及 ALWAYS 子節點，保留主角、指定敵人、場景物件。負控制 16 樣本確認舊畫面提示／NPC 重疊，observer 拒絕；修後 16 樣本提示與其他人物均為零，再跑上述全部 304 張。沒有降低門檻、移取樣點或隱藏場景道具。

角色增亮另用原格 HDR 與實際變形頭部 alpha 遮罩核對：三個固定點低／高品質 W/H 上限各為 0、0、1.5873%，空白 GPU 遮罩 H=0 必須拒絕。492 雙人補拍的原矩形上限約 2.34～2.36%，不能直接判頭部不合格；三個白像素都在真正頭部 alpha=0，完整可能頭部範圍 alpha>0 的 W 為零，仍除同一不透明 H，得保守上限 0。reader 從原 binary 獨立重算，未抬高 alpha 門檻或放大頭部面積。此推論只適用無不透明前景遮擋且形變保持的固定取樣，不代表自然交戰所有瞬間。

探針無效落腳點／壞遷移資料自然退出 2，PNG 儲存失敗退出 1，具體錯誤保留。Root editor 匯入自然成功，但會把 16 個候選 .import 換行 CRLF 改 LF，原 source_held=false 照留；備份 editor bytes 後還原受測候選，逐份 10,085 來源相同，再跑正式測試。早期 observer 的編譯錯誤與只等待尚未啟動的作業取消也保留，不稱歷史全部 log 乾淨。工作設定、存檔及大量 derived cache 不放公開附件。
