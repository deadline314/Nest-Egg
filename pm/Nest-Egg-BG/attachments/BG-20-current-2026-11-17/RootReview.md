# 畫面複驗範圍

修前與修後 9,544 份來源的差異只有巡覽工具；所有地圖、擺設、材質與遊戲行為相同。修後完整 11 區一覽均由全部格組成，沒有把黑格自動略過。低、高及全亮皆已檢視，重要位置另看原生 1280×720 圖；完整原圖在 ZIP，公開一覽在票的 images 資料夾。

| 區域 | 本輪確認 |
|---|---|
| 當舖、清晨當舖 | 牆上樂器、桌面、門與燈有實際安裝面；清晨光色變化保持 |
| 港區街道 | 新版上下層路線、看板立面、地面與高台分層；全亮顯示的實心區沒有被當成通路 |
| 電話亭巷 | 電話亭及海報落在立面，告示牌留在地面；高品質光束不取代低品質下的物件辨識 |
| 碼頭倉庫 | 修後不再被固定教學文字遮擋；貨櫃、泵、階梯、開關、門與平台支撐可核對 |
| 倉庫深處 | 多層平台與牆、門、貨櫃的位置一致；原低照度情境保持，不以全亮替代正常光照 |
| 復原休息室 | 桌椅、層架、牆面物件與出入口有各自位置，前後層次保持 |
| 屋頂 | 水塔與支腳、探照燈、梯子及屋頂落點可分辨；另看原尺寸低品質圖 |
| 清晨麵攤 | 攤車、雨棚、桌椅及門的用途與落地保持 |
| 序章試貨區 | 高低靶、沙包、記分板、訓練器及站位線有用途；平台托架與地面支撐清楚 |
| 交接櫃區 | 委託櫃、候診椅、復原館牆牌、排隊牌與傘架有各自安裝面；門前照明及主要通路保持 |

三個提示控制的原生圖均檢視：純場景沒有提示面板、看板立柱仍在；顯示主角保留看門狗提示；跟隨主角保留看板及醫療針提示。這是實際軟體控制的原生驗證，不是人工遊玩或實體手把驗收。

場景用途與靜態支撐沿用本票既有的逐件清單及前後對照鏈，本輪補上當前完整相機格、序章與交接櫃原圖及原場景合理性套件 459／0。純場景照片不另宣稱敵人動作、聲音或量化角色對比；這些依各自既有驗收與相關票處理。沒有新增或刪除遊戲擺設來使畫面通過。
