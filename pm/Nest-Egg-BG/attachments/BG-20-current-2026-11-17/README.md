Python 3.10+、僅標準函式庫：`python verify.py <此附件資料夾>`。程式逐檔串流驗證，不把全部圖片解壓或常駐記憶體，會重讀實際來源、索引、PNG 尺寸與測試終端結果。

ZIP 內 `final/` 為修後完整畫面，`controls/` 是保留主角提示的反向控制，`sanity/` 與 `affected/` 是原測試入口，`original/` 保留修前原始紀錄與被提示遮擋的倉庫畫面。其餘修前大量圖片留在本機 D 槽。執行設定、存檔與產生式快取均未封裝。
