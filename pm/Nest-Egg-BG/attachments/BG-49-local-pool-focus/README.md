# 港口光池：區域取值修正與同畫面霧量對照

先讀 User-guide 與[五款相近作品的實際圖片](../../../../design/08-lighting/READABILITY_REFERENCES.md)。圖片只借明暗層次、局部燈光與輪廓安排，不能推出其引擎實作或玩家偏好。技術核對採用 [Godot 2D 燈與陰影](https://docs.godotengine.org/en/stable/tutorials/2d/2d_lights_and_shadows.html)及 [Unity Frame Debugger](https://learn.unity.com/tutorial/working-with-the-frame-debugger)：分析畫面要核對實際繪製狀態；本工具沒有引入 Unity 功能。

## 問題與修正

原光池工具只移動鏡頭，隱藏的玩家一直在出生點。正式光影控制器依目標位置選環境光和霧，導致街尾港口過渡帶仍套用出生點的市集設定。現在以不參與碰撞的觀察點帶動原控制器，真玩家保持出生位置，避免走進故事／傳送門觸發區。每筆保留觀察點、燈、隱藏玩家的位置、區域、實際霧量、環境光、輪廓光與霧的時間；取錯位置直接回報失敗。

光池公式、取樣帶、百分位、最低分母、燈具、陰影、輪廓光、原24格等待和自然雨霧都保持。公式以下的程式與舊版逐位元相同。**這次只改量測工具，沒有再改正式光影設定。**

## 原生負控制與修後

Godot 4.7.2、Forward+、HDR 2D、Vulkan llvmpipe，非實體 GPU。三次運行皆無 ERROR／SCRIPT ERROR，世界旗標保持。

| 運行 | 結果 |
|---|---|
| 故意恢復「只移鏡頭」 | 8筆錯誤位置，退出1；港口燈錯套 market、霧量1.0 |
| 正確位置、高品質 | 8筆位置有效，退出0；街尾燈176欄為 harbor_approach，實際霧量0.957862609 |
| 正確位置、低品質 | 8筆位置有效，退出0；同一區段與實際霧量 |

原自然雨霧運行的街尾光池分別為高6.065、低5.867。雨霧相位不同，不能和舊工具的7.697→7.542全關中位數拼成修前修後；舊數值原樣保留但不再作為港口局部驗收依據。前兩次原生位置檢查在8655900f；後續rebase至1a6196ca只加入玩家生命週期重設及相關測試／證據，量測工具 SHA 不變。霧量配對在1a6196ca執行。

## 相同場景的霧量配對

獨立重跑診斷在正式街道建立同一盞燈、同一鏡頭及正確觀察位置，保留所有雨、霧、燈、陰影與輪廓光的繪製。固定場景模擬後，交替設定**運行中的港口預設霧量**1.3／0.5／1.3／0.5，每次用原控制器的空間插值與原光池公式，非歷史checkout。沒有改磁碟上的設定或將雨霧藏起來。

| 品質 | 霧量1.3時光池倍數 | 霧量0.5時光池倍數 | 兩次往返 |
|---|---:|---:|---|
| high | 3.819654 | 4.368423 | 各狀態數值完全相同 |
| low | 5.280101 | 5.881819 | 各狀態數值完全相同 |

燈176欄位於過渡帶，插值後實際霧量是1.025282434／0.957862609，不是整段1.3／0.5。每張保存雨時間與飄移、霧時間、鏡頭、輪廓光位置／能量／啟用、可見性與世界旗標，配對內全部保持。高低品質的自然起始相位各自不同，不能互相比倍數。這只證實既有局部減霧改善了此固定畫面的光池，不能替代歷史全關不退化、實體 GPU 或戰鬥驗收。

四張配對圖片均實際檢視。角色在此量測隱藏，因此本包不提供敵人全白像素比例；BG-49原四條驗收保持未勾。

## 重跑與完整資料

在自己的1a6196ca暫存checkout，正常匯入正式資源，將 [replay](replay) 的 after 工具放回 `tools/light_pool_probe.gd`。把 legacy 及 pair 的兩組 `.gd/.tscn` 放進 `work/`，使用原生Forward+：

```sh
<Godot4.7.2> --path <checkout> --rendering-driver vulkan --rendering-method forward_plus res://tools/light_pool_probe.tscn -- --level=ch1_street --quality=high --max=40 --tag=high --out=<absolute-directory>
```

改 low 重跑；legacy 改場景為 `res://work/light_pool_legacy.tscn`，預期退出1；pair 使用 `res://work/pool_fog_pair.tscn`，只用本固定第一章街道場景。結束還原自己的暫存工具，不操作別人使用中的分支。

原選擇器以1a6196ca為固定base，選出0組：工具未被遊戲套件涵蓋。因此另外執行以上真正原生負控制、兩品質位置檢查和霧量往返，不把0組稱為遊戲測試全過。[raw.zip](raw.zip)包含完整55份log、圖片、JSON與重跑紀錄；[逐檔SHA](manifest.json)、[來源與結論數字](summary.json)。舊錯誤資料不刪除，也不改選擇器、門檻或known failures。
