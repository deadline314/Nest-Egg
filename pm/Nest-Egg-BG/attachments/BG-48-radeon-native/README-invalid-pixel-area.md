# Numeric measurements invalidated by BG-53

All contrast/mean/edge numeric data in this folder were produced using the incorrect pre-BG53 pixel-area denominator. They must not be used as passed readability evidence. Earlier PNGs also used the pre-BG54 capture encoding. Raw files remain untouched for historical comparison. Corrected measurement output is in ../BG-48-corrected-2026-11-11/; the original/fixed-aim and related runs here are not overwritten or silently reclassified.
