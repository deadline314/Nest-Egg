# BG-31 原生路線驗收（2026-10-11）

環境：Godot 4.7.2 stable（ed1daf0bf）、Forward+ Vulkan、Intel Arc B580，視窗 1280×720。來源為 main `f048d9d1`，修正後另加本次提交的更動。每一列都是獨立的作業系統程序，自然結束。

路線：主選單 → 開始任務 → 選難度 → 逐句讀完開場 → 用移動鍵走到老 K 面前按互動鍵、逐句讀完對話 → 暫停選單回主選單 → 繼續遊戲，重複三輪 → 結束程序。另開新程序讀同一份存檔：繼續遊戲 → 讀老 K 的下一段對話 → 再三輪回主選單／繼續 → 結束。

## 結果

- 修正前 3 個程序中 2 個在結束時報錯（靜音音訊驅動；未用真實音訊驅動測修正前）。
- 修正後 14 個程序（10 個靜音音訊驅動、4 個真實音訊驅動）結束時 0 錯誤、0 洩漏警告；新局 126 項、冷讀 117 項檢查全過。
- 整條路線沒有出現 `uninitialized RID`、腳本或編譯錯誤。

## 範圍與限制

- 顯示記憶體是引擎自己的統計，不是驅動層對整個程序的量測。
