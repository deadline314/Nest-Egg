# [BG-44] 補上第三章泵室機關與夾層公告終端

> 狀態：待辦

## 內文

### 需求
第三章泵室的排水輪 4 格內沒有對應的東西，配電盤借地上的電纜束；夾層通道的公共通知終端 8.5 格內沒有擺設。三樣都是玩家要操作的機關或要讀的資訊。

### 來源
2026-10-12，場景素材 Session 盤點第二、三章場景缺口（使用者要求：先用場景包預覽盤點缺背景與缺物件的場景，一項需求開一張 BG 票，依票補齊）。盤點方法與完整清單見[第二、三章場景缺口盤點](../../design/20-campaign-experience/CH2_CH3_SCENE_GAPS.md)。

### 驗收條件
- [ ] 排水輪、泵室配電盤、公共通知終端各有物件，就在互動點上
- [ ] 排水輪看得出能轉，轉動前後有可見的差別（輪的角度或水流）；配電盤有開與關兩種樣子
- [ ] 每件寫明支撐
- [ ] 新圖是賽璐璐畫風（平塗、深色描邊、硬邊兩色陰影），依真實尺寸（公尺）對主角身高合理；提示詞與種子留在清單，可以重現；素材檢查通過
- [ ] 實際光影下，光影品質「低」與「高」各量一次暗場可讀性：主角 ≥ 0.6、敵人 ≥ 0.45、地面邊緣 ≥ 1.0，沒有比改之前差
- [ ] 場景巡覽（實際光影與全亮診斷各一組）修前修後並排附在票上；場景檢查 0 錯誤、0 警告

### 測試流程
1. 第三章進泵室轉排水輪、開配電盤
2. 到夾層通道看公共通知終端
