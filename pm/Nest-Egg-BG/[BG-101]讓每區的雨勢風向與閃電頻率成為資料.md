# [BG-101] 讓每區的雨勢風向與閃電頻率成為資料

> 狀態：進行中

## 內文

### 需求
雨現在只有開或關、全遊戲同一種強度與同一個風；劇情寫的「雨小了一點」（第一章麵攤）、「暴雨」（第六章港區廣場）、「斜雨」（第六章廣播站前庭）都做不出來。閃電的頻率寫在光影設定裡，很多區域共用同一份光影設定，沒辦法每區不同，而且有的區段每分鐘打到 8 次。

這張票讓每區的天氣成為資料：幾種天氣預設（乾、小雨、中雨、雷雨、暴雨、斜雨），每個區域指定一種並可以覆蓋其中幾項；雨勢決定雨的密度與亮度並可以隨時間緩慢起伏，風決定雨絲傾斜的方向與陣風，閃電頻率改由天氣決定並跟著色彩腳本的時段（白天、清晨不打）。每區下不下雨以故事線的時段表為準，「未定」的區域維持原本的樣子。設計見 `design/22-living-scenes/WEATHER.md` 第 3.1、3.9 節。

### 來源
2026-11-28，使用者要天氣更擬真（BG-100）；主 session 確認設計並指定：天氣表讀色彩腳本的時段、下雨與否和故事線的表不一致時測試要失敗、舊的閃電頻率欄位只標停用不刪。

### 驗收條件
- [ ] 每個天氣預設與每個區域的設定都讀得到；表上沒有的區域和修改前一樣
- [ ] 資料寫錯（不認得的預設、數值超出範圍、不是數字）時記錄是哪一區哪一項，該項退回預設值，遊戲照常
- [ ] 每區下不下雨和故事線的時段表一致：表上「是」的區域有雨、「否」的沒有雨、「未定」的不在天氣表裡；不一致時測試失敗
- [ ] 第一章麵攤是小雨、第一章港區街道是中雨、第六章港區廣場是暴雨，三張同一格鏡頭的修前修後看得出密度差別；第六章廣播站前庭的雨往另一側斜
- [ ] 雨勢隨時間緩慢起伏，不會被看成閃爍
- [ ] 閃電頻率來自天氣資料並跟著時段：白天與清晨的區域不打閃電；舊的光影設定欄位標成停用，數值不改
- [ ] 「減少介面動態」開啟時：沒有陣風、雨勢不起伏、雨的數量降到 60%
- [ ] 主角附近的雨不比修改前搶眼（近層雨絲的亮度不超過修改前）
- [ ] 影格時間（中位數、95、99 百分位）開關天氣對照記在票上
- [ ] 受影響範圍的測試全過

### 測試流程
1. 截圖工具分別拍第一章麵攤、第一章港區街道、第六章港區廣場、第六章廣播站前庭的同一格鏡頭
2. 預期：麵攤的雨最稀最淡，港區廣場最密；廣播站前庭的雨往左斜
3. 把天氣表某一區的預設改成不存在的名字，進那一區：log 寫出區域與欄位，雨照預設的中雨下
4. 設定開「減少介面動態」，連拍幾格：雨絲傾斜不變
