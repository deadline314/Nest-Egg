# [BG-100] 研究並設計更擬真的天氣表現

> 狀態：完成

## 內文

### 需求
使用者希望遊戲裡的天氣與效果（打雷、下雨）更擬真，並點名 Silver Pines（使用者說的「銀松鎮」）做得很好。現在的雨只有開或關、固定強度，同一層雨絲等長等速，而且畫在子彈與危險預兆上面；閃電把整個畫面閃到接近全白，室內也跟著閃；雷聲和距離無關；地面除了水窪擺設沒有濕的感覺；過場舞台的雨是一層細線、閃電是全畫面白色疊層。

這張票只產出研究與設計文件，定下之後每一張天氣實作票的方向、每區的天氣、各畫質的取捨、「減少動態」與「減少閃光」的退法，以及閃電不能超過的亮度、時間與間隔。

### 來源
2026-11-28，使用者原話：「我希望在遊戲裡面的天氣或是效果，包括打雷下雨可以再更擬真，像是有一個遊戲叫做銀松鎮我覺得就做得很好。」由主 session 開「天氣」線轉交。

### 驗收條件
- [x] 寫下 Silver Pines 能從官方頁面、評測與訪談確認的天氣與光影手法，確認不了的照實寫「沒有查到」
- [x] 另外整理兩三款雨與雷做得好的 2D 遊戲與現實資料，拆成可用的手法：雨絲長度與速度、分層、遠近、風與陣風、水花、滴水、漣漪、濕地反光、霧與雨、閃電的時間結構、遠近閃電、雷聲延遲、室內外雨聲
- [x] 盤點現在的雨、霧、水窪、閃電、雨聲、過場雨，逐項和手法對照列出差距
- [x] 定出每區的天氣資料與依據，「未定」的區域不猜
- [x] 列出每個效果在高、中、低畫質保留什麼，以及「減少動態」「減少閃光」時怎麼退
- [x] 閃電的亮度上限、每次持續多久、最短間隔寫死在設計裡，不整面閃白、不連續閃
- [x] 排出實作順序與每一項的驗收方式
- [x] 待辦表（`design/22-living-scenes/BACKLOG.md`）加上「天氣」一線與它的待辦

### 測試流程
1. 打開 `design/22-living-scenes/WEATHER.md`
2. 每一個參考手法都附出處；Silver Pines 一節分「查得到的」與「沒有查到的」
3. 閃電一節有寫死的時間結構、亮度上限與間隔；畫質與無障礙各有一張表；最後一節是實作順序與驗收方式
