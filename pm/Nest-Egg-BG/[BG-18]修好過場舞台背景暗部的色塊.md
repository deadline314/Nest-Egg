# [BG-18] 修好過場舞台背景暗部的色塊

> 狀態：完成

## 內文

### 需求
過場舞台背景（例如當舖內部）暗部可以看到一格一格的深色方塊。背景圖是有損壓縮、解析度偏低（1536×864），放大到全螢幕並被打光調暗後，壓縮方塊會浮現，看起來像破圖，和角色並排時更明顯。需要讓所有過場舞台背景在全螢幕下暗部漸層平順。

### 來源
2026-10-05，使用者試玩第一章後回報（當舖過場截圖）：「女主在這個過場的動作還是很奇怪，為什麼套上骨架之後主角的各個部位的圖看起來都是破圖？那我當初繪製那麼好看的立繪就被浪費了，可以開票幫我處理到好嗎？看有什麼做法可以讓我套上骨架之後主角動起來的整體畫面還是好看且漂亮，然後所有 NPC 動起來不要那麼像機器人」。分析與做法見 `design/12-cast-redraw/RIG_QUALITY.md`。

### 驗收條件
- [x] 全部過場舞台背景在 1080p 與 4K 全螢幕下，暗部看不到方塊與條帶
- [x] 找出哪些舞台受影響，記錄原因與處理方式（壓縮格式、品質、解析度或抖色）
- [x] 處理後貼圖記憶體與載入時間沒有明顯增加（預載與進場不退步）
- [x] 舞台背景製作流程更新，新的舞台不會再出現同樣問題
- [x] 修前修後的截圖存檔

### 測試流程
1. 逐一播放第一章與第二章的過場，在暗部截圖放大
2. 以全螢幕 1080p 與 4K 各檢查一次
3. 比較載入時間與記憶體

# Commit-1

## 內文

過場舞台背景（當舖、麵攤、復原館…）出現一格一格忽明忽暗的深色方塊。原本以為是有損壓縮，實際原因是第一章的舞台把「窗光閃爍」效果開在整張背景立繪上：這個效果每 16 像素一格、讓約兩成的格子忽明忽暗，整張場景被切成方塊。
修正：舞台資料不再對整張背景開窗光閃爍；舞台檢查加入規則——蓋住整個舞台的圖層開了窗光閃爍會被抓出來（附自動測試）。規則與踩坑寫進 skill `scene-staging`。
