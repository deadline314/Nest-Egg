# [BG-23] 回收跨區預載並限制貼圖常駐

> 狀態：待辦

## 內文

### 需求

背景預載不能隨跨區持續累積未回收貼圖。保留進場順暢與畫面完整，讓額外預載的數量、常駐量及回收結果能被實際量測。

### 來源

2026-10-10，使用者要求注意本機 RAM／VRAM，避免大量圖片常駐造成重新開機；本輪驗收發現背景載入沒有完成結果的領取流程。查核與預算界線見[預載設計](../../design/20-campaign-experience/PREFETCH_LIFETIME.md)。

### 驗收條件

- [ ] 進行中、待載與額外快取均有明確上限，連續換區不超限；附服務計數與真實 RAM 量測，估算量不冒充 VRAM。
- [ ] 完成或失敗的背景請求都能被回收；清除途中、暫停、回主選單及新遊戲不遺留失去追蹤的請求。
- [ ] 重複路徑不重複排入；缺圖或載入失敗會指出具體資源並安全略過，不阻斷遊戲。
- [ ] 正在遊玩的區域不因快取淘汰缺圖，背景、法線、發光與角色外觀在實際 Forward+ 保持正確。
- [ ] 反覆跨區後額外快取保持有界；記錄退出警告的前後差異，不把既有警告直接隱藏。
- [ ] 受影響測試全過，附反覆跨區紀錄與實際画面；不修改其他 owner 的未提交環境貼圖工作。

### 測試流程

1. 隔離程序核對真正貼圖載入的完成／領取狀態，測重複、缺圖、失敗與清除途中。
2. 連續往返多區並回主選單，核對上限、回收、工作集與退出紀錄。
3. 實際 Forward+ 比對區域背景與角色，確認暫停／換區後仍完整顯示。
