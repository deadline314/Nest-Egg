# NE-240 情境互動：調查、交付、修理的缺件清單（交給故事 Session）

2026-10-11，演出與鏡頭 Session 整理。演出組不寫劇情、不改旗標；下面每一項都要故事 Session（劇本與旗標）先交付，關卡位置沿用第一章產生器既有的擺設。
演出組收到後只做：人物的走近反應、手勢與姿勢切換、道具的開關與聲音同步、存檔後不重複。凜本人的新動作（蹲下翻看、伸手放入、蹲下修理）屬主角動作，由角色 Session 交付，演出組只引用動作名稱。

## 1. 調查：當鋪帳冊箱

- 現況：當鋪店面第 53 欄有帳冊箱（擺設，`pawnshop_front__locked_ledger_box`），不能互動；劇本裡沒有任何關於它的文字或旗標。
- 需要故事 Session 決定與交付：
  1. 箱子裡是什麼、和第一章哪一段伏筆接在一起（老 K 的過去？地下室？）。
  2. 調查文字：初次看 1～3 句、再看一次 1 句；鎖著或打不開時的 1 句。
  3. 旗標：看過帳冊箱（例如「帳冊看過」），以及會不會因此解鎖其他對話或線索。
  4. 老 K 對「凜翻過帳冊」的反應要不要開口；若只要身體反應，演出組用既有走近反應（皺眉、揮手「別亂翻」），不需台詞。
  5. 適用時段：第一章哪個時間點可以看（晚飯前、天亮後店面）。
- 演出組之後做：凜走近時的提示、老 K 在旁時轉頭看、看過後老 K 的走近反應切換。

## 2. 交付：復原館外的交接櫃

- 現況：劇本產生器已經有交接櫃的對話與交付步驟（放入資料盤、取回執、補印回執），但交接櫃在關卡裡**沒有擺設**（產生器的檢查表寫著 object absent，位置預定復原館第 8 欄第 19 列）。
- 需要故事 Session（與關卡負責人）交付：
  1. 把交接櫃放進復原館關卡（第一章產生器），確認位置與門的朝向。
  2. 確認「放入資料盤」「取回執」「補印回執」三步驟的觸發點都綁在交接櫃上，回執只發一次（死亡、讀檔後不重發）的規則寫在旗標裡。
  3. 櫃門開、關各需不需要一句提示文字（例如「櫃門彈開」），或完全不用字。
- 演出組之後做：櫃門開關與聲音和凜伸手同步、阿梨在附近時看向櫃子。

## 3. 修理：倉庫抽水機（或修復招牌）

- 現況：碼頭倉庫第 86 欄有抽水機（擺設，`dock_warehouse__water_pump`），不能互動；劇本裡沒有修理的情節與旗標，「修好後燈亮、水退」的環境變化也沒有對應的關卡狀態。
- 需要故事 Session 決定與交付：
  1. 第一章要不要有修理情節；要的話選抽水機還是招牌，修理是主線、支線還是可選。
  2. 修理的條件（需要零件或道具嗎？從哪裡拿）與失敗時的一句提示。
  3. 修好後的旗標，以及修好前、後的環境變化（燈亮、水位、可通行的路）——由關卡負責人做成機關狀態並存檔。
  4. 修好時有沒有人在場說話（鷺用無線電、或只靠環境變化）。
- 演出組之後做：火花與聲音和凜的手同步、修好狀態的燈與水的過渡。
