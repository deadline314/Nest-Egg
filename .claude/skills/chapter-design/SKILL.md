# 章節設計 skill

目的：章節不再是「走一段路、看一段過場、再走一段路」。玩家大部分時間在**玩**（戰鬥與探索），故事用**地圖上的對話、廣播、環境**講，只有真正改變世界的大事才用過場。
性質標記：**出處**（有文獻或業界資料）、**建議**（起始值，要遊測校正）。業界沒有公認的「戰鬥／探索比例」與「過場最短間隔」，下面的比例都是建議值，不是標準。完整資料與連結：`design/13-story-v2/PACING_REFERENCE.md`（讀過才動手）；位置與比例見 skill `scene-staging`；小瑕疵檢查見 skill `continuity-qa`。

## 五條鐵則

1. **過場只用在「改變世界狀態」的事**：地圖永久改變、角色關係不可逆（死亡、背叛、加入）、新區域或新能力的首次揭露、章末。其餘一律走地圖上敘事。全章過場 ≤ 3 次（開場 ≤ 20 秒、中段大事 ≤ 45 秒、章末 ≤ 60 秒），一律可跳過。
2. **兩次過場之間至少純遊玩 8 分鐘**（約兩個區域）；過場佔總時長 ≤ 5%。
3. **張力是折線**：谷與峰一樣重要（出處：Level Design Book、World of Level Design）。每區一條小弧線：進場（環境敘事）→ 遭遇 → 區域高潮（迷你頭目或鎖場）→ 獎勵與存檔；整章再疊一條大弧線，後段峰值逐區抬高，第 7 區略降。
4. **每個新機制走四步**：引入（安全、單一敵人、低代價）→ 練習（2–3 次變化）→ 組合（與已學機制混用）→ 考驗（區域高潮或迷你頭目，之後回頭路再遇一次）。一章只引入 3–4 個新東西。
5. **地圖是網不是線**：每區至少一條迴圈（單向捷徑把後段接回前段）、一個「看得到拿不到」的獎勵、一個秘密；有一個遠處可見的地標讓玩家知道往哪走。

## 比例與量測（建議起始值）

| 項目 | 目標 | 警訊 |
|---|---|---|
| 全章通關時間（首次） | 30–45 分鐘 | < 25 或 > 55 |
| 戰鬥／探索（含平台與機關）／休息／過場 | 40–45%／35–40%／8–10%／≤ 5% | 過場 > 8% |
| 每分鐘遭遇數 | 0.5–0.8 | < 0.3（走路模擬器）或 > 1.0 |
| 每區停留 | 3–6 分鐘 | 任一區 > 8 分鐘 |
| 連續無遭遇時間 | ≤ 60 秒 | > 90 秒 |
| 兩次過場間隔 | ≥ 8 分鐘 | < 5 分鐘 |
| 單一遭遇死亡占全章死亡 | < 15% | ≥ 20%（死亡熱點，要調） |
| 地圖對話被跳過率 | < 30% | > 50% |

## 戰鬥遭遇

- 遭遇 = 一連串支援多種戰術的系統性挑戰，不是「一堆敵人站在房間裡」。五拍：預告（看得到或聽得到，可偷襲或繞路）→ 接觸（第一個敵人教一個行為）→ 加壓（增援或第二種敵人，用到地形）→ 高點（打破節奏的轉折，如高處敵人、地形落下）→ 收尾（清空後短暫安靜與掉落）。小遭遇只需預告、接觸、收尾。
- 時長：小遭遇 15–30 秒、標準 30–60 秒、區域高潮 60–90 秒；非頭目戰超過 90 秒是疲勞點。
- 同屏上限（攻擊令牌，出處：id／Naughty Dog 的做法，數字是建議）：存活 ≤ 6、同時主動近戰 ≤ 2、遠程 ≤ 2、重擊／特殊 ≤ 1；前兩區再降一級（存活 ≤ 3）。
- 敵人要有分工：近戰突進者、遠程壓制者、扛盾（用格擋破防）、高處騷擾者；每場至少兩種，同類不連續超過兩場。
- 每區 1 場鎖場（區域高潮、入口預告、鎖場 ≤ 90 秒、2–3 波每波 2–4 隻、下一波在上一波剩 1 隻時入場並預告 1 秒）＋ 3–5 場開放遭遇（敵人沿路徑放置，可繞過、可偷襲、可帶到地形上）。
- 迷你頭目打 60–120 秒、2 個階段、用剛學的機制；頭目前一個房間放存檔點，頭目後放捷徑與氣泡。最終頭目 3–4 分鐘、3 階段。
- 地形配合：可破壞的掩體、上下兩層的垂直空間、危險地形（電擊地板、水、起重機）用在「加壓」那一拍，不要一開場就用；入口附近放弱敵、深處放強敵。

## 地圖

- 鎖與鑰匙：鎖 = 暫時過不去（太寬的縫、要打破的牆、高台），鑰匙 = 能力或機關；可見但不可達的獎勵，之後帶新能力回來拿（出處：Metroidvania 設計通則）。
- 單向捷徑解鎖後避免長路折返；回頭路要有新遭遇或新獎勵。
- 三段式：入口段（引入）→ 中段（發展、迴圈、捷徑）→ 高潮段（鎖場或迷你頭目）→ 出口段（獎勵、存檔、下一區預告）。
- 光與色：賽博龐克雨夜用亮度與霓虹色引導（出口與下一個目標略亮、危險略暗紅）；每區一個主色與一個地標，整章一座中央地標（多區從不同角度看到，最終戰在它頂端）。
- 每區至少一段爬升與一段下潛；跨區用垂直連接（升降梯、管線）形成立體地圖。
- 秘密：可破壞牆或隱藏通風管，一句話或一個視覺線索提示，獎勵是改裝零件或錢，不鎖主線。

## 敘事融入玩法（少過場）

| 手法 | 適合傳達 | 對流暢度影響 | 規格（建議） |
|---|---|---|---|
| 環境敘事（塗鴉、屍體、海報、道具） | 世界背景、前因、警告 | 零 | 一個畫面一個故事 |
| 地圖氣泡（NPC 或凜的內心） | 當下情緒、提示、關係 | 低、不停下、不鎖操作 | 每句 ≤ 18 字、最多 2 行、同屏 ≤ 2 個；顯示 1.2 秒 + 0.1 秒 × 字數（上限 4 秒）；一段連續 ≤ 4 句；兩段之間至少 20 秒純遊玩 |
| 廣播／無線電（可移動時播） | 委託、指示、情勢 | 低 | 全程可操作、可跳過 |
| 戰鬥 barks | 敵人反應、凜的吐槽 | 極低 | 每場最多 2 句、≤ 10 字、不重複 |
| 日誌／文件／物品描述 | 深度背景 | 零（自願） | 做成收集 |
| 過場 | 改變世界狀態的大事 | 高 | 全章 ≤ 3 次 |

- 出處：Half-Life 幾乎不奪走操控；Hollow Knight 用環境線索與短 NPC 對話；Dark Souls 靠物品說明與環境；Bastion 的動態旁白不重複；Hades 以短句分散在遊玩之間；Katana Zero 對話可打斷、不讓玩家等。
- 重要資訊（任務目標、機關提示）要重複：氣泡 + HUD 一行提示。玩家死亡重來時不重播長對話。
- 全章主要「劇情窗口」約 10–14 個（每區 1–2 個），每個 ≤ 15 秒，全部可略過。

## 工作流程

1. 先寫章節設計文件（`design/13-story-v2/`）：章節目標（一句話）、一頁式地圖圖解（區域連線、迴圈、捷徑、鎖與鑰匙、秘密、存檔點、地標）、逐區表（功能、時長、遭遇數、敵人種類與上限、新機制、獎勵、劇情窗口）、教學表、敘事表（每個窗口的手法與字數）、過場清單與判準、風險表。
2. 地圖由產生器（`tools/level/build_ch1.py`）資料化；敵人配置、遭遇、鎖場、機關都寫在資料裡，不改程式。
3. 劇本場景由 `tools/story/build_ch1_story.py` 產生：先決定每個窗口用哪種手法（氣泡／廣播／環境／過場），過場要通過上面的判準。
4. 檢查：`CutsceneChecker`、`StoryLint`、`Chapter1MapSuite`（可達性、敵人在可達處、出入口）、遊玩測量（遭遇數、死亡熱點）。
5. 遊玩測試至少 5 位沒看過的玩家，抓「同一處卡住 ≥ 3 人」；記錄事件日誌（遭遇開始結束、死亡位置、對話顯示與跳過、區域進出時間）。
6. 學到的新規則補進這份 skill 與參考文件。

## 專案內已經有的工具（做新章節先用這些，不要另外發明）

| 需求 | 工具 | 重點 |
|---|---|---|
| 同時攻擊的敵人數上限 | `AttackTokens`（`data/combat/attack_tokens.json`、`LevelData.attack_caps`） | 近戰 2、遠程 2；敵人行為的出手判斷寫 `_cooldown <= 0.0 and _token_free() and …` |
| 鎖場遭遇 | `MechanismData.Kind.ENCOUNTER` + `arena_gate` 的 GATE、`EncounterZone` | 範圍內事先擺好的敵人就是成員；增援、鎖場最長秒數、完成後存世界狀態；競技場閘門重生時一定打開 |
| 地圖上說話 | 場景 mode `bubbles`（`MapBubbles`） | ≤ 18 字、同屏 ≤ 2、不鎖操作；戰鬥短句標 `bark`（≤ 10 字） |
| 擺遭遇 | 產生器的 `Area.encounter(name, x0, x1, members, reinforcements, lock, slug, …)` | 成員數、同屏上限、鎖場範圍內敵人數都由產生器與 `Chapter1MapSuite` 檢查 |
| 設計資料與圖解 | `data/levels/ch1_design.json`、`python3 tools/level/build_ch1.py --render` | 每區的特色（迴圈、獎勵、秘密、地標、垂直空間）與遭遇清單；圖解輸出到 `pm/ST/images/` |
| 迷你頭目 | `EnemyData.persists_damage`（例：`ch1_inspector`） | 死後傷會留著，只回復一部分 |
| 引擎保留的地圖字元 | `# = ^ | ~ P C H B * & .` 與數字 | 新敵人、機關不要用這些字元；鎖場的動態字元用希臘字母 |

## 常見錯誤

| 錯誤 | 症狀 | 做法 |
|---|---|---|
| 走路 → 過場 → 走路 | 節奏碎、沒有累積感 | 過場 ≤ 3 次，其餘用氣泡與廣播 |
| 過場瑣碎、不知道在幹嘛 | 玩家跳過、記不得 | 只有改變世界狀態才用過場 |
| 戰鬥太少、太空 | 每分鐘遭遇 < 0.3 | 每區 ≥ 3 場 + 1 場鎖場 |
| 戰鬥擠成一團 | 被誰打都不知道 | 攻擊令牌、分工 |
| 全程鎖場 | 探索被打斷 | 鎖場每區 1 場 |
| 一次教太多 | 搞不清楚用什麼 | 引入→練習→組合→考驗 |
| 地圖是一條直線 | 沒選擇、沒回頭理由 | 迴圈、捷徑、可見但不可達獎勵、秘密 |
| 每區長得一樣 | 迷路、無記憶點 | 主色、地標 |
| 氣泡太長太多 | 讀不完 | ≤ 18 字、同屏 ≤ 2 |
| 難度尖峰藏在非頭目段 | 單點死亡占比高 | 死亡熱點 ≥ 20% 就調整；加檢查點 |
