## 取捨與注意

- 砲管圖比較暗（近黑藍），與砲塔（中灰藍）有色差，之後如要統一可在遊戲裡調色。
- 砲塔右側的接環可當砲管的樞軸位置；砲管圖的樞軸在左端圓環中心。
- 紅色雷射束本身沒有畫，只有鏡頭與砲口的紅光，雷射線之後用特效。
