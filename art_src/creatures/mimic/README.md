## 取捨與注意

- 兩張風格與配色一致，但**尺寸與比例不完全相同**：閉合圖的箱身約佔畫面寬 87%，張開圖的箱身只約佔 60%（箱身比較矮短、箱蓋掀起）。兩個狀態切換時，請以兩圖的「箱身底緣與箱腳」對齊並自行縮放，不要直接以整張畫布對齊。
- 閉合圖是略帶前視的透視（看得到箱蓋頂面），閉合圖看不到「嘴」的那一面；張開圖的嘴在右側面。
- 閉合圖整體偏暗（深灰黑加鏽橘），在深色背景上靠橫向紅色縫光辨識。
- 張開圖的箱蓋與箱身在鉸鏈處相連（alpha 是同一個連通區），要做開合動畫得沿鉸鏈處（圖左側、箱身上緣左端附近）切出蓋子；蓋子的內裡與牙齒是朝向觀看者的，切開後箱口內裡（紅色肉面）在箱身這邊。
