## 取捨與注意

- 用途是縮到很小、一群一起飛，所以只畫一張。拼合示意見 `pm/Nest-Egg/images/NE-93-assembly.png` 右下：一隻大圖與 14 隻縮放 0.16 到 0.3 倍的隨機旋轉／鏡像，縮小後輪廓與紅眼仍然看得出是蜂。
- 兩片翅膀畫在同一側（近側）一起舉起；做拍翼動畫時可把兩片翅膀切下來，繞翅根旋轉。
- 這隻是黃銅金，與第一章自爆蟲的「黃黑警示環」都有黃色，但章節不同（不會同時出現），且外型完全不同。
