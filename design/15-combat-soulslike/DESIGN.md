# 戰鬥系統與打擊感：魂系貫穿全遊戲

> 來源：2026-10-03 使用者說「魂系機制不只有最終 Boss，而是可以融入進整個遊戲的設計，這就是為什麼我有格擋加近戰；所以戰鬥系統、手感、打擊感是整個遊戲最重要的要素之一，僅次於故事與解謎機關的玩法」。
> 這份是**提案**，確認後才開票實作。數值都是起始值，要靠試玩調。
> 相關：頭目見 [../13-story-v2/BOSSES.md](../13-story-v2/BOSSES.md)，解謎見 [../13-story-v2/PUZZLE.md](../13-story-v2/PUZZLE.md)，近戰武器種類與敵人攻擊型態素材庫見 [../14-combat-variety/DESIGN.md](../14-combat-variety/DESIGN.md)。

## 0. 優先順序與「魂系」在這裡的意思

| 順位 | 支柱 | 說明 |
|---|---|---|
| 1 | 故事＋解謎機關 | 戰鬥不能壓過它：死亡本身就是故事（見 §6），戰鬥的挫折要有劇情的意義 |
| 2 | **戰鬥系統、手感、打擊感** | 每一場戰鬥都是「學一個動作、用出來」，不是清怪數量 |
| 3 | 探索 | 捷徑、錨點、隱藏路線 |

「魂系」不等於難。這裡取它的五個本質，**不取**它的懲罰與晦澀：

| # | 魂系的本質 | 在 Nest Egg 的做法 |
|---|---|---|
| 1 | 動作有承諾 | 每個攻擊都有前搖、出招、後搖；出招後不能隨意取消，只有衝刺能取消後搖（§2） |
| 2 | 敵人有文法，學會就贏 | 每種敵人只教玩家一件事；招式有預兆、顏色語言固定（§3） |
| 3 | 防守有回報 | 完美格擋讓敵人失衡，接處決；格擋不是只是少受傷（§4） |
| 4 | 死亡是學習，不是懲罰 | 死因看得出來；死亡畫面講機制；重來的路很短（§5、§6） |
| 5 | 打得贏的成就感 | 打擊感：命中要讓人想再打一次（§7） |

**不取**：晦澀的敘事、藏起來的機制（本作的原則是機制一定告訴玩家）、冗長的跑屍路、數值碾壓才過得了的關卡。

## 2. 玩家的動作（進攻端）

### 2.1 一個核心迴圈

```
讀預兆 → 閃避或格擋 → 敵人露出破綻（失衡、後搖） → 近戰輸出 → 失衡條滿 → 處決
```

槍負責**牽制與弱點**，近戰與格擋負責**傷害與失衡**。這個分工要靠數值做出來，而不是靠規定：

| | 槍 | 近戰 | 格擋／完美格擋 |
|---|---|---|---|
| 對生命的傷害 | 低～中，靠彈藥（有限） | 中～高 | 反彈子彈兩倍傷害 |
| 對失衡條的傷害 | 極低 | 中～高（重攻擊最高） | **最高**（完美格擋） |
| 風險 | 低（遠） | 高（貼身） | 中（要抓時機） |
| 用在 | 打飛行物、弱點、牽制、打斷遠處蓄力 | 破綻輸出、打斷近處蓄力 | 把敵人的大招變成自己的機會 |

### 2.2 近戰動作組（建議，隨 NE-117 實作）

| 動作 | 輸入 | 內容 | 備註 |
|---|---|---|---|
| 輕攻擊（三連） | 點按近戰鍵 | 三段，節奏由武器資料定；第三段有短暫停頓 | 揮空有後搖；每段可接衝刺取消 |
| 重攻擊 | 按住近戰鍵 | 蓄力後出招，衝擊力高、能打硬直；蓄力中可被打斷，**蓄力階段沒有霸體** | 敵人重招的最佳對應 |
| 衝刺攻擊 | 衝刺中按近戰鍵 | 衝刺距離的突進斬，打衝刺後的破綻 | 取代單純的「衝刺然後轉身」 |
| 跳躍攻擊 | 空中按近戰鍵 | 下劈，落地有硬直，打飛行與高處的敵人 | 落地硬直是風險 |
| 輸入緩衝 | — | 後搖最後約 0.12 秒內的輸入會被記下，後搖一結束就出招；與現有跳躍緩衝同一套寫法 | 手感的關鍵，見 §7.4 |
| 處決 | 敵人失衡時按近戰鍵 | 沿用現有終結技，改成吃失衡條（見 §4.3） | |

### 2.3 衝刺

沿用現有衝刺（無敵、0.17 秒、冷卻 0.4 秒），調整：

- **衝刺是魂系的翻滾**：無敵幀要「剛好蓋住大部分招式的判定」而不是整段無敵；起始值保持現有的 0.17 秒加 0.05 秒，等有了第一批敵人招式再依資料調。
- **後搖可被衝刺取消**，但衝刺本身仍有冷卻，不會無限取消。
- 衝刺中可以射擊的現有行為保留（不破壞原功能）。

### 2.4 資源：不新增體力條

魂系常見的體力條**在這款不加**，理由：

1. 目前已有彈藥、衝刺冷卻、護盾能量三種資源，再加體力會讓畫面與腦袋塞滿。
2. 「動作有承諾」可以靠前搖後搖達成，不需要體力：亂揮的代價是被反擊，不是沒力氣。
3. 護盾能量已經扮演防守的體力。

近戰消不消耗電量是 NE-117 與 14-combat-variety 的待決事項，**這份建議：不消耗，只靠前後搖與揮空硬直限制**（重武器的後搖與揮空硬直自然就重）。若試玩發現近戰可以無腦連打，再考慮加「過熱」，而不是體力。

### 2.5 近戰的欄位

建議**獨立的近戰欄位，槍與近戰同時帶著**（不是和槍搶同一個欄位切換）：槍的切換用現有武器欄，近戰是另一個武器。理由：魂系的節奏是「近戰、格擋、閃避」之間切換，如果每次還要換武器，節奏會被打斷。這是 14-combat-variety 待決事項 1，這裡給出建議。

## 3. 敵人的文法（防守端的資料）

### 3.1 顏色語言（全遊戲統一）

預兆要「看得懂」靠的是固定的顏色與形狀，不是每個敵人自己發明。

| 預兆 | 顏色與形狀 | 玩家的應對 | 例 |
|---|---|---|---|
| **可擋** | 白色閃光（出招前 0.2 秒以上） | 格擋；剛好擋是完美格擋 | 一般揮砍、子彈 |
| **要閃** | 橙色閃光＋地面標記 | 衝刺或跳躍，**擋不住** | 爆炸、範圍攻擊、抓取以外的大招 |
| **可斷** | 紫色蓄力光 | 重攻擊、近戰或射擊打斷蓄力 | 守門人的蓄力、沈望的筆記本 |
| **危險抓取** | 紅色閃光＋聲音 | 只能閃，擋不住也斷不了 | 抓取、吞噬 |

規則：

1. 同一種顏色在整個遊戲代表同一件事，頭目也一樣。
2. 預兆時間有下限（起始值：可擋 0.25 秒、要閃 0.35 秒、抓取 0.5 秒），**寫進資料驗證**，低於下限就報錯，這樣公平性是測得出來的。
3. 一個招式只屬於一個類別，不混用。
4. 色盲對策：除了顏色，每類有不同的形狀與音效（可擋＝弧線、要閃＝地面圈、可斷＝旋轉光環、抓取＝閃爍），選項裡可開啟高對比。
5. 彈幕的可讀性規則沿用 BOSSES.md。

### 3.2 每種敵人只教一件事

| 敵人類型 | 教什麼 |
|---|---|
| 清掃兵（遠程） | 格擋子彈、完美反彈 |
| 盾衛犬（衝撞） | 衝刺穿過、完美格擋讓它暈 |
| 近戰敵人（電鋸臂等） | 看預兆閃避或擋，打後搖 |
| 重裝敵人（高韌性） | 輕擊推不動，要用重攻擊或完美格擋 |
| 自爆類 | 擋不住的東西要躲 |
| 飛行物 | 槍的用途 |
| 精銳（組合） | 同時應用上面幾種 |

每一章的敵人名單互不重複（沿用 NE-97）。敵人資料新增：`attack_class`（可擋／要閃／可斷／抓取）、`telegraph_time`，由驗證器檢查下限。

### 3.3 敵人的失衡條

見 §4.2。每個敵人一個，由資料決定上限、回復速度、對各類攻擊的受力。

## 4. 防守與回報

### 4.1 護盾：能量改為「架勢」

現有護盾能量的行為保留（不破壞原功能），**在畫面與用語上改為「架勢」**，讓玩家與敵人用同一個概念：

- 玩家擋下攻擊：架勢降低。降到 0 破防（現有行為）。
- 完美格擋：**不消耗架勢**，甚至回復一部分（鼓勵冒險）。
- 這是 Sekiro 的核心。本作的差別是玩家還有槍，可以拉開距離重整架勢。

### 4.2 敵人的失衡條

| 項目 | 內容 |
|---|---|
| 來源 | 完美格擋（最多）、近戰（依武器）、反彈子彈（中）、普通子彈（極少） |
| 滿了 | 敵人**失衡**：硬直約 1.5～2.5 秒（頭目較短），此時近戰鍵變處決 |
| 回復 | 一段時間沒受力後慢慢回復，頭目回復得比雜兵快 |
| 與現有受擊分層的關係 | **疊在上面，不取代**：輕擊／畏縮／硬直仍然決定單次反應，失衡條決定「破防」。現有的「破防敵人」狀態改為由失衡條觸發 |
| 頭目 | 失衡條分段（例如沈望每階段一條），處決造成大量傷害但**不是一擊秒殺** |

### 4.3 處決

- 雜兵：處決直接擊殺（沿用現有終結技，回彈藥）。
- 精銳：處決扣大量生命。
- 頭目：處決造成大量傷害並進入長一點的硬直，**每個失衡條只能處決一次**，避免處決連鎖。
- 處決有專屬演出（慢動作與鏡頭拉近，克制），第二次起可縮短，避免看膩。

### 4.4 完美格擋的難度

窗口起始 0.16 秒（現有）。**不放寬預設值**，改由輔助選項放寬（§8）。完美格擋成功時，敵人的攻擊動作要「被彈開」（動畫反應，沿用 NE-102 的硬直反應），不是只有閃光。

## 5. 修復與錨點：魂系的「篝火」

### 5.1 錨點

世界裡的**錨椅**就是篝火（見 WORLD.md 的錨定規則）。坐上錨椅：

| 效果 | 說明 |
|---|---|
| 存檔 | 在這裡「備份」 |
| 補滿修復劑 | 修復劑（有限次數的回復，取代隨處撿的補品；沿用既有消耗品資料，上限與補充規則是資料） |
| 一般敵人重生 | **只有坐錨椅才會重生**（見 §6.2） |
| 傳送 | 在錨椅之間移動 |
| 整備 | 換武器、改裝 |

錨點的距離是魂系手感的關鍵：**頭目門前一定有近的錨點，從錨點到頭目不超過約 30 秒**（BOSSES.md 已寫「檢查點近」）。

### 5.2 修復劑

- 數量固定（起始 3 瓶，改裝可加），錨椅補滿。
- 喝的時候有動作（約 0.8 秒，可被打斷），這是魂系的風險點。
- 不在戰鬥中隨處掉補血，**掉落的主要是彈藥與帳**（錢）。

## 6. 死亡：和劇情「再來一次」接起來

這是本作最特別、也最容易衝突的地方，所以單獨說清楚。

### 6.1 兩條規則

1. **劇情規則（已定案）**：世界不會因為你死而重置。以死解謎（PUZZLE.md）、頭目的血量保留（BOSSES.md 看門狗）都靠這條。
2. **魂系規則**：重生有代價，休息才重置世界。

### 6.2 整合方式

| 事件 | 世界狀態 | 玩家狀態 |
|---|---|---|
| **死亡** | **保持**：已擊倒的雜兵不復活、已開的捷徑不關、頭目血量保留、謎題狀態保留 | 回到最近的錨椅；錨人記憶耗損一次（死亡畫面，見 PLOT.md）；**身上的帳掉在死亡處**，回去撿；再死一次，那筆帳就沒了 |
| **坐錨椅休息** | **重置**：一般敵人重生（頭目不重生，已擊敗的頭目與劇情敵人永遠不回來） | 補滿修復劑與彈藥 |

這樣的好處：

1. 死亡對進度的懲罰比傳統魂系輕（敵人沒復活），符合「死亡是學習」與「再來一次」的主題。
2. 休息變成**玩家的選擇**：不休息就帶著殘血繼續推，風險自負；休息就重置世界。這就是魂系的篝火張力。
3. 掉帳是現成的魂系回收機制，而且「帳」在世界觀裡本來就是命的單位，語意是通的。
4. 頭目血量保留，讓「挑戰頭目」變成可以慢慢磨的事，卻不是輕易過關：頭目會**在你死後回復一段（起始值：每次死亡回復 30% 已損血量）**，避免變成耗時間磨。這個比例要試玩調。

### 6.3 死亡畫面

已有：死亡次數、錨人耗損、敗北圖鑑卡的攻略提示（死亡一次就顯示機制）。補充要求：

- 死因要看得出來：顯示**最後一擊的來源與類別**（可擋／要閃／可斷／抓取），一句話。
- 沒有「讀取中」的長等待：從死亡到能操作，目標 3 秒內。
- 第二次死在同一個頭目：階段演出可略過，直接重來。

## 7. 打擊感

### 7.1 一次命中的組成（管線）

打擊感不是單一數值，是下面七件事**同時對齊**。缺任何一件都會覺得「軟」。

| # | 元素 | 在這個專案的現況與做法 |
|---|---|---|
| 1 | 預兆與蓄力 | 動作有前搖，讓命中有「重量的來源」；沿用 NE-107 的動作設計 |
| 2 | 命中頓幀 | **局部**頓幀（只凍結攻擊方與被打方，已有 `Fx.freeze`）；全域 `Fx.hitstop` 只留給完美格擋與處決這類大事件 |
| 3 | 敵人反應 | 三層（NE-102）＋方向（NE-103）＋非人形（NE-105）；新增「失衡」與「被彈開」 |
| 4 | 視覺 | 閃白（已限制不過曝）、火花、斬痕（拖尾）、衝擊方向的粒子；特效克制 |
| 5 | 聲音 | **分層音效**：輕、重、格擋、完美格擋、破防、處決各自不同，重擊帶低頻；音高依武器；一次命中通常是「揮動聲＋命中聲＋材質聲」三層 |
| 6 | 鏡頭 | 震動依力道（`Fx.shake`）、處決時微幅拉近；**不要每次命中都震**，輕擊不震 |
| 7 | 控制回饋 | 輸入緩衝、取消窗口、命中後的動作補償（命中時角色微微前傾或後座），玩家覺得「手跟得上」 |

### 7.2 起始參數（依力道分級）

| 事件 | 局部頓幀 | 鏡頭震動 | 音效層 | 備註 |
|---|---|---|---|---|
| 子彈（輕擊） | 幾乎無 | 無 | 輕 | 現有 |
| 畏縮 | 0.03 秒 | 無 | 輕 | 現有 |
| 近戰輕攻擊 | 0.04 秒 | 小 | 中 | 新 |
| 硬直／近戰重攻擊 | 0.06～0.09 秒 | 中 | 重＋低頻 | 重攻擊取高值 |
| 擊殺 | 0.07 秒 | 小～中 | 重 | 現有 |
| 完美格擋 | 0.08 秒（全域） | 中 | 專屬（金屬清脆） | 現有，再補敵人被彈開 |
| 破防（玩家或敵人） | 0.1 秒 | 大 | 專屬 | 玩家破防現有 |
| 處決 | 0.15 秒＋短慢動作 | 大＋拉近 | 專屬 | 新，第二次起縮短 |

### 7.3 武器的手感差異

用資料決定，不寫在程式裡（NE-117 的資料欄位已涵蓋）：

| 類型 | 手感目標 |
|---|---|
| 短刃 | 輕、快、連擊的節奏感，頓幀小但頻繁 |
| 長刀 | 標準，有明確的「揮、停、收」 |
| 重武器 | 慢、重，前搖長但命中像撞牆，頓幀與震動最大 |
| 長柄 | 距離帶來的安全感，近身有死角 |
| 鞭、鎖鏈 | 軌跡的流暢，命中點在尖端 |

### 7.4 控制的響應度（比視覺更重要）

1. **輸入緩衝**：攻擊、衝刺、格擋、跳躍都有緩衝窗口（起始 0.12 秒，與現有跳躍緩衝一致）。
2. **取消優先序**：受擊 > 衝刺 > 格擋 > 攻擊後搖。任何時候按格擋，只要不在不可取消的出招中，就能舉盾（魂系玩家的預期）。
3. **格擋要能「馬上」舉**：完美格擋窗口從按下那一幀起算，輸入延遲要壓到最低，不能被其他動畫吃掉。
4. **以影格為單位寫資料**：前搖、出招、後搖用影格（60 FPS）定義，不用「約幾秒」，才能精確調手感與寫測試。
5. **判定只在出招區間**（NE-117 已列）。
6. 頓幀期間的輸入**不丟失**，凍結結束後生效。

### 7.5 公平性規則

1. 玩家受擊後的無敵時間（現有 `hurt_invulnerability` 1.0 秒）是**動作遊戲的慷慨**，與魂系的「被連打」不同。**建議保留**，因為這款有彈幕；但近戰敵人的多段攻擊要設計成「每一段都有各自的預兆」，不靠無敵時間硬撐。
2. 不做一擊必殺（除非劇情明確要求，例如被抓取的特定場景）。
3. 敵人不能在失衡時的玩家處決演出中被其他敵人打斷（演出中玩家無敵）。
4. 同一個畫面最多同時有幾個「要閃」的預兆，上限是資料，避免視覺爆炸。

## 8. 難度與輔助

故事優先，所以輔助要能讓**只想看故事的人也過得了**，而且不羞辱：

| 選項 | 內容 |
|---|---|
| 完美格擋窗口 | 標準 0.16 秒，輔助可加寬（例如 0.28 秒） |
| 敵人失衡條 | 輔助：上限降低 |
| 死亡掉帳 | 可關閉 |
| 頭目死後回血 | 可調 0%～50% |
| 預兆強度 | 高對比、更長的預兆 |
| 傷害承受 | 沿用現有輔助難度資料 |

**待決**：輔助模式下死亡的「錨人耗損」要不要照算？這是敘事的一部分，建議**照算**（難度不改劇情），但耗損的數字不影響結局。見 §10。

## 9. 與各章頭目的對應：每章教一個

魂系的好處是每一場頭目都在教下一個技巧。把近戰與格擋的學習曲線排進章節：

| 章 | 頭目 | 這一章教玩家 |
|---|---|---|
| 1 | CERBERUS 看門狗 | 閃避與讀預兆；跳壓與背部近戰（第一次摸近戰） |
| 2 | 阿勇 | **格擋與完美格擋**；反擊連段 |
| 3 | JANUS 守門人 | **打斷蓄力**（紫色預兆）；繞背 |
| 4 | ATROPOS 清理隊隊長 | 衝刺取消與機動；衝刺攻擊 |
| 5 | 老鬼（必安） | **掙脫與反擊**（非致命，換一種節奏） |
| 6 | KERAUNOS 棘 | **失衡與處決**的完整迴圈（大型招式被完美格擋 → 失衡） |
| 7 | EPIMETHEUS 明天 | 在減速圈裡調整節奏（時機被改變的完美格擋） |
| 8 | THEMIS 協定 | 部位與時機的綜合；多段 |
| 9 | ELPIS 沈望 | **全部**：槍、近戰、格擋、處決、打斷，三階段各考一個 |

BOSSES.md 已有各頭目的近戰機會，這張表只排「學習順序」。實作上，第一章就要有近戰系統的雛形，所以 **近戰系統是整個遊戲的前置票，不是最後才補**。

## 12. 業界參考（做法的來源，細節實作時再逐項查證）

| 作品／來源 | 取用的概念 |
