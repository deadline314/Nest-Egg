# 介面：更有趣的版面與更多動畫

2026-11-27，使用者提供一張參考畫面（另一款遊戲的調酒選單，沒有存檔），說有些介面可以做得類似這樣、有趣一點；要符合現在的遊戲風格，介面可以有更多動畫。本文記錄從參考畫面拆出來的做法與決策。只取版面與動效的手法，不取對方的美術與題材。

## 參考畫面在做什麼

- **東西是斜的、疊的**：酒瓶以不同角度散放、互相壓住，標籤跟著瓶身歪；沒有一樣東西是水平垂直對齊在格線上的。
- **字就是圖**：「開始」兩個大字佔了畫面四分之一，壓在一個鋸齒狀的對話框上，字下面再疊一層不同顏色的英文字。選項的中文與英文疊印在同一塊標籤上。
- **形狀有來源**：按鈕是撕下來的紙標籤、吊牌（有打孔與繩孔）、瓶身標籤，不是抽象的框。
- **色彩很少**：黑、灰、白為底，只有一個強調色（橘），分類標籤各用一個低彩度的顏色。
- **有質感**：半色調網點、噴濺的顆粒、不規則的剪紙邊緣。
- **資訊仍然清楚**：斜歸斜，每個選項一眼讀得出來，主要動作（開始）最大、最亮。

## 專案現況

- 共用面板在 NE-392 換過外觀（底色層次、邊線淡出、重點邊），但所有畫面仍然是水平垂直對齊的清單與方框。
- 動畫只有：按鈕標記滑出、項目依序滑入、換武器選取框滑動、設定分頁滑入（NE-389）。選單開關、背包換頁、商店交易、結算畫面大多是直接出現。
- 主選單是左上角四行小字，後面是程式繪製的城市；標題與選項都很小。

## 決策（NE-403）

把參考畫面的手法換成這個世界的語言。沉港市的資訊長在招牌、貼紙、封條、當票、貨運標籤、全像投影上：

| 參考畫面的手法 | 在這個遊戲裡變成 |
|---|---|
| 斜放、互相壓住的物件 | 主選單與背包的主要項目微微傾斜（2 到 6 度）、互相重疊一點；選到的那一項轉正並往前 |
| 巨大的標題字壓在不規則形狀上 | 畫面標題（主選單的遊戲名、背包、商店、死亡、結算）放大，壓在一塊斜切的色塊或霓虹招牌底板上，後面疊一層錯位的外文小字 |
| 紙標籤、吊牌 | 當票、貨運吊牌、封條貼紙：武器與道具的卡片像貼了標籤的實物；分類用吊牌 |
| 單一強調色 | 沿用既有的青色當主強調色，洋紅留給主角與危險；其餘壓成深藍灰 |
| 半色調、顆粒 | 掃描線、半色調網點、霓虹燈管的光暈，只用在大色塊上，不蓋文字 |

動畫：

- 畫面開啟：標題色塊斜著切進來，項目依序彈入並帶一點過衝後停住。
- 移動選取：選到的項目轉正、放大一點、往前一步；離開的項目回到傾斜。
- 確認：被按下的項目壓下去再彈回，其他項目往兩側退開。
- 待機：選到的項目有很慢的呼吸；大色塊上的掃描線緩慢移動。
- 數值變化（信用點、彈藥、生命）：數字滾動，增加與減少的方向不同。

限制：

- 傾斜只用在標題與主要項目的外框，內文一律水平；最小字級與對比不變。
- 所有動畫 300 毫秒內完成、不擋輸入、連按以最後一次為準；「減少動態」時全部直接到位且不傾斜過場。
- 鍵鼠與手把的焦點順序不因為視覺重疊而改變；滑鼠的點擊範圍跟著畫面上看到的形狀。
- 720p、1080p、21:9 與文字放大都通過既有的版面檢查。
- 先做主選單與背包兩個畫面當樣板，確認方向後再推到其他畫面。

## 驗證

每個畫面附修前修後截圖，以及開啟動畫的三格（開始、中間、結束）。
