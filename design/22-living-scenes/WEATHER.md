# 天氣：雨、雷與閃電、風、濕地面

2026-11-28，使用者：「我希望在遊戲裡面的天氣或是效果，包括打雷下雨可以再更擬真，像是有一個遊戲叫做銀松鎮我覺得就做得很好。」這份文件是天氣線（BG-100～119）的研究、現況盤點與設計。只取手法，不取參考遊戲的美術與題材。

不變的前提（使用者明講過的）：特效克制、粒子少而精、不過曝、不持續閃爍；判讀永遠優先（主角、敵人、子彈、危險預兆、提示）；主角的霓虹發光保留；「減少動態」「減少閃光」一律有效。

### 1.3 現實的時間結構

- **閃電**：一次雲對地閃電先有很暗的梯級先導，接著一道很亮的回擊；之後常有幾次再回擊，間隔約 20～80 毫秒，人眼剛好分得出來，所以看起來是「亮、閃一兩下、熄」。大多數閃電只有幾次回擊。（[NOAA](https://www.weather.gov/mlb/what_is_lightning)、[Britannica：雲對地閃電](https://www.britannica.com/science/thunderstorm/Cloud-to-ground-lightning)）
- **雷聲**：聲音每 3 秒約走 1 公里；超過十幾公里通常聽不到雷，只看得到天邊亮（俗稱熱閃）。（[Britannica：Thunder](https://www.britannica.com:443/science/thunderstorm/Thunder)、[NOAA Dr. Lightning](https://www.weather.gov/media/safety/Dr_Lightning_Guide-science.pdf)）
- 遠雷是長而低的隆隆聲、近雷先有尖銳的爆裂聲再接隆隆聲：這一點沒有查到可引用的來源，是一般錄音的聽感，素材挑選時用耳朵確認。

### 1.4 光敏感的硬性標準

- WCAG 2.3.1：任何一秒內閃光不超過三次，或閃光夠暗、夠小。WCAG 自己舉的例子就是把電影裡很亮的閃電剪成一秒內最多三次。飽和紅色的閃光更敏感，另有門檻。（[W3C：Three Flashes or Below Threshold](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html)）
- Xbox 無障礙準則 118：大約每秒超過三次、或面積約佔畫面 20% 以上的閃光是風險；所有遊戲都要做光敏感測試，建議用 Harding FPA 工具。（[XAG 118](https://learn.microsoft.com/en-us/gaming/accessibility/xbox-accessibility-guidelines/118)）

### 1.5 手法拆解（要用的）

| 主題 | 手法 |
|---|---|
| 雨絲 | 同一層裡長度、粗細、速度各有 ±25% 左右的變化，不是等長直線；越遠越細、越短、越慢、越淡，越近越長、越快、越亮但越稀 |
| 分層 | 遠的一兩層畫在角色後面（它們本來就在角色後面），只有最近的一層畫在角色前面；再遠處是一整片「雨幕」：背景前的一層淡淡的斜向紋理，表示遠方也在下雨 |
| 風 | 每區一個基準風向與強度，雨絲依風傾斜；陣風是幾秒的緩起緩落，不是固定週期的正弦；陣風時近層傾斜多、遠層少（遠層看起來動得慢） |
| 雨勢 | 雨勢是一個數字，雨絲數量、亮度、水花、漣漪、雨聲都跟著它；可以隨時間在一個範圍內緩慢起伏（一兩分鐘的週期） |
| 接觸 | 水花落在真的會被打到的地方：走道頂面、欄杆、棚頂、箱子頂、角色肩頭；被棚子擋住的地方沒有雨也沒有水花 |
| 滴水線 | 屋簷與棚子邊緣一排間隔不規則的水滴往下掉，落點有小水花；下大雨時變成斷續的水線 |
| 積水 | 積水的漣漪頻率跟著雨勢；雨停了就靜止，只剩偶爾的滴落 |
| 濕地面 | 走道頂面一條細的反光帶；燈與霓虹在濕地上拉成直向的長倒影，被漣漪打碎；角色腳下有淡淡的倒影或深色水痕 |
| 霧與雨 | 雨越大，遠景越朦朧（遠景的霧色加深、對比降低）；霧是雨的結果，不是另外一個開關 |
| 閃電 | 預閃（暗、短）→ 主閃（最亮）→ 零到兩次再閃 → 餘光（慢慢退）；遠的只亮雲層與天際線的輪廓、沒有雷或雷很晚；近的才照亮場景：朝光的一面亮，另一面出現短暫的硬影 |
| 雷聲 | 延遲依距離（每公里 3 秒）；遠雷低、長、小聲，近雷先爆裂再隆隆 |
| 室內外 | 室外是寬頻的雨聲；棚下多一層打在棚頂的密集聲、整體悶一點；室內是悶掉的雨聲（只剩低頻）加窗上的雨聲，閃電只從窗戶看得到 |

## 3. 設計

### 3.1 天氣是資料

- 天氣設定獨立成一份資料（天氣預設），和光影設定分開：光影屬於畫面線、而且很多區域共用同一份光影設定（例如三章的當舖都用夜晚屋頂），天氣要能每區不同。
- 每個區域在一張表裡指定用哪個天氣預設，可以覆蓋其中幾項。表的鍵是關卡 id，不改地圖檔；地圖線不用寫回產生器。
- 室內外不靠資料標記，靠地形：頭上有屋頂、或站在棚子底下，就是「遮住的地方」，雨、水花、雨聲、閃電照明都依這個判斷。棚子類的擺設在擺設資料標成「擋雨」。
- 閃電的頻率從光影設定移到天氣：天氣接手後，光影設定的閃電頻率不再使用（畫面線不用改檔，天氣線在接手的票裡把舊欄位標成停用並說明）。
- 資料寫錯時記錄是哪一區哪一項，該項退回預設值（中雨、無閃電），不讓遊戲壞掉。表上沒有的區域維持今天的樣子。

每個天氣預設的欄位：

| 欄位 | 意思 | 範圍 |
|---|---|---|
| 雨勢 | 0＝不下、0.3＝小雨、0.55＝中雨（今天的樣子）、0.8＝大雨、1＝暴雨 | 0～1 |
| 雨勢起伏 | 雨勢在 ±這麼多之間以一兩分鐘的週期緩慢變化 | 0～0.25 |
| 風 | 基準風向與強度（負＝往左吹），決定雨絲傾斜 | −1～1 |
| 陣風 | 陣風的強度；0＝沒有 | 0～1 |
| 閃電頻率 | 每分鐘平均幾次（遠近合計） | 0～4 |
| 近閃比例 | 其中有多少是會照亮場景的近閃 | 0～0.3 |
| 雨霧 | 雨讓遠景與霧變濃的程度 | 0～1 |
| 地面濕度 | 走道反光與倒影的強度；雨停了也可以是濕的 | 0～1 |

### 3.2 雨

- **三層＋雨幕**：遠、中兩層畫在角色與地形後面、背景前面；近層畫在角色前面、**子彈與危險預兆後面**。最遠處加一層背景前的雨幕（淡斜紋，跟風傾斜、緩慢流動），表示遠方也在下雨。
- **每滴不同**：同一層裡長度、寬度、速度各自依雜湊有變化（約 ±25%），亮度依長度略變；仍然一次繪製，不每滴一個節點。
- **雨勢**決定每層顯示幾滴（固定上限、依雨勢取前 N 滴，不重新配置）、亮度、水花與漣漪的頻率。雨勢起伏慢到不會被察覺成「閃」。
- **風**：雨絲傾斜＝基準風＋陣風；陣風是隨機時刻開始、2～5 秒緩起緩落的一陣，之後回到基準。近層傾斜全額、中層 70%、遠層 45%。
- **雨霧**：雨勢 × 雨霧把遠景霧色與 `FogLayer` 的濃度往上推（透過光影控制器的介面，不另蓋一層），上限是光影設定原值的 1.5 倍。
- **判讀**：
  - 近層在主角附近（以主角為中心約 48 像素）的雨絲亮度降到 60%，所以主角附近的雨不比今天搶眼。
  - 雨不畫在子彈、危險預兆、提示之上。
  - 近層雨絲的最高亮度不超過今天近層的亮度（0.4）。

### 3.3 雨和世界的接觸

- **擋雨**：屋頂（地形）與標成擋雨的擺設（棚子、雨棚、屋簷）底下沒有雨絲也沒有水花；雨停在棚頂上，棚頂有水花。
- **水花**：落在走道頂面、欄杆、棚頂、箱子頂；角色站在雨裡時，肩頭與頭頂偶爾有一個很小的水花（每個角色每秒約 1～3 個，依雨勢）。水花用天氣自己的固定大小粒子池，不佔戰鬥特效的粒子。
- **滴水線**：每個擋雨物的外緣一排水滴，間隔不規則（雜湊決定），落點有小水花；雨勢高時滴得快、像斷續的水線。雨停後滴水慢慢變少再停。
- **積水**：漣漪頻率跟著雨勢，在遮住的地方與乾的區域不漣漪。
- 通電積水（NE-400）的通電預警不受影響，天氣不改它的顏色與亮度。

### 3.4 濕地面

- **反光帶**：濕的走道頂面一條細的淡色反光線，亮度依地面濕度；被燈照到的地方更亮。室內、棚下乾的地方沒有。
- **燈的倒影**：畫面內的燈與霓虹招牌在它下方最近的濕地面上，畫一條直向拉長、往下淡出的同色倒影，被漣漪打成幾段並輕微晃動。倒影亮度上限低於燈本身的一半，不能讀成發光的拾取物或危險。
- **角色腳下**：高畫質有淡淡的倒影（角色剪影翻轉、很淡、往下淡出）；中、低畫質是一塊深色水痕。
- 濕地面的顏色要通過 BG-78 的遊戲性顏色檢查：不能和預兆、拾取、通電積水的顏色混淆。

### 3.5 閃電與雷

**時間結構（寫死）**：

| 階段 | 時間 | 亮度（相對主閃） |
|---|---|---|
| 預閃 | 60～120 毫秒 | ≤ 25% |
| 主閃 | 50～90 毫秒 | 100% |
| 再閃 | 0～2 次，每次間隔 40～80 毫秒、持續 30～60 毫秒 | ≤ 70%，一次比一次弱 |
| 餘光 | 250～500 毫秒，平滑退回 | 由當時亮度退到 0 |

一次閃電從開始到結束不超過 0.9 秒；任何一秒內亮度的峰值不超過 3 個（符合 WCAG 2.3.1 與 XAG 118）。

**遠閃與近閃**：

- **遠閃**（大多數）：只照亮天空與遠景：雲層的一塊區域變亮，遠景樓群的輪廓浮出來；可走的場景、角色、敵人的亮度不變。遠閃有 30% 沒有雷聲（太遠聽不到），其餘雷聲延遲 4～12 秒，低、長、小聲。
- **近閃**：天空先亮，接著場景被一道從天空那一側打來的冷白光照亮：朝光的一面亮（透過光影控制器的方向光與法線貼圖），另一面在主閃期間出現短暫的硬影；之後跟著餘光退掉。雷聲延遲 0.3～1.5 秒，先爆裂再隆隆。
- 延遲由距離決定：同一次閃電，越亮的越近、雷越早。

**亮度上限（寫死）**：

- 近閃時環境光的亮度最多提高到原本的 1.8 倍，而且絕對亮度不超過 0.35（以光影控制器的環境光亮度計）；角色的曝光檢查與暗場可讀性在主閃那一格也要通過。
- 遠閃時天空的顏色最多往閃電色推 45%，只在天空與遠景層。
- 永遠不用全畫面的白色疊層；閃電只透過光影控制器與背景的介面改亮度。

**間隔（寫死）**：

- 任兩次閃電最少隔 8 秒；兩次近閃最少隔 25 秒。間隔用隨機（平均依頻率），不出現規律節奏。
- 進入區域、從檢查點重生後的前 5 秒不打閃電。
- 劇情過場中不打（過場自己的閃電用同一套結構與上限）；暫停時不打。
- 戰鬥中（有敵人正在交戰）只打遠閃，不打近閃，避免在戰鬥中改變敵人與子彈的亮度。

**室內**：遮住的地方看不到天空，只有窗戶與門口外面的天空亮（遠閃與近閃都只亮窗外）；室內環境光最多提高到 1.2 倍。雷聲照常但悶掉。

### 3.6 聲音

- **雨聲分層**：小雨、中雨、大雨三個迴圈，依雨勢交叉淡入淡出；暴雨時再疊一層大雨。雨勢起伏時音量跟著慢慢變。
- **遮住的地方**：依鏡頭中心是不是在遮住的地方（不是依光影區段），0.5 秒內轉換：
  - 棚下：雨聲略悶、多一層雨打在棚頂的密集聲。
  - 室內：雨聲只剩低頻（低通約 800 赫茲）、小 8 dB；有窗的區域加一層窗上的雨聲。
- **風聲**：風聲迴圈的音量跟著風與陣風，陣風時短暫變大。
- **雷聲**：分成「近雷」（爆裂＋隆隆）與「遠雷」（低、長）兩組素材；遠雷再小 10 dB 並低通；室內的雷照樣低通。
- 素材依 `audio-pipeline`：CC0、登記授權、響度與迴圈規格。現有的 `amb_rain`、`amb_rain_light`、`amb_wind` 與 4 個雷聲先盤點能用哪些，缺的再找。

### 3.7 過場舞台

- 舞台上的雨換成和關卡同一套雨（多層、每滴不同、風與陣風、雨勢），由舞台資料指定天氣預設或雨勢；一次繪製。
- 舞台的閃電用同一套時間結構與上限，照亮舞台的天空層與背光的剪影，不用全畫面白色疊層。
- 舊的舞台資料（`count`、`speed`、`length`、`wind`）照舊能讀，換算成新參數；寫錯時記錄是哪個舞台哪一層。

### 3.8 畫質三檔

| 效果 | 高 | 中 | 低 |
|---|---|---|---|
| 雨絲 | 三層＋雨幕，全數量 | 三層＋雨幕，數量 70% | 兩層（中、近），數量 50%，沒有雨幕 |
| 水花 | 地面、欄杆、棚頂、角色肩頭 | 地面、棚頂 | 地面，數量一半 |
| 滴水線 | 有 | 有 | 有（數量一半） |
| 積水漣漪 | 跟雨勢 | 跟雨勢 | 跟雨勢 |
| 濕地反光帶 | 有 | 有 | 有（不受燈加亮） |
| 燈的倒影 | 有，被漣漪打碎 | 有，不打碎 | 沒有 |
| 角色腳下 | 淡倒影 | 深色水痕 | 深色水痕 |

### 3.9 減少動態、減少閃光

「減少動態」指專案現有的「減少介面動態」設定（場景裡的額外擺動已經看它）。

| 設定 | 天氣怎麼退 |
|---|---|
| 減少動態 | 雨照常下（它是世界的一部分），但：沒有陣風（固定傾斜）、雨勢不起伏、數量降到 60%、沒有前景雨簾、角色肩頭沒有水花、倒影不晃 |
| 減少閃光 | 只有遠閃：亮度上限是一般遠閃的 35%、只有一個峰值（沒有預閃與再閃）、亮起時間至少 100 毫秒（沒有瞬間跳亮）、只在天空；不打近閃、不出現硬影；雷聲照常 |
| 兩個都開 | 兩邊都套用 |

### 3.10 效能

- 雨絲、雨幕、滴水線、倒影都是固定頂點數的一次繪製，不每滴一個節點、不每影格配置。
- 水花用天氣自己的固定大小粒子池。
- 離開畫面不算、暫停時停住。
- 每張實作票用 `tools/frame_time_probe.tscn`（同一台機器、同一組關卡、交替量幾輪）記錄開與關（`--off=weather`）的影格時間中位數、95、99 百分位。

## 4. 實作順序與驗收

一項一張票，依序往下（BG-101 起）。每張都要：資料寫錯時記錄並退回預設；新行為有測試而且把行為關掉時測試會失敗；主角與危險預兆可讀性、BG-78 遊戲性顏色、暗場可讀性檢查通過；「減少動態」「減少閃光」的行為有測試；同一格鏡頭的修前修後與連續幾格；影格時間記在票上。

| 順序 | 項目 | 驗收方式 |
|---|---|---|
| 1 | 天氣資料與每區設定：天氣預設、每區的表、雨勢與風接到現有的雨、閃電頻率從光影移過來 | 測試：每個預設與每區設定都讀得到；壞資料記錄區域與欄位並退回預設；未列的區域和今天一樣。截圖：ch1_stall（小雨）、ch1_street（中雨）、ch6_harbor_plaza（暴雨）同一格鏡頭各一張 |
| 2 | 閃電與雷重做：時間結構、遠近、亮度與間隔上限、室內只亮窗外、雷依距離延遲；過場的閃電改用同一套 | 測試：逐格量一次閃電的亮度曲線，峰值數、持續時間、上限都在設計內；任一秒峰值 ≤ 3；最短間隔與近閃間隔；減少閃光時沒有近閃、只有一個峰值；室內不改場景亮度；過場不用全畫面疊層。截圖：遠閃與近閃各連續 5 格；主閃那一格的可讀性與曝光檢查 |
| 3 | 雨本身：每滴不同、三層＋雨幕、遠層移到角色後面、近層移到子彈與預兆後面、陣風、雨勢起伏、雨霧 | 測試：圖層順序（遠層在角色後、近層在子彈下）；同一層長度與速度確實有變化；雨勢 0 時不畫；減少動態時沒有陣風。截圖：同一格修前修後、陣風連續 3 格；主角附近亮度量測不高於修前 |
| 4 | 雨和世界的接觸：擋雨擺設、水花打在欄杆與角色肩頭、滴水線、漣漪跟雨勢 | 測試：棚下沒有雨絲與水花；水花不用戰鬥特效池；雨勢 0 時漣漪停。截圖：棚子邊緣的滴水線連續 3 格、肩頭水花近拍 |
| 5 | 濕地面：反光帶、燈與霓虹的倒影、角色腳下倒影或水痕 | 測試：乾的區域與遮住的地方沒有反光；倒影亮度上限；BG-78 顏色檢查。截圖：ch1_street 霓虹段修前修後、三個畫質各一張 |
| 6 | 聲音：雨聲依雨勢分層、棚下與室內悶掉、風聲跟陣風、遠近雷 | 測試：雨勢與遮住與否對應的音量與低通值；素材登記與授權檢查通過。附錄音的音量曲線圖 |
| 7 | 過場舞台的雨與閃電套用同一套 | 測試：舊的舞台資料照舊讀得到並換算；舞台雨一次繪製。截圖：序章開場舞台修前修後、閃電連續 5 格 |
| 8 | 室內看得到的天氣：窗上的水痕、窗外的雨與閃電 | 測試：沒有窗的室內不畫；乾的區域不畫。截圖：ch2_ledger_office、ch4_ward_lamp_bay |

每張票推完的影格時間對照用同一組關卡（`frame_time_probe` 的預設 8 關），開與關各量，中位數與 95、99 百分位都記在票上。
