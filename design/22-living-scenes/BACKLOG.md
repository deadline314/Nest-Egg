# 畫面與玩法的後續待辦

2026-11-28，使用者指示：「接下來就一直做，如果票都做完了就看還有什麼可以做，持續精進遊戲內容跟畫面。不要停下來直到我跟你說暫停。」這份清單是手上的票做完之後的下一步，由上往下做。每一項開始前照 `pm-ticket` 開票（一個需求一張），做完在這裡把那一項標成已開票並寫上票號。清單做完時，各自依下面的「找下一項的方法」補新的項目進來，不要停。

分工：標「畫面」的由做景深與介面的 session 負責，標「玩法」的由做環境機關的 session 負責。兩邊都不要同時改同一批檔案。

## 找下一項的方法

清單做完時依序做這幾件事，找到值得做的就寫進上面的表再開票：

1. 用截圖工具把每一章每個區域各拍一輪，和向陽區樣板並排，挑出最平、最像貼上去的三個畫面。
2. 從頭玩一段（或用流程探針跑一段），記下連續三分鐘以上都在做同一件事的地方。
3. 看 `pm/` 裡狀態還不是完成的票，挑不需要真人或實體手把就能往前推的條件。
4. 查同類型遊戲的做法，只取手法，不取別人的美術與題材。

## 不做的事

- 不重開使用者已經定案的東西（主角外觀、劇情、對白）。
- 不為了畫面犧牲判讀：玩家、敵人、子彈、落點與提示永遠優先。
- 特效克制：不過曝、不持續閃爍；「減少動態」與「減少閃光」一律要有效。
