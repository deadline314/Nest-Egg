2026-10-10。這批候選針對 ST-10 已量到的前門與廚房背景覆蓋不足；不是 BG-21 電子告示牌、梯子或牆面占位替換的完成證明。正式舞臺尚未採用這兩份候選，所有原生構圖及家具接觸結論另行驗證。

原圖只有1536×864，不能一邊要求鏡頭完整收進頭腳，一邊靠縮小角色避開背景邊界。保留原圖的家具、地面、色盤與演出座標，只延展安靜的外圍建築及空地；新邊緣不增加道具、標示或敘事焦點。

## 可重現加工與來源

[固定配方](../../assets_src/pipeline/qwen_stage_extensions.json)記錄原圖、參考圖、ComfyUI原始生成圖、正式候選輸出的SHA，以及提示詞、模型、seed、步數、配準矩陣和世界座標。實際生成尺寸1152×640與參考1152×648分開記錄，沒有假定編碼器輸出固定大小。使用Python3.12、Pillow、NumPy、OpenCV5.0.0。

```text
python -X utf8 -B tools/assets/stage_extension.py --prepare
python -X utf8 -B tools/assets/stage_extension.py
python -X utf8 -B tools/assets/test_stage_extension.py
python -X utf8 -B tools/comfyui/test_cache_options.py
```

預設只在CPU逐張加工已檢查的原始圖，不啟動模型。原圖和生成圖先核對SHA、像素上限與尺寸；配準只接受接近原比例的旋轉與平移，不接受任意拉伸。以生成圖補外圈，外圈接縫做局部色差銜接，最後把原圖完整放回；輸出使用lossless WebP。先寫候選暫存檔，只有輸出SHA、單圖1.5MiB上限、家具座標與原圖像素全部吻合才替換輸出。失敗保留既有圖。

`--generate` 才會呼叫本機 ComfyUI；一次一張、25步、reference resolution=0、Qwen prefix cache關閉。關閉prefix cache只避免額外參考快取常駐RAM，模型權重仍會佔用記憶體。原有其他生成工作保持既有設定；不同cache設定不能誤用相同的舊生成快取。重新生成的SHA不保證一致；不同結果一律拒絕寫入這份已審候選，必須重新檢查並登記。

本輪兩張廚房試生、一次前門試生逐次執行，未批量保留圖片張量。廚房首次新增地板材質不符，拒絕；前門完整大画布外緣多餘藍色區域、超過單圖預算，裁去額外外圈並保留整張原圖。新增前門地面與廚房灰色走道已目視，家具中心原封保留。這些是美術候選審查，不是玩家實際座椅或演出驗收。

## 正式採用門檻

根據真正 `CutscenePlayer` 的連續姿勢包絡與有效鏡頭，分別以16:9和寬螢幕 Forward+／HDR捕捉正式分鏡；確實核對字幕保留區、角色頭脚、背景覆蓋、地板材質、座面、遮擋、光影與接縫。合成坐姿只供鏡頭診斷，不能取代原正式坐椅流程。兩份藝術候選沒有改原圖比例，仍須檢查真正鞋底與椅面接觸。

原生驗證通過才由唯一的第一章產生器 owner 修改正式背景路徑、原點與source_width，依原產生器重建相關舞臺並保存圖證。未通過時維持 `native_adopted=false`；不得用探針自然退出0或純幾何有解代替完整驗收。
