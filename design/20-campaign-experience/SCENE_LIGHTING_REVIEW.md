# 第一章場景光影與視覺優先序

2026-10-11。對應 BG-30。逐區的用途與擺設見[場景用途審查](SCENE_PURPOSE_REVIEW.md)；光影系統的架構見 [08-lighting](../08-lighting/DESIGN.md)。

## 參考：Leyla In Veil 實際看到的畫面

來源是 Steam 商店頁（app 3904870，開發者 cloud_li）的官方截圖 10 張與官方文字說明，2026-10-11 查看。官方自述是「HD-2D 像素風橫向動作射擊生存恐怖」。**沒有看到**的部分：預告片影片、撿東西丟敵人與油桶爆炸的實際畫面（商店文字沒提，截圖也沒拍到），這兩項留給 NE-95 與 NE-254 另外查證，這裡不當成已知。

| 看到的 | 這裡怎麼用 |
|---|---|
| 每個房間一個主光源（吊燈、圓窗月光、螢幕），其餘很暗；主光有看得見的柔和光錐 | 採用：每區指定一個主光，其他光源只當點綴，不互相搶 |
| 每個房間一個主色調的環境光（深紅、深藍、灰綠），不混色 | 採用：每份光影設定一個主色，霓虹只點綴 |
| 角色靠最近的主光被照亮，暗處仍看得到輪廓 | 採用，但做法不同：它的房間是單一平面，背景可以幾乎全黑；Nest Egg 有高低差與多條路線，玩家要看得到平台、牆與落點，所以環境不能黑到只剩光池 |
| 地板有反光（燈、角色、掉落物） | 部分採用：反光只落在地板頂面（BG-20 已改），不畫進地面的剖面 |
| 爆炸的暖光照亮整個房間 | 留給 NE-95 |
| 沒有持續的全畫面雜訊 | 已在 BG-27 處理 |

另外沿用橫向動作遊戲常見的層次做法：**背景比前景淡、對比低，前景的角色與敵人顏色深而飽和**。這一條沒有逐一查證出處，是實測後採用的：把背牆調暗時，深色裝甲的敵人反而更難辨認（對比從 0.43 掉到 0.38）；改成背牆比可玩層淡一階、帶一點冷色之後，敵人與主角都變清楚。

## 原本的問題

- 環境光太低（街道 0.29、倉庫 0.28），加上 0.5～0.6 的暗角，建築本體、牆面與地面幾乎全黑，只剩自發光的窗像燈籠飄在空中；倉庫與倉庫深處的敵人是黑底上的黑色剪影，最低對比 0.16（門檻 0.45）。
- 地面霧氣是邊緣銳利的實心圓，而且用整關同一個高度畫，在倉庫會畫進地面的剖面裡；畫面一變亮就看得到一顆顆圓盤。
- 電話亭巷用的是「不調整」的預設光影，整區全亮、沒有夜色，和相鄰的街道接不起來。
- 低血量的紅色暗角在最強的一拍幾乎蓋滿整個畫面，提示文字與敵人被染紅。

## 做法

1. **環境光提高、暗角減輕**：第一章五份光影設定的環境光亮度提高到 0.41～0.51，暗角降到 0.3～0.35，對比略降。夜色、主色與霓虹都保留。
2. **背牆退後一階**：緊貼在角色後方的背牆整體比可玩層淡約兩成、略偏冷，角色、敵人與可走的地面從牆面前跳出來。
3. **主角的最低亮度跟著提高**：背景變亮後，主角的補光下限同步提高；白色零件的曝光預算不變（NE-213 的上限仍然有效），所以頭髮不會再過曝。
4. **霧貼著實際地面**：霧逐欄找鏡頭下方的地面，不畫進地面剖面；霧團改成邊緣淡出的柔光。
5. **電話亭巷有自己的光影設定**：和街道同一片夜色，但光較平、沒有閃電、燈不會壞，符合安全區。
6. **低血量提示只留在畫面邊緣**：紅色暗角往內收的幅度與濃度都降低，中間的角色、敵人與提示文字保持乾淨，邊緣仍然脈動。

## 量測

原生 Forward+（Intel Arc B580，1280×720），`tools/scene_tour.tscn --player`：每一格把主角放在畫面中央下方的地面上，量主角與畫面內每個敵人的輪廓對比（算法與門檻同 `tools/contrast_probe.gd`：主角 0.6、敵人 0.45），每格取 5 次的中位數。「畫面亮度」是整格的平均亮度（線性）。

| 區域 | 畫面亮度 修前 → 修後 | 主角對比 最低／中位 修前 → 修後 | 敵人對比 最低／中位 修前 → 修後 | 光影品質低：主角最低／敵人最低 |
|---|---|---|---|---|
| 當舖 | 0.080 → 0.145 | 0.78／0.86 → 0.69／0.88 | —／— → —／— | 0.69／— |
| 街道 | 0.028 → 0.045 | 0.59／0.71 → 0.58／0.65 | 0.34／0.74 → 0.48／0.70 | 0.58／0.51 |
| 電話亭巷 | 0.151 → 0.034 | 0.71／0.74 → 0.71／0.71 | —／— → —／— | 0.71／— |
| 碼頭倉庫 | 0.018 → 0.041 | 0.70／0.76 → 0.57／0.68 | 0.16／0.67 → 0.38／0.67 | 0.57／0.38 |
| 倉庫深處 | 0.016 → 0.031 | 0.71／0.72 → 0.58／0.64 | 0.16／0.58 → 0.46／0.56 | 0.57／0.45 |
| 復原休息室 | 0.095 → 0.183 | 0.80／0.88 → 0.77／0.82 | —／— → —／— | 0.79／— |
| 屋頂 | 0.030 → 0.051 | 0.72／0.82 → 0.68／0.81 | —／— → —／— | 0.69／— |
| 清晨麵攤 | 0.018 → 0.033 | 0.67／0.70 → 0.60／0.63 | —／— → —／— | 0.63／— |
| 當舖（清晨） | 0.059 → 0.092 | 0.77／0.83 → 0.69／0.83 | —／— → —／— | 0.69／— |

- 敵人的最低對比從 0.16～0.34 提高到 0.38～0.48，中位數都在 0.56 以上。碼頭倉庫還有一格 0.38 低於門檻（貨櫃頂上的守衛，背後是天花板的暗處）。
- 主角的中位數都在 0.63 以上；街道、倉庫、倉庫深處各有一格落在 0.57～0.58，略低於 0.6。原因是背景變亮後，主角從「黑底上的亮人」變成「中間調背景前的人」，這個指標在兩者之間最低。畫面上看得清楚，但數字沒有全部過線，如實記錄。
- 光影品質「低」的數字與「高」幾乎相同：可讀性靠的是環境光與背牆的層次，不靠體積光與法線。

## 之後的章節怎麼沿用

- 新的光影設定：環境光亮度在 0.4～0.5 之間（再低看不到建築與牆面，再高平台的亮邊就不夠突出，資料檢查會擋），暗角不高於 0.35；一個主色、一個主光。
- 角色後方的背牆自動退後一階，不用逐關設定。
- 做完用 `tools/scene_tour.tscn --player` 量一次，敵人最低對比要過 0.45，主角中位數要過 0.6；再用 `--quality=low` 確認低品質沒有變差。
- 安全區不用「不調整」的預設光影，給它和相鄰區域同一片天色的設定。
