# 章節逐區稽核（NE-233～235 的自動部分）

2026-10-12。三張章節驗收票的「逐區檢查長度、迴圈、捷徑、落點、檢查點」與「沒有明顯占位素材」中，能從資料自動判斷的部分。人工完整遊玩、畫面與手感另外驗收，這份工具通過不代表章節可以發行。

```
godot --headless --path . res://tools/chapter_audit.tscn [-- --chapter=ch2_heron] [--json=<輸出路徑>]
```

## 檢查什麼

| 項目 | 怎麼判斷 | 門檻 |
|---|---|---|
| 長度 | 每區寬度（格）與估計時間（`PacingEstimate.area`：走路、戰鬥、對話、拾取、機關、商店）；整章加總乘第一次玩的倍率 | 整章第一次玩少於 30 分鐘列「注意」（目標 30–45，同第一章節奏參考） |
| 迴圈與死路 | 出入口與 `next_level` 組成區域圖（共用地圖的區域算一個），迴圈數 = 連線 − 區域 + 連通塊 | 每章至少 1 個迴圈；只有一個出入口、裡面沒有拾取／人物／劇情／商店的死路列「注意」 |
| 走不到 | 從章節入口沿出入口走 | 有走不到的區域是「錯誤」 |
| 上鎖與捷徑 | 每個要旗標才開的出入口，找有沒有來源會寫入那個旗標（故事結果、衍生旗標、劇情物品、關卡頻道與跳過旗標、練習完成／失敗） | 沒有任何來源是「錯誤」（可能永遠打不開） |
| 落點 | 沿用場景合理性檢查（`SceneAudit`）：起點與復原點有地面、沒卡進牆、出入口另一端存在、道具不懸空 | 任何錯誤都列出，細節跑 `tools/scene_report.tscn` |
| 復原點間距 | 起點、復原點與出入口沿橫向排序後的最大間距 | 超過 160 格（約 24 秒路程）列「注意」：死掉要走太遠才回得來 |
| 程式暫代物件 | 還用簡單畫法的固定物件（木箱、油桶、玻璃、升降平台、電源開關）；找不到外觀而退回頭像剪影的人物；外觀缺檔的敵人 | 列在「占位」，對應 BG-47；物件型互動點的擺設缺口由場景組量距離盤點（[第二、三章場景缺口](CH2_CH3_SCENE_GAPS.md)，BG-38～46） |

經濟面（主路收入、補給與成長預算）在[跨章經濟帳本](CAMPAIGN_ECONOMY.md)；發行包內容與章節順序在[累積章節發行](RELEASE_PIPELINE.md)的匯出檢查。

## 守門（PacingSuite 會檢查）

每章：沒有錯誤（走不到、永遠打不開的鎖、場景錯誤）、至少一個迴圈、復原點間距不超過門檻、每個上鎖出口都有開鎖來源。整章太短與占位只列在報告與票上，不擋測試——它們要等內容落地，不是程式錯誤。
