## 每章開始前必備交付

| 內容 | 必須能回答的問題 | 不通過的例子 |
|---|---|---|
| 因果頁 | 前章發生了什麼，誰決定來此，為什麼現在行動，做完何事才去下一章？ | 從章末標題直接換到新地方、角色不知道為何接新委託 |
| 世界與角色事實表 | 誰知道什麼、手上有哪些物品與裝備、關係／年齡／身份、死亡規則及語句的真假？ | 燈知道還未揭露的錨人，凜未死卻說剛復原，汐被畫成墓 |
| 完整主線與可選支線 | 必須目標有可行下一步；支線有選擇、資訊、世界／角色反應；錯過會發生什麼？ | 只列「查帳」卻沒有證據與結論，支線只是殺五隻敵人，拒絕交談卡主線 |
| 逐場稿 | 地點、在場者、動機、臺詞、動作、鏡頭、聲音、玩家操作與結果都寫出 | 用「感動對話」佔位；只有臺詞沒有真正演出或玩家參與 |
| 空間與節奏圖 | 路線、觀察點、捷徑、安全區、關卡功能與張力的起落如何對應事件？ | 一直右走、固定每區同一鎖場／頭目、用裝飾梯子假裝有路線 |
| 分支與狀態矩陣 | 開始、完成、略過、中斷、死亡、退出讀檔、回訪的劇情／獎勵／門狀態？ | 對話開始發獎，略過隨機做選擇，退出後拿兩次盤 |
| 內容／素材與預算 | 新敵人、物件、情境動作、聲音、UI、尺寸、支撐、圖層、重用來源與owner？ | 為每句生成新大圖、未修角色換色當新敵人、沒有支撐的梯子與招牌 |

長篇對白不以斷句或刪主詞解決；每句說完整意思，專名首次出現用同場解釋。小氣泡與戰鬥短句仍遵守實際顯示預算。電影場有動作與視線變化，NPC 主動對話給確認、返回和手把焦點。

## 單段演出填寫格式與已裁定例子

每段填寫：起因／資訊增量／玩家參與／開始與結束條件／預計閱讀與固定演出時間／鎖操作區段／略過結果／再次失敗成本／所需動作與素材。時長是製作估計，錄製與首次玩家結果另列，不能當行業門檻。

| 例段 | 目的／玩家參與 | 強制中斷與略過 | 重試／再次發生 | 所需演出 |
|---|---|---|---|---|
| 序章訓練 | 親手試動詞；錯時馬上再試 | 操作不中斷，只有清楚示範；可略整段並拿到第一主線提示 | 當場恢復；無真死亡、錢與記憶扣款 | 試槍後座、靶破、格擋接觸、跌倒扶起 |
| 第一章首次建檔 | 知道為何在診間、以後去哪裡、誰承擔什麼費用 | 特殊死亡後電影，可略；略後登記與物品／位置同完整播放 | 全輪一次；普通死亡不再播 | 運送剪影、醒來、拿衣物、坐起到站起 |
| 第二章屋頂破傘 | 鷺照顧別人卻笑說沒事，週日是她不願解釋的私人時間 | 主動開始對話進21:9，接近預告可離開；不鎖整個屋頂 | 長段只首次；再問給已選過的回應，無重複獎勵 | 遞茶、偏傘、自己淋半邊、回頭看雨 |
| 第二章對帳 | 自己從收據看出錯收利息，幫助阿梨決定 | 調查介面可返回，對話是完成後的解釋，不代替推理 | 假說錯有具體缺證據提示，不收罰款、不強迫重打一場 | 帳冊翻頁、收據比對、記下差額 |
| 第三章首次陽光 | 讓玩家感覺由暗到亮，並察覺階層差異 | 過渡保持可走，只有主動停步有短反應；不是必須長暫停 | 回訪保持新光照與簡短反應，不重演驚訝 | 玻璃反光、凜遮眼、林小姐開門與指窗 |
| 第三章偷聽 | 凜看見真實交易，同時開始自己的隱瞞 | 在安全區確認開始；交談可略，完成後記錄看見的資訊；退出不算已聽完 | 不重發通行證；讀檔可重來短段，完成態有回訪文字 | 門縫／漏音合理、老 K 遞文件、葉寫手背、凜收起筆記 |
| 第四章鷺失去復原 | 把便利翻成不可挽回的失去 | 劇情失敗與戰鬥重試分清；可略已看過長段，狀態相同 | 第一次戰鬥失敗不提前寫鷺死亡；歷史回放不能偽裝可救活 | 伸手、終端無響應、靜音雨聲、空椅與遺物 |
| 第八章洪水回家 | 回收傘與家的弧線，玩家主動帶他離開 | 進店無戰鬥威脅；關鍵臺詞可看完整，也可略；互動結果不變 | 非戰鬥失敗有近處安全回退；不重播整段洪水路 | 浮標籤、挽手、穿外套、撐傘、扶上船 |

第三章首次陽光、樣品房等主動可停留內容不能計作一律強制中斷。反過來，必須看完才能走的NPC對話確實是鎖操作，不能因名字叫dialogue就把時間隱去。功能告示牌、閱讀物件、普通廣播、氣泡不觸發21:9。

第二章對帳例段所需素材是帳冊、收據、折頁與比較焦點，不能只列臺詞沒有可操作證據。玩家在地圖查到線索後回看帳本，線索自動儲存；UI 只呈現故事 source 中的結論，不自己生成另一套正確答案。

## 原創口語與角色差異

只讀指定字幕少量場景來觀察問答、日常衝突與技術詞語在情境中的語法，不引用它的臺詞。以下是本輪原創口氣樣例，供 ST-18／20 定稿用；不是正式遊戲新增源。

| 角色／情境 | 原創樣例 | 用詞與動機 |
|---|---|---|
| 凜／報酬 | 這筆錢先別算進去，盤還在倉庫裡。 | 直接、具體，把情緒轉到能確認的事情，但句意完整 |
| 老 K／出門 | 飯留在鍋裡喔，回來先吃，帳明天再算。 | 碎念小事，關心行動而非講大道理 |
| 鷺／淋雨 | 你坐裡面一點，我這件外套早就濕透了。 | 玩笑掩蓋照顧，不提前說明棠與錨人 |
| 燈／路線 | 先別碰那條線，我還沒把另一頭斷開。 | 技術提醒說清物件與條件，不用謎語式「線。等。」 |
| 阿梨／要不要幫忙 | 我缺的是攤位的許可，不是你口袋裡的錢。 | 給自己的需求與決定，不替凜作情感選擇 |
| 葉／交易 | 我可以讓你看原始報表，但這不代表我同意你帶走它。 | 禮貌、條件與控制；不用空泛反派宣言 |
| 林小姐／晴岸 | 這扇窗下午有陽光，您可以坐一下再決定。 | 尊稱、邀請與銷售事實；不用旁白預洩母親 |
| 守門人／門禁 | 請先把通行證放在桌上，我才能替您開門。 | 工作習慣完整，不靠一詞臺詞表演失憶 |
| 蘇／廣播 | 如果名字念錯了，請打斷我，我會重念。 | 平靜、承認有人在聽，把尊重落實到動作 |
| 沈望／確認 | 我們先核對這一頁，沒有簽名的地方不能往下辦。 | 工程師精確與契約，事實準確但不替她辯護 |

同角色可以變語氣，不能為了平均句長變機械。臺詞寫完逐場問誰能知道這些事，專名是否已介紹，回答是否接住前句，錢／物品／地點是否真實；母語審稿仍另驗。字幕裡省略標點與快速短回答不照搬到我們必須能讀清的文字。
