# 第一章逐區場景用途與裝飾審查

2026-10-11。接續 [來源盤點](SCENE_PURPOSE_INVENTORY.md)：那份只核對資料，這份是看過原生畫面後的判斷。畫面用 `tools/scene_tour.tscn` 把九個區域依固定格子拍成兩組：實際光影，以及環境光全亮、關掉後製的診斷畫面（只看擺放、支撐與圖層，不拿來驗收光影）。修前修後用同一組格子重拍。

## 判斷原則

每一區只回答四件事，回答不出來的東西就不該留在畫面上：

1. **這裡是做什麼的**：住處、街道、店面、倉庫、屋頂。擺設要能從用途推出來。
2. **靠什麼認出這一區**：一個地標加一組主色與主材質，不和相鄰區域混用。
3. **每件東西靠什麼撐著**：站地、掛牆、吊天花板或放在別的物件上；光也一樣，照到地面就停。
4. **玩家要先看到什麼**：角色與敵人 → 可走的地面與平台 → 互動物與危險 → 裝飾 → 背景。裝飾不能比前面幾項亮或密。

## 各區共通的問題與處理

| 問題 | 看到的畫面 | 處理 |
|---|---|---|
| 燈的光錐穿過地板 | 每盞場景燈下方的地面剖面裡都有一段錐形的光，暗場景看起來像地板下插著火把 | 光錐照到地面為止；地面反光只落在地板頂面那一條。霓虹招牌的地面反光同樣處理 |
| 室內下雨 | 當舖、倉庫、倉庫深處有天花板，燈的光錐裡仍有雨絲，鏡頭前還有快速飄過的雨簾 | 頭上有屋頂的燈不畫雨絲；鏡頭在屋頂下或關卡沒下雨時不畫雨簾 |
| 平台懸空 | 街道立面上的窄平台、倉庫與倉庫深處的層架只是一條橫板，下面什麼都沒有 | 平台下方加三角托架（兩端各一支，中間每 72 像素一支），看得出是架在牆面上 |
| 門框疊在門的圖上 | 當舖地下室鐵門旁邊多一個偏移的紅框 | 出入口只留互動範圍與提示，畫面用原本的鐵門 |
| 實際光影下背景只剩窗光 | 街道、屋頂的建築本體幾乎全黑，只看到一排排發光的窗，像燈籠飄在空中；倉庫斷電時連牆與貨櫃都看不到 | 屬於光影與視覺優先序，交 BG-30；全畫面雜訊交 BG-27 |
| 出入口是紅色或黃色的空框 | 當舖大門、街道兩端、倉庫入口 | 占位素材，交 BG-21 |
| 提示牌密集 | 當舖前 50 格內有 5 支 | 整併交 BG-22 |

## 逐區

擺設後面的記號：地＝站在地面、牆＝掛在牆面、頂＝吊在天花板、物＝放在別的物件上。決定：留＝保留原位；其餘寫明。

### 當舖（ch1_pawnshop；清晨版 ch1_pawnshop_dawn 共用地圖）

- 用途：凜的住處兼老 K 的店面，章節起點與存檔點。左側門外是下雨的街，往右依序是店面、櫃台、廚房，最右邊的梯子上屋頂。
- 色盤與材質：暖色紅磚牆、石板地與石頂；吊燈是暖黃光。清晨版改冷灰光。
- 地標：招牌「什麼都收，不收命」、牆上的樂器、掛鍋的廚房。
- 擺設（19）：標籤貨架、上鎖的鐵門、櫃台與收銀機、帳本箱（物）、槍械工作台、接漏水的水桶、木箱堆、傘架、碗櫃、水缸、餐桌、今天留的午餐、茶壺爐、舊冰箱（以上皆地）；牆上樂器、當舖招牌、掛鍋、撕頁日曆（牆）；紙罩燈（頂）。全部留：每一件都對得上「店面／住家」，而且從左到右剛好把店和廚房分開。
- 修正：地下室鐵門不再疊門框；燈的光錐不再穿地板、室內光錐沒有雨絲。
- 交接：大門的紅框（BG-21）、提示牌（BG-22）。

### 下層港區街道（ch1_street）

- 用途：主要戰鬥路段，連接當舖、電話亭巷、市集（封路）與碼頭倉庫。
- 色盤與材質：紫色雨夜天空、深灰綠立面、洋紅與青色霓虹；地面是裂開的石板。
- 地標：遠方有紅色條紋的巨塔、直式霓虹招牌「麵藥酒旅社當」、發亮的「再來一次，沒關係」看板。
- 擺設（10）：魚販推車、停著的機車、纏線的電線桿、排隊告示、兩組直式霓虹招牌、復活廣告看板、冒蒸汽的人孔、水位尺、雨傘販賣機（皆地）。全部留：都是街上會有的東西，間隔約 20～30 格一件，沒有擋住戰鬥落點。看板有支架、是劇情物件（BG-26 已補驗支撐）。
- 修正：路燈光錐不穿地板；立面上的窄平台加托架。
- 交接：實際光影下建築本體太暗（BG-30）；兩端黃框出入口（BG-21）。

### 電話亭巷（ch1_booth_alley）

- 用途：安全的小巷，放復原用的電話亭與備份機。
- 色盤與材質：與街道同一組立面與天空，光較平。
- 地標：電話亭、貼滿海報的牆。
- 擺設（9）：塗鴉鐵捲門、垃圾袋、報架、靠牆的腳踏車、復原指示牌、備份機、閃爍的路燈、排水管（皆地）；海報牆（牆）。全部留。
- 修正：路燈光錐不穿地板。

### 碼頭倉庫（ch1_warehouse）

- 用途：室內戰鬥與水位謎。前半是貨櫃與看門狗，後半是水坑。
- 色盤與材質：鏽紅浪板牆、石板地；斷電時幾乎全黑，警示燈是紅色。
- 地標：成排貨櫃、看門狗的充電座、中央的水坑。
- 擺設（8）：充電座、巡邏探照燈、纏膜棧板、旋轉警示燈、抽水機（皆地）；吊鏈（頂）；水底踏板、浮筒與木箱（放在層架上，淹水後浮起）。全部留：都和貨物、看守、排水有關。
- 修正：層架加托架；室內不再有雨絲與雨簾；光錐不穿地板。
- 交接：斷電時牆與貨櫃完全看不到（BG-30）。

### 倉庫深處（ch1_vault）

- 用途：保險箱守衛戰、階梯與上層走道，章節的資料盤在這裡。
- 色盤與材質：同碼頭倉庫。
- 地標：開著門的 2 號貨櫃。
- 擺設：原本整區只有貨櫃一件，五個畫面寬的走道是空的。補上纏膜棧板、旋轉警示燈、巡邏探照燈三件倉庫自己的物件（皆地，放在戰鬥落點之外）。戰鬥場地本身維持空曠，不往走道上塞東西。
- 修正：階梯與層架平台加托架；室內不再有雨。
- 交接：保險箱區缺一眼認得出來的保險箱或置物櫃牆面，列入 BG-21 的素材需求。

### 復原休息室（ch1_lounge）

- 用途：過關後的安全區，有吧台與人物。
- 色盤與材質：紫灰色抽屜牆與磁磚地、青色邊光、洋紅霓虹。
- 地標：吧台與酒瓶牆、點唱機。
- 擺設（9）：卡座沙發、圓桌與凳子、點唱機、吧台、角落的盆栽與燈串、衣帽架（地）；酒瓶層架、菜單板、霓虹酒杯招牌（牆）。全部留。
- 修正：光錐不穿地板。

### 屋頂（ch1_rooftop）

- 用途：安靜的敘事場景，從當舖的樓梯間上來。
- 色盤與材質：紅磚女兒牆與遠處樓群、紫色雨夜、冷白燈。
- 地標：生鏽的水塔、天線叢。
- 擺設（8）：樓梯間小屋、水塔、天線叢、一對碟型天線、接雨水的桶子、破傘下的茶桌、摺疊椅與箱子、繩圈與掛鉤（皆地）。全部留：樓梯間小屋本身就是門，出入口不另畫門框。
- 交接：屋頂裂縫與高低差的背景覆蓋（BG-28）。

### 清晨麵攤（ch1_stall）

- 用途：章末回家前的短場景。
- 色盤與材質：與街道同一組立面，清晨的灰光，麵攤是唯一的暖光。
- 地標：阿梨的麵攤車與燈籠。
- 擺設（6）：麵攤車、擺碗的桌子、疊起來的凳子、貓的紙箱窩、清晨的鐵捲門（地）；燈籠掛在攤車上（物）。全部留。

## 之後的章節怎麼沿用

- 新區域先寫上面四件事，再放擺設；每件擺設在資料裡寫明支撐方式。
- 新的光源一律給地面高度，光錐與反光會自己停在地面。
- 室內用天花板圍起來，雨就不會進來；不需要逐關關掉。
- 平台的支撐是自動的：後面有牆就是托架，沒有牆就是往上的吊索；要改造型在地形繪製處換一次，不用逐關擺。
- 背景的建築站在實心地面上，並往下蓋到看得到的最低處；單向走道不會把樓墊高（BG-28）。新主題不用設定；舊主題用 `facades_follow_platforms` 保留舊規則。
- 做完跑一次場景巡覽，實際光影與全亮診斷各一組，和修前逐格對照。
