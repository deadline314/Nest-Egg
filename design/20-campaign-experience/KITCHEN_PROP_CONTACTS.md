## 手部接觸指令（2026-10-26，基礎能力）

播放器新增 `reach`，近側／遠側手各自保持一個目標，動畫器原本的站走、坐姿、呼吸與骨長保留。這是正式演出使用的基礎能力，尚未把廚房四段動作接入故事；不能以手腕到達診斷叉當作握住把手、吃麵或全角色接縫驗收。

```json
{"do":"reach","id":"k","hand":"front","to":[75,125],"time":0.35}
{"do":"reach","id":"k","hand":"front","space":"actor","to":[-50,-179],"time":0.35}
{"do":"reach","id":"k","hand":"front","release":true,"time":0.35}
```

`hand` 是 `front` 或 `back`，與角色朝向無關。`to` 預設為舞台點；`space: actor` 表示相對演員腳底的舞台像素偏移，跟著演員平移，不額外乘人物倍率或朝向。`angle` 是舞台空間的弧度，預設0。`time` 是0至5秒，預設0.35，`wait` 預設true並計入預算。零秒明確表示立即切換；一般接觸、換目標與收手使用緩動。換座標空間先換算當下點；途中收手先固定當下點，再交回原動畫。

沒有握持變體啟用時，目標是手腕；現有握持變體已啟用時，沿用其校準握點。此指令不會自動換手圖、建立第三隻手、附掛物件或補畫手指。提壺仍須另外驗證掌心、把手、遮擋與物件唯一性。

世界點先經完整骨架逆矩陣，方向只經逆基底，涵蓋鏡像、人物倍率與父節點旋轉。兩段 IK 只改旋轉，過近／過遠的點不夾成假接觸、不拉骨頭；保留該影格原手臂並對該指令警告一次。非有限數字、座標超過±8192、無效手名或時長在檢查及播放入口拒絕；奇異矩陣在求逆前拒絕。損毀的新指令不清掉原接觸。每人重用兩份接觸狀態，未接觸的手不執行 IK，舊近戰後手 API 不改。
