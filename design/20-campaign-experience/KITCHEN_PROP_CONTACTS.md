## 手部接觸指令（2026-10-26，基礎能力）

播放器新增 `reach`，近側／遠側手各自保持一個目標，動畫器原本的站走、坐姿、呼吸與骨長保留。這是正式演出使用的基礎能力，尚未把廚房四段動作接入故事；不能以手腕到達診斷叉當作握住把手、吃麵或全角色接縫驗收。

```json
{"do":"reach","id":"k","hand":"front","to":[75,125],"time":0.35}
{"do":"reach","id":"k","hand":"front","space":"actor","to":[-50,-179],"time":0.35}
{"do":"reach","id":"k","hand":"front","release":true,"time":0.35}
```

`hand` 是 `front` 或 `back`，與角色朝向無關。`to` 預設為舞台點；`space: actor` 表示相對演員腳底的舞台像素偏移，跟著演員平移，不額外乘人物倍率或朝向。`angle` 是舞台空間的弧度，預設0。`time` 是0至5秒，預設0.35，`wait` 預設true並計入預算。零秒明確表示立即切換；一般接觸、換目標與收手使用緩動。換座標空間先換算當下點；途中收手先固定當下點，再交回原動畫。

沒有握持變體啟用時，目標是手腕；現有握持變體已啟用時，沿用其校準握點。此指令不會自動換手圖、建立第三隻手、附掛物件或補畫手指。提壺仍須另外驗證掌心、把手、遮擋與物件唯一性。

世界點先經完整骨架逆矩陣，方向只經逆基底，涵蓋鏡像、人物倍率與父節點旋轉。兩段 IK 只改旋轉，過近／過遠的點不夾成假接觸、不拉骨頭；保留該影格原手臂並對該指令警告一次。非有限數字、座標超過±8192、無效手名或時長在檢查及播放入口拒絕；奇異矩陣在求逆前拒絕。損毀的新指令不清掉原接觸。每人重用兩份接觸狀態，未接觸的手不執行 IK，舊近戰後手 API 不改。

## 廚房正式接入（2026-10-26）

背景改採無烘入壺的候選，原圖另檔保留；不宣稱生成前後家具像素相同。固定甕身搭獨立控制桿；固定壺身搭獨立鉸鏈鍋蓋，避免用兩張整件圖交替造成形狀晃動。來源與重建配方在 `assets_src/pipeline/story_staging_art.json`，共用grade、alpha清理、輪廓normal與匯入政策；只在右／下補至偶數畫布，原始接觸座標不縮放。非發光表面不產假glow。

`tools/story/kitchen_staging.py` 集中來源區塊、接點與編舞資料。桌面190.75、椅座238.0、floor304，凜3.9／老K4.0不變。凜實際轉爐鈕後火與餘光關閉，再讓出路線；老K握左側黑提把，同一隻近手搬壺，蹲低使壺口在水龍頭下，遠手開蓋、操作控制桿、關水再關蓋。壺以高位越過桌面，最後放回耐熱墊。沒有重開火、倒入乾杯、額外報酬或新故事旗標。

```json
{"do":"reach","id":"k","hand":"front","space":"prop","prop":"kettle","to":[350,200],"contact":[64,39],"angle":1.5707963}
{"do":"prop_hold","id":"kettle","actor":"k","hand":"front","point":[350,200]}
{"do":"prop_move","id":"kettle_lid","angle":1.2,"time":0.4}
{"do":"prop_release","id":"kettle"}
```

`contact` 是目前手圖的原始像素；`space: prop` 的 `to` 是道具來源畫布像素（非Sprite圖層用節點局部點）。預設角度仍為舞台方向；只有 `follow_rotation: true` 才相對道具跟轉。持續接觸追實際矩陣，不能用控制桿端點之間的直線代替圓弧。`region` 選來源畫布區塊，`pivot` 在所選區塊內；`parent_prop`／`anchor` 把蓋軸接在壺身來源點，子件只可獨立轉動，不能獨立提走。匯入縮圖不改尺寸或接點。

握持只接受已穩定且誤差≤0.25舞台像素的真接觸，保留原物件和正向基底，轉身不鏡像壺。每舞台最多八件握持、一手一件、弱引用清理失效持有人；演員IK後才更新壺，避免循環依賴。開始握持後近手改跟人物，開蓋／轉桿前先等近手穩定；放下先釋放道具再收手。持物移動與道具轉動使用物理Tween；原本無接觸的移動仍用原更新方式。

scene的 `props` 最多八筆具名初值（pos／angle／visible／state），先驗整批再套用；返家重入以空壺、熱爐重建，不能殘留裝水中狀態。舞台預設則是關爐、關水、蓋關、滿壺在墊上，供第三章及完成後重建。閉壺滿／空外觀相同，滿水狀態由實際入水與開蓋時可見的水面建立，並非捏造另一張閉壺材質。局部水流只重用八條線，隱藏即停更新，低幀率保留越界餘數；室外雨的預設參數及重設方式保持。

首輪原生逐格檢查發現凜擋住裝水、起身手目標過早升高，以及放壺點太近肩部。保留失敗輸出後改站位、按原起身時長留1.2秒、調整放壺站位與朝向；維持骨長和原接觸判定。獨立編舞檢查不代稱真人整章、實體硬體或角色完整接縫驗收；吃麵與交盤仍另驗。


首輪完整76組另抓到新背景餐桌0.53H，超出原家具比例契約；當輪不能當通過。實際背景縮放由0.8改0.75，重新以來源畫布對齊floor304、桌面190.75與椅座238.0，桌腳在後景300.25，沒有放寬比例表。爐鈕與耐熱墊隨實際背景重校，甕略往左讓門框留空。凜站位與轉鈕幅度避免身體遮住控制處，老K起手先向上提再轉入搬運點，避免目標穿過肩部附近的不可達內圈。放壺驗證改對真正具名耐熱墊的表面，不再複製舊世界座標。加入這些修正後的預估演出44.14秒，原60秒上限保留。
