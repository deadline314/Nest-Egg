# 一般死亡的等待與重試

2026-11-12，ST-13 重驗。正式第二次死亡在生命歸零後約4.50秒才出現可用、可聚焦的重試操作；第一章的初次建檔已完成，這是一般死亡，超過原2–3秒要求。原生前置、直接量時與程序退出分別記錄；正確沿用既有 AudioRelease 後的四個 default headless 程序重現兩次第二次死亡超時，兩次第三次死亡約2.80秒。這是操作可用時間下限，尚不等於完整重新取得玩家控制。

## 行為

保留所有台詞、每步停留與記憶卡，讓玩家自願看完；不用縮短文字顯示時間來換速度。一般死亡先保留短暫說明，再顯示既有「從檢查點重來／回主選單」與焦點說明。操作開放後，剩餘文字與卡片仍照原順序播放；自然播完不得把已移到另一按鈕的焦點搶回。原可略過序列在操作開放前的確認／互動／取消行為保留。

操作等待不超過第一段的原時間與1.2秒之較小值，與可自願閱讀的完整序列分開。一般死亡的進場等待先以0.7秒候選量測，首死診間等特殊故事流程維持原1.1秒與原過場；死亡計數、扣款與黑幕前保存均不改。重試仍須通過 Main 原本的目的地驗證與實際保存，失敗保留原重試提示，不可先換區、復活或發結果。回主選單沿用既有行為，不能宣稱其普通保存具有相同硬門禁。

## 驗證

1. 保留原第二次死亡約4.50秒的反例與第三次資料；清楚標示先前死亡、建檔與錄音完成的情境前提。
2. 真正量操作可見、可用與可聚焦，不額外要求整段自願閱讀已完成；確認序列仍按原時間到結尾、焦點不被搶回、原略過語意可用。
3. 由真正 Main、原關卡與生命傷害進入死亡，公開按重試，量至新玩家可操作；第二、第三次都須在3秒內。記錄真正轉場、保存結果與初始化成本，不以局部畫面按鈕時間代稱。
4. 真正拒寫時仍留原死亡／重試提示，修復後只復原一次；保留首死診間及原存檔回歸。
5. 原受影響測試全過，再看原生畫面、焦點與可自願閱讀的內容。所有清場等待在量測結束後，沿用 AudioRelease，不改遊戲時間或用診斷模式代替 default 執行。

若完整 Main 重試超時，以實際分段時間定位；不能移動量測終點、放寬三秒或略過保存來通過。
