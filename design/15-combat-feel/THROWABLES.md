> 來源：使用者 2026-10-11「我蠻喜歡 Leyla In Veil 的美術設計，特別是地圖的效果，像是光影、爆炸特效、可以撿取地上的東西丟向敵人，丟油桶會爆炸之類的」。

## 2. 規則

| 項目 | 規則 |
|---|---|
| 撿起 | 站在物件旁按互動鍵；有撿起動作（彎腰→舉起），時間依重量 0.18～0.4 秒 |
| 拿著 | 舉在頭上；雙手空出（武器外觀收起）；移動速度依重量 ×0.6～0.9；畫出拋物線與落點（油桶加畫爆炸範圍）。高低落差、斜上、往下都看得到會落在哪 |
| 丟出 | 拿著時按射擊鍵往準星方向丟（滑鼠或右搖桿）；初速與重力依重量（輕的遠而平、重的近而彎），再加上玩家移動速度的三成 |
| 放下 | 再按互動鍵放在腳前；衝刺、近戰、格擋會先放下再照常動作；受傷、上載具、撥電話、死亡時掉在原地 |
| 命中 | 掃掠判定（不穿牆、不穿過敵人）；傷害、擊退與衝擊力（受擊分層：可讓一般敵人硬直）；部位判定與裝甲沿用子彈規則（打到看門狗的裝甲會彈開） |
| 丟空 | 撞牆反彈、落地彈一下後平躺；可以再撿 |
| 油桶 | 丟出後撞到任何東西立刻爆；放在地上被子彈、近戰或爆炸打壞時**先燒 0.6 秒引信**（警示燈快閃、火花、地上畫出越縮越緊的爆炸範圍），再爆；爆炸同時傷害敵人與玩家，並穿過裝甲；旁邊的油桶被炸到會各自燒引信，一個接一個 |
| 數量 | 每個區域最多 24 個；重進區域依地圖重新擺放，不會累積 |
| 顏色語言 | 可撿物上緣一條細亮線（與可破壞物一致）；預覽線青色；爆炸範圍紅色 |
