## 2. 原則（本專案的頭目戰契約）

1. **一句話的核心機制**：每個頭目只有一條，講得完。機制改變玩家的站位或瞄準，不是單純加血或加彈。
2. **攻擊習慣看得出個性**：選招依「距離帶」與「上一招的結果」，不是均勻亂數。玩家看兩三輪就能預測，預測正確有回報。
3. **每一招都有預兆與至少一種應對**：預兆 ≥ 0.5 秒（簡單難度更長），預兆裡有姿勢、光與聲音其中兩種；應對是閃（跳、蹲、衝刺無敵）、擋（盾、格擋）、打斷或利用場地之一。沒有無法反應的傷害。
4. **顏色語言全遊戲一致**：紅＝要打到你了；**橙＝現在打得到牠的弱點**；灰＝裝甲，子彈彈開；青＝屏障。
5. **階段改變空間或規則**：每階段至少新增一招或改變一條規則，用身體變化表示（掉零件、斷鍊、冒煙），並有一次 1 秒以上的停頓讓玩家看。
6. **場地是招式的一部分**：高低平台、掩體、可投擲物與油桶（NE-254）都要有用途；不鎖場的頭目要讓逃跑是合理的選擇。
7. **資料描述**：招式、預兆、冷卻、階段門檻、部位、距離帶與習慣全部寫在 `data/bosses/<頭目 id>.json`。程式提供「招式種類」（衝刺撲咬、點射、地面震波、標記轟炸、跳壓…），新頭目用資料組合招式種類；只有真正新的動作才加新的種類。
8. **死亡後狀態保留**：持久世界的頭目，損失的血量照 `persists_damage` 保留；階段由血量推得，所以斷掉的零件、斷掉的鍊子也跟著保留，不另外存。

## 4. 第一章　看門狗（CERBERUS）完整規格

**一句話**：鍊子的長度就是牠的地盤——在地盤邊緣引牠撲咬，牠會被鍊子扯回，背部電源露出。

**故事對應**：碼頭倉庫的保全機甲，被鍊在前廳的狗屋旁看門；牠不追出地盤，是因為牠被拴著。第三階段鍊子斷了，牠第一次離開狗屋。死亡後世界保留：她醒來，牠的傷與斷掉的零件都還在（BOSSES.md 的劇情時刻）。

**習慣（選招規則，依序判斷）**

1. 玩家在地盤外（超過鍊長）：第一階段點射，第二階段起叫飛彈；待機時退回狗屋。
2. 玩家很近（3 格內）：吠叫震波。
3. 玩家在地盤內中距離：撲咬；**上一次撲咬被鍊子扯回**時，先退回狗屋喘一秒，下一招改用點射、飛彈或吠叫（吃過虧）。
4. 不連續用同一招兩次（第三階段的連撲例外）。

**招式**

| 招式 | 預兆 | 判定 | 應對 | 階段 |
|---|---|---|---|---|
| 撲咬 | 壓低身體、眼睛轉紅、地上畫出撲咬路徑（到鍊子盡頭為止）0.7 秒 | 沿地面衝刺，身體接觸傷害；撲到玩家前方一點或鍊子盡頭（身體前緣碰到黃黑線）就停 | 站在黃黑線外讓牠撲空；或跳、衝刺穿過、舉盾 | 1～2 |
| 被扯回（撲咬的結果） | 鍊子拉直發亮、金屬響、火花 | 往後彈並踉蹌 1.4 秒，背部電源打開（橙），垂下的槍臂不擋 | 射背部電源（2 倍；牠是四足，從正面要壓低槍口、從頭底下斜射，或繞到背後射）；近戰要衝刺穿過繞到背後砍 | 1～2 |
| 點射 | 舉起槍臂（槍臂發橙光）、紅色瞄準線先跟著你，最後 0.25 秒變亮鎖定 | 3 發都沿鎖定的線 | 線鎖定後跳起或舉盾；舉槍時打槍臂 | 1 |
| 吠叫震波 | 抬頭、頭部感測器打開（橙）、低頻聲 0.8 秒 | 左右各一道貼地震波 | 跳過震波；預兆中打頭 3 下可**打斷**，牠踉蹌、背部露出 | 全 |
| 肩部飛彈 | 肩上艙門、地上 3 個紅圈 1.0 秒（落點在預兆開始時決定，不追蹤） | 落點小爆炸 | 離開紅圈；高台不安全 | 2～3 |
| 連撲 | 同撲咬但更短的預兆 0.55 秒 | 不受鍊子限制，可連續兩次；第二次撲完會失衡 0.9 秒、背部打開 | 衝刺穿過、拉開距離；失衡時打背 | 3 |
| 跳壓 | 蹲低蓄力、落點地上出現陰影 0.8 秒 | 落地左右震波，落地硬直 1 秒、背部打開 | 離開陰影、跳過震波，然後打背 | 3 |

所有預兆在任何難度都不少於 0.5 秒（簡單難度較長、困難較短，與冷卻倍率連動一半）。

**階段**

| 血量 | 變化 | 演出 |
|---|---|---|
| 100～60% | 有槍臂、拴著鍊子 | — |
| 60～30% | 槍臂壞掉不見（不能再點射），改用肩部飛彈 | 停頓 1.2 秒、提示「槍臂壞了——小心肩上的飛彈」 |
| 30% 以下 | 鍊子斷：不再受地盤限制、退回狗屋的習慣消失；動作加快 1.25 倍，會連撲與跳壓 | 停頓 1.2 秒、提示「鍊子斷了！牠不再受地盤限制」 |

**部位與裝甲**（顏色語言：橙＝現在打得到；灰＝裝甲，子彈彈開並顯示「擋下」）

| 部位 | 倍率 | 何時打開（橙） | 關著時 |
|---|---|---|---|
| 身體 | 1 | 不打開；爆炸與近戰終結本來就無視裝甲（NE-254 的油桶） | 裝甲，子彈與近戰彈開；近戰碰到打開的部位就打部位 |
| 頭部感測器 | 1.5 | 吠叫預兆與出招中 | 裝甲，打到算頭部但被擋下（NE-252：看得到的頭一定打得到） |
| 槍臂 | 1 | 點射預兆與出招中（第一階段） | 裝甲；第二階段起不存在；硬直時垂下不擋 |
| 背部電源 | 2 | 硬直時（被鍊子扯回、打斷吠叫、連撲失衡、跳壓落地） | 藏在身體裡，打不到 |

第一次子彈被裝甲擋下時提示一次「裝甲擋下了——瞄準發橙光的部位」；第一次背部露出時提示「背部電源露出了！」。

## 5. 資料格式（`data/bosses/<頭目 id>.json`）

```json
{
  "moves": {
    "<招式 id>": {"kind": "<招式種類>", "telegraph": 0.7, "recover": 0.4, "params": {}}
  },
  "phases": [
    {"until": 0.6, "moves": ["<招式 id>"], "speed": 1.0, "armored": true, "leashed": true, "enter_toast": ""}
  ],
  "habits": {"close_range": 48, "far_range": 260, "close": ["<招式 id>"], "mid": ["<招式 id>"], "far": ["<招式 id>"], "after_yank": ["<招式 id>"]},
  "leash": {"length": 208},
  "parts": {"<部位 id>": {"open": "always,stagger,phase:N,move:<招式 id>（逗號分隔，任一成立）", "closed": "armor | hidden", "gone_from_phase": 0, "close_in_stagger": false}}
}
```

- 招式種類（程式提供）：`lunge`（沿地面撲咬，到鍊子盡頭會被扯回；`stagger_on_end` 撲完失衡）、`burst`（點射，`lock` 秒前鎖定瞄準）、`bark`（地面震波）、`missiles`（標記轟炸，落點不追蹤）、`pounce`（跳壓）。任何招式都可以設 `break_part`／`break_hits`：預兆中打中該部位幾次就打斷。新頭目先組合既有種類，參數不夠才加種類。
- 每招可指定 `pose_windup`／`pose_act`，其他狀態用 `poses`：骨架外觀當成骨架動作 id，零件式外觀（例如四足的看門狗）當成零件動畫的狀態名；換外觀時只改資料。階段的 `hide_parts` 在零件式外觀藏起整個零件（例如打壞的砲塔）。
- `phases` 依序排列，`until` 是這一階段結束的血量比例；最後一階段 `until` 為 0。
- 部位的大小、骨頭與倍率仍寫在 EnemyData 的 `hurt_parts`（換四足立繪時改骨頭名稱即可，NE-218）；本檔只寫「何時打開」。
- 讀檔失敗、欄位缺漏或招式指向不存在：記錄檔案與欄位位置，退回安全預設（只用點射、不拴鍊），遊戲不崩潰。
- 頭目專屬的動作：`custom_kinds` 宣告招式種類，由 PatternBoss 的子類別實作（`_implements_kind`、`_custom_*` 掛鉤）；子類別沒實作的種類會記錄錯誤、那招不會被選。`bar_name` 指定血條名稱（守門人是「門禁裝置穩定度」）。頭目自己的機制設定另放一段（例如守門人的 `gatekeeper`），由子類別讀。
