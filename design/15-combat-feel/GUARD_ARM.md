# 格擋改成「主角拿東西出來擋」

2026-10-11 使用者提出。對應票：NE-269。

## 現況

- 按住格擋時，主角身前浮出一道弧形的光盾；主角自己沒有專屬的格擋姿勢。
- 姿勢資料只有兩項：上身前傾一點、兩腳換成前後站。手臂照常舉槍瞄準，所以看起來像「拿著槍歪著站」，不像在擋東西。放開格擋走路時回到正常步伐，反而正常。
- 數值（`data/player/player_tuning.tres`）：完美格擋的時間窗 0.16 秒；可擋的角度是瞄準方向左右共 120 度；防禦量上限 100，低於 20 舉不起來；格擋時移動速度剩 35%。短時間內重複按，時間窗會縮小。
- 沒有任何升級項目會改變格擋。

## 別人怎麼做（查到的資料）

- **按一下與按住分開**：格鬥遊戲常見的做法是「輕點」給較長的判定時間、「按住」給較短的，避免移動時誤觸，也讓刻意的輸入比較好成功。[CvS2 P-Groove](https://srk.shib.live/w/Capcom_vs_SNK_2/P-Groove)
- **揮空要有代價**：Dead Cells 的盾牌，輕點是招架，時間窗內沒有東西打到就會有 0.6 秒不能再擋。成功則沒有傷害、可以馬上再招架。[Dead Cells Wiki：Shield](https://deadcells.wiki.gg/wiki/Shield)
- **不同攻擊有不同結果**：同一個招架，子彈是反彈回去、炸彈是以更高傷害彈回、爆炸只吸收不反擊。玩家因此學會「什麼該擋、什麼該躲」。（同上）
- **升級掛在招架上**：Dead Cells 的盾牌詞綴都是「招架成功時發生某件事」（流血、冰凍、連續招架加成），不是單純加數字。（同上）
- **擋子彈是一條升級路線**：Cyberpunk 2077 用刀可以擋子彈但耗很多體力，再升一級才變成把子彈彈回去。[PC Gamer：Mantis Blades](https://www.pcgamer.com/how-to-get-cyberpunk-2077-mantis-blades-build)
- **防禦量隔一段時間才回復、被打穿有硬直**：讓一直按著擋不是免費的。[東方心綺樓 Wiki：Blocking](https://shinpiroku.koumakan.jp/wiki/Blocking)
- **防連按**：成功後短時間內同一輸入不再受理，或連按時縮短完美時間窗。[Sonic Hurricane：CvS2 parry](https://www.sonichurricane.com/articles/cvs2pvsk.html)
- **敵人的出招要看得懂**：招架要成立，敵人的起手動作必須清楚、彼此分得開。[What Is A Parry System](https://discourse.weareopen.coop/news/what-is-a-parry-system)

這些是查到的資料，沒有逐一實機驗證；數字以各來源寫的為準。

## 採用方向

### 擋的東西：機械臂展開的折疊臂盾

凜的左手本來就是機械臂。格擋時前臂外側的裝甲片像扇子一樣展開成一面窄長的臂盾，橫在身前；另一隻手把槍收到腰側。放開時裝甲片收回前臂。

為什麼選這個：
- 東西是她身上本來就有的，不用解釋從哪裡拿出來；持槍的手不用放開武器。
- 是實體的金屬片，符合「雨、鏽、工作服」的世界，不是懸在空中的能量罩。受擊時火花與凹痕都有地方畫。
- 臂盾是一個可以換、可以改裝的零件，升級有實體可以對應。

備案（這張票不做，記下來）：強化骨架的折疊傘。傘是這個世界到處都有的東西（見 `design/13-story-v2/UMBRELLA.md`），當盾很有特色，但需要空出一隻手，和雙手持槍衝突。

### 專屬姿勢

- 舉盾：機械臂前臂橫在胸前到臉前，盾面朝瞄準方向；另一手持槍垂在腰側。脊椎直立、重心略低，兩腳前後站穩，不再整個人往前歪。
- 完美格擋：前臂往外一撥的短動作。
- 被打穿：手臂被彈開、上身後仰的硬直。
- 舉著盾移動：上半身維持舉盾，下半身用正常步伐（現在放開後走路正常，舉著時也應該一樣）。
- 盾面跟著瞄準方向上下轉，取代現在浮在空中的弧形光盾；可擋的角度要和畫面上盾的大小對得起來。

### 升級（掛在臂盾上的零件）

每一項都是「換一個零件」，並且在畫面上看得出來（盾的大小、顏色、多一個裝置）。

| 零件 | 改變什麼 | 畫面上的差別 |
|---|---|---|
| 反應晶片 | 完美格擋的時間窗變長（容錯） | 盾緣多一條指示燈，完美時亮起 |
| 延伸片 | 可擋的角度變大 | 盾面變寬 |
| 緩衝襯墊 | 防禦量上限變高、被打穿的硬直變短 | 盾背多一層襯墊 |
| 散熱鰭片 | 防禦量開始回復的等待變短、回復變快 | 盾緣有散熱片 |
| 偏折塗層 | 完美格擋把子彈彈回去（原本只是擋下） | 盾面有反光塗層 |
| 輕量骨架 | 舉盾時移動速度變快 | 盾變薄 |

升級放在哪裡取得、要花什麼、怎麼和現有的武器改裝與經濟配合，由戰鬥與經濟那邊決定，這份只定「有哪些軸可以升」。數值一律放資料檔。

### 規則上的調整（建議，交給戰鬥組定案）

- 輕點是「招架」、按住是「舉盾」：輕點時間窗內沒有東西打到，短時間不能再招架（揮空的代價）。
- 不同攻擊不同結果：子彈被擋下（有偏折塗層才彈回）、近戰攻擊讓對方硬直、爆炸只能減傷不能招架。
- 沿用現有的防禦量、連按縮窗與鎖定規則，不重做。
