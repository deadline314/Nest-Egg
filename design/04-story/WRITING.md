# 文本風格指南：讓它像人在說話

> 來源：2026-10-03 使用者回饋「文本盡量減少 AI 感」「`監視蜂在頭頂` 這種句子就很 AI 味」。
> 目標：玩家聽到的是一群有名有姓的人在講話，不是在讀一份寫得很順的稿子。
> 這份指南同時是寫作規則與自動檢查的依據（檢查規則見最後一節）。

## 為什麼現在的台詞有 AI 味

| 症狀 | 現有的例子 | 為什麼怪 |
|---|---|---|
| 對白在教學 | 「紅色瞄準線一亮就閃，或者舉盾擋回去。」「監視蜂在頭頂：往斜上方瞄準射擊。」 | 沒有人在現場這樣講話。這是在念操作說明，只是換了嘴巴。 |
| 格言收尾 | 「有錢人住在雲上面，我們住在雨裡。」「可是我要買的，從來就不是船票。」 | 每一句都想當金句，整份劇本都在抬頭望遠，沒有人低頭做事。 |
| 說得太完整 | 「這不是治療。」「我只想帶我弟去看一次真正的天空。」 | 角色把自己的情緒與動機講完了，沒留給玩家猜。 |
| 對仗與排比 | 「他們叫它『上傳室』。」「不是偷東西，是去接我弟弟回家。」 | 「不是……是……」是最典型的生成句型。 |
| 所有人同一種聲音 | 芽、老 K、凜講話長度、語氣、斷句幾乎一樣。 | 沒有口癖，沒有毛病，沒有廢話。 |
| 太乾淨 | 沒有打斷、沒有答非所問、沒有寒暄、沒有錢。 | 真人會先抱怨天氣、再問你吃了沒、最後才說正題。 |

## 十條規則

1. **對白不講操作。** 提示留給畫面上的提示、物件旁邊的文字與教學看板；通訊裡的人只講他們此刻真的會講的話（「上面！」「別站那邊。」）。如果一句台詞拿掉後玩家少了一個操作知識，那一句就不屬於劇本。
2. **一句只做一件事。** 大部分台詞 8～20 字，上限 40 字。沒有一口氣兩個分句還帶比喻。
3. **不講情緒，講東西。** 凜不說「我很擔心」，她說「藥還剩三天。」
4. **用具體的名詞。** 房租、粥、創可貼、電鍋、第三個轉角、四萬三。不要「命運」「希望」「代價」「靈魂」這類抽象的大詞，除非角色真的在吵架。
5. **留白比解釋有力。** 重要資訊讓角色避開不講、講一半、被打斷、轉移話題。玩家補完的那一刻才有重量。
6. **每個人有毛病。** 見下表的口癖與壞習慣；同一句話換人講要不一樣。
7. **要有廢話。** 寒暄、抱怨、換話題、講到一半去講別的。廢話讓人像人，但每場不超過兩句，且要能順便透露人物。
8. **用台灣的口語。** 「欸」「啦」「喔」「齁」「蛤」，量要少；不用書面語的連接詞（「然而」「因此」「儘管」）。廣告與公文例外，那些要像公文。
9. **標點克制。** 不用破折號（——）當戲劇停頓；省略號（……）只在角色真的沒話講，一場最多兩次；驚嘆號一場最多一個。
10. **不要每句都是收尾。** 一場戲結束在動作或一句普通的話，不要結束在一句漂亮的話。

## 角色的聲音

| 角色 | 句長 | 口癖與毛病 | 絕不會說 | 範例 |
|---|---|---|---|---|
| **凜** | 極短，常常只有一個詞 | 用反問代替回答；不說謝謝，說「嗯」；緊張時算數字 | 「我很害怕」「謝謝你」 | 「多少。」「欸，別碰那個。」「藥還有三天。」 |
| **芽** | 長短不一，連珠炮 | 嘴上抱怨、手上在忙；愛挑剔細節；用精確的數字講事情；偶爾停一下才說「上面」 | 「我擔心你」（她會說「你要是死了我換誰搭檔」） | 「十一秒。我說的是你剛剛站在那邊發呆的時間。」 |
| **老 K** | 中等，愛碎念，不講完 | 句尾拖「喔」；講到重點就改去講別的；每次都問「手沒事吧」；抱怨瓦斯貴 | 直接承認、直接道歉 | 「你喔。出門前把外套拉鍊拉起來。」 |
| **航** | 小孩的短句，偶爾冒出精準得不像小孩的詞 | 問題一個接一個；喜歡問天空；咳嗽時換氣的方式 | 大人的詞（除了那些聽起來是別人教他的） | 「姐，天空的藍色是什麼藍？像鉛筆盒那種嗎？」 |
| **監管者** | 完整、有禮、像客服 | 每句都有稱謂與敬語；從不提高音量；把殘忍講成手續 | 髒話、情緒字 | 「七號小姐，您的資料已經等候多時。請隨我來。」 |
| **回收員** | 平淡，像在辦手續，偶爾露出累 | 先唸流程再講人話；稱呼編號；不想打 | 威脅（他只是陳述） | 「依規定我得先講一遍。你可以不聽。」 |
| **阿婆（麵攤）** | 絮絮叨叨，一句話三個岔路 | 加蛋；問航的病；講以前；對天穹的稱呼是「上面那邊」 | 抽象詞 | 「又瘦了喔，來，這顆蛋不用錢，下次還我一個故事。」 |
| **維修員老陳** | 斷斷續續，氣音 | 數字不離口（班次、層數）；對年輕人用「囝仔」 | 完整的解釋 | 「十七層……不對，十八……那晚推車過去，有人在數數。」 |
| **天穹廣播** | 公文、客服、廣告的混合 | 句子完整、語氣溫柔、永遠「為您」 | 任何不確定的詞 | 「天穹集團提醒您，今日降雨持續。為您準備的傘，已放在每一個轉角。」 |

## 對照：壞的寫法與好的寫法

> 這些是目前劇本裡的句子。寫第一、二章新劇本時，逐句檢查有沒有同樣的毛病。

| 壞 | 為什麼壞 | 好 |
|---|---|---|
| 「巷口有兩個天穹保全。紅色瞄準線一亮就閃，或者舉盾擋回去。」 | 在教操作 | 芽：「巷口兩個。你要是被打到我下個月的薪水就沒了。」 |
| 「前面是鎮暴員，正面的盾打不穿。跳過去打背後，或騙他撞牆。」 | 在教操作 | 芽：「盾牌那隻看起來很貴欸。」凜：「貴的比較不會動。」 |
| 「碎片就在前面的貨櫃裡。熱源……很大一個。小心。」 | 設定好的過場句 | 芽：「貨櫃那邊有東西在發熱。……我是說比你還熱。」 |
| 「沉港市的雨，從來沒有停過。有錢人住在雲上面，我們住在雨裡。」 | 格言、對仗、旁白感 | 凜：「雨又開始了。」老 K：「它什麼時候停過。」 |
| 「航的病，只有軌道醫院治得好。一張船票，加上手術費……我存了四年。」 | 角色向觀眾解釋 | 老 K：「四萬三。」凜：「差多少。」老 K：「你自己不會算喔。」 |
| 「放心。我只想帶我弟去看一次真正的天空。」 | 說得太完整 | 凜：「我走了。」航：「姐，回來的時候可以順便看天空嗎。」凜：「……順便。」 |
| 「他們叫它『上傳室』。」 | 一次講完設定 | 芽：「名單上他旁邊寫的是『準備中』。準備什麼，沒寫。」 |
| 「不是偷東西，是去接我弟弟回家。」 | 「不是……是……」句型 | 凜：「這次不用偷什麼。去接他而已。」 |
| 「你以為是你偷走了它？是它在呼喚你。」 | 神祕兮兮的反派台詞 | 監管者：「七號小姐，您終於來取回它了。路上辛苦。」 |
| 「這條路要付多少，我都付。」 | 抽象的決心 | 凜：「多少錢？我身上有四萬三。」 |

## 資訊怎麼給（取代教學式的對白）

| 要讓玩家知道的 | 不要這樣給 | 改用 |
|---|---|---|
| 這種敵人怎麼打 | 角色在通訊裡念攻略 | 物件旁邊的一行提示、第一次遇見時的場景安排（安全的示範）、敗北圖鑑 |
| 前面有危險 | 「前方有 X 個敵人」 | 氣氛：燈光、聲音、剪影；人話：「欸，有人。」 |
| 這個機關是什麼 | 角色解說用途 | 機關自己的提示與安全示範 |
| 世界設定 | 旁白 | 廣播、廣告、道具文字、場景小東西 |
| 劇情真相 | 角色直接說出口 | 道具、錄音、細節的措辭；角色避開不講 |

## 讓一場戲有生活感的做法

- 先寒暄一句，再進正題。「吃了沒」比「情況如何」自然。
- 讓對話被東西打斷：電話、雨、咳嗽、槍聲、廣播。
- 讓人答非所問。凜：「藥呢。」老 K：「你鞋帶散了。」
- 讓錢出現。台灣的對話裡錢是最直接的壓力來源，也最能顯示每個人的處境。
- 一場戲只留一個重點，其餘都是氣氛。

## 長度規則（沿用並補充）

| 類型 | 上限 |
|---|---|
| 過場（靜態對話） | 每段最多 6 句 |
| 動畫過場 | 整段最多 16 句，每次演出之間最多 3 句 |
| 通訊 | 每段 1～2 句，不暫停遊戲 |
| 對話（場景人物） | 每段最多 8 句，玩家主動觸發 |
| 單句 | 超過 40 字要拆；超過 56 字不收 |
| 道具文字（文件、錄音） | 220 字以內（背包放得下） |

## 自動檢查（寫進測試與開發工具）

下列規則由劇本檢查器掃描所有場景台詞與道具文字，違反就視為錯誤（除非標示為警告）。

| 規則 | 說明 | 等級 |
|---|---|---|
| 教學詞 | 對白中出現「瞄準線、格擋、衝刺、預兆、鎖定、彈幕、終結、血量、擊破、破防、冷卻、關卡、玩家、任務目標」 | 錯誤 |
| 對比句型 | 「不是……而是……」「不是……，是……」「這不是……，這是……」 | 錯誤 |
| 破折號 | 「——」在一個場景出現超過 1 次（廣告與公文除外） | 錯誤 |
| 省略號 | 「……」在一個場景出現超過 2 次 | 錯誤 |
| 驚嘆號 | 一個場景超過 1 個 | 錯誤 |
| 書面連接詞 | 然而、因此、儘管、由於、此外、與此同時（廣播與監管者除外） | 錯誤 |
| 空泛大詞 | 彷彿、宛如、仿佛、如同、命運、宿命、救贖、靈魂、深淵、終將、注定 | 錯誤（每章合計容許 2 次，用在關鍵的一句） |
| 單句長度 | 超過 40 字 | 警告；超過 56 字為錯誤 |
| 抽象名詞密度 | 希望、絕望、代價、未來 每章合計超過 4 次 | 警告 |
| 講者長度 | 同一個講者連續 3 句都超過 24 字 | 警告 |
| 講者一致 | 凜的句子平均長度應明顯短於芽與監管者 | 警告（人工檢視） |

## 寫完之後自己問

1. 把講者的名字遮起來，我還認得出是誰在講嗎？
2. 這句話拿掉，玩家會少知道什麼？（少一個「操作」＝刪；少一個「人」＝留。）
3. 這句話有沒有人真的會這樣說？
4. 有沒有一句漂亮的話，是整場戲的收尾？把它換成一句普通的。
5. 有沒有哪個資訊角色講得太完整？讓他少講一半。
