# 雲蛇腹面與頸部接合（NE-90）

2026-10-10，原生 Forward+ 完整二十節預覽確認：左向頭的白腹朝下、身體白腹朝上；右向頭身間露出直切邊。NE-98 已完成，這次沿用仍在進行中的 NE-90 修復與動作接縫驗收。

出生／傳送的真 trail 方向立即決定頭與身體的腹面手性。轉向後角度保持在一圈內，避免角度累積造成頭腹面誤翻。

彎曲時不能整條身體跟著頭跨過±90°就瞬間翻面：遠尾可能仍朝舊方向。被原頭圖蓋住的首截面跟隨頭；可見截面依自己的路徑切線決定腹面，並在約 1/6 秒內連續轉換。各橫截面共用頂點，混合比例在相鄰截面間連續插值；片段著色器混合正反兩份完整貼圖取樣，避免直接壓縮 UV 時把鱗片拉成橫條。這個短暫轉動讓腹面逐漸移到另一側，而不是整尾突然換顏色。

著色器只處理顏色，保留原 UV 與 Godot 的 CanvasTexture 法線解碼，不寫入 NORMAL、NORMAL_MAP 或 light。原有法線圖及品質設定的啟停仍交給引擎；不增加繪製節點、第二條身體或新貼圖。[引擎的 CanvasItem 法線介面](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/canvas_item_shader.html)。

來源立繪保持定稿，不更動 PNG。雲蛇頭的接合校準使用原圖像素：中心 `(12,17)`，橫截面高度 `19`，對應原頭圖不透明範圍 y=7.5～26.5。避開不透明邊緣整數座標的浮點誤差，九個截面取樣均須 alpha≥0.5。身體起點放入該截面、前兩個關節間距平順接到原身寬。保留二十節、原間距、原尾端與傷害判定點；不能截短尾巴或放大頭來藏缺陷。

頭設定可選 `join`（來源圖像素中心）與 `join_width`（來源像素高度）；沒有校準維持原接點。接點須用真 Sprite 世界轉換，包含翻面與旋轉。入地仍沿原地面高度裁切。

驗收分兩層：真 Worm 的穩定兩面向 UV 與頭世界腹面方向一致、接合截面覆蓋不透明頭像素；兩圈連續轉向每幀檢查可見 UV 的變化量、遠尾依自己的方向維持腹面。再以完整全身、兩面向、待機與動作原生 Forward+ 畫面檢查白腹、輪廓與硬切口，尤其要檢視頭跨過±90°前後幀。數值通過不代表視覺通過。
