# 原生部件裁切的取樣格（NE-267）

局部補袖口使手的來源外框擴大後，重新計算緊密裁切會改變所有手指的
次像素取樣格。來源手指完全相同，仍不代表 runtime 手指相同。
鄭的舊切圖 171×100、候選緊裁 180×100，直接重裁使 8374 個遠端像素不同。

可選的 `parts.<part>.crop_phase` 保存原切圖 `origin`、`size`、`affine` 和
密度 `k`。origin 是原切圖 (0,0) 在部件軸上的完整座標；affine 是原
float32 逆向取樣矩陣。欄位型別、有限值、原生尺寸、密度、骨軸與 origin
對應在 check_spec／發布前檢查，錯誤指出部件與欄位。

新外框只按整數像素向外擴張，不能縮掉原 footprint。OpenCV 即使在整數
平移後也可能因中間運算捨入改變取樣，所以原 footprint 仍使用原矩陣與
原尺寸的 backend 呼叫，再平移到新 canvas；新區域依同一格點延伸。
省略此欄位的角色保留原變換、渲染及 PNG 位元組，不自動重建舊角色。

獨立原型 v1 的簡單取整仍有 2210 手指差異；v2 的 remap 在不變來源上
也不等同原 backend，均拒絕並保留。v3 的 reference-footprint 方法使
新手 pivot 增加 [9,0]，手指 diffuse／alpha、同 source 接觸點與 CPU
normal 遠端皆零差。CPU 原型與七項回歸不代表實機驗收。

採用後仍須檢查正式 Godot normal 的未改區域、source→UV→接觸座標一致，
以及同一姿態下的實際全彩與逐格接點；保留原錯誤圖與真正一像素孔負控。
不得改骨點、動畫、像素精度或 alpha 門檻來掩蓋重取樣或缺料。
