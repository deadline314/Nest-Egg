# 賽博龐克改版

> 來源：2026-10-02 使用者於開發對話中提出——射擊改滑鼠操作（滾輪換武器、左鍵射擊、右鍵格擋、Shift 衝刺無敵）、遊戲風格改為賽博龐克、之後走悲壯劇情（參考 Cyberpunk: Edgerunners）、角色改用骨架綁定並以程式繪製暫代圖、角色比例放大、先完成完整第一關；手感與音效維持現有水準。

## 目標

以「可遊玩的 Demo」為基準，讓第一關在美術風格、角色、劇情三方面都能代表正式版的方向，同時保留現有的射擊、打擊與移動手感。

## 決策

### 1. 操作：滑鼠瞄準射擊

| 動作 | 鍵盤滑鼠 | 手把 |
|---|---|---|
| 瞄準 | 滑鼠（360°） | 右搖桿 |
| 射擊 | 左鍵 | RT |
| 格擋 | 右鍵（按住） | LT |
| 換武器 | 滾輪；1～4 直選；Q 上一把 | LB / RB |
| 衝刺（無敵） | Shift | B |
| 跳躍 | Space、W | A |
| 蹲下／從平台落下 | S（+ 跳躍） | 十字↓ |
| 近戰／終結 | F | Y |
| 搭乘／互動 | E | X |

- 理由：滑鼠瞄準讓射擊從「8 方向」變成「精準點射」，是射擊手感的上限；角色永遠面向準星。
- 準星本身就是回饋：連射時擴散、命中出現命中標記、擊殺時變色。
- 武器欄改為最多 4 把，各自保留彈藥，滾輪循環切換。
- 舊版存檔的按鍵設定與新操作不相容，載入時自動改回新預設，避免玩家升級後無法射擊。

### 2. 格擋與完美反彈

- 按住右鍵舉起能量護盾，擋下準星方向扇形範圍內的子彈與接觸攻擊。
- 剛按下的短暫時間內為「完美格擋」：子彈朝準星方向反彈、傷害加倍，有專屬的頓幀與音效。
- 格擋消耗護盾能量，放開後自動回復；能量耗盡會破防並短暫硬直。
- 爆炸無法格擋，必須用衝刺閃避——讓「格擋」與「衝刺」各有用途，不會一招通吃。
- 格擋中移動變慢、不能射擊，維持攻守取捨。

### 3. 骨架角色與美術替換流程

- 所有人形角色（主角、敵兵、頭目）共用同一套人形骨架與程式動畫：跑、跳、蹲、衝刺、格擋、受傷、死亡，以及雙手持槍跟隨準星的手臂反向動力學。
- 外觀由「零件圖片」決定：頭、頭髮、軀幹、骨盆、上臂、前臂、手、大腿、小腿、腳、衣襬，以及可破壞的裝甲片。
- 每個零件有固定的畫布尺寸與「關節支點」，寫在角色設定檔裡；暫代圖由程式繪製並輸出成 PNG。
- 正式美術（例如 ComfyUI 產出）只要依相同畫布尺寸與支點畫好同名 PNG，直接覆蓋即可，不必改程式。規格另寫成美術交付文件。
- 角色比例放大約 2 倍、鏡頭拉近，跳躍與移動數值依新比例重新調校。
- 受傷時裝甲片逐片脫落並噴飛，延續「看外觀就知道血量」的設計。

### 4. 美術風格：雨夜沉港市

- 色彩：洋紅、青、黃三色霓虹為主光，深藍黑為底；高飽和光源 + 低飽和暗部。
- 場景：持續降雨（含地面水花）、霓虹招牌（中日文字樣、會閃爍）、全像廣告、多層城市天際線、霧氣、濕地反光。
- 敵人機械（無人機、砲台、自爆機）維持程式繪製，改為霓虹機械風格；人形敵人改用骨架。

### 5. 劇情：原創世界觀，悲壯基調

- 只參考 Edgerunners 的情緒與節奏（底層的夢想、代價、失去），不使用其角色、地名、專有名詞。
- 對話分兩種：**過場**（暫停遊戲、黑邊、逐字顯示、點擊推進）與 **通訊**（不暫停、畫面角落、自動推進），讓劇情不打斷戰鬥節奏。
- 第一章「雨夜」：開場、關卡中途通訊、頭目登場、結尾，結尾留下悲劇伏筆。
- 世界觀、角色與第一章劇本另寫成劇情文件。

### 6. 第一關

開場過場 → 教學（屋頂巷弄）→ 霓虹市集 → 貨運站（機甲段落）→ 天穹集團設施入口 → 頭目戰 → 結尾過場 → 結算。全程可遊玩、可死亡重來、劇情不因重來而重播。
