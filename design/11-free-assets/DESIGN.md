> 來源：2026-10-03 使用者要求：用高解析度的免費素材（樹、工廠、雲、賽博龐克場景等）換掉目前程式繪製的場景與背景，並換上光影；先找來源、存下來、給範例，再嘗試替換；全部流程最後整理成 Skill。角色（女主）的素材由使用者另行處理，本批不碰角色、敵人與立繪。

## 授權原則

1. **只收 CC0（公眾領域）**：不需標註、可商用、可修改。每個素材下載時自動記錄作者、授權與出處到 `assets_src/LICENSES.json`。
2. 授權不明、CC-BY、CC-NC、「免費但禁止再散布原檔」（多數 itch.io 免費包）一律不放進專案；若之後要用，單獨開票確認條款。
3. 原始下載檔（動輒數十 MB）放 `assets_src/raw/`，不進版控，可用 `tools/assets/fetch_assets.py` 重抓；進版控的是加工後的遊戲素材與授權清單。

## 加工路線（資料 → 遊戲素材）

| 素材 | 來源形式 | 加工 | 產出（遊戲內格式） |
|---|---|---|---|
| 地形材質 | PBR 貼圖組（反照率＋法線） | 取無縫方塊、縮到目標解析度、依色盤調色、頂面與側邊由本體裁切並加邊緣磨損、法線依 Godot 2D 的 Y+ 向上慣例轉換 | `art/environment/materials/<id>_{body,top,side}.png` ＋ `_n.png` |
| 建築立面 | 立面模型或牆面貼圖＋窗戶 | 渲染或拼接成一層一層的模組、窗戶另輸出自發光遮罩 | `art/environment/facades/*.png` ＋ `_n`、`_glow` |
| 道具 | 3D 模型（glTF） | 正交鏡頭渲染（反照率＋鏡頭空間法線）、裁切、縮到 4 倍解析度、自發光部位另輸出遮罩 | `art/environment/props/<id>.png` ＋ `_n`、`_glow` |
| 天空與雲 | HDRI 色調映射圖 | 取地平線以上的橫帶、左右無縫處理、壓暗並偏色到夜晚色盤 | `art/environment/backdrop/sky_*.png` |
| 遠景、中景 | HDRI 的城市天際線、模型渲染的樓群 | 去背（亮度與色彩遮罩）、剪影化、窗光抽出成自發光層 | `art/environment/backdrop/*.png` ＋ `_glow` |
| 樹與植被 | 3D 模型 | 同道具；多變體各渲一張 | `art/environment/props/tree_*.png` |

所有加工由 `tools/assets/` 的腳本完成並寫成清單，**重跑一次就能重現同樣的成品**；新增素材只改清單。

## 與現有系統的對接

- 地形、立面、道具、背景都已是資料驅動（`data/environment/**`），只要貼圖路徑與尺寸規格相符就能直接換；解析度比現有 4 倍更高時，提高資料的貼圖倍率欄位（不改程式邏輯的前提下新增欄位）。
- 光影沿用 NE-23 的法線貼圖與 NE-22 的自發光層：每張素材的 `_n.png` 與 `_glow.png` 規格不變。
- 寫實素材比手繪像素亮、彩度低，必須統一調色（降亮度、偏冷、加霓虹色邊）才能放進賽博龐克夜景；調色參數放資料，不寫死在程式。
- 檔案大小：單張貼圖上限 1024 px（地形 512 px），背景 4096×1024 內；總量以專案 `art/` 目錄成長不超過 60 MB 為限，超過就降解析度或改 WebP。

## 沒有免費模型的部分：用本機 Qwen Image 生成（2026-10-03，使用者要求）

吊車、龍門吊、控制台、堆高機、閘門、販賣機、看板、霓虹招牌、室內過場舞台等，在 CC0 素材庫找不到合適的模型。這些改用本機 ComfyUI 的 Qwen Image 2.1 非審查版（int8）生成，來源是我們自己的提示詞與種子（沒有第三方授權問題）。

| 項目 | 做法 |
|---|---|
| 透明背景 | 採官方做法：提示詞套用「This is an RGBA image with transparency. ＜主體＞. The image has alpha channel and the background is transparent.」，模型直接寫出真正的 alpha 通道，不需要白底去背。結構之間（支架、橫撐、纜線）都是真透明 |
| 畫風 | **賽璐璐**（2026-10-03 使用者決定，沿用凜的 A 畫風：平塗色、乾淨深色描邊、硬邊雙色陰影、冷白輪廓光、小面積霓虹點綴）。試過寫實版：和動漫角色落差大；也試過全紫色調的賽璐璐版：對比不足、融進夜景背景。因此提示詞要求「固有色（鏽褐、鋼灰、褪紅、青綠、暖黃）、明顯比深藍夜景亮」，調色再略提亮 |
| 視角 | 要求「正射、側面或正面立面、沒有透視、沒有地面與投影」，才能當 2D 橫向卷軸的道具使用 |
| 尺寸 | **依真實高度換算**：清單每個道具寫 `height_m`（公尺），乘以每公尺像素數（30，凜約 1.7 m ≈ 44 px 碰撞高）得到遊戲內高度，寬度跟著圖的長寬比（`fit: meters`）。超大型道具（龍門吊、吊車臂）與有單向平台的道具（逃生梯、麵攤、雨棚）維持原尺寸（`fit: keep`），後者用舊圖當版面參考（編輯模式）並對位平台，以保住關卡可站的位置。道具以底邊對齊地面，所以變大不會陷進地裡 |
| 法線與發光 | 法線由亮度細節與輪廓斜面算出；發光層由規則抽出（霓虹管＝高亮高彩度、信標＝純紅、螢幕＝亮面），規則放在清單 |
| 可重現 | `assets_src/pipeline/qwen_props.json`（道具）與 `qwen_scenes.json`（過場舞台背景、近景條帶）記錄提示詞、種子、調色；原圖快取在 `assets_src/work/qwen/`（不進版控），重跑只重新處理 |
| 場景圖 | 過場舞台用不透明的整張室內圖（1536×864），亮點抽成自發光層；清晨版本用編輯模式從夜晚版修改而來，構圖一致 |

## 賽璐璐化的做法（BG-1～4，2026-10-04）

地形材質、建築立面、遠中景樓群、天空都**用程式繪製**，不用 AI 生成：這些素材要求「左右／上下可無縫」與「窗光、信標、法線層與資料一一對應」，程式繪製天生無縫、可重跑、色盤與種子都在清單，也不占用 GPU。樹木與植被（BG-3）形狀自由，沿用 Qwen 生成（`assets_src/pipeline/qwen_props.json`，`nature` 畫風）。

| 素材 | 工具 | 清單 |
|---|---|---|
| 地形材質 | `tools/assets/cel_tile.py`（`Tile` 與 9 種 `PAINTERS`）＋ `process_material.py` | `materials.json` 的 `cel` 區塊 |
| 建築立面與遠中景 | `tools/assets/cel_facade.py`、`decor.py`、`build_facades.py`、`process_backdrop.py` | `facades.json`、`backdrop.json` 的 `layers` |
| 天空 | `tools/assets/cel_sky.py` ＋ `process_sky.py` | `backdrop.json` 的 `skies` 的 `cel` 區塊 |
| 樹木與植被 | `qwen_props.py` | `qwen_props.json`（風格 `nature`） |

## 統一調色（NE-66，2026-10-04）

- 調色算法只有一份：`tools/assets/grade.py`，各加工腳本（材質、立面、背景、天空、道具、場景圖）都呼叫它。每個清單項目自己的 `grade` 先套用，接著套用全域調色 `assets_src/pipeline/grade_master.json`（`all` 全部、`kinds` 各類別）；預設不改變任何像素。自發光層不套用全域調色。改完重跑對應腳本。
- 檢查：`python tools/assets/grade.py --check`（驗證調色資料）與 `python tools/assets/check_assets.py`（大小、授權、調色資料、每件道具都有法線與標示的發光層）。環境元件測試套件有同樣的涵蓋檢查。
- 替換前後的同機對照（2026-10-04，軟體渲染，縮小解析度）：環境貼圖記憶體與取樣成本變高，後續見 BG-17。

## 環境匯入成本（BG-17）

- 原圖與世界尺寸保留，以 Godot 內建無損匯入的 `process/size_limit` 降低貼圖解析度。參數集中在 `assets_src/pipeline/texture_import.json`：以明確世界矩形繪製的道具採受限半解析度，道具至少保留每世界像素 4 貼圖像素；使用區域取樣的地形、前景剪影、立面、舞台與場景整圖保留原尺寸；舞台引用的道具由原尺寸中介資料補償世界大小。視差背景由既有資料記錄原始寬度，依匯入比例補償縮放，保留平鋪尺寸、底邊及擺位。每支加工工具完成後自動套用，直接新增環境圖時匯入前跑 `python tools/assets/texture_import.py`，`check_assets.py` 會拒絕漏套用的圖。只處理環境，不改角色、UI 或舞台家具位置。
- `tools/environment_probe.tscn -- --level=level_01 --quality=low --out=<folder>`：三個固定位置、五隻靜止敵人、固定種子、關閉 vsync，截圖在計時結束後保存。修前／修後／替換前使用同機、同解析度、相同腳本。記錄 renderer 程序貼圖配置與環境匯入 payload（含法線、實際尺寸、格式及 mipmaps），不能以 PNG 大小或未壓縮估算冒充 GPU 記憶體。軟體 Vulkan 明確標示，不與實體 GPU 舊數字直接互比。
- GPU 工作使用 `python tools/comfyui/gpu_lock.py -- <command>`。鎖跨 linked worktree 共用並支援 Windows／Linux；鎖不卸載模型，ComfyUI 啟停與生成遵循本次 Session 分工。

舞台圖層僅補充來源寬度 metadata，渲染時補償匯入比例；原始家具位置、圖層順序與既有 scale 資料不變。重建舞台資料後，匯入前再執行同一匯入政策，素材檢查會指出缺少的 metadata。

環境渲染路徑目前均為 linear／nearest（沒有 mipmap sampler）；匯入政策因此不配置未使用的 mipmaps。肖像 UI 的 mipmap 取樣不在環境政策內。未來新增環境 mipmap sampler 時須同步政策與同機畫面／記憶體驗收。細長圖縮圖取整若使來源長寬比偏差超過 1%，保留原尺寸。
