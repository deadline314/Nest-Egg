# 市集入口敵人輪廓

2026-11-11，BG-53 修正取樣像素面積、BG-54 修正暗部 PNG 編碼後，以 Radeon RX 9070 XT／Forward+ 重驗 BG-48 的相關區域。在第二章市集入口，主角與地面通過，但敵人仍低於原門檻 0.45；巡覽工具的程序成功不代表敵人通過，原始每敵人量測另行判讀。

高品質 `related-high-after` 的 `ch2_market_gate`、c03:r01 有一名敵人對比 0.15317484；低品質 c01:r01 有兩名敵人，最低約 0.10328。高品質原霧參照最低 0.20856，低品質約 0.10240。這些跨程序自然時序資料不作嚴格改善比值；保留全部來源、圖片與失敗。紅棕衣物在紫霧與牆面前不易辨識，尚未將索引順序猜成特定敵人 id。

## 修復範圍

BG-55 專門處理市集入口的真敵人可讀性。先在只讀觀察中記錄實際敵人 id、位置、受光／霧與明暗狀態，再以固定相機、角色來源、動畫與霧時間建立同格對照。區分敵人材質／法線、局部燈光、霧及背景明暗的影響，按根因修復；不調高全區環境光、移除陰影或降低門檻。資料可表達的局部差異放在資料，不新增場景專用分支。

高、低品質逐格確認敵人 ≥0.45、主角 ≥0.6、地面邊緣 ≥1.0；原生完整圖與敵人原尺寸近拍分別檢查。保留敵人既有身份、造型、攻擊／傷害、出場位置及場景雨霧風格。相關公眾攤道、復原館外與第一章共用敵人外觀另做相同條件回歸，避免改善一處卻損壞其他場景。

原始資料隨 BG-53／BG-48 的 corrected 原生封包保存；本問題獨立於復原館外的局部霧量調整，後者不能證明市集敵人已通過。帳房另有敵人低於門檻，維持 BG-42 的未完成驗收，不與本票混為一處。

## 局部資料與受控結果

實際暗部目標是三名押運手（`ch2_escort`，共用 `collector_brute`，腳底 584/712/968,320）與一名投帳手（`ch2_bill_thrower`，共用 `collector_gunner`，1128,320）。原市集 profile 的敵人補光倍率只有主角補光的 0.6；診斷中單獨減霧並不能讓全部目標過原門檻，提高敵人補光比例則可改善衣物和軀幹。

採用市集入口專用 `market_gate` profile，僅把敵人補光比例改成 1.0，另改 profile id 供關卡引用。原 `market` 保持逐 byte 不變；不改共用敵人外觀、環境光、character_floor、霧密度 1、燈具或陰影。關卡產生器同步使用新區段 id，環境音、音樂、場景預覽以原 market 的內容補新 id 別名。

原生比較使用 Main 相同的 WorldEnvironment 和 bloom。固定真角色姿勢、雨點與 shader TIME，但移相機後仍呼叫實際燈光預算、牆影與霧取光的 owner 更新。單純把 Level 停住會把相機相關 owner 也停在舊畫面，不能以那種 A/A 一致充作正確畫面；已用真 owner 負控制重現並修正驗證工具。低品質保留關閉牆影的原規則，沒有為了控制而取消應有的陰影。

最終先保留真 physics bodies、用原角色碰撞求解接觸地面，另強制更新接觸陰影的真射線與最近光源快取；早期 floor-minus-two 浮空圖只留工具診斷。每品質 21 格含 14 可站格，同 live instance 的 A/A→局部 profile→恢復 A→局部 profile 全圖原浮點 SHA 完全還原。高品質全區主角／地面／敵人最小值 3.468495／3.426117／0.759697，低品質 3.060109／3.433574／0.787024，門檻仍 0.6／1／0.45。原 profile 最暗押運手 c3:r1、腳底 (968,320)，同格高 0.208321→0.984478、低 0.269702→1.027129。靜止敵人含武器附近的包圍框均無 RGB 全高於 0.92 的白像素，衣物細節仍在。

原 AI 高低品質各觀察押運手與投帳手，保留真狀態轉換、攻擊與 HP；只安排主角位置與耐久，沒有敵人狀態注入。押運手實際蓄力／突進／恢復，投帳手每品質產生 5 個真敵方投射物。攻擊驚嘆號、棍頭與紙彈仍使用原 HDR 亮效；動態圖的含效果框白像素不冒稱敵身過曝比例。原資料、精確方法、未完成輪次、全部 SHA 與負控制收據見 `pm/Nest-Egg-BG/attachments/BG-55-market-gate-2026-11-11/README.md`。

公眾攤道（24 格）與復原館外（9 格）高低品質均通過，兩地沒有敵人，不能冒稱已量到敵人。第一章兩個共用外觀區域（4 格）及上述兩地皆以原 profile 與現況 authored 作同程序控制，每格全 float bytes 完全相同，證明本票的局部資料沒有影響其他區域。第一章仍有原有不足：打手 (2136,320) 高 0.212734／低 0.300872、清掃兵 (1352,320) 高 0.415826／低 0.413017，及主角真接地平台 (2008,255.984375) 的 edge 高 0.503747／低 0.237566；它們保留 exit1，不能將無退步比較說成原門檻全部通過。平台支撐 y256、gap 0.015625 與真陰影均已驗證，只有此次接地重驗可作缺陷依據。這些區域沒有為本票提高環境光或改共用 profile。
