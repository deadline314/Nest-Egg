# 近戰攻擊模組與軟鞭：參考資料與設計

2026-10-12。使用者的要求：「現在只有基礎的揮動，沒有完整且獨立的近戰攻擊模組」；「像鞭子的武器為什麼不是永遠保持柔軟，而是會突然變直再變軟」；做之前多看別人怎麼做——至少五個不同來源、不要同一個遊戲或同一家公司、除了文字也要看截圖、截圖留在票裡；不必照抄，取各家的特點做出自己的。

票：NE-276（鞭子從頭到尾都是軟的）、NE-277（完整且獨立的近戰攻擊模組）。相關：NE-275（握法與圖層，已完成）、NE-237／NE-270（戰鬥組在雲端分支上的招式與鞭身，尚未併入 main）。

## 二、鞭子：從頭到尾都是軟的（NE-276）

戰鬥組在雲端分支上的做法（NE-270，未併入 main）是兩種模式切換：平常用 Verlet 模擬下垂；出招時改成「每一節的角度跟著導引」，並且在出招開始的那一格把整條鞭身一口氣排成直線。這就是使用者看到的「突然變直再變軟」。main 上則是一條永遠筆直的線。

我們的做法（來源 1、3 的結合）：

- **只有一種狀態：一條一直在模擬的繩子**。握把那一端釘在掌心；出招時不改變模擬方式，只多一個「鞭梢的目標點」沿著這一招的路徑走，鞭梢與靠近鞭梢的幾節被它用有限的力拉過去，其餘的節點由繩子自己帶動。沒有任何一格是用排的。
- **繩子比要打的距離長一點**（留 6～8% 的鬆弛）：鞭梢到達最遠點時，中段仍然有弧度，不會變成一把尺。
- **單分子鞭的線是從握把放出來的**：平常只放出短短一段垂著（不拖地一大截），出招時放長、收招時收回——長度是連續變化的，不是換一條。
- 命中判定仍然照招式資料；鞭梢在出招那一刻要已經在最遠點附近（看得到是它打到的）。
- 自己的特點（來源 2 給的想法，列為後續）：按住近戰鍵把鞭子留在外面、跟著準星甩；軟的鞭身碰到小型飛行物可以擋掉。來源 1 的纏與拉也列為後續。

驗收的量法寫在票上：整招逐格量「握把到鞭梢的直線距離 ÷ 鞭身長度」（1.0 就是一把尺），不能有哪一格等於 1、相鄰兩格也不能跳變。

## 三、完整且獨立的近戰攻擊模組（NE-277）

現況：一招＝一段手臂的姿勢內插，武器跟著前臂；身體幾乎不動；另一隻手不參與；五把武器的招式長得很像，只有軌跡的顏色與形狀不同。

要做成的樣子（來源 4、5、6、7）：

1. **一招是一個完整的、自己帶齊所有東西的單位**（資料）：預兆、出手、跟隨、收招四段的關鍵姿勢；身體怎麼動（踏步、轉身、壓低、躍起）；武器走的路徑；另一隻手在哪；軌跡與特效；判定（可以多段：持續＋間隔）；命中回饋（停頓幾格、敵人怎麼反應、聲音哪幾層）；可取消點。不再是「共用的揮砍姿勢＋不同的顏色」。
2. **武器帶著手，不是手帶著武器**：這一招先決定武器的路徑，兩隻手用 IK 去握（NE-275 已經有握點與另一隻手的握法）。雙手武器出招時兩隻手都在桿上。
3. **姿勢少而強**（來源 4）：每招 4～6 個關鍵姿勢，補間不加在關鍵姿勢中間；時間是資料，改一個數字就能調手感。
4. **每把武器有自己的一套**，不是同一套換皮：
   - 熱能長刀：三段斬（斜砍、反斬、踏步下劈），可以接衝刺斬。
   - 單分子匕首：近身連刺，按住是連續的快刺，最後一下往後跳開。
   - 離子戰戟：雙手，長距離的刺與橫掃；按住是把戟頭頂在前面的戒備姿勢（敵人撞上來會被電）。
   - 液壓錘：雙手，慢而重；按住蓄力，放開砸地（範圍震盪）；靠走位與時機。
   - 單分子鞭：遠距離的甩擊；按住把鞭子留在外面甩（來源 2）。
5. **獨立**：近戰模組自己管招式的播放、判定與回饋，不混在主角的槍械瞄準與手臂 IK 裡；輸入只有「按、按住、放開、方向」，模組回報「現在在哪一段、能不能取消」。這樣之後加新武器只加資料與少量的招式腳本。

做的順序（每一步都能單獨驗收）：
1. 招式資料的新格式與播放器（先讓現有的招式原樣跑在新的播放器上，行為不變）。
2. 武器路徑＋雙手 IK（先做液壓錘與離子戰戟，因為它們現在最假）。
3. 身體的動作（踏步、轉身、壓低）與多段判定。
4. 每把武器的「按住」招式。
5. 命中回饋分層（停頓、敵人反應、聲音）。

和戰鬥組分支的關係：`origin/feature/combat` 上有 29 個尚未併入 main 的提交（NE-237 的招式動作驗證、NE-270 的鞭身、NE-254 的投擲等），改了同樣幾個檔案。開始做之前要先決定：是把那個分支先併進 main，還是由這張票接手近戰、把那邊近戰相關的部分作廢。這件事要使用者決定。

## 四、實作後的樣子（2026-10-12，NE-277 第一輪）

和戰鬥組分支的關係：`origin/feature/combat` 和目前的 main 沒有共同的歷史（main 重寫過），而且 main 已經有 NE-260、NE-261、NE-275、NE-276 的成果；這一輪以 main 為準，不併那個分支。

**一招的資料**（招式組 `data/melee/<id>.json` 的每一招；欄位說明在 `MeleeMove`）：

| 欄位 | 內容 | 例 |
|---|---|---|
| windup／active／recovery／cancel_after | 前搖、出招、收招秒數與命中後可取消點（搬家前就有，數值不動） | 錘的下砸 0.34／0.12／0.5 |
| follow | 跟隨段秒數（收招的前段）：四段＝前搖、出招、跟隨、收招 | 0.2 |
| hits | 判定的各段 `{at, length, damage}`：多段攻擊寫多筆，每一段同一個目標可以再被打一次 | 匕首的按住連刺四段 |
| body | 身體：step 踏步、drop 壓低、twist 轉身；前搖先往後縮一點（預兆），出手到最前，跟隨段停住，收招回來 | 長刀第三刀 step 8、drop 5 |
| path | 武器的路徑：4～6 個關鍵點 `{t, angle, reach, tilt}`；前手的掌心追著它（手去握武器） | 錘舉到頭頂、砸到地上 |
| grip | 單手或雙手；雙手時後手握在桿上，長柄的後手可以沿桿子滑（刺擊時握在桿尾） | 錘、戰戟＝2 |
| feedback | 敵人反應的輕重（和 stagger 一致）、低頻與高頻兩層命中聲 | 重：落地悶響＋撞擊尾音 |

**每把武器的一套**（含按住招式；按下＝第一招，第一招打完還按著＝按住招式）：

| 武器 | 連段 | 升級尾招 | 按住 |
|---|---|---|---|
| 熱能長刀 | 斜砍、反斬、踏步下劈 | 突刺 | 蓄力（最多 0.5 秒），放開衝刺斬，蓄滿加傷 |
| 單分子匕首 | 刺、刺、橫劃 | 後跳回斬 | 重複：一次四段快刺，按著一直刺 |
| 離子戰戟（雙手） | 刺、上撩橫掃 | 迴旋交叉掃 | 持續：把戟頭頂在前面，每 0.25 秒電一次，最多 2 秒 |
| 液壓錘（雙手） | 舉過頭下砸、由下往上撈 | 重砸 | 蓄力（最多 0.8 秒），放開砸地震開，蓄滿加傷 |
| 單分子鞭 | 甩擊 | 回甩 | 持續：鞭子留在外面跟著準星甩，每 0.2 秒判定，最多 1.6 秒 |

**量法與工具**：`tools/melee_module_probe.tscn`（逐格量前手掌心離路徑多遠、雙手招式後手離桿多遠、身體位移）、`tools/melee_joint_audit.tscn`（逐格接點稽核，可以放在舊版本上量修前）、`tools/melee_move_film.tscn`（每一招在固定進度各拍一格的對照表，原生視窗）。只有資料的測試武器在 `tests/fixtures/melee/test_spear.json`。


## 2026-10-20：拍攝不得改玩家設定（NE-237）

連段／成長圖證工具改用各自的 user:// 設定檔，光影、粒子、震動與減閃光均不寫回玩家設定。單靠程序結束前還原不夠：中途失敗或關窗也必須保留玩家原檔。成長工具與連段工具均接受 --out，把本次新拍的圖存到指定資料夾，避免覆蓋票裡的歷史圖證。

本次只修工具資料隔離，不改招式、姿勢、數值與遊戲呈現。依使用者指南採用既有 Settings.use_storage 邊界，核對玩家設定的完整原始 bytes／SHA，並從另一程序讀回高品質及原本特效偏好；不以記憶體還原代替磁碟驗證。
