# 頭目設計

> 來源：2026-10-03 使用者要求第七、八章也要有頭目，可以是夢魘；**每一章的頭目都要有自己的特色與特殊的攻擊方式**。
> 修訂歷程：先要求不要硬堆疊空間機制、多一些大型多部位與彈幕；再補充**機制還是可以保留**，要把機制與類型合併；機制要在遊戲裡告訴玩家，**死亡一次就直接顯示在死亡畫面**（原本是失敗三次，使用者改成一次）；最終頭目要有**終局感、很多特效**，檔案機不夠，已換掉；**最終頭目必須是貫穿整個故事的某個人**，不是機器，已改為女性的沈望。**最終戰是魂系的感覺：三階段，每階段一條血條加一條條款，血條歸零就撕裂一條條款**；這也是要加入近戰攻擊的原因之一。
> 章節見 [PLOT.md](PLOT.md)，解謎動詞見 [PUZZLE.md](PUZZLE.md)，人物見 [WORLD.md](WORLD.md)。這份定形式、部位、階段、機制、招式與回饋，數值開票時再定。

## 原則

| # | 原則 | 說明 |
|---|---|---|
| 1 | **類型加機制，各頭目自己組合** | 類型（大型多部位、近身對決、機動、彈幕、非致命）決定骨架，**每個頭目最多一條招牌機制**決定它的味道 |
| 2 | **機制要能用一句話講完** | 講不完的就刪 |
| 3 | **機制一定要告訴玩家** | 戰鬥中有提示，**死亡一次就直接顯示在死亡畫面**（見下方） |
| 4 | **改變手感的機制要有回饋** | 看得到（圈、顏色、軌跡）、聽得到（音高、音效），讓玩家知道現在發生什麼、怎麼應對 |
| 5 | 不要讓玩家的操作被懲罰 | 不做「你的攻擊延遲三秒」這種讓人覺得壞掉的規則 |
| 6 | 招式要有預兆 | 蓄力、地面標記、光、聲音 |
| 7 | 頭目也在講故事 | 它怎麼打、什麼時候停，都是劇情的一部分 |
| 8 | 沒有壞人 | 頭目大多是被這個世界逼到這裡的人，打倒他們要有重量 |
| 9 | **最終頭目要有終局感，要有魂系的感覺** | 三階段、血條加條款、撕裂的演出、每階段不同的攻擊模式，近戰、格擋、閃避都有回報 |

## 魂系與近戰（依賴）

> 近戰動作組、打擊感、電話亭與死亡規則見 [../15-combat-feel/DESIGN.md](../15-combat-feel/DESIGN.md)。**魂系（失衡條、處決、假動作）只有阿勇、棘、沈望三隻（待確認）**，其餘頭目維持動作遊戲＋彈幕；下表是頭目對近戰功能的需求。

使用者：最終戰要有魂系遊戲的感覺，**這也是想把近戰攻擊加進遊戲的原因之一**。現有的遊戲有格擋與完美反彈、衝刺無敵、近身終結，但**近戰還不是一個完整的系統**。頭目設計依賴以下近戰功能，需要另外設計並開票：

| 近戰功能 | 用在哪 |
|---|---|
| 輕攻擊與重攻擊 | 所有頭目的近戰輸出 |
| 衝刺取消與翻滾 | 躲開延遲刀、抓取 |
| **完美格擋→失衡→處決** | 大型招式被完美格擋之後，頭目失衡，玩家可以近戰處決，造成大量傷害 |
| 近戰打斷 | 打斷頭目的蓄力（守門人、沈望的筆記本） |
| 近戰與射擊的切換 | 沈望第二階段：幽影不會被近戰驚醒，槍聲會 |

魂系頭目的共同特性（最終戰完整實現，其他頭目取一部分）：

| 特性 | 內容 |
|---|---|
| 預兆與延遲 | 重招有清楚的預兆，但出招有**延遲與假動作**，要看動作不要看按鍵 |
| 格擋有回報 | 完美格擋會讓頭目失衡，打出處決 |
| 低容錯但公平 | 玩家死得很快，但每次死都看得出原因（沿用死亡畫面的提示） |
| 階段轉換演出 | 血條歸零時的撕裂演出，第二次起可以略過 |
| 檢查點近 | 死亡後不用重走長路，第二次起略過階段演出 |

## 怎麼告訴玩家機制

使用者：最好在遊戲裡以某種方式告訴玩家機制是什麼，要顯示在死亡畫面。原本是失敗超過三次才顯示，**後來改為死亡一次就直接顯示**，不讓玩家白白卡關。

現有的**死亡畫面**已經會顯示一張「敗北圖鑑」卡片（標題、一段話、一句攻略），資料在 `data/codex/defeat_cards.json`。**頭目機制提示沿用同一套介面與資料**，不另做一套。

| 層 | 內容 | 何時 |
|---|---|---|
| 一　戰鬥中的提示 | 機制第一次生效的那一刻，畫面上一句話（「圈內，一切都變慢」），搭配圖示與聲音。同一機制只出現一次 | 第一次遇到 |
| 二　**機制提示卡** | 死亡畫面上的一張卡片：**機制的名字、一句話、一張小圖**。不是敗北卡的「死因」，是「這個頭目怎麼打」 | **在這個頭目第一次死亡時**自動顯示；之後每次死亡畫面角落都有「提示」鈕，可以重新打開 |
| 三　頭目筆記 | 收進圖鑑，隨時可看 | 看過提示卡之後 |

| 規則 | 內容 |
|---|---|
| 記錄 | 每個頭目記錄「是否已自動顯示過」與失敗次數，存進存檔，**擊敗後歸零**。第九章沒有擊敗，只有結束，結束時歸零 |
| 門檻 | **預設 1 次（第一次死亡就顯示）**。可以在設定裡調整成更多次，或關閉自動顯示 |
| 不重複打擾 | 自動顯示只出現一次；之後只在角落給一個鈕，想看再開 |
| 沒有復原時 | 第七章賣掉復原權之後，死亡畫面只剩「讀取存檔」，**提示卡一樣顯示** |
| 語氣 | 一句講重點，不寫廢話 |

## 共用元件（提案）

要新增七個頭目，先把共用的東西抽出來，不然會再複製七份。現有兩個頭目可以重用：

| 現有 | 內容 | 重用在 |
|---|---|---|
| 監管者 `warden_boss.gd` | 點射、跳躍、扇形散射、召喚、兩階段、受傷窗口 | 第一章看門狗、第六章守衛長 |
| 回收員 `reclaimer_boss.gd` | 衝刺斬、瞬移射擊、電軌、兩階段 | 第四章清理隊隊長 |

| 元件 | 說明 |
|---|---|
| `BossBase` | 階段切換、預兆、受傷窗口、場地矩形、死亡演出。兩個既有頭目各自重複了一份常數，新頭目只寫招式，數值走資料 |
| **部位系統** | 每個部位有自己的判定、血量與狀態：**灰色＝不能打、橙色發光＝現在可以打**。破壞部位會觸發事件。頭目總血量是各部位之和 |
| **彈幕圖樣（資料）** | 扇形、環形、柵欄（有缺口）、螺旋、慢速追蹤、直線雷射。物件池、同屏上限（提案 200 發） |
| **減速圈** | 一個區域元件，進入圈內的投射物與斬擊特效、判定的時間尺度變慢。**只改實體的時間尺度，不改全域時間** |
| **復原連結** | 第二章與第六章共用：頭目死亡後由終端復原，可被打斷，記憶條顯示 |
| **場地破壞** | 第四章：可以被擦除的掩體與平台，保留最小安全地面 |
| **機制提示** | 見上方，沿用死亡畫面與敗北圖鑑的資料與介面 |

### 彈幕的可讀性規範

| 規範 | 內容 |
|---|---|
| 一定有路 | 任何彈幕都要有一條看得到的安全路徑 |
| 預兆 | 發射前至少 0.5 秒的預兆（光、聲音、地上的標記） |
| 顏色 | 會傷害玩家的子彈用一致的顏色，不得與背景撞色 |
| 速度 | 密度高時速度要慢，速度快時密度要低 |
| 一次一種 | 同一時間只有一種圖樣是主角 |
| 難度參數 | 沿用既有難度設定，彈幕密度與速度各有係數 |

## 第一章　看門狗（CERBERUS，碼頭倉庫保全機甲）

> 2026-10-11 打法已依 NE-253 重做（鍊子與地盤、裝甲與橙色部位、三階段），完整規格見 [../15-combat-feel/BOSS_FIGHTS.md](../15-combat-feel/BOSS_FIGHTS.md) 第 4 節；下表保留原始構想。

| 項目 | 內容 |
|---|---|
| 類型 | **大型機甲**，教學頭目 |
| 部位 | **槍臂**（持續射擊，破壞後停掉點射）、**背部電源**（平時有裝甲，跳壓之後的硬直才露出，橙色發光，傷害加倍） |
| 階段 | **100～60%**：槍臂運作。**60～30%**：槍臂被破壞，改用肩部飛彈。**30%**：裝甲脫落，電線外露，動作變快 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 點射 | 抬起槍臂，紅色瞄準線 0.6 秒 | 蹲或跳 |
| 跳壓 | 收縮，地面出現陰影 | 離開陰影；落地硬直露出背部電源 |
| 飛彈齊射（輕彈幕） | 肩部艙門打開，地上落點圈 | 離開圈 |
| 呼叫無人機 | 艙門打開 | 最多兩台，優先打掉 |

**劇情時刻**：階段三中它把她夾住，一個笑話：「再來一次，沒關係。」她醒來，頭目的血條還是原來的樣子。這是玩家第一次知道「世界不會因為你死而重置」。

## 第二章　阿勇（收帳人頭目）

| 項目 | 內容 |
|---|---|
| 類型 | **近身對決** |
| 場地 | 市集倉庫二樓，後方高處是小薇的終端 |
| 階段 | **第一條命**：標準的近身對決。**倒下後**：小薇的終端亮起，他站起來進入**第二條命**：殼有瑕疵，動作變慢、硬直變長，但每一擊更重 |
| **機制一：復原** | **打斷連結**：在他倒下前後三秒內射擊終端（終端會發光），他就不會復原，永久死亡 |
| **機制二：利息** | 被他打中，身上疊一層「利息」，頭上顯示層數（最多 5 層），**每層讓下一擊多傷 10%**。**地上有亮著的「結帳」地墊，踩上去清空層數**。層數 6 秒沒有被再打中也會自己消退 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 鐵棍重擊 | 蓄力 0.8 秒後前衝 | 衝刺或跳過，撲空會硬直 |
| 債務簿（輕彈幕） | 甩出紙頁，扇形，緩慢落下 | 往兩側紙頁的縫鑽 |
| 叫人 | 吹哨 | 兩個收帳小弟 |
| 滯納金（第二條命） | 同一招式延遲一拍再追加一次 | 看清第二次 |

**劇情時刻**：小薇的剪影一次比一次淡。打斷連結讓阿勇永久死亡；不打斷，消耗的是他女兒。

## 第三章　守門人（JANUS，錨庫分站，用盡者）

| 項目 | 內容 |
|---|---|
| 類型 | **重裝防禦** |
| 場地 | 診所大廳，玻璃牆外是日照區的陽光 |
| 部位 | **護盾**（正面擋子彈，被盾擊撲空三次之後裂開）、**背部通訊器**（破壞後不再有增援） |
| 階段 | **100～50%**：護盾完整。**50%**：護盾裂開，動作變慢但範圍變大，他開始說「謝謝您的光臨」 |
| **機制：遺忘迴圈** | 他是用盡者。**每次受傷，有三成機率他忘記自己在做什麼，重複上一招**。頭上會出現「？」，並說「……我剛剛在做什麼？」。玩家可以利用，例如把他卡在一個慢招裡。**打斷他的蓄力，他會道歉並中斷** |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 盾擊 | 台詞「對不起」，蓄力長 | 繞到背後，或打斷 |
| 通行證掃描 | 橫向光束掃過，台詞「請出示」 | 蹲或跳 |
| 呼叫警衛 | 按下牆上的通訊箱 | 打壞背部通訊器就不會再有 |
| 通知單（輕彈幕） | 台詞「您的預約已過期」，格狀的紙片 | 往格子的縫鑽 |

**劇情時刻**：打倒他時，他說：「歡迎再來。」凜愣住。他是「再來一次」的另一種聲音。

## 第四章　清理隊隊長（ATROPOS，廢棄廠房）

| 項目 | 內容 |
|---|---|
| 類型 | **機動＋彈幕**，沿用回收員的位移 |
| 場地 | 廢棄廠房，平台與掩體 |

## 第九章　沈望（ELPIS，最終 Boss，「履行者」之形）

使用者：最終戰可以有非常精彩的演出，**Boss 有三階段，每階段都是血條加條款，每打掉一條血就有條款被撕裂的演出，三個階段各有不同的攻擊模式**，要有魂系遊戲的感覺。

| 項目 | 內容 |
|---|---|
| 是誰 | **沈望，74 歲，女，天穹創辦人。** 廣告裡的聲音、看板上的臉、契約的署名、電話裡的「來找我」、塔頂花園裡對汐說話的老太太。**玩家從第一章起一直在聽她、看她** |
| 名字 | 「望」是 ἐλπίς（**ELPIS**），潘朵拉的罐子裡唯一留下的東西：希望。見 [NAMES.md](NAMES.md) |
| 為什麼在這 | 洪水協定啟動，帳房要執行。契約一旦成立就不能中止，**包括她自己**。她不信任別人，也不信任自己的心軟，所以**今晚她親自走進帳房，把自己放在核心**：她是鎖，也是鑰匙 |
| 畫面 | 螢幕上方是**三條條款**，每條條款下面是一條血條。打掉一條血，那條條款就在畫面上被**撕裂** |
| 勝負 | **玩家打得贏她**。但打贏了她，**贏不了契約**：第四條條款撕不掉（見下方）。這就是「輸」 |

### 三個階段

| | 第一階段 | 第二階段 | 第三階段 |
|---|---|---|---|
| 名稱 | **歸檔** | **重播** | **履行** |
| 條款 | **一、記憶歸帳房所有** | **二、耗損不可逆** | **三、契約一旦成立，不得中止** |
| 形態 | 巨大的上半身，十二片翼，條款光環 | 翼全展開，整個身體由帳頁組成，手裡多了一支巨大的羽筆 | 巨大的形體崩塌，**沈望本人走下來**，一個老太太，拿著筆記本 |
| 場地 | 被撕開的塔頂平台 | 塔層崩塌，平台一塊塊掉落 | 只剩一座圓形的花園平台，種著茉莉 |
| 風格 | **慢節奏的大型招式與彈幕**，教玩家她的節奏 | **多目標**：幽影與她同時攻擊，近戰與槍聲各有用處 | **近身決鬥**：快、致命、低容錯，彈幕只剩殘響 |
| 近戰的角色 | 完美格擋拍擊，失衡處決 | 近戰靜音擊殺沉睡的幽影，格擋鏡像 | 全面：格擋、閃避、輕重攻擊的節奏 |

### 每階段的攻擊（筆記本的句子就是招式的名字）

| 階段 | 招式 | 預兆與應對 |
|---|---|---|
| **一** | **她喜歡茉莉**（彈幕） | 花瓣般的記憶核心像雨一樣落下，表面是 M1～M8 的文字。警示燈標出落下的欄位，有縫可鑽 |
| | **不要問她昨天的事**（三連拍） | 雙手連續拍擊，**第三下延遲**（魂系的延遲刀）。第二下之後，要等 |
| | **早上先開窗**（橫掃） | 翼橫掃：**低掃要跳，高掃要翻滾**，地上有影子提示 |
| | 筆記本 | 她左手拿著筆記本。**近戰打在筆記本上，會中斷她當下的招式** |
| **二** | **早上先開窗**（幽影） | 翼上的窗打開，**這趟旅程中最常殺死你的敵人**以幽影走出來 |
| | **她睡著的時候，不要叫醒她** | 幽影**沉睡**，不吵醒它們它們不動。**槍聲與衝刺會吵醒它們，近戰靜音擊殺不會** |

| | **羽筆斬** | 大型單手斬：長蓄力加快斬，格擋時機要抓 |
| **三** | **每天都去，不要停**（連段） | 五到七連擊，每擊一拍，節奏固定，要學；打斷節奏的唯一方法是完美格擋 |
| | **她問你是誰，說：我是來陪你的**（抓取） | 張開雙臂的擁抱。**被抓住扣血；完美格擋會反轉，變成處決** |
| | **再來一次，沒關係**（復原） | 血量剩三成時，**她復原一次**：場上陌生人的臉被燒掉，補回一小段血。**近戰打斷筆記本可以阻止** |
| | 殘響 | 少量的花瓣彈幕，作為背景 |

### 撕裂的演出

| 階段 | 條款被撕裂的畫面 |
|---|---|
| **一** | 「記憶歸帳房所有」像一張契約被一雙看不見的手**撕成兩半**。三片翼燒成灰，光環碎掉一角，鏡頭拉遠，她下沉一層。雨**停了一瞬**，然後繼續往上落 |
| **二** | 「耗損不可逆」的墨水**倒流**，筆記本被燒出一個洞，翼上的窗全部碎裂。**雨從往上落變成往下落**，像被放回原來的方向 |
| **三** | 「契約一旦成立，不得中止」被撕開，光環碎成千片。**雲蓋裂開了一瞬，露出星空**（這座城市十五年來第一次看見星星），然後合上。她跪下 |

撕裂演出第二次起可以略過。

### 贏了，卻輸了

沈望跪在地上，巨大的形體只剩下她一個人。筆記本掉在地上，翻開最後一頁：

> **四、雙方同意。**　受錨者：已簽署。　錨人：**未簽署。**

玩家的攻擊**穿過去**，撕不掉。她說：「**你贏了。可是契約還在。對不起，這是契約。**」

然後畫面出現兩個鍵：

| 鍵 | 結果 |
|---|---|
| **「算了」** | A 結局。凜放下武器，沈望合上筆記本 |
| **「再來一次」**（她的標語） | B 結局。凜不肯放棄，朝最後一條條款撲過去。**沈望站起來：「再來一次，沒關係。」** 她復原成完整的樣子，最後一條條款落下，無法閃躲 |

### 二周目

借帳之後，凜在第七章櫃台**代簽**，「錨人」那一欄不再是「未簽署」。第四條條款變成「雙方同意：**已簽署**」，**可以被改寫**。沈望停下，看著凜手上的簽名：「**你和我一樣了。**」

| 條款在畫面上被撕裂 | 三個階段結束時 |

使用者要求多一點沈望的劇情，最終 Boss 才有力量（見 [CHARACTERS.md](CHARACTERS.md) §6）。對最終戰的影響：

| **情感的鋪墊** | 玩家在第七章**扮演過她的一個早晨**（間章五），在第九章塔內**扮演過二十二年前的她**（間章六）。打她之前，玩家已經替她做過決定、聽過汐的廣播、無法問她。**撕裂她的條款，是撕裂玩家剛剛在間章六替她簽的字** |
| **筆記本** | 她的每一個攻擊都是筆記本上的一行字；第三階段結束時，最後一頁是：「**如果有一天有人問她想不想繼續，請讓她回答。**」（她自己寫的，她完全不記得） |
| **汐的回答** | 第一階段結束的轉折：汐出現在帳房的邊緣，**第一次回答那個問題**（回答的內容由使用者決定，見 CHARACTERS.md）。她不是來阻止戰鬥，是來被問 |
| **傘** | 凜在第八章得到傘，第九章的戰鬥可以**開傘格擋**與**傘降**（見 [UMBRELLA.md](UMBRELLA.md)）。沈望的白傘是第三階段的招式之一：**傘撐開，條款像雨一樣落下**；完美格擋它是整場戰鬥最有成就的一次反彈 |
| **為什麼夠強** | 它不只是血量與招式：**她是一個玩家看過她如何活、替她決定過一次的人**，所以撕裂她時，不是勝利，是又一次替別人決定 |
