# 頭目設計

> 來源：2026-10-03 使用者要求第七、八章也要有頭目，可以是夢魘；**每一章的頭目都要有自己的特色與特殊的攻擊方式**。
> 修訂歷程：先要求不要硬堆疊空間機制、多一些大型多部位與彈幕；再補充**機制還是可以保留**，要把機制與類型合併；機制要在遊戲裡告訴玩家，**死亡一次就直接顯示在死亡畫面**（原本是失敗三次，使用者改成一次）；最終頭目要有**終局感，強大到不可戰勝，要有很多特效**，檔案機不夠，已換掉；**最終頭目必須是貫穿整個故事的某個人**，不是機器，已改為沈望。
> 章節見 [PLOT.md](PLOT.md)，解謎動詞見 [PUZZLE.md](PUZZLE.md)，人物見 [WORLD.md](WORLD.md)。這份定形式、部位、階段、機制、招式與回饋，數值開票時再定。

## 原則

| # | 原則 | 說明 |
|---|---|---|
| 1 | **類型加機制，各頭目自己組合** | 類型（大型多部位、近身對決、機動、彈幕、非致命）決定骨架，**每個頭目最多一條招牌機制**決定它的味道 |
| 2 | **機制要能用一句話講完** | 講不完的就刪 |
| 3 | **機制一定要告訴玩家** | 戰鬥中有提示，**死亡一次就直接顯示在死亡畫面**（見下方） |
| 4 | **改變手感的機制要有回饋** | 看得到（圈、顏色、軌跡）、聽得到（音高、音效），讓玩家知道現在發生什麼、怎麼應對 |
| 5 | 不要讓玩家的操作被懲罰 | 不做「你的攻擊延遲三秒」這種讓人覺得壞掉的規則 |
| 6 | 招式要有預兆 | 蓄力、地面標記、光、聲音 |
| 7 | 頭目也在講故事 | 它怎麼打、什麼時候停，都是劇情的一部分 |
| 8 | 沒有壞人 | 頭目大多是被這個世界逼到這裡的人，打倒他們要有重量 |
| 9 | **最終頭目要有終局感** | 巨大、華麗、不可戰勝，特效多，但每個階段只加一件新東西 |

## 怎麼告訴玩家機制

使用者：最好在遊戲裡以某種方式告訴玩家機制是什麼，要顯示在死亡畫面。原本是失敗超過三次才顯示，**後來改為死亡一次就直接顯示**，不讓玩家白白卡關。

現有的**死亡畫面**已經會顯示一張「敗北圖鑑」卡片（標題、一段話、一句攻略），資料在 `data/codex/defeat_cards.json`。**頭目機制提示沿用同一套介面與資料**，不另做一套。

| 層 | 內容 | 何時 |
|---|---|---|
| 一　戰鬥中的提示 | 機制第一次生效的那一刻，畫面上一句話（「圈內，一切都變慢」），搭配圖示與聲音。同一機制只出現一次 | 第一次遇到 |
| 二　**機制提示卡** | 死亡畫面上的一張卡片：**機制的名字、一句話、一張小圖**。不是敗北卡的「死因」，是「這個頭目怎麼打」 | **在這個頭目第一次死亡時**自動顯示；之後每次死亡畫面角落都有「提示」鈕，可以重新打開 |
| 三　頭目筆記 | 收進圖鑑，隨時可看 | 看過提示卡之後 |

| 規則 | 內容 |
|---|---|
| 記錄 | 每個頭目記錄「是否已自動顯示過」與失敗次數，存進存檔，**擊敗後歸零**。第九章沒有擊敗，只有結束，結束時歸零 |
| 門檻 | **預設 1 次（第一次死亡就顯示）**。可以在設定裡調整成更多次，或關閉自動顯示 |
| 不重複打擾 | 自動顯示只出現一次；之後只在角落給一個鈕，想看再開 |
| 沒有復原時 | 第七章賣掉復原權之後，死亡畫面只剩「讀取存檔」，**提示卡一樣顯示** |
| 語氣 | 一句講重點，不寫廢話 |

## 共用元件（提案）

要新增七個頭目，先把共用的東西抽出來，不然會再複製七份。現有兩個頭目可以重用：

| 現有 | 內容 | 重用在 |
|---|---|---|
| 監管者 `warden_boss.gd` | 點射、跳躍、扇形散射、召喚、兩階段、受傷窗口 | 第一章看門狗、第六章守衛長 |
| 回收員 `reclaimer_boss.gd` | 衝刺斬、瞬移射擊、電軌、兩階段 | 第四章清理隊隊長 |

| 元件 | 說明 |
|---|---|
| `BossBase` | 階段切換、預兆、受傷窗口、場地矩形、死亡演出。兩個既有頭目各自重複了一份常數，新頭目只寫招式，數值走資料 |
| **部位系統** | 每個部位有自己的判定、血量與狀態：**灰色＝不能打、橙色發光＝現在可以打**。破壞部位會觸發事件。頭目總血量是各部位之和 |
| **彈幕圖樣（資料）** | 扇形、環形、柵欄（有缺口）、螺旋、慢速追蹤、直線雷射。物件池、同屏上限（提案 200 發） |
| **減速圈** | 一個區域元件，進入圈內的投射物與斬擊特效、判定的時間尺度變慢。**只改實體的時間尺度，不改全域時間** |
| **復原連結** | 第二章與第六章共用：頭目死亡後由終端復原，可被打斷，記憶條顯示 |
| **場地破壞** | 第四章：可以被擦除的掩體與平台，保留最小安全地面 |
| **機制提示** | 見上方，沿用死亡畫面與敗北圖鑑的資料與介面 |

### 彈幕的可讀性規範

| 規範 | 內容 |
|---|---|
| 一定有路 | 任何彈幕都要有一條看得到的安全路徑 |
| 預兆 | 發射前至少 0.5 秒的預兆（光、聲音、地上的標記） |
| 顏色 | 會傷害玩家的子彈用一致的顏色，不得與背景撞色 |
| 速度 | 密度高時速度要慢，速度快時密度要低 |
| 一次一種 | 同一時間只有一種圖樣是主角 |
| 難度參數 | 沿用既有難度設定，彈幕密度與速度各有係數 |

## 第一章　看門狗（碼頭倉庫保全機甲）

| 項目 | 內容 |
|---|---|
| 類型 | **大型機甲**，教學頭目 |
| 部位 | **槍臂**（持續射擊，破壞後停掉點射）、**背部電源**（平時有裝甲，跳壓之後的硬直才露出，橙色發光，傷害加倍） |
| 階段 | **100～60%**：槍臂運作。**60～30%**：槍臂被破壞，改用肩部飛彈。**30%**：裝甲脫落，電線外露，動作變快 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 點射 | 抬起槍臂，紅色瞄準線 0.6 秒 | 蹲或跳 |
| 跳壓 | 收縮，地面出現陰影 | 離開陰影；落地硬直露出背部電源 |
| 飛彈齊射（輕彈幕） | 肩部艙門打開，地上落點圈 | 離開圈 |
| 呼叫無人機 | 艙門打開 | 最多兩台，優先打掉 |

**劇情時刻**：階段三中它把她夾住，一個笑話：「再來一次，沒關係。」她醒來，頭目的血條還是原來的樣子。這是玩家第一次知道「世界不會因為你死而重置」。

## 第二章　阿勇（收帳人頭目）

| 項目 | 內容 |
|---|---|
| 類型 | **近身對決** |
| 場地 | 市集倉庫二樓，後方高處是小薇的終端 |
| 階段 | **第一條命**：標準的近身對決。**倒下後**：小薇的終端亮起，他站起來進入**第二條命**：殼有瑕疵，動作變慢、硬直變長，但每一擊更重 |
| **機制一：復原** | **打斷連結**：在他倒下前後三秒內射擊終端（終端會發光），他就不會復原，永久死亡 |
| **機制二：利息** | 被他打中，身上疊一層「利息」，頭上顯示層數（最多 5 層），**每層讓下一擊多傷 10%**。**地上有亮著的「結帳」地墊，踩上去清空層數**。層數 6 秒沒有被再打中也會自己消退 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 鐵棍重擊 | 蓄力 0.8 秒後前衝 | 衝刺或跳過，撲空會硬直 |
| 債務簿（輕彈幕） | 甩出紙頁，扇形，緩慢落下 | 往兩側紙頁的縫鑽 |
| 叫人 | 吹哨 | 兩個收帳小弟 |
| 滯納金（第二條命） | 同一招式延遲一拍再追加一次 | 看清第二次 |

**劇情時刻**：小薇的剪影一次比一次淡。打斷連結讓阿勇永久死亡；不打斷，消耗的是他女兒。

## 第三章　守門人（錨庫分站，用盡者）

| 項目 | 內容 |
|---|---|
| 類型 | **重裝防禦** |
| 場地 | 診所大廳，玻璃牆外是日照區的陽光 |
| 部位 | **護盾**（正面擋子彈，被盾擊撲空三次之後裂開）、**背部通訊器**（破壞後不再有增援） |
| 階段 | **100～50%**：護盾完整。**50%**：護盾裂開，動作變慢但範圍變大，他開始說「謝謝您的光臨」 |
| **機制：遺忘迴圈** | 他是用盡者。**每次受傷，有三成機率他忘記自己在做什麼，重複上一招**。頭上會出現「？」，並說「……我剛剛在做什麼？」。玩家可以利用，例如把他卡在一個慢招裡。**打斷他的蓄力，他會道歉並中斷** |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 盾擊 | 台詞「對不起」，蓄力長 | 繞到背後，或打斷 |
| 通行證掃描 | 橫向光束掃過，台詞「請出示」 | 蹲或跳 |
| 呼叫警衛 | 按下牆上的通訊箱 | 打壞背部通訊器就不會再有 |
| 通知單（輕彈幕） | 台詞「您的預約已過期」，格狀的紙片 | 往格子的縫鑽 |

**劇情時刻**：打倒他時，他說：「歡迎再來。」凜愣住。他是「再來一次」的另一種聲音。

## 第四章　清理隊隊長（廢棄廠房）

| 項目 | 內容 |
|---|---|
| 類型 | **機動＋彈幕**，沿用回收員的位移 |
| 場地 | 廢棄廠房，平台與掩體 |
| 階段 | **100～50%**：鷺同行（腳本掩護），**她在一半血量時倒下**，戰鬥暫停，畫面是終端：「復原：無法執行」。**50%～**：他變快，彈幕變密 |
| **機制：清理** | 他的招式會**擦掉掩體與平台**，被擦掉的**不會回來**，場地逐步清空，玩家的選擇越來越少。被擦掉的位置留下淡淡的輪廓。**永遠保留最小的安全地面**，不會把場地清到沒有立足之地 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 衝刺切（沿用回收員） | 蹲低，刀光亮起，地上畫出路線 | 衝刺穿過或跳過；撲空硬直 |
| 瞬移射擊（沿用回收員） | 身體閃爍消失，新位置出現圈 | 離開圈，躲開瞄準線 |
| **標記轟炸（彈幕）** | 被標記處紅圈，依序亮起，2 秒後空襲 | 紅圈有順序，往沒標記的地方走 |
| 清掃線 | 地上白線，橫向雷射掃過，擦掉線上的掩體與平台 | 在被擦掉之前跳出去，不要一直躲同一個掩體 |

**劇情時刻**：鷺倒下時沒有「歡迎回來」。玩家第一次看到無法復原，之後才是二階段。

## 第五章　老鬼（收屍人隊長）

| 項目 | 內容 |
|---|---|
| 類型 | **非致命追逐** |
| 是誰 | 老 K 雇的退休傭兵，收屍人的隊長，凜在第二章起一直看到的灰衣人 |
| 為什麼在這 | 他守著地下室的入口。老 K 要他別讓她進去 |

| 血條 | 是他的**體力**，不是血 |

| **機制：搬運** | **他的招式不造成傷害**，而是把你扛走、拉回、遮住視野。被他扛走會回到巷口，沒有懲罰，只是時間 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 擒抱 | 低身衝來，雙臂張開 | 衝刺躲開；被抓住連按掙脫 |
| 繩索 | 拋出繩圈 | 跳過；套住腳踝會被拉回原位 |
| 灰霧 | 煙霧彈 | 視野遮蔽 3 秒，靠聲音判斷 |
| 呼哨 | 手指入口 | 灰衣人從屋頂落下，**擋路但不攻擊** |

**劇情時刻**：玩家會覺得奇怪：為什麼他不殺我？打完，他把灰外套鋪在樓梯上，走開。**這是揭露前的最後一個線索。**

## 第六章　守衛長（廣播站）

| 項目 | 內容 |
|---|---|
| 類型 | **重火力＋落雷** |
| 場地 | 廣播站屋頂，暴雨與天線。母親坐在角落的錨椅上，罩著玻璃 |
| 階段 | **第一條命**：重火力。他死後復原一次。**第二條命**：他的動作變得遲疑。**第二次死亡時，他看著母親，自己按掉復原，戰鬥結束。** 這一次不由玩家決定。玩家若在此之前打斷連結，同樣結束，但母親不會被讀取 |
| **機制一：落雷與磁吸** | 藍光圈依序亮起，1.2 秒後落雷。**玩家可以用義體磁吸把落雷引到他身上，傷害加倍**（不學也能通關，但學會比較快） |
| **機制二：母親的記憶條** | 母親的記憶條顯示在畫面角落，他每復原一次，她就忘記他多一點，台詞逐次退化（「兒子」→「你是……」→ 沉默） |

| 招式 | 預兆 | 應對 |
|---|---|---|
| **天線召雷（彈幕）** | 藍光圈依序亮起 | 離開圈，或用磁吸引雷 |
| 重型榴彈 | 拋物線，地上落點圈 | 離開圈 |
| 靜電場 | 身體周圍閃兩下，球形電場 | 離開近身範圍 |
| 呼叫增援 | 無線電 | 雨衣保全 |

**劇情時刻**：他看著母親，按掉復原。**第一次有一個人自己選擇不被復原**，是第九章的預告。

## 第七章　明天（夢魘）

| 項目 | 內容 |
|---|---|
| 類型 | **巨型夢魘**，由日曆頁組成的巨大人形，臉是空白的 |
| 是誰 | 每個人說過的「明天再說」：老 K、燈、沈望，也是凜自己 |
| 場地 | 凜在日照區的長椅上睡著，夢見一片無限延伸的日照花園，日曆頁在風中飄 |
| 部位 | **雙手**（發動攻擊，可被打斷）、**胸口的時鐘**（核心，平時被日曆頁遮住） |
| **機制：減速圈** | 它的身體周圍有一圈圈的日曆頁軌道，**圈內所有投射物與斬擊都會變慢**：你射出的子彈進圈會慢下來；斬擊的特效與判定也變慢；它的彈幕進圈同樣會慢。**你自己的移動不受影響** |
| 階段 | **100～66%**：圈固定，教玩家「圈內變慢」。**66～33%**：圈會收縮與擴張，**收縮的瞬間胸口時鐘露出**（橙色發光），這是主要輸出時機。**33%～**：它說：「**今天。**」圈消失，所有東西回到正常速度，進入最快的一輪攻擊，也是最後的輸出窗口 |

### 減速圈的回饋

| 回饋 | 內容 |
|---|---|
| 視覺 | 圈是旋轉的日曆頁軌道；進入圈的子彈拖出長長的軌跡，顏色變冷；斬擊特效被拉長 |
| 聲音 | 進入圈內的音效降半音，像被拉長 |
| 提示 | 第一次進圈時旁白一句：**「圈內，一切都變慢。」** |
| 不懲罰 | 慢下來的斬擊傷害不變，只是晚一點到；玩家的移動、衝刺、跳躍都不受影響 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 改天（彈幕） | 日曆頁環繞身體，依序翻開，朝玩家散射；進了圈就變慢，出了圈變快 | 利用圈的位置判斷速度；彈幕有縫 |
| 明早 | 巨大的手從地平線往下抓，地上先出現手的影子 | 影子出現就移動，**手落下後的硬直可以打** |
| 下次 | 在你剛才站的位置留下殘影，2 秒後爆炸 | **別站在原地** |

**劇情時刻**：它死不了，它變成太陽。凜醒來，老 K 已經不認得她了。**她在夢裡贏了「明天」，在現實裡已經是今晚。**

## 第八章　協定（洪水協定的閘門管理機）

| 項目 | 內容 |
|---|---|
| 類型 | **巨型固定機關**，不移動，靠部位與水柱 |
| 場地 | 天穹塔基座的巨大水閘廳，水位隨戰鬥升降。下方的平台上有被困的人（剪影），選擇性地救 |
| 部位 | **左閥、右閥、中央泵**。每個部位在它的蒸氣孔打開的那幾秒露出（橙色發光）。依序破壞 |
| 階段 | **三個部位都在**：慢速，水柱規律。**破壞兩個**：水位上升，水柱變密。**破壞三個**：它說：「優先順序已更新。」戰鬥結束 |
| 選擇 | 下方的人可以去救，救一個要花時間，水位會繼續上升。**不救不影響結局，只影響船上的人數** |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 放水 | 被標記的區塊閃紅，3 秒後洪流沖過 | 爬高或躲進凹槽 |
| 閘門夾 | 兩側閘門閉合，警示燈與聲音 | 在閉合前穿過 |
| 優先序廣播 | 它說「正在評估」，一個圈跟著你 | 圈鎖定後 1 秒落下，離開 |
| 水柱（彈幕） | 地上一排噴口亮起，依序噴出，有縫 | 站在兩根水柱之間的縫 |

**劇情時刻**：它沒有感情，沒有抗拒，只是照做。這是第九章沈望的預演：她的聲音是這台機器的聲音。

## 第九章　沈望（最終 Boss，「履行者」之形）

使用者：最終頭目要有終局感，強大到不可戰勝，要有很多特效，**而且要是貫穿整個故事的某個人**，**並且是女性，名字有深意**。**舊的「帳房」檔案機設計作廢。** 帳房是地點，履行者是沈望走進帳房之後的**形態**。

| 項目 | 內容 |
|---|---|
| 是誰 | **沈望，74 歲，女，天穹創辦人。** 廣告裡的聲音（「再來一次，沒關係」是她本人錄的）、看板上的臉、契約的署名、電話裡的「來找我」、塔頂花園裡對汐說話的老太太。**玩家從第一章起一直在聽她、看她** |
| 名字 | 「望」是希臘文 ἐλπίς（Elpis），潘朵拉的罐子裡唯一留下的東西：希望。代號 **ELPIS**，見 [NAMES.md](NAMES.md) |
| 為什麼在這 | 洪水協定啟動，帳房要執行。契約一旦成立就不能中止，**包括她自己**。她不信任別人，也不信任自己的心軟，所以**今晚她親自走進帳房，把自己放在核心**：她是鎖，也是鑰匙 |
| 外觀 | 巨大的形體由被磨掉的記憶組成（房間、手、臉、傘），**高過整個畫面**，背後是一圈**十二片翼**，每一片是翻開的帳頁，頭頂旋轉的條款光環，塔外的雨往上落。**她本人就在胸口的核心：一個小小的、平靜的、穿著睡衣的老太太，手裡拿著那本筆記本，一頁一頁翻** |
| 大小 | 第一階段看到上半身，之後鏡頭一路拉遠，最後看見整座塔都是她的身體 |
| 部位 | **雙手**（抓取與拍擊）、**翼**（發射帳頁彈幕）、**筆記本**（她手裡那本，平時被光環遮住，每個條款之間露出） |
| **不可戰勝** | 她**打不倒**。畫面上沒有血條，只有**契約進度**：「條款 1／8」。形體被打碎，會用帳房裡的記憶**復原**：場上會看到一張張陌生人的臉被燒掉，用來補回她的身體。旁白是她的聲音：**「再來一次，沒關係。」** 這是整個故事裡，她最像反派的一刻。**打斷她手裡的筆記本，可以取消她當下條款的攻擊**，這是玩家的主動權 |
| 她說話 | 全程用平靜的口氣唸筆記本。每一條條款，是她每天為汐做的一件事。她沒有被打動，也沒有惡意，只是照做 |
| 勝負 | 撐過第八條條款，或生命歸零（會提早觸發同一段演出），進入「輸」的演出與最後的選擇 |

### 八條條款：她的筆記本

**每個階段只加一件新東西**，玩家一次只需要學一件事。每個階段開始與結束都有一段大場面。條款就是 [WORLD.md](WORLD.md) 裡她筆記本上的句子。

| 條款 | 筆記本 | 階段 | 新東西 | 內容 | 大場面 |
|---|---|---|---|---|---|
| 1 | 她喜歡茉莉。 | **歸檔** | 彈幕 | 花瓣般的記憶核心像雨一樣落下，表面顯示 M1～M8 的文字。警示燈標出落下的欄位 | 開場：塔頂被撕開，她從光裡升起，鏡頭拉遠，畫面震動 |
| 2 | 不要問她昨天的事。 | 歸檔 | 更密的彈幕 | 同樣的圖樣，加入「空白」：突然安靜的缺口，缺口就是安全路徑 | |
| 3 | 早上先開窗。 | **重播** | 幽影 | 翼上的窗一扇扇打開，**這趟旅程中最常殺死你的敵人**以幽影走出來，依原本的招式，動作較慢，約 12 秒後消失 | 背景的雨變成一行行玩家的死亡紀錄 |
| 4 | 她睡著的時候，不要叫醒她。 | 重播 | 更多幽影 | 幽影不再主動追，**不吵醒它們，它們就不動**，要打就要先走到它們旁邊 | |
| 5 | 她叫錯我的名字，不要糾正她。 | **條款** | 條款區 | 她念出條款：「受錨者同意：已簽署」，場地的一側亮起「已簽署」的光，另一側「未簽署」。每八秒切換，切換前有 2 秒閃爍與「條款變更」 | 場地變成一張巨大的契約，地板浮出一行行字 |
| 6 | 她問你是誰，說：我是來陪你的。 | 條款 | 切換變快 | 同樣的規則，節奏更快 | |
| 7 | 每天都去。不要停。 | **履行** | 長走廊 | 場地變成長走廊，牆不斷逼近，她在盡頭 | 塔層在身後一層層崩塌，翼全部張開 |
| 8 | 再來一次，沒關係。 | **再來一次** | 她復原自己 | 你終於打穿她，她碎成記憶，然後**重新聚起來**，天空裂開，最後一條條款落下，無法閃躲 | 最終大場面，之後直接進入「輸」的演出 |

### 特效清單（提案）

| 特效 | 用在哪 |
|---|---|
| 螢幕震動、鏡頭拉遠 | 每個階段的開場 |
| 金色文字的雷電 | 條款落下 |
| 玻璃碎裂雨 | 記憶核心碎裂 |
| 旋轉的條款光環 | 全程，頭頂 |
| 翼的帳頁掀動與散落 | 彈幕發射 |
| 雨往上落 | 全程，背景 |
| 塔層崩塌 | 履行階段 |
| 天空裂開 | 第八條條款 |
| 陌生人的臉被燒掉 | 她復原自己的時候 |

**效能與穩定**：特效要走物件池與合併繪製，同屏上限要有，避免每影格配置；低畫質設定下以較少的粒子與較簡單的光環替代，不影響機制的可讀性（遵守 CLAUDE.md）。

### 輸的演出

凜倒在地上。沈望合上筆記本，說：「**對不起。這是契約。**」然後畫面出現兩個鍵：**「再來一次」**，那是她的標語；**「算了」**。

### 二周目

借帳之後，凜能在第七章櫃台代簽。第九章，**條款可以被改寫一次**，沈望才打得到。當「雙方同意：已簽署」出現，沈望停下，看著凜手上的簽名，說：「**你和我一樣了。**」
