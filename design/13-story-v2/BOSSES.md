# 頭目設計

> 來源：2026-10-03 使用者要求第七、八章也要有頭目，可以是夢魘，不一定是實體；**每一章的頭目都要有自己的特色與特殊的攻擊方式**。
> 同日修訂：不要每個頭目都有空間機制，硬堆疊不見得是好事；多一些**大型、只能打特定部位、依血量分階段**的頭目，部分可以有**彈幕**；要好玩、有趣、多樣，但**不要難理解**；任何會改變手感的機制都要有清楚的回饋。
> 章節見 [PLOT.md](PLOT.md)，解謎動詞見 [PUZZLE.md](PUZZLE.md)，人物見 [WORLD.md](WORLD.md)。這份只定形式、部位、階段、招式與回饋，數值開票時再定。

## 原則

| # | 原則 | 說明 |
|---|---|---|
| 1 | **多樣來自「類型」，不是來自「機制」** | 九個頭目分成幾種類型：大型多部位、近身對決、機動、彈幕、非致命。**只有兩個頭目有空間規則**（第七章、第九章），其餘靠類型與招式區分 |
| 2 | **一個頭目最多一條新規則** | 一場戰鬥玩家只需要學一件新事 |
| 3 | **規則要能用一句話講完** | 講不完的就刪 |
| 4 | **任何改變手感的機制都要有回饋** | 看得到（圈、顏色、軌跡）、聽得到（音高、音效）、有一句提示，讓玩家知道現在發生什麼、怎麼應對 |
| 5 | 不要讓玩家的操作被懲罰 | 不做「你的攻擊延遲三秒」這種會讓人覺得壞掉的規則 |
| 6 | 招式要有預兆 | 沿用現有頭目的做法：蓄力、地面標記、光、聲音 |
| 7 | 頭目也在講故事 | 它怎麼打、什麼時候停，都是劇情的一部分 |
| 8 | 沒有壞人 | 頭目大多是被這個世界逼到這裡的人，打倒他們要有重量 |

## 共用元件（提案）

要新增七個頭目，先把共用的東西抽出來，不然會再複製七份。現有兩個頭目可以重用：

| 現有 | 內容 | 重用在 |
|---|---|---|
| 監管者 `warden_boss.gd` | 點射、跳躍、扇形散射、召喚、兩階段、受傷窗口 | 第一章看門狗、第六章守衛長 |
| 回收員 `reclaimer_boss.gd` | 衝刺斬、瞬移射擊、電軌、兩階段 | 第四章清理隊隊長 |

| 元件 | 說明 |
|---|---|
| `BossBase` | 階段切換、預兆、受傷窗口、場地矩形、死亡演出。兩個既有頭目各自重複了一份常數，新頭目只寫招式，數值走資料 |
| **部位系統** | 每個部位有自己的判定、血量與狀態：**灰色＝不能打、橙色發光＝現在可以打**。破壞部位會觸發事件（停掉一種招式、掉出下一階段）。頭目總血量是各部位之和，階段依血量或破壞的部位數切換 |
| **彈幕圖樣（資料）** | 圖樣用資料描述：扇形、環形、柵欄（有缺口）、螺旋、慢速追蹤、直線雷射。物件池、同屏上限（提案 200 發） |
| **減速圈** | 一個區域元件，進入圈內的投射物與斬擊特效、判定時間尺度變慢。**只改變實體的時間尺度，不改全域時間** |

### 彈幕的可讀性規範

| 規範 | 內容 |
|---|---|
| 一定有路 | 任何彈幕都要有一條看得到的安全路徑（缺口、空檔、安全位置） |
| 預兆 | 發射前至少 0.5 秒的預兆（光、聲音、地上的標記） |
| 顏色 | 會傷害玩家的子彈用一致的顏色；背景與場景色不得與它撞色 |
| 速度 | 玩家能看得清楚的範圍內，密度高時速度要慢，速度快時密度要低 |
| 一次一種 | 同一時間只有一種圖樣是主角，其他是點綴 |
| 難度參數 | 沿用既有的難度設定（`difficulty_data.gd`），彈幕密度與速度各有係數 |

## 第一章　看門狗（碼頭倉庫保全機甲）

| 項目 | 內容 |
|---|---|
| 類型 | **大型機甲**，教學頭目 |
| 場地 | 碼頭倉庫的裝卸區，左右兩側有掩體 |
| 部位 | **槍臂**（持續射擊，破壞後停掉點射）、**背部電源**（平時有裝甲保護，跳壓之後的硬直才露出，橙色發光，傷害加倍） |
| 階段 | **100～60%**：槍臂運作。**60～30%**：槍臂被破壞，改用肩部飛彈。**30%**：裝甲脫落，電線外露，動作變快 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 點射 | 抬起槍臂，紅色瞄準線 0.6 秒 | 蹲或跳 |
| 跳壓 | 收縮，地面出現陰影 | 離開陰影；落地後的硬直露出背部電源 |
| 飛彈齊射（輕彈幕） | 肩部艙門打開，地上出現落點圈 | 離開圈；彈幕有明顯的縫 |
| 呼叫無人機 | 艙門打開 | 最多兩台，優先打掉 |

**劇情時刻**：階段三中它把她夾住，一個笑話。畫面：「再來一次，沒關係。」她醒來，頭目的血條還是原來的樣子（沒有回復）。這是玩家第一次知道「世界不會因為你死而重置」，**靠的是血條，不是規則**。

## 第二章　阿勇（收帳人頭目）

| 項目 | 內容 |
|---|---|
| 類型 | **近身對決**，有人味的頭目 |
| 場地 | 市集倉庫二樓，後方高處是小薇的終端 |
| 階段 | **第一條命**：標準的近身對決。**死亡後**：小薇的終端亮起，他站起來，進入**第二條命**：殼有瑕疵，動作變慢、硬直變長，但每一擊更重 |
| 特別 | 玩家可以**在他倒下前後三秒內打斷小薇的連結**（射擊終端，終端會發光提示），他就不會復原，永久死亡 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 鐵棍重擊 | 蓄力 0.8 秒後前衝 | 衝刺或跳過，撲空會硬直 |
| 債務簿（輕彈幕） | 甩出紙頁，扇形，緩慢落下 | 往兩側紙頁的縫鑽 |
| 叫人 | 吹哨 | 兩個收帳小弟 |
| 滯納金（第二條命） | 同一招式延遲一拍再追加一次 | 看清第二次 |

**劇情時刻**：小薇的剪影一次比一次淡。打斷連結讓阿勇永久死亡；不打斷，消耗的是他女兒。沒有第三條路。

## 第三章　守門人（錨庫分站，用盡者）

| 項目 | 內容 |
|---|---|
| 類型 | **重裝防禦** |
| 場地 | 診所大廳，玻璃牆外是日照區的陽光（凜第一次看見） |
| 部位 | **護盾**（正面擋子彈，被盾擊撲空三次之後裂開）、**背部通訊器**（破壞後不再有增援） |
| 階段 | **100～50%**：護盾完整。**50%**：護盾裂開，動作變慢但範圍變大，他開始說「謝謝您的光臨」 |
| 特別 | **打斷**：攻擊他的蓄力會讓他中斷並道歉（「對不起，我剛剛……」），這是玩家可以主動利用的，不是隱藏規則 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 盾擊 | 台詞「對不起」，蓄力長 | 繞到背後，或打斷 |
| 通行證掃描 | 橫向光束掃過，台詞「請出示」 | 蹲或跳 |
| 呼叫警衛 | 按下牆上的通訊箱 | 打壞背部通訊器就不會再有 |
| 通知單（輕彈幕） | 台詞「您的預約已過期」，格狀的紙片 | 往格子的縫鑽 |

**劇情時刻**：打倒他時，他說：「歡迎再來。」凜愣住。他是「再來一次」的另一種聲音。

## 第四章　清理隊隊長（廢棄廠房）

| 項目 | 內容 |
|---|---|
| 類型 | **機動＋彈幕**，沿用回收員的位移 |
| 場地 | 廢棄廠房，平台與掩體 |
| 階段 | **100～50%**：鷺同行（以腳本的方式掩護），**她在一半血量時倒下**，那一刻戰鬥暫停，畫面是終端：「復原：無法執行」。**50%～**：他變快，彈幕變密 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 衝刺切（沿用回收員） | 蹲低，刀光亮起，地上畫出路線 | 衝刺穿過或跳過；撲空硬直 |
| 瞬移射擊（沿用回收員） | 身體閃爍消失，新位置出現圈 | 離開圈，躲開瞄準線 |
| **標記轟炸（彈幕）** | 被標記處紅圈，依序亮起，2 秒後空襲 | 紅圈有順序，往沒標記的地方走 |
| 清掃線 | 地上白線，橫向雷射掃過，**擦掉線上的掩體** | 在掩體被擦掉之前跳出去。**這只是場景的破壞，沒有規則** |

**劇情時刻**：鷺倒下時沒有「歡迎回來」。玩家第一次看到無法復原，之後才是二階段。

## 第五章　老鬼（收屍人隊長）　待確認

這是「第五章被猜到」的方案之一，見對話。

| 項目 | 內容 |
|---|---|
| 類型 | **非致命追逐** |
| 是誰 | 老 K 雇的退休傭兵，收屍人的隊長，凜在第二章起一直看到的灰衣人 |
| 為什麼在這 | 他守著地下室的入口。老 K 要他別讓她進去 |
| 場地 | 當舖後巷，雨，通往地下室的樓梯口 |
| 血條 | 是他的**體力**，不是血 |
| 階段 | **100～50%**：灰外套，招式慢。**50%**：他脫下灰外套，露出舊傭兵的裝備，速度變快，為了不傷她，招式變成**圍堵** |
| 特別 | **他的招式不造成傷害**，而是把你扛走、拉回、遮住視野。被他扛走會回到巷口，沒有懲罰，只是時間 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 擒抱 | 低身衝來，雙臂張開 | 衝刺躲開；被抓住連按掙脫 |
| 繩索 | 拋出繩圈 | 跳過；套住腳踝會被拉回原位 |
| 灰霧 | 煙霧彈 | 視野遮蔽 3 秒，靠聲音判斷 |
| 呼哨 | 手指入口 | 灰衣人從屋頂落下，**擋路但不攻擊** |

**劇情時刻**：玩家會覺得奇怪：為什麼他不殺我？打完，他把灰外套鋪在樓梯上，走開。**這是揭露前的最後一個線索。**

## 第六章　守衛長（廣播站）

| 項目 | 內容 |
|---|---|
| 類型 | **重火力＋落雷** |
| 場地 | 廣播站屋頂，暴雨與天線。母親坐在角落的錨椅上，罩著玻璃 |
| 階段 | **第一條命**：重火力。他死後復原一次。**第二條命**：母親的記憶條下降，他的動作變得遲疑。**第二次死亡時，他看著母親，自己按掉復原，戰鬥結束。** 這一次不由玩家決定。玩家若在此之前打斷連結，同樣結束，但母親不會被讀取 |
| 特別 | **母親的記憶條**顯示在畫面角落，他每復原一次，她就忘記他多一點，台詞逐次退化（「兒子」→「你是……」→ 沉默）。這是劇情，不是機制 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| **天線召雷（彈幕）** | 藍光圈依序亮起，1.2 秒後落雷 | 離開圈。**進階**：用義體磁吸把落雷引到他身上，造成額外傷害（不必學也能通關） |
| 重型榴彈 | 拋物線，地上出現落點圈 | 離開圈 |
| 靜電場 | 身體周圍閃兩下，球形電場 | 離開近身範圍 |
| 呼叫增援 | 無線電 | 雨衣保全 |

**劇情時刻**：他看著母親，按掉復原。**第一次有一個人自己選擇不被復原**，是第九章的預告。

## 第七章　明天（夢魘）

| 項目 | 內容 |
|---|---|
| 類型 | **巨型夢魘**，由日曆頁組成的巨大人形，臉是空白的 |
| 是誰 | 每個人說過的「明天再說」：老 K、燈、沈遠，也是凜自己 |
| 場地 | 凜在日照區的長椅上睡著，夢見一片無限延伸的日照花園，日曆頁在風中飄 |
| 部位 | **雙手**（發動攻擊，可被打斷）、**胸口的時鐘**（核心，平時被日曆頁遮住） |
| **特色** | **減速圈**：它的身體周圍有一圈圈的日曆頁軌道，**圈內，所有投射物與斬擊都會變慢**。你射出的子彈進了圈會慢下來；你的斬擊特效與判定也會變慢；它的彈幕進了圈同樣會慢。**你自己的移動不受影響** |
| 階段 | **100～66%**：圈固定，教你「圈內變慢」。**66～33%**：圈會**收縮與擴張**，收縮的那一瞬間，胸口時鐘露出（橙色發光），這是主要的輸出時機。**33%～**：它說：「**今天。**」圈消失，所有東西回到正常速度，它進入最快的一輪攻擊，**也是最後的輸出窗口** |

### 減速圈的回饋

| 回饋 | 內容 |
|---|---|
| 視覺 | 圈是旋轉的日曆頁軌道，畫面上一目了然；進入圈的子彈拖出長長的軌跡，顏色變冷；斬擊的特效被拉長 |
| 聲音 | 進入圈內的音效降半音，像被拉長 |
| 提示 | 第一次進入圈時，旁白一句：**「圈內，一切都變慢。」** |
| 不懲罰 | 慢下來的斬擊傷害不變，只是晚一點到；玩家的移動、衝刺、跳躍都不受影響 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 改天（彈幕） | 日曆頁環繞身體，依序翻開，朝玩家散射；進了圈就變慢，出了圈變快 | 利用圈的位置判斷速度；彈幕有縫 |
| 明早 | 巨大的手從地平線往下抓，地上先出現手的影子 | 影子出現就移動，**手落下後的硬直可以打** |
| 下次 | 在你剛才站的位置留下一個殘影，2 秒後爆炸 | **別站在原地** |

**劇情時刻**：它死不了，它變成太陽。凜醒來，老 K 已經不認得她了。**她在夢裡贏了「明天」，在現實裡已經是今晚。**

## 第八章　協定（洪水協定的閘門管理機）

| 項目 | 內容 |
|---|---|
| 類型 | **巨型固定機關**，不移動，靠部位與水柱 |
| 場地 | 天穹塔基座的巨大水閘廳，水位隨戰鬥升降。下方的平台上有被困的人（剪影），選擇性地救 |
| 部位 | **左閥、右閥、中央泵**。每個部位在它的蒸氣孔打開的那幾秒露出（橙色發光）。依序破壞 |
| 階段 | **三個部位都在**：慢速，水柱規律。**破壞兩個**（剩一個）：水位上升，水柱變密。**破壞三個**：它說：「優先順序已更新。」戰鬥結束 |
| 選擇 | 下方的人可以去救，救一個要花時間，水位會繼續上升。**不救不影響結局，只影響船上的人數** |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 放水 | 被標記的區塊閃紅，3 秒後洪流沖過 | 爬高或躲進凹槽 |
| 閘門夾 | 兩側閘門閉合，警示燈與聲音 | 在閉合前穿過 |
| 優先序廣播 | 它說「正在評估」，一個圈跟著你 | 圈鎖定後 1 秒落下，離開 |
| 水柱（彈幕） | 地上一排噴口亮起，依序噴出，有縫 | 站在兩根水柱之間的縫 |

**劇情時刻**：它沒有感情，沒有抗拒，只是照做。這是第九章帳房的預演。

## 第九章　帳房（最終 Boss）

| 項目 | 內容 |
|---|---|
| 類型 | **巨型檔案機**，最終頭目，**打不倒** |
| 場地 | 天穹塔中心的檔案庫，垂直，無數記憶核心像書架一樣排開 |
| 部位 | **雙臂**（負責抓取與投擲記憶核心）、**讀取頭**（平時縮在機身裡，每個階段的招式之間會露出） |
| 勝負 | 最後一個階段結束，或生命歸零，觸發同一段「輸」的演出。二周目有借帳時可以勝，見 [PLOT.md](PLOT.md) |

**四個階段，每個階段只加一個新東西**，玩家一次只需要學一件事：

| 階段 | 新東西 | 內容 | 回饋 |
|---|---|---|---|
| 一　歸檔 | 彈幕 | 記憶核心從上方依序落下，表面顯示 M1～M8 的文字。上方出現警示燈標出落下的欄位 | 核心落下前有警示；被打中扣血，並閃出一行記憶的文字 |
| 二　重播 | 幽影 | 場邊出現幽影，是**這趟旅程中最常殺死你的敵人**，依原本的招式出現，動作較慢，約 12 秒後消失 | 幽影是白色剪影，頭上有該敵人的圖示；玩家一看就知道「這是殺過我的那一個」 |
| 三　條款 | 條款區 | 它念出條款：「受錨者同意：已簽署」，場地的一側亮起「已簽署」的光，另一側「未簽署」。每八秒切換，**切換前有 2 秒的閃爍與「條款變更」的字樣** | 光區就是規則：待在「已簽署」那一側，另一側持續扣血 |
| 四　履行 | 長走廊 | 場地變成長走廊，牆不斷逼近，讀取頭在盡頭發射彈幕 | 牆逼近的方向有紅色漸層，不能停下 |

**劇情時刻**：它說的條款，就是第七章櫃台上的那兩行。玩家一直在那一側（「未簽署」）。
