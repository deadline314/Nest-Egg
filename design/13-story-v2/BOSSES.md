# 頭目設計

> 來源：2026-10-03 使用者要求第七、八章也要有頭目，可以是夢魘之類，不一定是實體；**每一章的頭目都要有自己的特色與特殊的攻擊方式**。
> 章節見 [PLOT.md](PLOT.md)，解謎動詞見 [PUZZLE.md](PUZZLE.md)，人物見 [WORLD.md](WORLD.md)。
> 這份只定「是誰、為什麼在這、特色、招式、劇情時刻」，數值與動作資料開票時再定。

## 原則

| # | 原則 | 說明 |
|---|---|---|
| 1 | **每個頭目有一條自己的空間規則** | 九個頭目不能只是血條不同。每一個都改變「這個場地怎麼運作」 |
| 2 | **頭目是那一章主題的考試** | 它考的是那一章教的動詞 |
| 3 | 招式要有預兆 | 沿用現有頭目的做法：蓄力、地面標記、光、聲音，玩家看得到、聽得到 |
| 4 | **頭目也在講故事** | 它怎麼打、什麼時候停，都是劇情的一部分 |
| 5 | 沒有壞人 | 頭目大多是被這個世界逼到這裡的人。打倒他們要有重量 |

## 總覽

| 章 | 頭目 | 形式 | 特色（空間規則） | 考的動詞 |
|---|---|---|---|---|
| 1 | **看門狗** | 保全機甲 | **世界不重置**：凜必定死一次，頭目的傷與場地水位都保留 | 水位、錨點 |
| 2 | **阿勇** | 人 | **復原階段**＋「利息」疊加；可以打斷小薇的連結，讓他不復原 | 對帳 |
| 3 | **守門人** | 用盡者 | **遺忘迴圈**：每次受傷，他可能忘記剛才在做什麼，重複上一個招式 | 對帳 |
| 4 | **清理隊隊長** | 人（天穹） | **清理**：他的招式會擦除掩體與平台，場地被逐步清空；鷺在前半同行 | 回放、義體 |

| 7 | **明天** | 夢魘 | **延遲**：你的攻擊延遲三秒才生效 | 全部 |

### 重用與框架

現有兩個頭目可以重用：

| 現有 | 機制 | 重用在 |
|---|---|---|
| 監管者 `warden_boss.gd` | 點射、跳躍、扇形散射、召喚、兩階段、受傷窗口 | 第一章看門狗、第六章守衛長（重新套皮、改招式） |
| 回收員 `reclaimer_boss.gd` | 衝刺斬、瞬移射擊、電軌、兩階段 | 第四章清理隊隊長 |

兩個頭目各自重複寫了階段切換、預兆、可傷害窗口與場地範圍的常數。**提案**：抽出 `BossBase`（階段、預兆、窗口、場地矩形、死亡演出），新頭目只寫招式，由資料描述數值。開票時評估。

## 第一章　看門狗（碼頭倉庫保全機甲）

| 項目 | 內容 |
|---|---|
| 場地 | 淹水的裝卸區，三道閘門控制水位（第一章的水位謎在這裡成為戰鬥） |
| **特色** | 世界不會因為你死而重置。凜在這一戰**必定死一次**（演出）。復原後，頭目還帶著剛才的傷，水位也還是原來的樣子 |
| 二階段 | 裝甲裂開，電線外露。水位高時全場通電（站平台）；水位低時電路暴露，傷害加倍。玩家用閘門控制 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 點射 | 抬起槍臂，紅色瞄準線 0.6 秒 | 蹲或跳 |
| 跳壓 | 收縮，地面出現陰影 | 離開陰影；落地的水波要跳過 |
| 探照標記 | 頭頂燈亮並掃描，被照到後 1.5 秒飛彈齊射 | 離開光柱或躲到掩體後 |
| 呼叫無人機 | 肩部艙門打開 | 最多兩台，優先打掉 |

**劇情時刻**：二階段中它把她夾住，一個笑話。畫面：「再來一次，沒關係。」她醒來，頭目還在流油。這是玩家第一次知道「世界不會重置」。

## 第二章　阿勇（收帳人頭目）

| 項目 | 內容 |
|---|---|
| 場地 | 市集倉庫二樓；高處的平台上有小薇的終端 |
| **特色** | **復原階段**：他死了會被復原，站起來時殼有瑕疵（慢、拖步）。**玩家可以在他倒下前後三秒內打斷小薇的連結**（射擊終端），他就不會復原，永久死亡 |
| 二階段（復原後） | 動作變慢，但多一招「滯納金」：舊招式延遲一拍再追加一次 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 債務簿 | 甩出紙頁扇形，落地標記格子「欠」，2 秒後爆 | 離開標記的格子 |
| 鐵棍重擊 | 蓄力 0.8 秒後前衝 | 衝刺或跳過，撲空會硬直 |
| **利息** | 命中你後，你身上疊「利息」，每層讓下一擊多傷 10% | 走到亮著的「結帳」地墊清除 |
| 叫人 | 吹哨 | 兩個收帳小弟 |

**劇情時刻**：小薇的剪影一次比一次淡。打斷連結會讓阿勇永久死亡，不打斷會消耗他女兒的記憶。沒有第三條路。

## 第三章　守門人（錨庫分站，用盡者）

| 項目 | 內容 |
|---|---|
| 場地 | 診所大廳。玻璃牆外是日照區的陽光（凜第一次看見） |
| **特色** | **遺忘迴圈**：他是用盡者。每次受傷，他有三成機率忘記剛才在做什麼，**重複上一個招式**。玩家可以打斷他的慢招，讓他卡在一個容易閃的招式裡；也可以不利用 |
| 二階段 | 他開始說「謝謝您的光臨」，動作變慢，範圍變大 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 盾擊 | 台詞「對不起」，蓄力長 | 繞到背後或跳過 |
| 通行證掃描 | 橫向光束掃過，台詞「請出示」 | 蹲或跳 |
| 呼叫警衛 | 按下牆上的通訊箱 | **打壞通訊箱就不會再有增援** |
| 您的預約已過期 | 閘門落下，封鎖地面分區 | 逼玩家移動，跳過閘門 |

**劇情時刻**：打倒他時，他說：「歡迎再來。」凜愣住。他是「再來一次」的另一種聲音。

## 第四章　清理隊隊長（廢棄廠房）

| 項目 | 內容 |
|---|---|
| 場地 | 廢棄廠房，平台與掩體 |
| **特色** | **清理**：他的招式會**擦除**掩體與平台，場地被一塊塊清空，玩家的選擇越來越少。前半有鷺同行（以腳本的方式掩護），**她在一半血量時倒下** |
| 二階段（鷺倒下後） | 沿用回收員的衝刺與瞬移，並開始擦除平台 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 清掃線 | 地上出現白線，橫向雷射掃過，**擦除線上的掩體** | 在掩體被擦掉之前跳出去 |
| 標記轟炸 | 被標記處紅圈，2 秒後空襲 | 離開圈 |
| 衝刺切（沿用回收員） | 蹲低，刀光亮起 | 衝刺穿過或跳過；撲空硬直 |
| 蒸發噴霧 | 噴口冒白煙，區域持續傷害 | 站到高處 |

**劇情時刻**：鷺倒下時，終端說「復原：無法執行」，沒有「歡迎回來」。玩家第一次看到無法復原的畫面，之後才是頭目的二階段。

## 第五章　老鬼（收屍人隊長）　待確認

這是「第五章被猜到」的一部分提案，見對話。

| 項目 | 內容 |
|---|---|
| 是誰 | 老 K 雇的退休傭兵，收屍人的隊長，凜在第二章起一直看到的灰衣人 |
| 為什麼在這 | 他守著地下室的入口。老 K 要他別讓她進去 |
| 場地 | 當舖後巷，雨，通往地下室的樓梯口 |
| **特色** | **他不傷你，他要把你搬走。** 他的招式不造成傷害，而是把你扛起來、拉回、遮住視野。玩家的目標是**撐到他體力耗盡**，不是把他打倒 |
| 二階段 | 他脫下灰外套，露出舊傭兵的裝備，速度變快。為了不傷她，他的招式變成**圍堵**：四面八方的繩索 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 擒抱 | 低身衝來，雙臂張開 | 衝刺躲開；被抓住會被扛著往巷口走，連按掙脫 |
| 繩索 | 拋出繩圈 | 跳過；套住腳踝會被拉回原位 |
| 灰霧 | 煙霧彈 | 視野遮蔽 3 秒，靠聲音判斷 |
| 呼哨 | 手指入口 | 灰衣人從屋頂落下，**擋路但不攻擊** |

**劇情時刻**：玩家會覺得奇怪：為什麼他不殺我？打完，他把灰外套鋪在樓梯上，走開。**這是揭露前的最後一個線索。**

## 第六章　守衛長（廣播站）

| 項目 | 內容 |
|---|---|
| 場地 | 廣播站屋頂，暴雨與天線。母親坐在角落的錨椅上，罩著玻璃 |
| **特色** | **落雷與磁吸。** 玩家可以用義體把落雷引到頭目身上。**母親的記憶條**顯示在畫面角落：他每復原一次，她就忘記他多一點，台詞逐次退化（「兒子」→「你是……」→ 沉默） |
| 復原 | 第一次死亡後他復原。**第二次死亡時，他看著母親，自己按掉復原，戰鬥結束。** 這一次不由玩家決定。玩家若在此之前打斷連結，同樣結束，但母親不會被讀取 |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 天線召雷 | 藍光圈 1.2 秒，落雷 | 離開圈；用義體磁吸把雷引到他身上 |
| 重型榴彈 | 拋物線，落點積水 | 躲開，積水會擴散電流，跳到乾的地方 |
| 靜電場 | 身體周圍球形電場，閃兩下 | 離開近身範圍 |
| 呼叫增援 | 無線電 | 雨衣保全 |

**劇情時刻**：他看著母親，按掉復原。這是**第一次有一個人自己選擇不被復原**，是第九章的預告。

## 第七章　明天（夢魘）

| 項目 | 內容 |
|---|---|
| 是誰 | 沒有身體。一個高大的、由日曆頁組成的人形，臉是空白的 |
| 為什麼在這 | 凜在日照區的長椅上睡著，夢見它。它是每個人說過的「明天再說」：老 K、燈、沈遠，也是凜自己 |
| 場地 | 一片無限延伸的日照花園，日曆頁在風中飄 |
| **特色** | **延遲。** 你的攻擊延遲三秒才生效：傷害數字飄在半空，三秒後才落下。它的招式預兆是即時的，傷害也延遲。玩家必須預判，不能只靠反應：**「現在做明天的事」** |
| 二階段 | 它開始說「今天」，延遲縮短成一秒，最後成零。**直到它說「今天」，才真正打得到** |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 改天 | 召喚日曆頁盤旋，指向某一格，三秒後那格被撞 | 在落下前離開那格 |
| 明早 | 巨大的手從地平線往下抓，地上先出現影子 | 影子出現時就移動 |
| 下次 | 複製你剛才的位置，三秒後在那裡爆炸 | **別站在原地** |
| 再說 | 把一個攻擊暫存，在兩招之後才釋放 | 記住它存了什麼 |

**劇情時刻**：它死不了。它變成太陽。凜醒來，老 K 已經不認得她了。**她在夢裡贏了「明天」，在現實裡已經是今晚。**

## 第八章　協定（洪水協定的閘門管理機）

| 項目 | 內容 |
|---|---|
| 是誰 | 天穹塔基座的閘門機。洪水協定的執行者，它依優先順序決定哪裡先淹 |
| 為什麼在這 | 凜要穿過它的大廳，才能下到港區。沈遠說過：契約一旦成立就必須履行，洪水協定也是 |
| 場地 | 巨大的水閘廳，水位會升降。下方的平台上有被困的人（剪影） |
| **特色** | **放棄區。** 它依優先順序把區域標成「放棄」並放水。玩家可以**覆寫三個優先順序面板**，把下層改成「優先」，水勢才會減弱。面板上的優先表有錯，要找出來（對帳） |
| 選擇 | 下方的人可以去救。救人要花時間，水位會繼續上升。**不救不影響結局，只影響船上的人數** |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 放水 | 被標記的區塊閃紅，3 秒後洪流沖過 | 爬高或躲進凹槽 |
| 閘門夾 | 兩側閘門閉合 | 在閉合前穿過 |
| 優先序廣播 | 它說「正在評估」，指定你為「優先」或「放棄」 | 被標為「放棄」，你所在的地面會持續下沉，要換位置 |
| 排水泵 | 中心出現漩渦 | 離心的拉力，往外跑 |

**劇情時刻**：覆寫之後，它說：「優先順序已更新。」沒有感情，沒有抗拒，只是照做。這是第九章帳房的預演。

## 第九章　帳房（最終 Boss）

| 項目 | 內容 |
|---|---|
| 場地 | 天穹塔中心的檔案庫，垂直，無數記憶核心像書架一樣排開 |
| **特色** | **死亡重播**與**契約條款**。打不倒 |
| 勝負 | 生命歸零，或三分鐘後，觸發同一段「輸」的演出。二周目有借帳時可以勝，見 [PLOT.md](PLOT.md) |

| 招式 | 預兆 | 應對 |
|---|---|---|
| 歸檔 | 記憶核心從上方落下，表面顯示 M1～M8 的文字 | 躲開。被擊中會「遺忘」：技能關閉三秒 |
| **重播** | 場邊出現幽影，是**這趟旅程中最常殺死你的敵人**，依原本的招式出現 | 玩家自己的死亡史成為考題；每種敵人幽影會依序出現 |
| **條款** | 它念出條款：「受錨者同意：已簽署」，場地的一側亮起「已簽署」的光區，另一側「未簽署」。每八秒切換 | 待在「已簽署」的一側。這是同意的視覺化 |
| 履行 | 場地變成長走廊，牆不斷逼近 | 不能停下 |

**劇情時刻**：它說的條款，就是第七章櫃台上的那兩行。玩家一直在那一側（「未簽署」）。
