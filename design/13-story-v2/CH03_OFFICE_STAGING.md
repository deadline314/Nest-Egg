# 第三章 辦公接待廊的正式過場（C18～C20）分鏡

> 票：ST-21（第三章）。作者來源：`tools/story/ch3_source.py` 的 `_office`；舞台：`ch3_source.office_stage()` → `data/cutscene/stages/ch3_office_hall.json`（由 `build_ch3_story.py` 產生，不手改）。

## 這場戲在做什麼

凜拿了異議回執，在天穹辦公廊撞見老 K 和葉談條件，聽到「備份是老 K 交的」。這是第三章的轉折：玩家跟凜一起**偷聽**，
所以畫面要讓人一眼看懂「誰在門外、誰在裡面、聲音從哪裡漏出來」，情緒要落在聽的人身上。

## 參考了什麼、取了什麼

| 參考 | 它做得好的地方 | 我們怎麼用（或做得更好） |
|---|---|---|
| 電影的偷聽戲（定場鏡頭 → 室內 → 反應鏡頭） | 先交代地理位置，觀眾才知道誰聽得到誰；情緒在反應鏡頭 | C18 開頭用全景：凜在門外、兩人在玻璃會議室、門縫透光。之後每兩三句就切回凜 |
| Dishonored 的鑰匙孔／門縫窺看 | 「被限制的視野」讓玩家覺得自己在不該在的地方 | 室內鏡頭的窗框、底框與玻璃反光畫在演員**前面**，看起來是隔著玻璃；門縫有一道冷光拉到走廊地上 |
| Disco Elysium 的插話 | 對話中間穿插主角的內心反應，讓旁觀變成參與 | 凜的反應多半是**沉默的停頓**（0.7～1.1 秒）；只有在玩家做過支線（看清葉手背的字）時，凜會多一句把兩件事連起來 |
| Oxenfree／Katana Zero 的中途打斷 | 對話進行中也能選，選擇表達角色的情緒 | 談話中段給三個選擇：忍住聽完、伸手推門（燈叫住她，不懲罰）、先退開；退開後回等候臺**從中段接著聽，不重播前半** |
| Kentucky Route Zero 的固定劇場鏡頭 | 鏡頭少動，每次移動都有理由 | 只在兩個時刻推鏡：葉在手背寫字、葉提到「月報異議」（凜就是送異議的人）；其他全是固定鏡頭與硬切 |
| Hitman 等的偷聽字幕 | 偷聽的台詞一定有字幕與講者 | 聽到的台詞用低語樣式（灰字、慢速），講者名字照常顯示；三種語言都有 |
| Firewatch／Night in the Woods 的留白 | 關鍵句之後的沉默比台詞更有力 | 「她不知道那份資料是我交的」之後硬切到凜、停 1.1 秒，再進中段的選擇 |

做得更好的地方：
- **偷聽可以中斷又不浪費玩家的時間**：前半聽過就記下（`ch3_trade_half_heard`），退開後回來直接接中段。
- **支線的回報在主線裡出現**：看過葉手背的字（SQ7-G2），後半會多凜的一句，沒看過的人不會看到斷掉的句子。
- **不走一段看一段**：取回執後直接接到手背的字與等候臺的選擇，不必再走到等候臺觸發。

## 舞台與鏡頭（量自 `tianqiong_corridor.webp`）

- 立繪 1536×864 縮 0.5 鋪滿（舞台 -64..704 × -36..396），壓暗一階（同 NE-251 的處理），會議室保留午後暖光，走廊這側壓暗。
- 走廊地面從 y≈296 起，凜站在 300、縮放 2.95（約 172，約為門高 227 的四分之三）。
- 玻璃底框 285～294，室內兩人站在 285、縮放 2.4（在玻璃後一兩公尺）。
- 玻璃直框在 187、307.5、419.5，玻璃在 514 結束；側門 521～651，門縫在左緣。

| 鏡頭 | 中心 | 縮放 | 用途 |
|---|---|---|---|
| wide | (330, 243.5) | 0.88 | 定場：三個人與門縫都在畫面裡 |
| rin | (399, 254) | 1.05 | 凜的反應：凜在右三分之一，玻璃裡的兩人在左邊 |
| inside | (285, 250) | 1.2 | 隔著玻璃的兩人鏡頭，凜在畫面外 |
| ye | (300, 250) | 1.2 | 往葉推近（手背的字、月報異議） |

構圖檢查（`CutsceneChecker.staging_problems`）照常適用：畫面內演員的腳在對話框之上、頭在 21:9 黑邊之下。
為了正反打，檢查改成和播放器一致：**畫面外的演員不檢查**（頭頂原本就這樣）、**同一段裡換舞台時重新追蹤演員**（播放器會清掉演員）。

## 流程

```
取件格 → C18 全景（老 K 走進會議室）→ C19 手背的字 → 等候臺選擇
  ├ 看清手背那一行（可選，SQ7-G2）→ 回到選擇
  ├ 留下聽 → C20 前半 → 中段選擇
  │            ├ 忍住聽完 ─────────────┐
  │            ├ 伸手推門 → 燈叫住凜 ──┤→ C20 後半 → 反應與記錄 → C21 回家路線
  │            └ 先退開（之後回等候臺從中段接著聽）
  └ 先退回樣品房（之後回等候臺再選）
```

截圖：`tools/ch3_office_capture.tscn`（Forward+）。
