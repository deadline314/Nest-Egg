| 項目 | 本組（故事主線）做 | 交給 |

## 4. 劇本的機制怎麼用現有系統做

| 劇本 | 做法 |
|---|---|
| S02 修收音機 | 工作檯是一個物件；三個接點各一個選擇（電源、天線、音源），錯接只播一句雜訊說明再選一次；轉旋鈕兩段選擇；最後「儲存／關掉」。結果旗標分開寫（修好、聽到、儲存） |
| S06 付款或先問 | 選擇有真正的交易（代墊 40）與現金不足的改接場景，沿用第一章宵夜的交易流程 |
| S08 三份證據 | 每份證據是一個可讀的物件與劇情物品；取得即寫旗標與物品，順序任意 |
| S10 對帳 | 乾燥作業桌的三步選擇：先選本金欄、再選已付利息、最後選批號；選錯有劇本寫好的一句提示，可重選，不扣東西 |
| S12 斷連選擇 | 戰鬥中停下來的選擇說明（安全暫停）由頭目戰在血量門檻呼叫；隔離箱的操作是關卡機關。頭目本身由戰鬥 Session 製作 |
| S14 鷺的第 214 次 | B3 電話亭的短演出；次數存成章節旗標，同一事件只加一次 |
| S17～S21 客人簿 | 阿梨的視角：不讓玩家操作凜的身體走進阿梨的房間（那會變成凜在扮阿梨），改成從館外的客人簿入口開始的一串演出；客人名單可任意順序，每位客人的「問、聽、記、回答」是依序的選擇，錯的回答由客人說一句完整的話再選一次，可以隨時回到凜那邊 |
| S22 章末 | 屋頂演出、章末卡、存檔；港區交通線若還沒有實作，用劇本的「步行路線已接通」版本 |

## 5. 新旗標

依劇本第 6 節的狀態表命名；預設值由產生器從場景結果自動登記（第一章同一套）。存檔格式不變。

旗標檢查（ContinuityAudit）不允許拼字只差一兩個字的旗標，所以章末用 `ch2_heron_closed`（不和 `ch1_complete` 撞），三位客人用各自的物件命名：`guest_ticket_answered`（鄭先生）、`guest_band_answered`（陳女士）、`guest_letter_answered`（洪先生）。上屋頂的出入口要的旗標由早上結算的場景直接寫（`ch2_morning_settled`），不用推導旗標，地圖可達性檢查才看得到誰寫它。

## 6. 交付順序

1. 本文件、相依票（頭目、遭遇、新 NPC 外觀）。
2. 區域產生器與 11 個區域（可走完、出入口相通、電話亭站得穩、暗場可讀）。
3. 作者來源 S00～S22、回訪、任務與三語欄位；章節銜接。
4. 流程探針：從第一章結尾推到第二章章末，兩條阿勇路線與主要可選支線。
5. 舊第二章從正式流程移除。

頭目戰與遭遇交回前，阿勇戰以「戰鬥 Session 交付的頭目」為前置；本組的流程探針以真實的頭目事件入口（制伏旗標）銜接，並在票上寫明。


## 7. 實作紀錄（2026-10-11）

- 區域：`tools/level/build_ch2.py` 產生 10 區（客人簿改成演出，不另做 H11 區域），沿用第一章的工具；當舖與屋頂和第一章共用牆面與擺設（`pawnshop_shell`、`rooftop_shell`），沿用第一章審過的擺設位置。
- 劇本：`tools/story/ch2_source.py`（作者來源）→ `tools/story/chapter_compiler.py`（共用轉譯）→ `data/story/ch2_heron.json`；`python3 tools/story/build_ch2_story.py` 同時寫出劇情文件與交易資源。
- 劇情系統的兩個補充：接續（then）可以接到分派，依當下進度挑段落；選錯再選一次經由只有一條路線的分派回到剛才的選擇。
- 章節銜接：第一章天亮的當舖播完章末卡後接 `ch2_pawnshop`；屋頂的章末對話寫入 `ch2_heron_closed` 時播第二章章末卡並結算（`LevelData.complete_on_flag`）。
- 阿勇戰的接點（NE-265）：血量到門檻時播 `ch2_t_s12_choice`（寫 `yong_link_choice`）；保留路的復原與暫停閂各是 `ch2_t_s12_keep_revival`、`ch2_t_s12_keep_pause`；斷連成功由隔離箱寫 `yong_link_isolated`、`yong_link_revoked`；制伏完成時啟動機關頻道 `ch2_yong_down`，帳房關卡的 `channel_done_flags` 會寫 `ch2_yong_subdued`（頭目戰不用自己寫旗標），之後帳櫃播 S13（含 120 報酬，只發一次）。戰鬥提示 `ch2_s12_bark_mark`、`ch2_s12_bark_egret`，敗北提示 `ch2_s12_defeat_hint`。
- 驗證：`tools/ch2_flow_probe.tscn`（`--route=cut|keep --supper=stay|leave --pay`）從第一章結束推到第二章章末；`Chapter2StorySuite` 檢查出入口、入口、任務標記、劇情關卡與章節銜接。
