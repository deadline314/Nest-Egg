## 核心設定（一段話）

在沉港市，人死了可以「再來一次」：復原時系統讀取一個愛你的人（錨人）的記憶來補上你的樣子，讀過的記憶就被磨掉。窮人只有家人可以當錨人，所以每一次重來，都有人在替你付帳。凜每次死亡重來，養父老 K 就少記得她一點。前四章他看起來像反派（鎖著的地下室、天穹的辦公室），第五章才知道他是錨人。她想把他失去的拿回來，最後要決定：一個無法回答的人，要不要替他決定。

遊戲裡玩家按下的每一次「再來一次」，就是故事裡的那一次。

## 演出原則（避免大量文本變無聊）

| 手法 | 用在哪 | 備註 |
|---|---|---|
| 死亡畫面即敘事 | 每次死亡 | 文字、語音、八段重點記憶都是故事（見 PLOT.md） |
| 據點會變 | 巢蛋當舖 | 貨架標籤逐漸空白，老 K 的對白依章節分狀態 |
| 動畫過場 | 章首、頭目登場、章末 | 沿用 NE-38 過場動畫系統；每段不超過 6 句 |
| 不暫停的通訊 | 關卡中 | 1～2 句，兼具提示；閒聊與吵架都放這裡 |
| 場景敘事 | 道具、廣告、氣象預報、牆上字跡 | 伏筆全放這層，玩家不看也不影響主線 |
| 世界回應 | 雨量、霓虹、看板詞隨劇情變化 | 雨量與全城復原次數成正比，天氣本身就是演出 |
| 每章一個安靜場景 | 沒有戰鬥與提示，只有人 | |
| 非戰鬥關 | 第八章 | 洪水夜，從塔頂下到港區，回家，只有水 |

文本分三層，讓文字量大也不累：**主線**（必看、短）→ **道具與通訊**（順手看）→ **檔案與回放**（想知道才看）。
