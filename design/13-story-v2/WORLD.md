## 一句話

一座靠「再來一次」撐著的城市：每次重來，都有一個愛你的人替你付帳。

## 為什麼是這個設定

這是一款有「死亡重來」的動作遊戲。玩家按下「再來一次」幾十次，這個動作本身就是遊戲最熟悉、最不會被當回事的東西。所以我們讓它成為故事的核心：**玩家在前半部按下的每一次重來，在世界裡都真的發生了，而且有人付了代價。**

這同時滿足三件事：

- 《星際效應》的做法：先有一個情感核心，再讓規則變成情感的代價（時間膨脹之於庫柏，記憶耗損之於老 K）。
- 《尼爾》的做法：用這個媒介獨有的東西（重來、存檔、介面）承載主題，而不是靠台詞講。
- 《邊緣行者》的做法：悲劇出於角色愛人的方式，不是出於陰謀。

## 世界概觀

### 沉港市

海平面上升後半沒入海中的港口城市，終年降雨，向上蓋成三層。

| 層 | 名稱 | 樣貌 | 遊戲場景 |
|---|---|---|---|
| 下層 | **港區** | 泡水的碼頭與市集，霓虹倒映在積水裡，工人、傭兵、收帳人與付不起房租的人 | 巢蛋當舖、霓虹市集、碼頭倉庫、屋頂與巷弄 |
| 中層 | **夾層** | 冷白色的診所、工廠與錨庫分站，天穹員工與家屬的居住層 | 診所、廢棄廠房、錨庫分站 |
| 上層 | **日照區** | 雲層之上，唯一有真正陽光的地方。養老社區「晴岸」與天穹塔在這裡 | 晴岸、天穹塔 |

### 雨

雨不是氣候。十五年前天穹啟動「雲蓋計畫」，人為維持一層雨雲給地下的錨庫散熱。**全城每天的雨量，跟全城每天的復原次數成正比**，這是氣象局公開的數字。港區的老人說：「雨是大家的第二次機會。」

這件事要到很後面才被玩家連起來，但前面每一章都放了一句氣象預報、一則看板（「今夜降雨量偏多，復原申請量高峰」），沒有人把它當回事。

### 錢與帳

| 名詞 | 說明 |
|---|---|
| **信用點** | 唯一通用貨幣，由天穹發行 |
| **巢蛋** | 存款。凜的筆記本最後一頁寫著一個數字：480,000，那是「晴岸」一間房的頭期款 |
| **付帳** | 港區俗語，兩個意思：付錢，以及「當某個人的錨人」。「誰替你付帳？」就是在問「你死了誰會救你」 |
| **收帳人** | 港區的討債幫派，也是第一、二章的常見敵人 |
| **復原費** | 每次復原收 1,200 點，從受錨者的帳戶扣。凜的巢蛋一直漲得慢，一部分是這個原因 |

## 核心技術：錨定

天穹的商品，品牌名「**再來一次**」，標語：

> 再來一次，沒關係。有人愛你，就有第二次。

| 名詞 | 說明 |
|---|---|
| **備份** | 在街頭的「錨點」終端存檔，記下神經結構。備份只有骨架，沒有「這個人之所以是這個人」的紋理 |
| **受錨者** | 被備份、也會被復原的人 |
| **錨人** | 另一個與受錨者有深厚感情的活人。復原時，系統讀取他對受錨者的記憶，補上紋理 |
| **復原** | 在錨點旁的復原室列印身體（殼），約十分鐘後醒來，記憶回到上一次備份的那一刻 |
| **耗損** | 讀取會把錨人腦中關於受錨者的記憶磨掉，先磨最鮮明的細節（某一天、某句話、某個表情），最後剩下事實（「我知道她叫什麼」）而沒有感覺 |
| **漂移** | 復原出來的人，像錨人記得的樣子。邊角會先被磨平，所以反覆復原的人會越來越溫柔、越來越圓 |
| **復原權** | 每個孩子在學校免費得到一份「安心保單」，內含復原權。復原權可以賣回天穹換現金，賣掉就永遠沒有了，港區俗語叫「把命當了」 |

### 規則的邊界

- 錨人的記憶用完（**用盡**）、或錨人死了，就無法復原。
- 感情越深，復原越像本人，耗損也越大。
- 花錢請「**常駐錨人**」（受過訓練、領薪水的錨人）不會傷到私人感情，但復原出來的人「平平的，沒味道」。有錢人都這樣活。
- 沒有人愛你，或愛你的人付不起，你就只有一次。這種人叫「**無帳者**」，是港區最安靜的一群。
- 天穹公開的說法是「錨人可能出現輕度記憶耗損」。真實的耗損率沒有公開。

## 社會

| 群體 | 說明 |
|---|---|
| **有帳者** | 有人替他付帳的人。港區大多數人。他們彼此都知道代價，但沒人談 |
| **用盡者** | 被用盡的錨人。他們不是失憶，是「知道我愛過一個人，但沒有感覺了」，通常住在天穹的安養病房。天穹員工中最忠誠、最冷靜的人有很多是用盡者，因為沒有牽掛可以被利用 |
| **無帳者** | 沒有人替他付帳的人，死了就是死了 |
| **常駐錨人** | 領薪水的專業錨人，由用盡者與貧民組成，有錢人的消耗品 |
| **回音派** | 小型宗教團體：「復原出來的不是人，是人的回音。」他們在碼頭邊發傳單，大多數人覺得他們煩 |

### 港區俗語

| 話 | 意思 |
|---|---|
| 再來 | 道別，原本是「再來一次」的縮寫，現在人人這樣說「我走了」 |
| 帶傘了嗎 | 出門前的問候，意思是「平安回來」。港區每個人都這樣問 |
| 最後一次 | 忌諱，沒有人說 |
| 把命當了 | 賣掉復原權 |

### 對立方

沒有人是壞人。每個人都有一個「所以我才……」，而且那句話有一半是對的。

#### 沈遠（74 歲，天穹創辦人）

| 項目 | 內容 |
|---|---|
| 中心思想 | **愛不必記得，只要履行。** |
| 為什麼 | 他的妻子汐溺死，他把她復原回來，三十一次，每次都被耗掉對她的記憶。現在他完全不記得她，每天仍去花園陪她。 |
| 他怎麼活 | 他有一本筆記本，寫著給自己的指示：「她喜歡茉莉。不要問她昨天的事。早上先開窗。」 |
| 對 | 他每一天都在履行，這是真的 |
| 錯 | 他從沒問過汐想不想繼續。他把「履行」當成「愛」，而不是「問」 |
| 結束 | 凜在他面前問了汐這個問題，是二十年來第一次有人問。 |
| 信條如何應驗 | 他說「不必記得」，老 K 忘了凜，卻每天問「帶傘了嗎」。他是對的。 凜對他說：「他不知道自己在問誰。」他也是對的。 |

#### 葉（41 歲，天穹風控長）

| 項目 | 內容 |
|---|---|
| 中心思想 | **耗損率 11%，換 89% 的人不必死。** |
| 為什麼 | 她曾是哥哥的錨人，復原過十二次。她不記得他的臉，但他有兩個孩子，那兩個孩子是活的 |
| 她怎麼活 | 每天早上在手背寫下：「他叫阿翰。你愛他。」 |
| 對 | 數字是真的 |

#### 阿勇（收帳人頭目，第二章頭目）

他身後的平台上有他十二歲的女兒小薇，他的錨人。他死了又被復原，她站在那裡，眼神一次比一次空。他不是壞人，他是每一個「為了家人而幹壞事」的人。

## 母題與小物件

小物件在前面出現至少三次，每次都像調味。**結尾只動這一個**（機制 4）。

| 小物件 | 出現 | 結尾 |
|---|---|---|
| **帶傘了嗎** | 每章開場與每次出門 | 凜最後一次回答：「帶了。」 |
| **當舖的標籤** | 貨架上每件東西的來歷，老 K 以前會講，後來停了，標籤開始空白 | 洪水夜，漂在水上 |
| **漏水桶** | 屋頂的滴水聲 | 在晴岸，他睡不著，因為太安靜。燈替他裝了雨聲機 |
| **歡迎回來** | 每次復原的語音，少年的聲音 | 第八章，終端不再說話 |
| **筆記本** | 凜的帳，最後一頁是 480,000；沈遠的指示本；葉手背上的字 | 三本都是「不靠記憶的愛」 |
| **雨** | 氣象預報與看板 | 真結局：雨停 |
| **數字** | 復原次數、巢蛋、鷺的二百一十四次 | 倒數 |
