## 一句話

一座靠「再來一次」撐著的城市：每次重來，都有一個愛你的人替你付帳。

## 為什麼是這個設定

這是一款以故事為導向的探索＋ARPG，有「死亡重來」。玩家按下「再來一次」幾十次，這個動作本身就是遊戲最熟悉、最不會被當回事的東西。所以我們讓它成為故事的核心：**玩家在前半部按下的每一次重來，在世界裡都真的發生了，而且有人付了代價。**

這同時滿足三件事：

- 《星際效應》的做法：先有一個情感核心，再讓規則變成情感的代價。
- 《尼爾》的做法：用這個媒介獨有的東西（重來、存檔、介面）承載主題，而不是靠台詞講。
- 《邊緣行者》的做法：悲劇出於角色愛人的方式，不是出於陰謀。

## 世界概觀

### 沉港市

海平面上升後半沒入海中的港口城市，終年降雨，向上蓋成三層。

| 層 | 名稱 | 樣貌 | 遊戲場景 |
|---|---|---|---|
| 下層 | **港區** | 泡水的碼頭與市集，霓虹倒映在積水裡，工人、傭兵、收帳人與付不起房租的人 | 巢蛋當舖、霓虹市集、碼頭倉庫、屋頂與巷弄、廣播站 |
| 中層 | **夾層** | 冷白色的診所、工廠與錨庫分站，天穹員工與家屬的居住層 | 診所、廢棄廠房、錨庫分站、安養病房 |
| 上層 | **日照區** | 雲層之上，唯一有真正陽光的地方。養老社區「晴岸」與天穹塔在這裡 | 晴岸、天穹塔 |

### 雨

雨不是氣候。十五年前天穹啟動「雲蓋計畫」，人為維持一層雨雲給地下的錨庫散熱。**全城每天的雨量，跟全城每天的復原次數成正比**，這是氣象局公開的數字。港區的老人說：「雨是大家的第二次機會。」

這件事要到很後面才被玩家連起來，但前面每一章都放了一句氣象預報、一則看板（「今夜降雨量偏多，復原申請量高峰」），沒有人把它當回事。

### 錢與帳

| 名詞 | 說明 |
|---|---|
| **信用點** | 唯一通用貨幣，由天穹發行 |
| **巢蛋** | 存款。凜的筆記本最後一頁寫著一個數字：480,000，那是「晴岸」一間房的頭期款 |
| **付帳** | 港區俗語，兩個意思：付錢，以及「當某個人的錨人」。「誰替你付帳？」就是在問「你死了誰會救你」 |
| **收帳人** | 港區的討債幫派，也是前期的常見敵人 |
| **復原費** | 每次復原收 1,200 點，從受錨者的帳戶扣 |

## 核心技術：錨定

天穹的商品，品牌名「**再來一次**」，標語：

> 再來一次，沒關係。有人愛你，就有第二次。

| 名詞 | 說明 |
|---|---|
| **備份** | 在街頭的「錨點」終端存檔，記下神經結構。備份只有骨架，沒有「這個人之所以是這個人」的紋理。學校每年替孩子更新備份（安心登錄） |
| **受錨者** | 被備份、也會被復原的人 |
| **錨人** | 另一個與受錨者有深厚感情的活人。復原時，系統讀取他對受錨者的記憶，補上紋理 |
| **錨椅** | 讀取時，錨人必須坐在錨椅上。診所有出租的錨椅間；也有人私設家用的，不合法、不登記 |
| **復原** | 在錨點旁的復原室列印身體（殼），約十分鐘後醒來，記憶回到上一次備份的那一刻。錨人在這十分鐘內必須坐上錨椅 |
| **匿名登記** | 錨人可以要求不讓受錨者知道自己是誰（原本是為了防止收帳人拿錨人當人質）。帳本上只會顯示「錨人：匿名」 |
| **耗損** | 讀取會把錨人腦中關於受錨者的記憶磨掉，先磨最鮮明的細節（某一天、某句話、某個表情），最後剩下事實（「我知道她叫什麼」）而沒有感覺 |
| **轉存** | 被磨掉的記憶沒有消失，會被轉存進天穹的「帳房」。**贖回需要受錨者與錨人雙方簽署同意，費用以「一間晴岸的房」估價：480,000** |
| **漂移** | 復原出來的人，像錨人記得的樣子。邊角會先被磨平，所以反覆復原的人會越來越溫柔、越來越圓 |
| **復原權** | 每個孩子在學校免費得到一份「安心保單」，內含復原權。復原權可以賣回天穹換現金，賣掉就永遠沒有了，港區俗語叫「把命當了」 |

### 規則的邊界

- 錨人的記憶用完（**用盡**）、或錨人死了，就無法復原。
- 感情越深，復原越像本人，耗損也越大。
- 花錢請「**常駐錨人**」（受過訓練、領薪水的錨人）不會傷到私人感情，但復原出來的人「平平的，沒味道」。有錢人都這樣活。
- 沒有人愛你，或愛你的人付不起，你就只有一次。這種人叫「**無帳者**」，是港區最安靜的一群。
- 天穹公開的說法是「錨人可能出現輕度記憶耗損」。真實的耗損率沒有公開。
- 死後十分鐘內沒有人把你送到終端，殼就等不到你。窮人大多死了就是死了。

## 社會

| 群體 | 說明 |
|---|---|
| **有帳者** | 有人替他付帳的人。港區大多數人。他們彼此都知道代價，但沒人談 |
| **用盡者** | 被用盡的錨人。他們不是失憶，是「知道我愛過一個人，但沒有感覺了」，通常住在天穹的安養病房。天穹員工中最忠誠、最冷靜的人有很多是用盡者，因為沒有牽掛可以被利用 |
| **無帳者** | 沒有人替他付帳的人，死了就是死了 |
| **常駐錨人** | 領薪水的專業錨人，由用盡者與貧民組成，有錢人的消耗品 |
| **收屍人** | 死後十分鐘內把你送到終端的行當。灰色的外套，不說話。付得起的人很少；玩家會以為他們是天穹的回收隊 |
| **付帳人** | 港區的都市傳說：匿名的錨人是放高利貸的，「你欠他一條命，他遲早來收」。收帳人拿這個嚇人。真相是另一回事 |
| **租來的家人** | 「情感租賃」業：窮人把「被某個人記得」當工作賣給孤單的有錢人。愛被明碼標價 |
| **忘川** | 讓人忘掉痛苦記憶的藥。錨人買來止痛，窮人賣自己的記憶換錢，與錨定相反的市場 |
| **回音派** | 小型宗教團體：「復原出來的不是人，是人的回音。」他們在碼頭邊發傳單，大多數人覺得他們煩 |

### 港區俗語

| 話 | 意思 |
|---|---|
| 再來 | 道別，原本是「再來一次」的縮寫，現在人人這樣說「我走了」 |
| 帶傘了嗎 | 出門前的問候，意思是「平安回來」。港區每個人都這樣問 |
| 最後一次 | 忌諱，沒有人說 |
| 把命當了 | 賣掉復原權 |

## 勢力

| 勢力 | 主張 | 代表 | 他們對的地方 | 他們錯的地方 |
|---|---|---|---|---|
| **天穹** | 死亡是最大的不平等，我們讓每個人都有第二次。代價誠實標示，沒有人被強迫。 | 沈遠、葉、帳房 | 每年因此活下來的人數是真的 | 「誠實標示」的耗損率不是真的；也沒有人問過錨人 |
| **斷錨派「潮」** | 記憶是自己的財產，不是貨幣。 | 蘇 | 原則 | 他們想毀掉錨庫，但港區的人沒有別的路可走 |
| **收帳人** | 沒有人白白得到第二次。 | 阿勇與他的幫派 | 世界確實是這樣運作的 | 他們收的帳，最後大多由孩子付 |
| **巢蛋當舖與鄰里** | 先顧眼前的人。 | 老 K、收屍人、麵攤與碼頭上的人 | 他們撐起了港區 | 他們不問，也不說，所以每個人都在替別人決定 |

## 人物

每個人用同一個格式：想要什麼、怕什麼、相信什麼、他對在哪、他錯在哪、怎麼結束、最難忘的一場戲。

| 最難忘的一場戲 | 第一章末，天亮的宵夜。她把最後一碗麵推過去：「不收錢。」凜：「那我欠你。」阿梨：「那就欠著。」 |

她是凜的對照：一個把「欠」當成可以留著的東西的人。

### 對立方

沒有人是壞人。每個人都有一個「所以我才……」，而且那句話有一半是對的。

#### 沈遠（74 歲，天穹創辦人）

| 項目 | 內容 |
|---|---|
| 中心思想 | **愛不必記得，只要履行。** |
| 為什麼 | 他的妻子汐溺死，他把她復原回來，三十一次，每次都被耗掉對她的記憶。現在他完全不記得她，每天仍去花園陪她 |
| 他怎麼活 | 他有一本筆記本，寫著給自己的指示：「她喜歡茉莉。不要問她昨天的事。早上先開窗。」 |
| 帳房 | 他在還記得汐的時候親手設計了帳房：契約一旦成立就必須履行，**任何人都不能中止，包括他自己**。他怕有一天他自己會心軟 |
| 對 | 他每一天都在履行，這是真的 |
| 錯 | 他從沒問過汐想不想繼續。他把「履行」當成「愛」，而不是「問」 |
| 結束 | 凜在他面前問了汐這個問題，是二十年來第一次有人問。他想停下帳房，停不了 |
| 信條如何應驗 | 他說「不必記得」，老 K 忘了凜，卻每天問「帶傘了嗎」。他是對的。凜對他說：「他不知道自己在問誰。」他也是對的 |

#### 葉（41 歲，天穹風控長）

| 項目 | 內容 |
|---|---|
| 中心思想 | **耗損率 11%，換 89% 的人不必死。** |
| 為什麼 | 她曾是哥哥的錨人，復原過十二次。她不記得他的臉，但他有兩個孩子，那兩個孩子是活的 |
| 她怎麼活 | 每天早上在手背寫下：「他叫阿翰。你愛他。」 |
| 對 | 數字是真的 |
| 錯 | 她用「如果大家知道就沒人敢簽」當理由，隱瞞真實的耗損率。這是他們說的謊 |
| 結束 | 她完全可以收買凜，卻在最後批准了一個她不該批准的例外 |
| 信條如何應驗 | 她說「數字不會累」，她的帳本最後成了凜的證據 |

#### 帳房（最終 Boss，機械）

| 項目 | 內容 |
|---|---|
| 是什麼 | 天穹塔中心的檔案機。保管所有被磨掉的記憶，執行契約 |
| 它不是誰 | 它沒有主張，沒有感情，不說話。它只做契約寫的事 |
| 為什麼是它 | 它是沈遠「履行重於記得」這句話變成機器的樣子，**它比設計它的人還不能被說服** |
| 戰鬥 | 打不倒。它以玩家這趟旅程的**死亡紀錄**出招：重播殺過你的敵人 |
| 為什麼凜一定會輸 | 契約沒有成立（需要老 K 的同意），它沒有任何打開的理由 |

#### 收屍人

老 K 雇的幾個退休傭兵，灰色外套，不說話。凜每次死亡，他們都會在十分鐘內把她送到終端。他們的工錢，是老 K 每月的存款。玩家前四章看到他們時，會以為是天穹的回收隊或監視者。

#### 阿勇（收帳人頭目，第二章頭目）

他身後的平台上有他十二歲的女兒小薇，他的錨人。他死了又被復原，她站在那裡，眼神一次比一次空。他不是壞人，他是每一個「為了家人而幹壞事」的人。

**他的副手**（暫名，成年）在阿勇死後接手。帳本公開讓港區的復原申請下降，收帳人放出去的復原貸款收不回來，他把帳算在凜身邊的人身上。他也有要養的人，也不是壞人，但他做了無法原諒的事。

|---|---|---|

## 機制即世界

以下是遊戲系統與世界設定的對應。**這些是設計提案，要實作前各自開票評估成本。**

| 遊戲系統 | 世界裡的意思 | 說明 |
|---|---|---|
| 死亡後重來 | 復原 | 在最近的錨點醒來，扣復原費 1,200 點 |
| 死亡畫面 | 錨點的語音與狀態列 | 前半：「復原完成　今日第 N 次　錨人狀態：良好」。第四章中點起：「累計 N 次　錨人：匿名　耗損 xx%」 |
| 重點記憶 | 讀取的過程 | **十個節點**，每個節點之後的第一次死亡，畫面先顯示一段錨人的記憶，並解鎖進「記憶」收藏。前四段是匿名視角，第五章之後才署名。見 [PLOT.md](PLOT.md) |
| 死亡後的世界 | 世界沒有死 | 開關、箱子、水位在你死後保持原狀，這是解謎的一種動詞。第四章之後，用這個解法會顯示耗損，並提供另一種解法。見 [PUZZLE.md](PUZZLE.md) |
| 據點（當舖） | 老 K 的店 | 標籤隨劇情逐步空白；老 K 的對白依章節分狀態；工作檯是武器改裝 |
| 信用點與巢蛋 | 錢，也是記憶 | HUD 上有一條「巢蛋」進度。第五章之後它同時是贖回費 |
| 雨量 | 全城復原次數 | 環境雨量與死亡次數輕微連動，是調味，不是機制 |
| 檢查點 | 錨點 | 街頭終端 |
| R18 模式 | 內容設定檔 | 設定裡可開關。關閉時沒有露骨內容，劇情略有不同，收集不受影響，見 [MATURE.md](MATURE.md) |
| 分支旗標 | 凜的選擇 | `knows_ali_address`、`answered_call`，存檔缺漏時退回「已避免」 |
| 賣掉復原權之後 | 沒有復原 | 死亡畫面沒有「再來一次」，只有「讀取存檔」 |
| 最終決定 | 習慣即命運 | 最後的選擇是「再來一次」與「算了」兩個鍵 |
| 畫廊 | 收藏 | 通關後解鎖，內容之後設計，見 [MATURE.md](MATURE.md) |
