# 第四章廠房入口

本段接續[第四章劇本](SCRIPT_CH04.md)第 07–08 場。病房公用取件聯指出舊廠代收，玩家先找復原館的阿梨確定換班貨門，再拿紙上的批次和現場班表核對。不需要回房重問棠。

| 區域 | 行進與觀察 |
| --- | --- |
| 病房外櫃檯 | 有取件聯後沿戶外連廊走到復原館。還沒拿聯時，門提示回床頭櫃。 |
| 復原館 | 阿梨交代代收箱從哪個門進來。前章的申訴決定仍由阿梨作主。她提供的是現場辨認方式與板上的資料，不收費。 |
| 廠房外廊 | 沿靠貨門的停擺掛鐘找到班表。玩家比對月報十七的轉介去向，核對正確才開啟貨門。選錯讀出不同欄位，不耗物品。 |
| 裝卸帶 | 下層有連續固定地板，上層用短臺階連到維修線。從內側鬆開棘輪後可由上層返回外牆，形成可回訪的環路。地板與敵人活動可於後續清理戰分開變更。 |

首次看到割除輪廓先在固定地面觀察，維修閘可從廠內解除。這段的見聞只交代清理和路線，鷺、帳本私欄及收走掩體的正式狀態由後段決定。

裝卸帶採固定亮度的暖色工作燈。底層與上層踏板在原生 Forward+ 下可以辨認，附近的廠外仍保留暗色。
