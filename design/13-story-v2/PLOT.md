# 大致情節

> 階段 2＋3 合併的第一版。世界規則見 [WORLD.md](WORLD.md)，設計依據見 [REFERENCE.md](REFERENCE.md)。
> 這是「大致情節」：每章的目的、事件、演出、頭目與章末。逐句劇本在確認之後才寫。

## 情感核心

像《星際效應》的「我會回來」與「什麼時候」，整個故事只需要兩句話：

> 老 K：帶傘了嗎？
> 凜：（前七章）下面本來就是水。（最後一章）帶了。

凜整部作品從「不接受別人替她付出」走到「接受」，而她接受的那一刻，也是她離開的那一刻。

## 故事一句話

一個死過幾十次的女孩，為了替養父買一間有太陽的房間，終於發現每一次「再來一次」，都是他在付帳。

## 結構

四幕八章。每章有一個頭目、一個**安靜場景**（沒有戰鬥，只有人）、至少一段**演出**。

| 幕 | 章 | 凜相信的事 | 實際上 | 章末 |
|---|---|---|---|---|
| 一　付帳 | 1　帶傘了嗎 | 死亡便宜又方便，錢才是難的 | 每次重來，老 K 都付了 | 第一次復原是一個笑話 |
| | 2　鷺 | 鷺姐是最會活的人 | 她是最會被用掉的人 | 鷺的第二百一十四次 |
| 二　利息 | 3　晴岸 | 老 K 只是老了 | 他在被用掉 | 診斷書上有一個詞，她看不懂 |
| | 4　空殼 | 我可以一直做下去 | 鷺死了，因為沒有人能再付 | **中點**：帳本，累計次數 |
| 三　清帳 | 5　問 | 我會問他 | 他也從沒問過她 | 她決定公開帳本 |
| | 6　斷錨 | 說出真相就能解決 | 說出真相只是讓人睜著眼睛付 | 老 K 開始認不得她 |
| 四　巢蛋 | 7　日照 | 把他安頓好就是結局 | 那是她替他決定的，他想回家 | 她按下「把命當了」，老 K 走丟 |
| | 8　再來一次 | 我做完了 | 沒有人能再替她付帳 | 洪水夜，帶了 |

## 玩家一路上不知道的事：死亡畫面

| 階段 | 死亡畫面 |
|---|---|
| 第一～三章 | 「復原完成　**今日**第 N 次　錨人狀態：良好」。語音是少年的聲音：「歡迎回來。」 |
| 第四章中點起 | 「復原完成　**累計** N 次　錨人：K　耗損 xx%」 |
| 第八章 | 沒有「再來一次」。只有「讀取存檔」 |

**累計次數** = 故事開始前的 9 次 + 玩家實際死亡次數。故事不取決於玩家死了幾次，只取決於「超過幾次之後，老 K 的狀態分三檔」（輕、中、重），三檔的對白各寫一套。

### 死亡時的回憶片段

每次死亡，畫面在「復原中」時先顯示一段老 K 的記憶：一張靜態圖、一句話。同一段只會出現一次，用掉就換成灰色雜訊。共 60 段，最後 6 段**永遠保留**（不會被死亡用掉）。

範例（語氣要小、要具體，不講感情）：

| 編號 | 一句話 |
|---|---|
| 07 | 她第一天來，把鞋脫在門外，擺得像要被檢查。 |
| 23 | 她不吃紅蘿蔔。我每次都切得很細，她每次都挑出來，一根不剩。 |
| 41 | 她第一次笑出聲，是我踩到水桶。我沒告訴她那桶是故意放的。 |
| 55（保留） | 她說：「下面本來就是水。」我說：「那也要帶。」 |

這是「情理之中」的設計：玩家從第一章起每死一次就看到一段溫暖的小東西，覺得是遊戲在給安慰。**第四章才知道，那是被用掉的東西。** 結局時看到的，是你沒用掉的。

## 逐章概要

### 第一章　帶傘了嗎

| 項目 | 內容 |
|---|---|
| 目的 | 讓玩家喜歡這個家。這一章不能趕。 |
| 事件 | 雨夜。巢蛋當舖、老 K 的碎念、貨架的標籤、漏水桶。燈在通訊裡。鷺介紹一份差事：碼頭倉庫，搬一批貨。凜算一遍錢，翻到筆記本最後一頁：晴岸，480,000，目前 27,400。 |
| 演出 | 開場動畫：從高空穿過雲層，一路向下到港區的雨；當舖門口的老 K：「帶傘了嗎？」凜：「下面本來就是水。」 |
| 頭目 | 倉庫的保全機甲「看門狗」 |
| 第一次死亡 | 頭目戰中死亡。畫面是一個笑話：**「再來一次，沒關係。」** 燈的聲音：「歡迎回來。」凜醒來，罵了一句，有點金屬味。她以為這是全世界的日常 |
| 安靜場景 | 回家吃飯。老 K 講貨架上每件東西的來歷。屋頂漏水，他說：「別修，那是我的鬧鐘。」 |
| 章末 | 她睡前看見老 K 在廚房站了一會兒，水燒乾了。他說「老了」。 |

### 第二章　鷺

| 項目 | 內容 |
|---|---|
| 目的 | 認識「失去」的前置。讓玩家愛上鷺 |
| 事件 | 市集差事，與鷺一組。鷺教凜怎麼在屋頂上看雨。港區老人說：「鷺姐以前是整個港區最難相處的人，現在是最好說話的。」霓虹看板：「今夜降雨偏多，復原申請量高峰。」 |
| 頭目 | 收帳人頭目阿勇。他的女兒小薇站在後方的錨點終端旁。他死了，被復原，小薇站在那裡，一次比一次空洞 |
| 演出 | 鷺死在這一戰，燈說：「歡迎回來，第 214 次。」所有人笑了，這是港區紀錄。凜笑了。這是玩家第一次看見「別人的」復原 |
| 安靜場景 | 屋頂，鷺教凜喝茶看雨，撐著一把破傘 |
| 章末 | 鷺說「週日我不接案」。凜在窗外看見她走進一棟白色的樓 |

### 第三章　晴岸

| 項目 | 內容 |
|---|---|
| 目的 | 展示「夢」的真實樣子；讓玩家看到凜的盲點 |
| 事件 | 凜為了確認價格、也為了替老 K 找失智症的藥，潛入夾層與日照區邊緣。第一次看見陽光（透過一塊玻璃）。晴岸的業務員 Ms. 林說：「這裡很安靜，安靜得有人睡不著。」凜偷到一份診斷資料，上面有一個詞：**錨人耗損症**。她看不懂，以為是別的病 |
| 頭目 | 錨庫分站的守門人，一個用盡者。他很有禮貌：「請問您有預約嗎？」打他時他一直在道歉 |
| 演出 | 她對著玻璃外的陽光站了很久，筆記本上寫下一個數字 |
| 安靜場景 | 她回家，老 K 在桌上留了飯，標籤寫著「今天的」，字跡抖。他問了兩次「帶傘了嗎」 |
| 章末 | 她沒有告訴他資料的事 |

### 第四章　空殼　（中點）

| 項目 | 內容 |
|---|---|
| 目的 | 讓玩家第一次看到「無法復原」，並揭露整個設定 |
| 事件 | 鷺要凜幫一個忙：偷一份天穹的帳本。燈說：「我幫你們看路。」他全程反常地安靜。凜在途中發現鷺把週日的病房地址寫在袖口 |
| 頭目 | 天穹清理隊隊長 |
| 鷺之死 | 鷺在這一戰倒下。錨點終端：「受錨者：鷺　錨人：棠（已故）　復原：無法執行。」沒有「歡迎回來」。凜愣在原地 |
| 鷺的遺言 | 她把帳本晶片塞給凜：「你自己看。不要先問老 K。」 |
| 演出 | 凜在病房見到棠。鷺每週來，每週說：「你好，我是鷺。」棠說：「你每個禮拜都來。」她不記得她，但記得「每個禮拜」 |
| 揭露 | 帳本裡有一行：**「受錨者：凜　錨人：K　累計：N 次　耗損：91%」** |
| 燈的坦白 | 「我每次都在想，今天要不要告訴你。每次都是明天。」 |
| 演出（機制） | 此後所有死亡畫面改成「累計 N 次　錨人：K　耗損 xx%」。玩家第一次有「不想死」的感覺 |
| 章末 | 她把帳本放回口袋，走回當舖，老 K 在廚房：「帶傘了嗎？」她答不出來 |

### 第五章　問

| 項目 | 內容 |
|---|---|
| 目的 | 讓兩個人把話講出來 |
| 事件 | 她回家，質問老 K。**「我不是替你付。是我想付。」「我沒有問你。」「你也沒問過。」** 沒有人說「我愛你」。他們繼續吃飯。她第一次問：「你想要我怎麼做？」他說：「去賺你的錢。」答非所問 |
| 葉 | 天穹風控長葉出場，她很客氣。她知道帳本被偷。她說：「我給你 480,000，你保持沉默，繼續工作，你是最好的樣本。」凜拒絕 |
| 頭目 | 葉的助手，一個把數字寫在手背上的人 |
| 安靜場景 | 全章最長的一段：當舖，一整晚，修一台收音機。老 K 講貨架上所有標籤的來歷，講到一半，停了 |
| 章末 | 她打電話給燈：「公開帳本。」 |

### 第六章　斷錨

| 項目 | 內容 |
|---|---|
| 目的 | 讓「說出真相」付出代價，展示沒有簡單的答案 |
| 事件 | 蘇與潮接手帳本，計畫從港區廣播站向全城公開。凜加入。廣播播出：蘇以平淡的語氣唸出一份用盡者名單 |
| 後果 | 港區沒有暴動。人們聽完，繼續排隊復原。一個女人說：「我知道。我還是要。」 |
| 衝突 | 蘇要毀掉錨庫，凜反對：「那些人沒有別的路。」 |
| 頭目 | 廣播站的守衛長，他的錨人（老母親）坐在一旁。凜可以選擇打斷連結，頭目就不能復原，母親也不會被讀取 |
| 章末 | 老 K 摔了一跤，醒來問：「你是誰家的孩子？」她說：「隔壁的。我常來。」 |

### 第七章　日照

| 項目 | 內容 |
|---|---|
| 目的 | 全作最輕、最亮的一章，也是失去之前的最後一段日子 |
| 事件 | 她湊不齊最後一筆錢。葉的帳戶凍結了她的存款。沈遠的筆記本、汐的花園、她來到天穹塔頂，見到沈遠與汐。凜問汐：「你想繼續嗎？」沈遠愣住：二十年來沒有人問過。汐說：「我不知道。我只知道他每天都來。」 |
| 葉的例外 | 葉批准了「復原權回購」，價格剛好是缺的那筆。她在帳本寫下：「例外一筆。」 |
| 演出 | 一個合約畫面，只有一個按鈕：「把命當了」。**玩家必須親手按下去** |
| 日照 | 她把老 K 接到晴岸。第一次真正的陽光。他說：「太亮了。」他睡不著：太安靜 |
| 安靜場景 | 她坐在窗邊，老 K 問：「你是誰家的孩子？」她說：「隔壁的。」他說：「那就好。」 |
| 章末 | 當晚風暴警報。老 K 不見了，床是空的。他去了他唯一想去的地方：家 |

### 第八章　再來一次

| 項目 | 內容 |
|---|---|
| 目的 | 結尾。要有前面七章全部的重量 |
| 事件 | 第三次大洪水之夜。她沿著水位上升的港區往回走。一路上，沒有收帳人、沒有保全，只有街上的人互相拉著手、撐著傘，開船出來接人（蘇的船是第一艘）。**沒有頭目** |
| 玩法 | 非戰鬥關：水位逐漸上升，她要在水裡爬、游、跳，到達當舖。路上的終端不再說「歡迎回來」。死亡畫面沒有「再來一次」 |
| 當舖 | 進到自己的家。貨架的標籤漂在水上，那些他曾經講過的來歷，一張一張碰到她的手。老 K 坐在桌前，水到膝蓋，正在燒水 |
| 最後一場戲 | 他看著她：「帶傘了嗎？」她說：「帶了。」他說：「那就好。」 |
| 離開 | 燈與蘇的船在窗外。她把老 K 抱上船。屋樑斷裂。她被壓在水裡。最近的錨點亮了：「復原權：已出售。」 |
| 最後一個畫面 | 一般結局：晴岸的房間，陽光，老 K 睡著，窗邊放著一台雨聲機，滴水聲。護理員問：「今天要帶傘嗎？」他說：「不用了，那就好。」HUD 出現最後一次：**巢蛋 480,000 / 480,000** |
| 結局回憶 | 播放「你沒用掉的那些片段」。死得少的玩家看得多，死得多的玩家看到的少，但最後 6 段所有人都看得到 |

## 為什麼這個結尾成立

對照 [REFERENCE.md](REFERENCE.md) 的驗收問題：

| 問題 | 答案 |
|---|---|
| 小物件前面出現三次、每次是調味？ | 「帶傘了嗎」每章開場；「歡迎回來」每次死亡；標籤與漏水桶每次回家 |
| 把它換成別的，結尾還成立嗎？ | 不成立。「帶傘了嗎」是這兩個人專屬的暗號 |
| 前面有一個場景因為結尾而翻面？ | 第一章的第一次死亡：一個笑話，變成第一筆帳 |
| 主角的死出於她最好的特質？ | 她接受不了欠人，所以替他決定；她愛他，所以回頭 |
| 最後一個畫面沒有旁白？ | 沒有，只有一台雨聲機 |
| 有數得出來的代價？ | 復原次數、耗損%、巢蛋、60 段回憶 |
| 反派信條以他沒料到的方式應驗？ | 沈遠：「愛不必記得，只要履行。」老 K 的「帶傘了嗎」證明他是對的，凜的離開證明他錯了 |

「意料之外」的來源：玩家猜得到老 K 在付帳（中點之前就有線索）。猜不到的是**重來這個動作本身就是那個帳**，而「最後一次」不是被殺，是她自己把命當了。

## 結局

| 結局 | 條件 | 內容 |
|---|---|---|
| **一般結局** | 通關 | 上述。凜死，老 K 在晴岸。城市還在下雨 |
| **真結局** | 蒐集全部「凜十歲時的錄音」與「鷺的信」（散落各章，不需死亡次數） | 一般結局之後，加一段：港區的復原申請三週內下降四成，氣象預報螢幕上：**「降雨暫停。原因：——　恢復時間：待定。」** 然後一個十歲的女孩站在學校的終端前，螢幕第一次出現新的一行：**「錨人耗損將使你的錨人失去對你的記憶。是否同意？」** 她轉頭看她母親。黑畫面 |

真結局的伏筆是：雨與復原量成正比；有人問了；城市可能改變，也可能不會。

## 悲劇的寫法

- 沒有人說「我愛你」。愛用動作講：煮水、問傘、切紅蘿蔔。
- 死亡時沒有音樂。只有雨聲。
- 沒有人在死前發表演說。鷺的遺言只有一句：「你自己看。」
- 反派不被打倒，也不被原諒。他們繼續做他們的事。
