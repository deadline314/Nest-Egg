## 情感核心

像《星際效應》的「我會回來」與「什麼時候」，整個故事只需要兩句話：

> 老 K：帶傘了嗎？
> 凜：（前七章）下面本來就是水。（第八章洪水夜）帶了。

凜整部作品從「不接受別人替她付出」走到「接受」。她接受的那一刻，在第八章；之後三個結局，各自用這句話收尾一次。

## 故事一句話

一個死過幾十次的女孩，為了替養父買一間有太陽的房間，發現每一次「再來一次」都是他在付帳，而她想把他失去的拿回來時，必須決定要不要替一個無法回答的人做決定。

## 視角間章：用別人的眼睛看同一件事

使用者：有些章節可以操控其他角色，用其他角色的視野看同一章（可以重用場景），或遊玩某個角色的回憶。我決定做**四段**，每段 10～20 分鐘，放在章節之間或章節之內，不增加章數。

| 間章 | 位置 | 視角 | 玩法 | 重用 | 為什麼是這個人 |
|---|---|---|---|---|---|
| **一　客人簿** | 第二章之後 | 阿梨 | 非戰鬥。「租來的家人」：三位客人各要她當一個人（死去的女兒、妻子、朋友）。玩家**問、聽、記**，在客人簿上記下細節，回答要對得上 | 第一章的復原館 | 讓玩家在事件發生前真的認識她；她是無帳者；從另一側教「問」 |
| **二　最後一個週日** | 第四章之後 | 鷺 | 前半：病房裡的空床，她哼棠的歌，把信放進櫃子。後半：戰鬥，用鷺的武器守住走廊，鷺**不可能贏** | 第四章的廠房，從另一條路線；她替凜清出的那條捷徑 | 她早知道自己不會再被復原，這是整個第四章翻面的一刻 |
| **三　洪水那一夜** | 第五章，打開地下室之後 | 老 K（七年前，56 歲） | 揹著披著外套的凜（只見剪影，看不到臉）穿過淹水的街，移動慢、不能戰鬥、水位上升。**十分鐘倒數**（復原的十分鐘規則）。到達當舖，架起地下室的錨椅。最後畫面只有一個鍵「確認讀取」，沒有第二個選項 | 第八章的洪水港區（不同街區） | 他第一次替一個**無法回答的人**決定。同樣的決定在第九章回到玩家手上 |
| **四　控制室** | 第六章廣播進行中 | 燈 | UI 為主的操作謎：重導中繼器、壓制干擾、切換畫面，同時是凜平常聽到的提示的另一頭。阿梨的求救進到他的通訊，**決定轉給凜，或不說** | 第六章的廣播站，換成控制室 | 他的缺陷是沉默；這裡是他唯一一次可以開口的地方 |

**間章中的失敗**：不是復原，不扣復原費，不消耗任何人的記憶。畫面是「回放」，倒回幾秒。

**實作提案**：可操控角色用資料描述（移動、武器、能力、失敗規則），共用既有骨架角色與玩家控制器；非戰鬥的視角（阿梨、燈、老 K）不需要射擊系統。開票時評估成本。

## 老 K 的雙重面貌：先像反派，後來才知道是愛

使用者的要求：愛你的人要讓玩家晚點才知道他是愛你的，否則玩家只看到他的行為，會以為他是反派。我們反過來利用這一點：**前四章，玩家喜歡他，也懷疑他。** 揭露時，同一批畫面意思整個翻過來（REFERENCE 機制 1）。

| 玩家看到 | 玩家的推論 | 真相 | 首次出現 |
|---|---|---|---|
| 地下室的門一直鎖著，「漏水，別開」 | 他藏著什麼 | 他私設的錨椅 | 第一章 |
| 他突然離席，回來眼神是空的 | 他在做什麼見不得人的事 | 凜剛死，他被叫去坐錨椅 | 第一章起，每次玩家死亡後 |
| 他抽一成手續費，有一本鎖著的帳 | 他在揩油 | 一成全部存起來，標著「給凜」 | 第二章 |
| 他說「上面指定」的差事 | 他在替天穹派她送死 | 他挑的是最安全的，並讓收屍人先清過路 | 第二章起 |
| 市集上有人說「付帳人遲早來收」 | 她的錨人是個放貸的 | 都市傳說，由收帳人拿來嚇人 | 第二章 |
| 灰衣人在她死後十分鐘內出現 | 天穹的回收隊在監視她 | 老 K 雇的退休傭兵，收屍人 | 第二章 |
| 他在天穹辦公室對葉說：「她不能再死了。」 | 他要她活著繼續賺 | 他在求葉別再派她去危險的地方 | 第三章 |
| 他叫她「別去上面」（晴岸） | 他不讓她看見什麼 | 他怕她看見那裡的人，也怕天穹認出她 | 第三章 |
| 帳本上「錨人：匿名」 | 有一個人在控制她 | 匿名是為了保護錨人，是他自己要求的 | 第四章 |

### 揭露前的守則

- 死亡畫面的記憶片段，前四段是**匿名視角**，語氣刻意像監視（「我在門口站了很久」「我每次都在窗邊」），第五章之後才署名。
- 帳本上不出現他的名字。
- 燈知道累計次數，不知道錨人是誰。
- 鷺不知道。
- 第四章留下三個以上的嫌疑人：老 K、葉、阿梨的客人之一、收屍人背後的某個人，玩家要在第五章自己推理。

## 死亡畫面與八段重點記憶

使用者：60 段太多，改成幾個重點，每個節點之後的第一次死亡出現，同時解鎖。

| 規則 | 內容 |
|---|---|
| 觸發 | 每個節點之後的**第一次死亡**，復原畫面先顯示一段記憶，並永久解鎖進「記憶」收藏 |
| 之後的死亡 | 只顯示一般狀態列 |
| 沒死過的玩家 | 同一段記憶也能在據點的貨架標籤上讀到，不會錯過 |
| 前四段 | 匿名視角，語氣像監視 |
| 後四段 | 署名老 K |
| 第七、八段 | 由劇情給，不靠死亡（賣掉復原權之後不再有復原） |
| 用在哪 | B 結局最後，八段全部重播 |

| 編號 | 節點 | 內容 |
|---|---|---|
| M1 | 第一章　首次死亡 | 她睡著的時候，左手會握著右手。我在門口站了很久。 |
| M2 | 第二章　阿勇戰後 | 她出門會數三步，然後回頭一次。我每次都在窗邊，每次都假裝沒有。 |

### 死亡畫面的演變

| 階段 | 畫面 |
|---|---|
| 第一～三章 | 「復原完成　今日第 N 次　錨人狀態：良好」。語音是少年的聲音：「歡迎回來。」 |
| 第四章中點起 | 「復原完成　累計 N 次　錨人：匿名　耗損 xx%」 |
| 第五章起 | 「錨人：K」 |
| 賣掉復原權之後 | 沒有「再來一次」，只有「讀取存檔」。語音消失 |

**累計次數** = 故事開始前的 9 次 + 玩家實際死亡次數。故事不取決於玩家死了幾次；死亡次數只影響狀態列的數字與老 K 的對白細節。

## 逐章概要

### 第一章　帶傘了嗎

| 項目 | 內容 |
|---|---|
| 目的 | 讓玩家喜歡這個家，並引入復原與阿梨 |
| 探索與解謎 | 當舖（據點）→ 屋頂 → 碼頭倉庫。倉庫的水位閘門是第一個謎，同時教「世界不會因為你死掉而重置」 |
| 事件 | 雨夜。鷺介紹一份差事。凜算一遍錢，翻到筆記本最後一頁：晴岸，480,000，目前 27,400。老 K：「帶傘了嗎？」凜：「下面本來就是水。」地下室鎖著，「漏水，別開」 |
| 安靜場景 | 出門前的晚飯。老 K 講貨架上每件東西的來歷。屋頂漏水，他說：「別修，那是我的鬧鐘」 |
| 頭目 | 倉庫的保全機甲「看門狗」 |
| 首次死亡 | 頭目戰中死亡，一個笑話。畫面：**「再來一次，沒關係。」** 燈的聲音：「歡迎回來。」凜赤裸地在復原室醒來，罵了一句，有金屬味。她以為這是全世界的日常 |
| 復原夜 | 她照港區的習慣去復原館：喝酒、吃東西、找人。夜班的阿梨接待她。成年人之間的一夜（露骨層可選） |
| 天亮的選擇 | **付錢離開**，或**留下來吃一碗宵夜**。阿梨：「不收錢。」凜：「那我欠你。」阿梨：「那就欠著。」選擇留下的話，阿梨提到有個收帳人在跟她要帳，並告訴凜住處與暗號（旗標 `knows_ali_address`） |
| 章末 | 她回到當舖，老 K 在廚房，水燒乾了。他說「老了」。他突然離席，回來眼神是空的。地下室的門縫下有光 |

### 第二章　鷺

| 項目 | 內容 |
|---|---|
| 目的 | 認識「失去」的前置，讓玩家愛上鷺 |
| 探索與解謎 | 霓虹市集。小謎「對帳」：收帳人的債務簿與實際帳目有出入，找出來就能知道阿勇的據點在哪。路上有人先清過路：電線被剪、守衛昏倒但沒死、門沒鎖 |
| 事件 | 鷺教凜在屋頂看雨。港區老人：「鷺姐以前是整個港區最難相處的人，現在是最好說話的。」看板：「今夜降雨偏多，復原申請量高峰。」市集上有人說「付帳人遲早來收」。老 K 抽一成手續費，帳本鎖著 |
| 阿梨 | 市集，她在找麵攤的位置，阿勇的人在向她要帳。**第一次教「問」**：凜可以掏錢解圍（她的習慣），也可以問：「你需要什麼？」答案不是錢，是一個攤位與一張許可。凜可以去她的住處看她練習做麵（設定 `knows_ali_address`，若第一章沒留下來，這是**第二次機會**）。她說：「名字還沒想好。」 |
| 安靜場景 | 屋頂，鷺教凜喝茶看雨，撐著一把破傘 |
| 頭目 | 收帳人頭目阿勇。平台上是他十二歲的女兒小薇，他的錨人。他死了，被復原，小薇站在那裡，眼神一次比一次空。**凜可以打斷連結**，阿勇就不能復原 |
| 演出 | 鷺死在這一戰，燈說：「歡迎回來，第 214 次。」所有人笑了，這是港區紀錄。凜笑了。這是玩家第一次看見「別人的」復原 |
| 間章一 | **客人簿**（阿梨，見上方） |
| 章末 | 鷺說「週日我不接案」。凜在屋頂上看見一個灰衣人，一直看著她 |

### 第三章　晴岸

| 項目 | 內容 |
|---|---|

### 為什麼 A 與 B 是同一個問題的兩個答案

**一個無法回答的人，要不要替他決定？**

- A：不能問，就不拿。
- B：不能問，還是拿，努力到最後，失敗。
- 真：不能問，就替他簽。

這是整個故事的主題「替你決定」的最後一次考驗。

## 悲劇的寫法

- 沒有人說「我愛你」。愛用動作講：煮水、問傘、切紅蘿蔔。
- 死亡時沒有音樂。只有雨聲。
- 沒有人在死前發表演說。鷺的遺言只有一句：「你自己看。」
- 反派不被打倒，也不被原諒。他們繼續做他們的事。
- 最痛的事不靠畫面，靠「我本來可以阻止」。鏡頭站在被傷害的人與想阻止的人這一邊。
- 成人內容的每一幕，都要通過 [MATURE.md](MATURE.md) 的三問測試。
