# 成人向內容守則（R18）

> 來源：2026-10-03 使用者更正：從沒說要做全年齡，要做 R18。不是單純色情，而是像《邊緣行者》一樣，用最貼近人類原始行為的描寫，襯托出最真實的樣貌。
> **更正說明**：「全年齡」出現在 [01-game-design.md](../01-game-design.md)（2026-10-02 初版）、根目錄 README、`project.godot` 描述與 NE-1，是當時設計文件的預設假設，不是使用者的要求。劇情重整第一版的參考筆記與 04-story 也沿用了（後者作廢，前者已重寫）。
> 以下標「**待確認**」的是提案，影響美術、發行與分級，確認前不動工。

## 定位

| 項目 | 內容 |
|---|---|
| 分級目標 | 成人向，台灣遊戲軟體分級「限制級」（18+） |
| 一句話 | 成人內容是「人被逼到邊緣時會做什麼」的證據，不是賣點 |
| 與純色情的差別 | 每一幕成人內容都要替故事做事；拿掉之後，我們會少知道這個人的一件事 |

### 三問測試

每一幕露骨的內容，都要能回答「是」：

1. 拿掉這一幕，我們是否少知道這個角色的一件非知道不可的事？
2. 這一幕讓玩家更理解這個人，還是只讓玩家更興奮？（必須是前者）
3. 改成含蓄處理，是否就失去真實？

三個都「是」才寫露骨；任何一個是「否」，改成含蓄或刪掉。

## 從《邊緣行者》看到的

引用字幕裡的對白（我沒有畫面，只能引字幕；分鏡層面的描述來自我對作品的理解，請你指正）：

| 觀察 | 證據 | 對本作的意義 |
|---|---|---|
| 死亡與身體是商品 | 第 1 集開場，醫生推銷「超夢」：「那位邊緣人剛死兩小時　從他的屍體上趁熱收穫來的　這毫無汙染的記憶」 | 本作的復原、殼與錨人也是商品，世界的殘酷是靠交易講出來的 |
| 窮是具體的 | 第 1 集：洗衣機顯示「餘額不足　停止運轉」；「連給洗衣機儲值的錢都不夠了」 | 本作的復原費、巢蛋、價格，要同樣具體 |
| 身體的改造有階級 | 第 1 集：「不要用那些盜版的」「一定要用正版更新」 | 本作的便宜殼與常駐錨人的「平平的」 |
| 成癮是倒數 | 第 10 集：「最後一瓶了」「一旦落到邊緣之外　就無法回頭了」 | 沿用「看得見的代價」（REFERENCE 機制 5） |
| 暴力有後果 | 曼恩的崩潰是整部作品最痛的一段，不是爽快的 | 暴力不奇觀化，打完要有人付代價 |
| 人的原始需要 | 全劇的共同點：愛、慾望、恐懼、飢餓、被需要，在最糟的處境下反而最清楚 | 這是本守則的根 |

## 內容層級

> 整張表是提案。**性的呈現程度是最需要你決定的一項**，因為它影響美術流程、平台與分級。

| 類別 | 本作做法 | 不做 |
|---|---|---|
| **暴力** | 露骨：肢體毀損、燒融、流血、死亡的難看。有後果：打完要看到被打的人是誰 | 以折磨取樂的長鏡頭；把無辜者的死當奇觀 |
| **性與裸體** | 成年角色的裸體、親密與性愛場面，用鏡頭與剪接呈現，等級對標《邊緣行者》。**待確認** | 生殖器官特寫的露骨描寫（A 片等級）。**待確認** |
| **性暴力** | 不作為場面呈現、不當賣點。**待確認：是否允許以最低限度作為既成事實被提及** | 任何呈現 |
| **藥物與成癮** | 直接呈現使用、買賣與戒斷 | 美化 |
| **身體** | 復原者赤裸醒來；義體改造的侵入感；便宜殼的瑕疵 | — |
| **語言** | 粗口與貧民口語 | 為了粗而粗 |
| **壓迫** | 債務、貧窮、身體與感情的買賣，是世界的事實 | — |

### 不討論的底線

1. **未滿 18 歲的角色不出現在任何性或性暗示內容中，也不被裸露或性化。** 包含燈（16 歲）、小薇（12 歲）與凜十到十二歲的回憶。
2. 成人內容不是主線之外的「福利」，也不獨立於劇情之外；沒有純粹的服務性場景。
3. 所有涉及性的場面，雙方都是成年角色。

## 原始行為在這個世界裡的位置

以下是世界觀裡本來就該有的東西，現在不必再迴避。**這些是提案，逐章落點見 [PLOT.md](PLOT.md)。**

| 元素 | 說明 | 為什麼是本作的主題 |
|---|---|---|
| **復原室** | 殼在這裡列印，受錨者赤裸醒來，消毒水與金屬味，頭一件事是吐、是餓 | 每一次重來都是一次出生；身體是商品，不是你的 |
| **復原夜** | 港區的習俗：復原當晚的人想吃、想喝、想被碰，用身體確認自己還活著 | 人在死過一次之後最先想要的，是觸感 |
| **租來的家人** | 常駐錨人之外還有「情感租賃」：窮人把「被某個人記得」當工作賣給孤單的有錢人 | 愛被明碼標價，與「付帳」呼應 |
| **忘川** | 一種藥，讓人把痛苦的記憶忘掉；錨人買來止痛，窮人賣自己的記憶換錢 | 與錨定相反的市場：有人付錢要記得，有人付錢要忘記 |
| **鷺與棠** | 二十年的伴侶。棠不記得鷺了，但她的身體記得：鷺替她洗澡，她閉上眼睛，習慣性地把頭靠過去 | 成人的親密不等於性；記憶用盡之後，剩下的是身體裡的習慣 |
| **凜的欲望** | 她從不欠人，連親密也要付錢。**待確認**：是否在第三章寫一個「付錢的一夜」，對象是夜班的復原館女子，她自己也有一段故事 | 呼應凜的缺陷（接受不了別人付出）；第八章她第一次不付錢地接受，才有重量 |
| **老 K 的身體** | 第五章與第七章，凜替他洗澡、換衣服 | 照顧的角色翻轉；老去的身體不被遮掩 |
| **沈遠的筆記本** | 裡面連身體上的親密都有指示（「不要在她睡著時碰她」） | 他把愛變成程序，這個細節比任何旁白都重 |
| **死亡的難看** | 第八章：溺水，沒有美化，沒有音樂 | 「悲壯」不能靠美化，要靠難看 |

## 對各系統的影響

| 系統 | 影響 | 備註 |
|---|---|---|
| 美術 | 血、傷口、裸體與身體部位的素材；復原室、病房、洗澡場景 | 需要確認生成模型與流程能做到，且素材來源要自己掌握 |
| 內容強度選項 | 提案：設定裡可選「完整／減弱」，減弱時關閉裸體與血 | 兼顧引導、平台審查與玩家舒適度。**待確認** |
| 年齡提示 | 啟動時顯示分級與內容警語；內容警語要指出具體類別 | 引導原則：一句講重點 |
| 現有系統 | 裝甲逐片脫落、終結技、敗北圖鑑原本是「全年齡替代」，保留為玩法回饋，不需拿掉；是否再疊加血與處決見 [01-game-design.md](../01-game-design.md) | 不破壞既有功能 |
| 發行 | 台灣「限制級」標示；Steam 等平台對成人內容有各自的揭露與審查規則，付款機構也有限制 | 我沒有查證各平台現行規定，**動工前要實際確認**，這不是法律意見 |
