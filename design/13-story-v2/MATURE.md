## 定位

| 項目 | 內容 |
|---|---|
| 分級目標 | 成人向，台灣遊戲軟體分級「限制級」（18+）；DLsite 的 18 禁；Steam 的 Adult Only |
| 一句話 | 成人內容是「人被逼到邊緣時會做什麼」的證據，不是賣點 |
| 與純色情的差別 | 每一幕劇情中的成人內容都要替故事做事；拿掉之後，我們會少知道這個人的一件事 |

### 三問測試（劇情中的成人場景）

每一幕露骨的劇情內容，都要能回答「是」：

1. 拿掉這一幕，我們是否少知道這個角色的一件非知道不可的事？
2. 這一幕讓玩家更理解這個人，還是只讓玩家更興奮？（必須是前者）
3. 改成含蓄處理，是否就失去真實？

三個都「是」才寫露骨；任何一個是「否」，改成含蓄或刪掉。畫廊的內容之後另訂規則。

### 不討論的底線

1. **未滿 18 歲的角色不出現在任何性、性暴力或性暗示內容中，也不被裸露或性化，包含背景事實的提及、畫廊、與敵人互動、戰敗 CG。** 包含燈（16 歲）、小薇（12 歲）與凜十二歲的回憶。性暴力的允許範圍只及於成年角色。
2. 所有涉及性的場面，角色都是成年人，**而且外觀也要看得出是成年人**（DLsite 對「看起來未滿 18 歲」有明文限制）。
3. 劇情中的成人場景不獨立於劇情之外，沒有純粹的服務性場景。

## 性暴力的設計：阿梨事件

使用者要它「給玩家迎頭痛擊」，而且「有機會避免」。這兩件事合在一起，是整個遊戲裡最有力的一種敘事：**玩家知道它可能發生，並且有能力阻止。**

### 原則

| 原則 | 說明 |
|---|---|
| 迎頭痛擊來自失去，不來自畫面 | 重量放在「我本來可以阻止」 |
| 從被害者與阻止者的視角 | 鏡頭與演出站在受害者與想阻止的人那一邊，不站在加害者那一邊 |
| 玩家不被獎勵，也不被拉成共犯 | 沒有任何誘因讓玩家想看第二次；不使用與一般親密場面相同的素材或音樂 |
| 一定能避免 | 避免的條件在遊戲裡看得到、做得到，不是隱藏的運氣，**一周目就能避免** |
| 避免要有代價 | 避免的選擇本身有成本，否則不是選擇 |
| 不重複 | 全作最多一次 |
| 僅限成年角色 | 見底線 1 |

### 避免條件

| 步驟 | 內容 |
|---|---|
| 對象 | 阿梨（成年），第一章末登場。之後成為凜的熟人，也是港區裡少數不要凜付錢的人 |
| 預警 | 第一章天亮，凜照例付錢、不讓她欠、轉身離開。若玩家選擇**留下來吃宵夜**（不付錢、接受別人給的），她會說起一個收帳人在跟她要帳，並告訴凜她的住處與暗號（旗標 `knows_ali_address`）。第三章有**第二次機會**：玩家可以主動去她的住處拜訪 |
| 事件 | 第六章廣播站行動進行到一半，通訊裡傳來阿梨的求救。玩家可以放下任務趕去（廣播沒有播完，蘇會失望，真相被延誤），也可以完成廣播 |
| 避免 | 需要**兩個條件**：`knows_ali_address` 與 `answered_call`。兩者皆有，事件不會發生；阿梨在第八章會出現在蘇的船上。只有 `answered_call` 而沒有地址：凜趕到時已經太遲 |
| 未避免 | 事件發生。第八章她不見凜，凜在船上沒有看到她。**主線結局不變**，改變的是凜在第八章的重量 |
| 存檔容錯 | 旗標缺漏或損毀時退回「已避免」（寧可不發生，也不要因為資料損毀讓玩家遇到它） |

玩家選擇「完成廣播」與「趕去救人」，是**真相與一個人**的取捨，與第五章的「錢與真相」同一種結構。

### 為什麼不是凜自己

主角的性暴力會把她變成只能被傷害的人，與「她學會問、學會接受」的弧線衝突。以身邊的人承受，凜承受的是**自己的缺陷造成的後果**，更貼近本作的主題。

## R18 模式

| 項目 | 內容 |
|---|---|
| 開關 | 設定裡可開關；首次啟動時詢問並說明內容類別 |
| 開啟 | 完整內容（露骨層） |
| 關閉 | 完全沒有露骨要素。**劇情稍有不同**：每個成人場景要有自己的替代內容，不是單純刪除 |
| 不受影響 | 收集、解謎、戰鬥、結局、八段重點記憶 |
| 阿梨事件 | 關閉時**不改**，事件仍然發生，但只用基底層**很隱諱地帶過**（使用者決定）。避免條件、後果與結構不變 |
| 實作 | 內容設定檔：每個成人場景準備「基底」與「露骨」兩層，由 R18 模式決定載入哪一層；整個露骨層可在建置時不出貨（審查後的安全閥） |

基底層必須自己就能成立：拿掉露骨層之後，劇情不能缺一塊。這同時是上述「三問」的第三問的實際檢驗。

## 原始行為在這個世界裡的位置

| 元素 | 說明 | 為什麼是本作的主題 |
|---|---|---|
| **復原室** | 殼在這裡列印，受錨者赤裸醒來，消毒水與金屬味，頭一件事是吐、是餓 | 每一次重來都是一次出生；身體是商品，不是你的 |
| **復原夜** | 港區的習俗：復原當晚的人想吃、想喝、想被碰，用身體確認自己還活著 | 人在死過一次之後最先想要的，是觸感 |
| **租來的家人** | 常駐錨人之外還有「情感租賃」：窮人把「被某個人記得」當工作賣給孤單的有錢人 | 愛被明碼標價，與「付帳」呼應 |
| **忘川** | 一種藥，讓人把痛苦的記憶忘掉；錨人買來止痛，窮人賣自己的記憶換錢 | 與錨定相反的市場：有人付錢要記得，有人付錢要忘記 |
| **鷺與棠** | 二十年的伴侶。棠不記得鷺了，但她的身體記得：鷺替她洗澡，她閉上眼睛，習慣性地把頭靠過去 | 成人的親密不等於性；記憶用盡之後，剩下的是身體裡的習慣 |
| **凜的欲望** | 她從不欠人，連親密也要付錢：第一章末「付錢的一夜」，對象是阿梨 | 呼應凜的缺陷；第八章她第一次不付錢地接受（「帶了」），才有重量 |
| **阿梨事件** | 見上方 | 凜的缺陷造成的後果 |
| **老 K 的身體** | 第六章，凜替他洗澡、換衣服 | 照顧的角色翻轉；老去的身體不被遮掩 |
| **沈遠的筆記本** | 裡面連身體上的親密都有指示（「不要在她睡著時碰她」） | 他把愛變成程序，這個細節比任何旁白都重 |
| **死亡的難看** | 第九章：帳房的重播；沒有美化，沒有音樂 | 「悲壯」不能靠美化，要靠難看 |
