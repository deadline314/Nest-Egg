> 來源：2026-10-03 使用者更正：從沒說要做全年齡，要做 R18。不是單純色情，而是像《邊緣行者》一樣，用最貼近人類原始行為的描寫，襯托出最真實的樣貌。

## 定位

| 項目 | 內容 |
|---|---|
| 分級目標 | 成人向，台灣遊戲軟體分級「限制級」（18+）；DLsite 的 18 禁；Steam 的 Adult Only |
| 一句話 | 成人內容是「人被逼到邊緣時會做什麼」的證據，不是賣點 |
| 與純色情的差別 | 每一幕成人內容都要替故事做事；拿掉之後，我們會少知道這個人的一件事 |

### 三問測試

每一幕露骨的內容，都要能回答「是」：

1. 拿掉這一幕，我們是否少知道這個角色的一件非知道不可的事？
2. 這一幕讓玩家更理解這個人，還是只讓玩家更興奮？（必須是前者）
3. 改成含蓄處理，是否就失去真實？

三個都「是」才寫露骨；任何一個是「否」，改成含蓄或刪掉。

### 不討論的底線

1. **未滿 18 歲的角色不出現在任何性、性暴力或性暗示內容中，也不被裸露或性化，包含背景事實的提及。** 包含燈（16 歲）、小薇（12 歲）與凜十到十二歲的回憶。性暴力的允許範圍只及於成年角色。
2. 成人內容不是主線之外的「福利」，也不獨立於劇情之外；沒有純粹的服務性場景，也不做「回想鑑賞」功能。
3. 所有涉及性的場面，角色都是成年人，**而且外觀也要看得出是成年人**（DLsite 對「看起來未成年」有明文限制，見下方）。

## 性暴力的設計

使用者要它「給玩家迎頭痛擊」，而且「有機會避免」。這兩件事合在一起，是整個遊戲裡最有力的一種敘事：**玩家知道它可能發生，並且有能力阻止。**

以下是提案，**待確認**：

### 原則

| 原則 | 說明 |
|---|---|
| 迎頭痛擊來自失去，不來自畫面 | 重量放在「我本來可以阻止」，不放在呈現的細節 |
| 從被害者與阻止者的視角 | 鏡頭與演出站在受害者與想阻止的人那一邊，不站在加害者那一邊 |
| 玩家不被獎勵，也不被拉成共犯 | 沒有任何誘因讓玩家想看第二次；不使用與一般親密場面相同的素材或音樂 |
| 一定能避免 | 避免的條件在遊戲裡看得到、做得到，不是隱藏的運氣 |
| 避免要有代價 | 避免的選擇本身有成本，否則不是選擇 |
| 可略過 | 呈現本身提供「略過」，略過不改變劇情，只改變畫面（見「內容強度」） |
| 不重複 | 全作最多一次，不當成氣氛反覆使用 |
| 僅限成年角色 | 見底線 1 |

### 怎麼避免（提案）：呼應凜的缺陷

凜的缺陷是**接受不了別人付出**。讓失敗與避免都落在這一點上，劇情與機制才是同一件事。

| 步驟 | 內容 |
|---|---|
| 對象 | 第三章「付錢的一夜」的夜班復原館女子（暫名**阿梨**，成年）。她之後在第四、五章成為凜的熟人，供應情報，也是港區裡少數不要凜付錢的人 |
| 預警 | 第三章：凜照例付錢、不讓她欠、轉身離開。若玩家選擇**留下來聽她說**（不付錢、接受一頓宵夜），她會說起一個收帳人在跟她要帳，並告訴凜她的住處與暗號（旗標 `knows_ali_address`）。這是一段可錯過的對話；第五章有**第二次機會**：玩家可以主動去她的住處拜訪，同樣設定旗標 |
| 呼應 | 第五章她再給一條情報：那個人在找她 |
| 事件 | 第六章，廣播站行動之後，收帳人報復。**行動進行到一半，通訊裡傳來阿梨的求救**：玩家可以放下任務趕去（廣播沒有播完，蘇會失望，真相被延誤），也可以完成廣播 |
| 避免 | 需要**兩個條件**：`knows_ali_address`（知道她住哪）與 `answered_call`（通訊響起時放下任務趕去）。兩者皆有，事件不會發生；阿梨在第八章會出現在蘇的船上。只有 `answered_call` 而沒有地址：凜趕到時已經太遲 |
| 未避免 | 事件發生。第七章她不見凜，凜在第八章的船上沒有看到她。**主線結局不變**，改變的是凜在第七章與第八章的重量 |

玩家選擇「完成廣播」與「趕去救人」，是**真相與一個人**的取捨，與第五章的「錢與真相」同一種結構。

### 為什麼不是凜自己

主角的性暴力會把她變成只能被傷害的人，與「她學會問、學會接受」的弧線衝突。以身邊的人承受，凜承受的是**自己的缺陷造成的後果**，更貼近本作的主題。

## 平台

我只讀到搜尋結果摘要，**官方頁面當時無法連線**，以下需要在動工前以 Steamworks 與 DLsite 的現行官方指引逐條核對，這不是法律意見。

| 平台 | 已知 | 對本作的影響 |
|---|---|---|
| **Steam** | 2025-07-16 起，Steam 規則新增：禁止「可能違反付款機構、發卡網路與銀行規範的內容，特別是某些成人向內容」。之後有大量成人遊戲被下架，其中包含描寫性侵、亂倫、折磨與奴役的作品。Valve 沒有給出清楚的細則 | **性暴力的露骨呈現是 Steam 最可能被拒或事後下架的一項。** 建議 Steam 版的性暴力只用演出與事後處理，不呈現行為本身 |
| **DLsite** | 分級有「一般向／R 指定／18 禁」。對露骨的性器官有「修正」（馬賽克）標準，作者與 DLsite 曾因馬賽克標準打過官司。禁止明確以幼兒為對象、或可被合理認為未滿 18 歲的角色的性表現。極端暴力與扭曲的性表現也在限制範圍內 | 露骨層（B）要依其修正規範實作；角色外觀要看得出是成年人；是否收錄性暴力的詳細規定要查官方指引 |
| 兩者共同 | 兩個平台的標準不同，同一份內容在一邊可以、在另一邊可能不行 | 內容必須做成**依平台切換的資料層**（見下） |

### 實作方向：內容設定檔

遵循 CLAUDE.md「新增內容以資料為主」：每個成人場景準備三層，建置時依平台決定出貨哪幾層，玩家也能在設定裡選。

| 層 | 內容 | 預設出現在 |
|---|---|---|
| 基底 | 含蓄：切黑、聲音、事後 | 所有版本（也是「減弱」模式） |
| 露骨 | 完整呈現（程度 B）；DLsite 版依其修正規範處理 | DLsite 版、玩家選擇「完整」 |
| 性暴力呈現 | 行為本身的呈現。**預設只在基底層**，露骨層需另行決定 | 待確認 |

基底層必須自己就能成立：拿掉露骨層之後，劇情不能缺一塊。這同時是上述「三問」的第三問的實際檢驗。

## 原始行為在這個世界裡的位置

| 元素 | 說明 | 為什麼是本作的主題 |
|---|---|---|
| **復原室** | 殼在這裡列印，受錨者赤裸醒來，消毒水與金屬味，頭一件事是吐、是餓 | 每一次重來都是一次出生；身體是商品，不是你的 |
| **復原夜** | 港區的習俗：復原當晚的人想吃、想喝、想被碰，用身體確認自己還活著 | 人在死過一次之後最先想要的，是觸感 |
| **租來的家人** | 常駐錨人之外還有「情感租賃」：窮人把「被某個人記得」當工作賣給孤單的有錢人 | 愛被明碼標價，與「付帳」呼應 |
| **忘川** | 一種藥，讓人把痛苦的記憶忘掉；錨人買來止痛，窮人賣自己的記憶換錢 | 與錨定相反的市場：有人付錢要記得，有人付錢要忘記 |
| **鷺與棠** | 二十年的伴侶。棠不記得鷺了，但她的身體記得：鷺替她洗澡，她閉上眼睛，習慣性地把頭靠過去 | 成人的親密不等於性；記憶用盡之後，剩下的是身體裡的習慣 |
| **凜的欲望** | 她從不欠人，連親密也要付錢：第三章「付錢的一夜」，對象是阿梨 | 呼應凜的缺陷；第八章她第一次不付錢地接受，才有重量 |
| **阿梨的事件** | 見上方「性暴力的設計」 | 凜的缺陷造成的後果 |
| **老 K 的身體** | 第五章與第七章，凜替他洗澡、換衣服 | 照顧的角色翻轉；老去的身體不被遮掩 |
| **沈遠的筆記本** | 裡面連身體上的親密都有指示（「不要在她睡著時碰她」） | 他把愛變成程序，這個細節比任何旁白都重 |
| **死亡的難看** | 第八章：溺水，沒有美化，沒有音樂 | 「悲壯」不能靠美化，要靠難看 |

## 對各系統的影響

| 系統 | 影響 | 備註 |
|---|---|---|
