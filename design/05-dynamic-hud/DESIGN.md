# 動態玩家介面（Dynamic Player HUD）

> 來源：2026-10-03 使用者提出「子彈、血量、護盾的 UI 希望做成 dynamic player UI，參考業界最佳實例，做一版好看一點的」。

## 業界參考與取用的原則

| 作品 | 做法 | 取用 |
|---|---|---|
| Dead Space | 血量畫在角色背上、彈藥投影在槍上，畫面角落沒有 HUD | 資訊跟著角色走，視線不用離開戰場 |
| Halo Infinite、Destiny 2 | 數值變動時才完整顯示，閒置自動淡出 | 閒置淡出、變動時彈出 |
| Returnal、Ratchet & Clank | 彈藥與冷卻顯示在準星周圍 | 彈藥放在準星旁，射擊時一定看得到 |
| Cyberpunk 2077 | 斜切分段的血條、受傷時故障閃爍 | 斜切格子、霓虹描邊、受傷故障抖動 |
| 格鬥遊戲、魂系 | 扣血時殘影條延遲縮短 | 損失的格子先變白再碎掉，看得出剛剛扣了多少 |

共通原則：**平常不擋畫面，需要時一定看得到**。低血量、護盾被打破這種危險狀態要一直顯示，不能淡出。

## 版面

1. **生命與護盾標籤（跟著凜）**：浮在凜頭部的背側（面向的反方向），會稍微延遲跟隨，像投影出來的全像標籤。上排是斜切的生命格，下排是護盾能量條。
2. **彈藥環（跟著準星）**：準星右側的弧形分段計量，旁邊顯示剩餘發數。主武器彈藥無限，所以不顯示彈藥環。
3. 原本左上角的生命格與護盾條移除；殘機、計時、武器欄、機甲耐久、頭目血條維持不變。

## 動態規則

| 情況 | 生命與護盾標籤 | 彈藥環 |
|---|---|---|
| 閒置（滿血、護盾滿、沒在格擋） | 約 2.5 秒後淡到幾乎透明（保留一點輪廓） | 只有主武器時不顯示 |
| 受傷 | 立刻完整顯示並抖動、紅色閃光，損失的格子先變白再碎掉 | — |
| 補血 | 新的格子由左到右亮起 | — |
| 格擋中、護盾回復中 | 完整顯示，護盾條即時增減 | — |
| 完美格擋 | 護盾條白色閃光 | — |
| 破防 | 護盾條變紅、閃爍並顯示「BREAK」，直到可以再次格擋 | — |
| 低血量（剩 1/3 以下） | 常駐顯示，生命格隨心跳節奏紅色脈動 | — |
| 射擊 | — | 每發扣一格，數字跳動 |
| 低彈藥（剩 25% 以下） | — | 變黃並脈動；剩最後幾發變紅 |
| 換武器 | — | 準星旁短暫顯示武器代號 |
| 死亡、劇情過場 | 隱藏 | 隱藏 |

## 設定

- 設定畫面新增「顯示」分頁，可切換「HUD 自動隱藏」。關閉後生命與護盾標籤一律完整顯示（給不習慣動態 HUD 的玩家）。
