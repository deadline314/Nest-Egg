## 演出原則（避免大量文本變無聊）

| 手法 | 用在哪 | 備註 |
|---|---|---|
| 可玩的回憶 | 洪水夜逃亡、NEST 十二歲、航的夢 | 短（2～4 分鐘）、規則與主線不同；對應《邊緣行者》的「超夢」，我們的版本是「回放」 |
| 動畫過場 | 章首、頭目登場、章末 | 沿用 NE-38 過場動畫系統；每段不超過 6 句 |
| 不暫停的通訊 | 關卡中 | 1～2 句，兼具提示；角色吵架、閒聊都放這裡 |
| 場景敘事 | 道具、廣告、牆上字跡 | 暗線全放這層，玩家不看也不影響主線 |
| 世界回應 | 雨量、霓虹、廣告詞隨劇情變化 | 雨是晴的情緒，天氣本身就是演出 |
| 每章一個安靜場景 | 沒有戰鬥與提示，只有人 | 沿用 BIBLE.md 製作原則 |

文本分三層，讓文字量大也不累：**主線**（必看、短）→ **道具與通訊**（順手看）→ **檔案與回放**（想知道才看）。
